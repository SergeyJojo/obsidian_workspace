
🧙🏾‍♂️ Конечно! Сейчас покажу тебе **идиоматичный способ работы с PostgreSQL в Go**. Для этого чаще всего используется пакет:

```
github.com/lib/pq — стандартный драйвер PostgreSQL
или
github.com/jackc/pgx — продвинутый драйвер с расширенными возможностями
```

Я покажу на основе `database/sql` + `lib/pq`, потому что он встроен в стандартную библиотеку, и далее предложу улучшение с `pgx`.

## 📦 Основные шаги и методы работы с PostgreSQL в Go

---

### 🔹 Подключение к базе

```go
import (
    "database/sql"
    _ "github.com/lib/pq"
)

func main() {
    connStr := "user=postgres password=secret dbname=mydb sslmode=disable"
    db, err := sql.Open("postgres", connStr)
    if err != nil {
        log.Fatal(err)
    }
    defer db.Close()
}
```

---

### 🔹 `db.QueryRow` — один результат (например, SELECT с WHERE)

```go
var name string
err := db.QueryRow("SELECT name FROM users WHERE id = $1", 1).Scan(&name)
```

---

### 🔹 `db.Query` — много результатов

```go
rows, err := db.Query("SELECT id, name FROM users")
defer rows.Close()

for rows.Next() {
    var id int
    var name string
    err := rows.Scan(&id, &name)
}
```

---

### 🔹 `db.Exec` — INSERT, UPDATE, DELETE

```go
res, err := db.Exec("UPDATE users SET active = $1 WHERE id = $2", true, 1)
rowsAffected, _ := res.RowsAffected()
```

---

### 🔹 Транзакции

```go
tx, err := db.Begin()
if err != nil {
    log.Fatal(err)
}
_, err = tx.Exec("UPDATE users SET balance = balance - 100 WHERE id = $1", 1)
if err != nil {
    tx.Rollback()
    return
}
tx.Commit()
```

---

### 🔹 Подготовленные запросы (prepared statements)

```go
stmt, err := db.Prepare("INSERT INTO users(name, age) VALUES($1, $2)")
defer stmt.Close()
_, err = stmt.Exec("Alice", 30)
```

## 💡 А теперь — idiomatic способ через `pgx`

`pgx` можно использовать как альтернативу:

```go
import (
    "github.com/jackc/pgx/v5"
    "context"
)

func main() {
    conn, err := pgx.Connect(context.Background(), "postgres://user:pass@localhost:5432/dbname")
    defer conn.Close(context.Background())

    var name string
    err = conn.QueryRow(context.Background(), "SELECT name FROM users WHERE id=$1", 1).Scan(&name)
}
```
