## **1. Глубокая работа с распределёнными графовыми структурами**

### **1.1. Алгоритмы для графов на больших данных**

#### **Pagerank**

- Используется для ранжирования узлов в графе.
- **Итеративный процесс:**
    
    1. Узлы передают "вес" своим соседям.
    2. Итерации продолжаются, пока веса не стабилизируются.
    
    - Пример: Google использует Pagerank для ранжирования страниц.

#### **Connected Components (Связные компоненты):**

- Позволяет находить все компоненты в огромном графе.
- Используется в социальных сетях (например, "найти группы пользователей").

#### **Distributed Graph Processing Frameworks:**

- Apache Giraph, Pregel (Google), Neo4j.

---

### **1.2. Consistent Hashing для графов**

- Когда распределяешь графовые данные между узлами, важно минимизировать перенос узлов при добавлении/удалении серверов.
- **Идея:**
    - Графовые узлы и рёбра распределяются через Consistent Hashing.

## **2. Оптимизация вычислений на уровне процессоров**

### **2.1. SIMD (Single Instruction Multiple Data)**

- Современные процессоры могут обрабатывать сразу несколько элементов данных за один такт.
- Используй библиотеки, такие как **AVX-512**, для работы с массивами чисел.
- Пример: Оптимизация сложения двух массивов.
    
    ```c
    __m512 a = _mm512_load_ps(array1);
    __m512 b = _mm512_load_ps(array2);
    __m512 result = _mm512_add_ps(a, b);
    ```
    

---

### **2.2. NUMA (Non-Uniform Memory Access)**

- В современных серверных архитектурах память организована в регионы, привязанные к процессорам.
- **NUMA-aware программы:**
    - Понимают, где физически расположена память.
    - Используют "локальную" память, чтобы минимизировать задержки.

## **5. Распределённые вычисления на уровне гипермасштабов**

### **5.1. Алгоритмы распределённой сортировки**

#### **External Sort:**

- Данные, которые не помещаются в память, сортируются блоками на диске.
- Этапы:
    1. **Split Phase:** Данные разбиваются на блоки.
    2. **Merge Phase:** Блоки сливаются в отсортированном порядке.

---

### **5.2. MapReduce в деталях**

1. **Map:**
    - Разделяет задачу на части.
    - Пример: Подсчёт частоты слов в текстах.
2. **Reduce:**
    - Собирает результаты.

Пример MapReduce для подсчёта слов:

```plaintext
Input:
   "cat dog", "dog cat"

Map:
   ("cat", 1), ("dog", 1), ("dog", 1), ("cat", 1)

Reduce:
   ("cat", 2), ("dog", 2)
```

## **7. Самые сложные вопросы и как отвечать**

### **7.1. Как вы решите проблему "горячих точек" в распределённой базе данных?**

#### Ответ:

1. Использую **Consistent Hashing** с виртуальными узлами.
2. Реплицирую данные по нескольким узлам.

### **7.2. Как проектировать систему, устойчивую к DDoS-атакам?**

#### Ответ:

1. Включаю Rate Limiting через API Gateway.
2. Использую WAF (Web Application Firewall).
3. Агрегирую трафик через CDN.
