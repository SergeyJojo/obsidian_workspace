## 🟩 **Задача 3 — [215. Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array)**

### 🔹 Твоя формулировка: «Максимальные элементы в массиве»

---

### 📋 Условие

Дан массив целых чисел `nums` и целое число `k`.  
Нужно вернуть **k наибольших элементов** (в любом порядке).

---

### 📌 Пример:

```go
nums = [100, 50, 0, 150, 100, 0, -30, 70]
k = 3

// Один из допустимых ответов:
[100, 150, 70]
```

---

## 🧠 Идея алгоритма

Есть несколько подходов:

### 🔹 Подход 1: Быстрый — сортировка

1. Отсортировать массив по убыванию
    
2. Взять первые `k` элементов
    

**Сложность:**

- Время: `O(n log n)`
    
- Память: `O(n)` — если копируем массив
    

---

### 🔹 Подход 2: Более эффективный — min-heap размером `k`

1. Поддерживаем кучу из `k` элементов
    
2. Если следующий элемент больше минимума — вытесняем
    

**Сложность:**

- Время: `O(n log k)`
    
- Память: `O(k)`
    

Для Go — используем `container/heap`

---

## ✅ Реализация на Go (heap)

```go
package main

import (
	"container/heap"
	"fmt"
)

// Мини-куча
type MinHeap []int

func (h MinHeap) Len() int            { return len(h) }
func (h MinHeap) Less(i, j int) bool  { return h[i] < h[j] }
func (h MinHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x any)         { *h = append(*h, x.(int)) }
func (h *MinHeap) Pop() any {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

func topK(nums []int, k int) []int {
	h := &MinHeap{}
	heap.Init(h)

	for _, num := range nums {
		if h.Len() < k {
			heap.Push(h, num)
		} else if num > (*h)[0] {
			heap.Pop(h)
			heap.Push(h, num)
		}
	}

	// Извлечём k наибольших (в любом порядке)
	result := make([]int, h.Len())
	for i := 0; h.Len() > 0; i++ {
		result[i] = heap.Pop(h).(int)
	}

	return result
}

func main() {
	nums := []int{100, 50, 0, 150, 100, 0, -30, 70}
	k := 3
	fmt.Println("Top k:", topK(nums, k)) // [100 150 70]
}
```

---

## 📈 Сложность

- **Время**: `O(n log k)`
    
- **Память**: `O(k)`
    

---

## 🧪 Edge Cases:

- `k == len(nums)` → возвращаем весь массив отсортированный
    
- Повторы допустимы: `[1, 2, 2, 2, 3], k=2 → [2, 3]`
    
- Если `k > len(nums)` — нужно валидировать вход
