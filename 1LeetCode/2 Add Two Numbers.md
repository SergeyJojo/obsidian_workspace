## 🧩 Условие (LeetCode #2 — Add Two Numbers)

> Даны два непустых связанных списка, представляющих два неотрицательных целых числа. Цифры хранятся в **обратном порядке**, и каждая их узел содержит **одну цифру**.  
> Нужно сложить два числа и вернуть результат в виде связного списка.

### Пример

```txt
Input:  l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: 342 + 465 = 807
```

---

## 📚 Подход

1. Мы складываем цифры поразрядно: `2 + 5`, `4 + 6`, `3 + 4`.
    
2. Если сумма >= 10 — сохраняем `перенос (carry)`.
    
3. Создаём новый список, в который кладём результат посимвольно.
    

---

## ✅ Решение на Go

```go
type ListNode struct {
    Val  int
    Next *ListNode
}

func addTwoNumbers(l1 *ListNode, l2 *ListNode) *ListNode {
    dummyHead := &ListNode{} // фейковая голова для удобства сборки списка
    current := dummyHead
    carry := 0

    // Пока есть хотя бы один узел или остался перенос
    for l1 != nil || l2 != nil || carry != 0 {
        var x, y int

        if l1 != nil {
            x = l1.Val
            l1 = l1.Next
        }
        if l2 != nil {
            y = l2.Val
            l2 = l2.Next
        }

        sum := x + y + carry
        carry = sum / 10         // 1 если >= 10
        current.Next = &ListNode{Val: sum % 10}
        current = current.Next   // переходим к следующему узлу
    }

    return dummyHead.Next
}
```

---

## 🧠 Пояснение

|Этап|Что происходит|
|---|---|
|`dummyHead`|Создаём фейковую "голову", чтобы проще собирать ответ|
|`carry`|Храним перенос при сложении (если 7 + 5 = 12 → carry = 1)|
|`for l1 != nil||
|`x`, `y`|Значения текущих узлов. Если `nil` — считаем 0.|
|`sum % 10`|Число, которое пойдёт в новый узел|
|`carry = sum / 10`|Перенос к следующему разряду|

---

## 🔍 Сложность

- **Время**: `O(max(N, M))` — где N и M — длины списков
    
- **Память**: `O(max(N, M))` — новый список
