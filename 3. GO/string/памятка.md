### **Памятка: Основные методы пакета `strings` в Go**

#### **1. Поиск и проверки**
```go
strings.Contains("hello", "ell")  // true - проверка подстроки
strings.HasPrefix("file.txt", "file")  // true - проверка начала
strings.HasSuffix("image.png", ".png") // true - проверка конца
strings.Count("ababa", "a")  // 3 - подсчёт вхождений
strings.Index("hello", "l")  // 2 - индекс первого вхождения
strings.LastIndex("hello", "l")  // 3 - индекс последнего вхождения
```

#### **2. Изменение строк**
```go
strings.ToLower("HELLO")  // "hello" - в нижний регистр
strings.ToUpper("hello")  // "HELLO" - в верхний регистр
strings.Title("hello world")  // "Hello World" - заглавные буквы
strings.Trim(" hello ", " ")  // "hello" - обрезка с обеих сторон
strings.TrimLeft("!!hello!!", "!")  // "hello!!" - обрезка слева
strings.TrimRight("!!hello!!", "!")  // "!!hello" - обрезка справа
```

#### **3. Разделение и соединение**
```go
strings.Split("a,b,c", ",")  // ["a", "b", "c"] - разделение
strings.Join([]string{"a", "b"}, "-")  // "a-b" - соединение
strings.Fields("a b  c")  // ["a", "b", "c"] - разделение по пробелам
```

#### **4. Замена**
```go
strings.Replace("oink oink", "k", "ky", 2)  // "oinky oinky" - замена
strings.ReplaceAll("oink oink", "oink", "moo")  // "moo moo" - полная замена
```

#### **5. Сравнение**
```go
strings.Compare("a", "b")  // -1 (a < b), 0 (a == b), 1 (a > b)
strings.EqualFold("Go", "go")  // true - сравнение без учёта регистра
```

#### **6. Повтор и работа с символами**
```go
strings.Repeat("na", 3)  // "nanana" - повторение строки
strings.Map(unicode.ToUpper, "hello")  // "HELLO" - применение функции к символам
```

#### **7. Буферизация (strings.Builder)**
```go
var b strings.Builder
b.WriteString("hello")
b.WriteByte(' ')
b.WriteString("world")
result := b.String()  // "hello world"
```
