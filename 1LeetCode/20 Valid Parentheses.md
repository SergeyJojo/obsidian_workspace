## ✅ 4. **Valid Parentheses** (LeetCode №20)

**Уровень:** Easy

---

### 🧾 Условие:

Дана строка `s`, содержащая только символы `'('`, `')'`, `'{'`, `'}'`, `'['`, `']'`.  
Проверь, является ли строка **валидной**:

- Каждая открывающая скобка должна быть закрыта скобкой того же типа.
    
- Скобки должны закрываться **в правильном порядке**.
    

---

### 📌 Примеры:

```text
Input: "()[]{}"      → Output: true
Input: "([)]"        → Output: false
Input: "{[]}"        → Output: true
```

---

## 🧠 Идея: Стек

- Когда видим **открывающую скобку** — кладём в стек ожидаемую закрывающую.
    
- Когда видим **закрывающую** — проверяем, совпадает ли она с верхушкой стека.
    
- В конце стек должен быть **пустым**.
    

---

## ✅ Go-реализация:

```go
func isValid(s string) bool {
    stack := []rune{}

    pairs := map[rune]rune{
        ')': '(',
        ']': '[',
        '}': '{',
    }

    for _, ch := range s {
        if ch == '(' || ch == '[' || ch == '{' {
            stack = append(stack, ch)
        } else {
            if len(stack) == 0 || stack[len(stack)-1] != pairs[ch] {
                return false
            }
            stack = stack[:len(stack)-1] // pop
        }
    }

    return len(stack) == 0
}
```

---

## 📈 Сложность:

- **Время:** `O(n)` — один проход по строке
    
- **Память:** `O(n)` — стек в худшем случае (все открывающие)
    

---

## 🧪 Почему работает:

- Скобки проверяются по **принципу послед-in — первый-out**, как у стека.
    
- Если порядок или типы нарушены — стек либо пуст, либо не совпадает верхушка.
