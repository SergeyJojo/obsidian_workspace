
### **Ответы на вопросы по Linux, Go, Kubernetes и системному администрированию**  

---

### **1. Какими способами можно посмотреть файлы, которые были открыты процессом?**  
**Ответ:**  
- `lsof -p <PID>` — список всех открытых файлов процессом.  
- `ls -l /proc/<PID>/fd/` — симлинки на открытые файлы в `/proc`.  
- `strace -e open,openat <command>` — логирование системных вызовов `open`.  

---

### **2. Как определить, почему тормозит приложение, если это бинарник без логов?**  
**Ответ:**  
- **`strace -c <command>`** — профилирование системных вызовов.  
- **`perf top`** — анализ потребления CPU.  
- **`htop`** — просмотр нагрузки на ядра.  
- **`vmstat 1`** — мониторинг нагрузки на память и CPU.  
- **`gdb`** — отладка бинарника (если есть символы).

### **3. Как преобразовать строку в число в Go?**  
**Ответ:**  
```go
import "strconv"

s := "42"
num, err := strconv.Atoi(s)  // string -> int
floatNum, err := strconv.ParseFloat("3.14", 64)  // string -> float64
```

### **4. Для чего `defer`?**  
**Ответ:**  
`defer` откладывает выполнение функции до завершения текущей функции.  
**Пример:**  
```go
func readFile() {
    file, _ := os.Open("file.txt")
    defer file.Close()  // Закроет файл при выходе из функции
    // ...
}
```

### **5. Для чего `select`?**  
**Ответ:**  
`select` ожидает выполнения одного из операций с каналами:  
```go
select {
case msg := <-ch1:
    fmt.Println(msg)
case <-time.After(1 * time.Second):
    fmt.Println("Timeout")
}
```

### **6. Значение `LoadAverage` в `top` = 1.5 15. Что это значит?**  
**Ответ:**  
Средняя нагрузка за:  
- **1 минуту** = 1.5,  
- **5 минут** = (не указано),  
- **15 минут** = 15.  
**Интерпретация:**  
- `1.5` на 4-ядерном CPU — норма (25% загрузки).  
- `15` — перегрузка (если ядер меньше 15).

### **7. Чем софт-линк отличается от хард-линка?**  
**Ответ:**  
| **Софт-линк (symlink)** | **Хард-линк** |  
|-------------------------|---------------|  
| Ссылка на имя файла | Ссылка на inode |  
| Работает между ФС | Только в одной ФС |  
| Удаляется, если оригинал удалён | Сохраняется, пока есть хард-линки |

### **8. Потребляет ли память зомби-процесс?**  
**Ответ:**  
**Нет.** Зомби (Zombie) — это запись в таблице процессов, которая не занимает память, но блокирует PID.

### **9. CPU Steal time = 10. Что это значит?**  
**Ответ:**  
Виртуальная машина **10% времени ждала** CPU у гипервизора (например, из-за перегрузки хоста).

### **11. Сколько минимальных узлов нужно, чтобы поднять кластер Kubernetes?**  
**Ответ:**  
- **1 узел** (All-in-one, например, minikube).  
- **Production:** 3 master + N worker (для отказоустойчивости).

### **12. Namespace висит в состоянии Terminating уже сутки. Причины?**  
**Ответ:**  
- Зависли **Finalizers** (например, `kubernetes`).  
- Ресурсы не удаляются (CRD, PVC).  
**Решение:**  
```bash
kubectl get namespace <name> -o json | jq '.spec.finalizers = []' | kubectl replace --raw /api/v1/namespaces/<name>/finalize -f -
```

### **13. Что такое глобальная переменная в Go?**  
**Ответ:**  
Переменная, объявленная **вне функций** (доступна во всех файлах пакета).  
```go
var GlobalVar = 42  // Глобальная
func main() {
    fmt.Println(GlobalVar)
}
```

### **14. Чем метод отличается от функции?**  
**Ответ:**  
- **Метод** привязан к типу:  
  ```go
  func (u User) GetName() string { return u.Name }
  ```  
- **Функция** независима:  
  ```go
  func GetName(u User) string { return u.Name }
  ```

### **15. Можно ли на Go писать драйверы для ядра Linux?**  
**Ответ:**  
**Нет.** Драйверы пишутся на **C** (Go не имеет низкоуровневого доступа к ядру).

### **16. Расшифровка аббревиатур:**  
- **GVK** — Group Version Kind (Kubernetes API-ресурсы).  
- **CFQ** — Completely Fair Queuing (алгоритм планирования I/O в Linux).  
- **MTTR** — Mean Time To Repair (среднее время восстановления).  
- **MTU** — Maximum Transmission Unit (макс. размер пакета, например, 1500 байт для Ethernet).
