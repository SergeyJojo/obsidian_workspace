# 1️⃣ Variadics (переменное количество аргументов)

Variadic-функция — это функция, которая может принимать **нефиксированное количество аргументов**. В PHP это реализуется с помощью `...` перед последним параметром.

### Синтаксис

```php
function sum(...$numbers) {
    $total = 0;
    foreach ($numbers as $n) {
        $total += $n;
    }
    return $total;
}

echo sum(1, 2, 3, 4); // 10
```

**Особенности:**

- `...$numbers` всегда собирается в **массив**.
    
- Variadic параметр **должен быть последним** в списке аргументов:
    

```php
function test($prefix, ...$items) { }
```

### Типизация

Можно типизировать элементы:

```php
function sumInts(int ...$ints): int {
    return array_sum($ints);
}
```

- Попытка передать не-int вызовет TypeError.
    

---

### Когда полезно

1. **Функции с непредсказуемым числом аргументов**:
    

```php
log('info', 'message 1', 'message 2', 'message 3');
```

2. **Обёртки над массивными функциями**:
    

```php
function multiply(int ...$nums): int {
    return array_product($nums);
}
```

# 2️⃣ Argument unpacking (распаковка массивов/iterables)

PHP позволяет **распаковывать массив или Traversable** в аргументы функции с помощью `...` при вызове.

### Пример

```php
function greet($a, $b, $c) {
    echo "$a, $b, $c\n";
}

$args = ['Привет', 'как дела', 'Сергей?'];

greet(...$args); // Привет, как дела, Сергей?
```

**Особенности:**

- Массив должен иметь **ключи, начинающиеся с 0** или быть последовательным индексированным массивом.
    
- Работает также с **iterable**, включая Generator:
    

```php
function sum($a, $b, $c) {
    return $a + $b + $c;
}

function gen() {
    yield 1;
    yield 2;
    yield 3;
}

echo sum(...gen()); // 6
```

---

### Смешивание variadics и unpacking

- Variadic собирает аргументы в массив.
    
- Unpacking распаковывает массив в отдельные аргументы.
    

```php
function add(...$nums) {
    return array_sum($nums);
}

$arr = [1, 2, 3];
echo add(...$arr); // 6
```

- Разница в том, что **variadic создаёт массив внутри функции**, а **unpacking превращает массив/iterable в отдельные аргументы при вызове**.

# 3️⃣ Расширенные нюансы

1. **Unpacking с ключами**:
    

```php
$arr = ['a' => 1, 'b' => 2, 'c' => 3];
foo(...$arr); 
```

- В PHP >= 8.1 ключи **игнорируются**, используются только значения.
    
- В некоторых случаях ключи могут вызвать ошибку, если ключи не-нумерические для numeric-indexed parameters.
    

2. **Unpacking с литералами и выражениями**:
    

```php
function foo($a, $b, $c) { }

foo(...[1, 2, 3]); // норм
foo(...range(1, 3)); // тоже норм
```

3. **Variadics + другие параметры**:
    

```php
function f($first, ...$rest) { }
f(1, 2, 3); // $first = 1, $rest = [2,3]
```

4. **Type variance**:
    

```php
function test(int ...$nums) {}
test(...[1,2,3]); // OK
test(...[1, '2', 3]); // TypeError
```

---

# 4️⃣ На практике

- **Variadics** полезны для **логирования, математических функций, обёрток**.
    
- **Unpacking** удобен для **динамического вызова функций**, например, когда аргументы приходят из массива или генератора.
    

**Пример реального использования:**

```php
function sendEmails(string ...$emails) {
    foreach ($emails as $email) {
        mail($email, "Subject", "Body");
    }
}

$users = ['a@example.com', 'b@example.com'];
sendEmails(...$users);
```

---

# 5️⃣ Чего остерегаться

1. Передавать очень большие массивы через unpacking может быть чуть медленнее, чем прямой цикл.
    
2. Variadic функции создают **внутренний массив** — если функция часто вызывается в tight loop, это стоит учитывать.
    
3. Смешивание типов требует внимательности: `int ...$nums` + unpacking из mixed массива → TypeError.
