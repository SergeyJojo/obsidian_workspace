### 12. **Запрос с `CASE` для динамического изменения значений**

**Пример: Применить скидку в зависимости от общего объёма покупок клиента. Если клиент потратил больше 50000, скидка 10%, если больше 100000 — скидка 20%. Если меньше — скидки нет:**

```sql
SELECT customer_id, total_spent,
       CASE
           WHEN total_spent > 100000 THEN total_spent * 0.80
           WHEN total_spent > 50000 THEN total_spent * 0.90
           ELSE total_spent
       END AS discounted_amount
FROM customer_spending;
```

Здесь:

- `CASE` используется для расчёта скидки, основываясь на сумме покупок.
- Это типичный случай, когда в запросе применяются различные условия для динамического изменения значения.

### 13. **Запрос с использованием агрегатных функций в подзапросе**

**Пример: Получить сотрудников, чья зарплата выше средней по всей компании, и отобразить среднюю зарплату в их отделах:**

```sql
SELECT e.first_name, e.last_name, e.salary, e.department_id,
       (SELECT AVG(salary) FROM employees WHERE department_id = e.department_id) AS department_avg_salary
FROM employees e
WHERE e.salary > (SELECT AVG(salary) FROM employees);
```

Здесь:

- Внешний запрос ищет сотрудников с зарплатой выше средней по компании.
- Подзапрос в `SELECT` вычисляет среднюю зарплату в их отделах.

### 14. **Использование `JOIN` с функцией `COALESCE` для замены NULL значений**

**Пример: Получить список заказов и их оплату, при этом если оплата не была произведена (NULL), вывести "Не оплачено":**

```sql
SELECT o.order_id, COALESCE(p.payment_amount, 'Не оплачено') AS payment_status
FROM orders o
LEFT JOIN payments p ON o.order_id = p.order_id;
```

Здесь:

- Используем `LEFT JOIN`, чтобы отобразить все заказы, даже если они не оплачены.
- Функция `COALESCE` заменяет `NULL` на строку "Не оплачено".

### 15. **Запрос с использованием `ROW_NUMBER` для нахождения первых N записей в каждой группе**

**Пример: Получить 3 самых дорогих товара в каждом отделе:**

```sql
WITH RankedProducts AS (
    SELECT product_name, price, department_id,
           ROW_NUMBER() OVER (PARTITION BY department_id ORDER BY price DESC) AS rank
    FROM products
)
SELECT product_name, price, department_id
FROM RankedProducts
WHERE rank <= 3;
```

Здесь:

- `ROW_NUMBER()` присваивает уникальный номер каждой строке в группе (по отделу), начиная с 1 для самой дорогой позиции.
- После этого мы фильтруем те товары, у которых номер позиции меньше или равен 3, чтобы получить топ-3 самых дорогих товара в каждом отделе.

### 16. **Запрос с использованием `UNION` для объединения данных из разных источников**

**Пример: Получить список всех клиентов, которые делали заказы в 2024 году, или покупали товары в 2023 году (объединение двух разных источников данных):**

```sql
SELECT customer_id, customer_name, 'Order' AS source
FROM orders
WHERE YEAR(order_date) = 2024

UNION

SELECT customer_id, customer_name, 'Purchase' AS source
FROM purchases
WHERE YEAR(purchase_date) = 2023;
```

Здесь:

- Используем `UNION` для объединения данных из двух разных таблиц.
- В каждой из таблиц добавляется дополнительная колонка `source`, чтобы указать источник данных.

### 17. **Использование `INTERSECT` для нахождения общих клиентов между двумя списками**

**Пример: Найти клиентов, которые сделали заказы в 2024 году и оставили отзывы в 2024 году:**

```sql
SELECT customer_id
FROM orders
WHERE YEAR(order_date) = 2024

INTERSECT

SELECT customer_id

WHERE YEAR(review_date) = 2024;
```

Здесь:

- `INTERSECT` находит общие строки между двумя подзапросами (в данном случае, общие клиенты).
- Это используется, когда нужно найти пересечение данных.

### 18. **Запрос с `NOT EXISTS` для исключения определённых данных**

**Пример: Получить список клиентов, которые не делали заказов в последние 6 месяцев:**

```sql
SELECT c.customer_id, c.customer_name
FROM customers c
WHERE NOT EXISTS (
    SELECT 1
    FROM orders o
    WHERE o.customer_id = c.customer_id
    AND o.order_date > DATE_SUB(CURRENT_DATE, INTERVAL 6 MONTH)
);
```

Здесь:

- `NOT EXISTS` исключает клиентов, у которых есть заказ за последние 6 месяцев.
- Мы используем подзапрос, чтобы проверить наличие заказов за этот период.

### 19. **Запрос с `GROUP BY` и вычислением суммарных данных по нескольким столбцам**

**Пример: Получить общее количество заказов и общую сумму покупок для каждого клиента в 2024 году:**

```sql
SELECT customer_id, COUNT(order_id) AS total_orders, SUM(order_amount) AS total_spent
FROM orders
WHERE YEAR(order_date) = 2024
GROUP BY customer_id;
```

Здесь:

- Используем `COUNT()` и `SUM()` для вычисления общего количества заказов и общей суммы для каждого клиента за 2024 год.
- Группируем по `customer_id` для получения данных по каждому клиенту.

### 20. **Запрос с оконной функцией для вычисления скользящей суммы (Running Total)**

**Пример: Вычислить накопленную сумму заказов для каждого клиента по времени:**

```sql
SELECT customer_id, order_date, order_amount,
       SUM(order_amount) OVER (PARTITION BY customer_id ORDER BY order_date) AS running_total
FROM orders;
```

Здесь:

- `SUM()` в оконной функции используется для вычисления накопленной суммы по заказам каждого клиента.
- `PARTITION BY` разделяет данные по клиентам, а `ORDER BY` сортирует их по дате заказа.
