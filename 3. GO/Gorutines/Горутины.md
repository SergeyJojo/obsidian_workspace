Структура горутины

В языке программирования Go структура `g` представляет собой внутреннюю сущность, описывающую горутину — лёгкий поток выполнения. Понимание полей этой структуры важно для глубокого анализа работы планировщика Go и управления горутинами. Ниже приведено описание основных полей структуры `g`:

- **`stack`**: Определяет границы стека горутины, включая начальный и конечный адреса.
    
- **`stackguard0` и `stackguard1`**: Используются для защиты стека от переполнения. Если указатель стека достигает значения `stackguard0`, происходит проверка на переполнение.
    
- **`_panic`**: Указывает на связанный список структур `_panic`, представляющих отложенные вызовы `panic` в текущей горутине.
    
- **`_defer`**: Указывает на связанный список отложенных вызовов `defer`, которые должны быть выполнены при выходе из функции.
    
- **`m`**: Ссылка на структуру `m`, представляющую системный поток (OS thread), на котором выполняется горутина.
    
- **`sched`**: Сохраняет состояние горутины при планировании, включая регистры и указатели стека.
    
- **`syscallsp`, `syscallpc` и `stktopsp`**: Используются для сохранения состояния стека и указателей при выполнении системных вызовов.
    
- **`param`**: Указатель на данные, передаваемые между горутинами или планировщиком.
    
- **`atomicstatus`**: Хранит текущее состояние горутины в виде атомарного значения, отражая её статус (например, выполняется, ожидает, завершена).
    
- **`stackLock`**: Мьютекс для защиты операций со стеком горутины.
    
- **`goid`**: Уникальный идентификатор горутины.
    
- **`schedlink`**: Используется для связывания горутин в очередях планировщика.
    
- **`waitsince`**: Временная метка, указывающая, с какого момента горутина находится в состоянии ожидания.
    
- **`waitreason`**: Причина, по которой горутина находится в состоянии ожидания.
    
- **`preempt`**: Флаг, указывающий, что горутина должна быть прервана для выполнения другой горутины.
    
- **`preemptStop`, `preemptShrink` и `asyncSafePoint`**: Флаги, связанные с механизмами прерывания и безопасными точками для асинхронных операций.
    
- **`paniconfault`**: Указывает, произошёл ли `panic` из-за ошибки сегментации или другой ошибки доступа к памяти.
    
- **`gcscandone`**: Флаг, показывающий, завершено ли сканирование стека горутины сборщиком мусора.
    
- **`throwsplit`**: Указывает, произошла ли ошибка при разделении стека горутины.
    
- **`activeStackChans`**: Флаг, показывающий, есть ли активные операции с каналами, связанные со стеком горутины.
    
- **`raceignore`**: Используется в режиме детектора гонок для игнорирования определённых горутин.
    
- **`sysblocktraced`**: Флаг, указывающий, была ли трассировка системного блокирования для этой горутины.
    
- **`sysexitticks`**: Временная метка выхода из системного вызова.
    
- **`traceseq`**: Счётчик событий трассировки, связанных с горутиной.
    
- **`tracelastp`**: Указатель на последний процессор (`P`), на котором выполнялась горутина.
    
- **`lockedm`**: Указывает, закреплена ли горутина за определённым системным потоком (`M`).
    
- **`sig`, `sigcode0`, `sigcode1` и `sigpc`**: Содержат информацию о полученных сигналах и адресах инструкций, связанных с ними.
    
- **`writebuf`**: Буфер для операций записи, используемый, например, при работе с `cgo`.
    
- **`gopc`**: Адрес вызова, создавшего горутину.
    
- **`ancestors`**: Ссылка на информацию о предках горутины для целей профилирования.
    
- **`startpc`**: Адрес начальной функции горутины.
    
- **`racectx`**: Контекст для детектора гонок.
    
- **`waiting`**: Указатель на структуру `sudog`, если горутина ожидает на канале или другой синхронизации.
    
- **`cgoCtxt`**: Контекст для вызовов `cgo`.
    
- **`labels`**: Указатель на метки, связанные с горутиной, используемые в трассировке.
    
- **`timer`**: Ссылка на таймер, связанный с горутиной.
    
- **`selectDone`**: Флаг, указывающий на завершение операции `select`.
    
- **`gcAssistBytes`**: Количество байт, которые горутина помогла собрать сбор
