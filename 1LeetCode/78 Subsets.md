## ✅ 7. **Subsets** (LeetCode №78)

**Уровень:** Medium

---

### 🧾 Условие:

Дан массив **уникальных** чисел `nums`. Верни все возможные подмножества (наборы с любым количеством элементов, включая пустое).

---

### 📌 Пример:

```text
Input: nums = [1,2,3]
Output:
[
  [],
  [1],
  [2],
  [1,2],
  [3],
  [1,3],
  [2,3],
  [1,2,3]
]
```

---

## 🧠 Идея: Рекурсия + Backtracking

- На каждом элементе решаем: взять его в текущее подмножество или нет
    
- Рекурсивно идём дальше, пока не переберём все элементы
    

---

## ✅ Go-реализация:

```go
func subsets(nums []int) [][]int {
    var res [][]int
    var path []int

    var backtrack func(index int)
    backtrack = func(index int) {
        if index == len(nums) {
            // создаём копию path, иначе ссылка изменится
            subset := make([]int, len(path))
            copy(subset, path)
            res = append(res, subset)
            return
        }

        // Не берем текущий элемент
        backtrack(index + 1)

        // Берем текущий элемент
        path = append(path, nums[index])
        backtrack(index + 1)
        path = path[:len(path)-1]
    }

    backtrack(0)
    return res
}
```

---

### 📈 Сложность:

- **Время:** `O(2ⁿ * n)` — каждая из `2ⁿ` комбинаций копируется (размер до n)
    
- **Память:** `O(2ⁿ * n)` на хранение результата
    

---

### Почему работает:

- Перебираем все варианты, включающие или исключающие каждый элемент
    
- Возвращаем все возможные подмножества
