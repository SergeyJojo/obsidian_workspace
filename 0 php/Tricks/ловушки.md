# 🧩 PHP Tricky Questions

---

## ⚙️ 1. Ссылки, значения и неожиданное поведение

### ❓ Что выведет?

```php
$a = 1;
$b = &$a;
$b = 2;
echo $a;
```

**Ответ:** `2`

> `$b` — ссылка на `$a`, значит любое присваивание меняет исходную переменную.

---

### ❓ А это?

```php
$a = [1, 2, 3];
$b = $a;
$b[0] = 99;
echo $a[0];
```

**Ответ:** `1`

> В PHP копируется по принципу _copy-on-write_. Копия `$b` создаётся только при изменении.

---

### ❓ И теперь?

```php
$a = [1, 2, 3];
$b = &$a;
$b[0] = 99;
echo $a[0];
```

**Ответ:** `99`

> Здесь `$b` — ссылка, поэтому изменение отражается в `$a`.

## 🧠 2. Работа со строками и типами

### ❓ Что выведет?

```php
$a = "0";
if ($a == false) echo "A";
if ($a === false) echo "B";
```

**Ответ:** `A`

> При нестрогом сравнении `"0"` → `false`, но при строгом сравнивании типы не совпадают.

---

### ❓ Что выведет?

```php
echo "5 apples" + "10 oranges";
```

**Ответ:** `15`

> PHP приводит строки к числам до первого нечислового символа.

---

### ❓ Что выведет?

```php
var_dump(0 == "0");
var_dump(0 == "");
var_dump("0" == "");
```

**Ответ:**

```
bool(true)
bool(true)
bool(false)
```

> Последняя строка ловит многих — `"0"` не считается пустым при сравнении с `""`.

## 🔁 3. Foreach и ссылки

### ❓ Что выведет?

```php
$array = [1, 2, 3];
foreach ($array as &$value) {}
foreach ($array as $value) {}
print_r($array);
```

**Ответ:**

```
Array ( [0] => 1 [1] => 2 [2] => 2 )
```

> Последний `$value` ссылается на последний элемент массива, и он перезаписывается.

✅ Правильный способ: `unset($value)` после `foreach`.

## 🔒 4. Замыкания и область видимости

### ❓ Что выведет?

```php
$a = 1;
$fn = function() use ($a) {
    $a++;
    return $a;
};
echo $fn();
echo $a;
```

**Ответ:**

```
2
1
```

> `$a` передаётся **по значению** в замыкание, не по ссылке.

---

### ❓ А теперь?

```php
$a = 1;
$fn = function() use (&$a) {
    $a++;
};
$fn();
echo $a;
```

**Ответ:** `2`

> Передача по ссылке `&$a` изменяет внешнюю переменную.

## 🧱 5. Классы и static поведение

### ❓ Что выведет?

```php
class A {
    public static $x = 0;
    function __construct() {
        self::$x++;
    }
}
new A();
new A();
echo A::$x;
```

**Ответ:** `2`

> Статические свойства общие для всех экземпляров.

---

### ❓ Позднее статическое связывание

```php
class A {
    public static function who() { echo __CLASS__; }
    public static function test() { static::who(); }
}
class B extends A {
    public static function who() { echo __CLASS__; }
}
B::test();
```

**Ответ:** `B`

> Из-за `static::` вызывается метод из класса-наследника (late static binding).

## 🧩 6. Замыкания и $this

### ❓ Что выведет?

```php
class A {
    public $x = 1;
}
$fn = function() { return $this->x; };
$a = new A;
$b = $fn->bindTo($a, A::class);
echo $b();
```

**Ответ:** `1`

> `bindTo` позволяет замкнуть `$this` на конкретный объект.

## ⚡ 7. Неочевидные конструкции

### ❓ Что выведет?

```php
echo "2" + "2", "2";
```

**Ответ:** `42`

> `"2" + "2"` = 4 (арифметика), потом конкатенация строки `"2"` через запятую → `42`.

---

### ❓ Что выведет?

```php
var_dump("true" == true);
var_dump("false" == false);
```

**Ответ:**

```
bool(true)
bool(true)
```

> При нестрогом сравнении `"false"` → 0, а `false` → 0.

---

## 🪓 8. Edge cases с unset и static

### ❓ Что выведет?

```php
function &ref() {
    static $x = 0;
    return $x;
}
$y = &ref();
$y++;
echo ref();
```

**Ответ:** `1`

> Возвращается ссылка на static-переменную — значение сохраняется между вызовами.

---

## 🔍 9. Объекты и клонирование

### ❓ Что выведет?

```php
class A { public $x = 1; }
$a = new A;
$b = $a;
$b->x = 2;
echo $a->x;
```

**Ответ:** `2`

> `$a` и `$b` — ссылки на один объект.

---

### ❓ А теперь:

```php
$a = new A;
$b = clone $a;
$b->x = 2;
echo $a->x;
```

**Ответ:** `1`

> `clone` создаёт новый объект с копией свойств.

---

## ⚙️ 10. Сложное поведение с foreach и ссылками

```php
$array = [1, 2, 3];
foreach ($array as &$val) {}
foreach ($array as $val) {}
print_r($array);
```

**Ответ:**

```
Array ( [0] => 1 [1] => 2 [2] => 2 )
```

> Из-за того, что `$val` остался ссылкой, последний `foreach` портит последний элемент массива.

## 🧮 11. Замыкания и переменные по ссылке внутри цикла

```php
$funcs = [];
for ($i = 0; $i < 3; $i++) {
    $funcs[] = function() use ($i) { echo $i; };
}
foreach ($funcs as $f) $f();
```

**Ответ:** `012`

> `$i` копируется в момент объявления.

А если добавить `&$i`:

```php
for ($i = 0; $i < 3; $i++) {
    $funcs[] = function() use (&$i) { echo $i; };
}
foreach ($funcs as $f) $f();
```

**Ответ:** `333`

> Все функции видят одну и ту же ссылку на `$i`.
