Вот классическое решение задачи **Two Sum** на PHP — с объяснением и оптимизацией.

---

### 📌 Условие задачи (LeetCode #1)
Дан массив целых чисел `nums` и целое число `target`.  
Нужно найти **индексы двух чисел**, сумма которых равна `target`.  
Можно предположить, что **ровно одно решение существует**, и **нельзя использовать один элемент дважды**.

**Пример**:  
```php
nums = [2, 7, 11, 15], target = 9 → [0, 1] (потому что 2 + 7 = 9)
```

---

## ✅ Оптимальное решение: за **O(n)** времени и **O(n)** памяти

Используем **хэш-таблицу (ассоциативный массив)** для хранения уже встречавшихся чисел и их индексов.

```php
<?php

/**
 * @param int[] $nums
 * @param int $target
 * @return int[]
 */
function twoSum(array $nums, int $target): array
{
    $map = []; // значение => индекс

    foreach ($nums as $i => $num) {
        $complement = $target - $num;

        // Если complement уже был — нашли пару!
        if (array_key_exists($complement, $map)) {
            return [$map[$complement], $i];
        }

        // Запоминаем текущее число и его индекс
        $map[$num] = $i;
    }

    // По условию задачи это не должно произойти,
    // но формально нужно вернуть что-то
    throw new InvalidArgumentException("No two sum solution");
}
```

---

### 🔍 Как это работает?
Для каждого числа `num` мы вычисляем, **какое число должно быть в паре**:  
`complement = target - num`.

Если такое число **уже встречалось** (есть в `$map`), значит — **мы нашли ответ**.

Пример по шагам (`nums = [2, 7, 11, 15]`, `target = 9`):

| Шаг | `num` | `complement` | `$map` до | Найдено? |
|-----|-------|--------------|-----------|--------|
| 0   | 2     | 7            | `[]`      | нет → запоминаем `2 => 0` |
| 1   | 7     | 2            | `[2=>0]`  | **да!** → возвращаем `[0, 1]` |

---

### ⏱️ Сложность
- **Время**: O(n) — один проход по массиву  
- **Память**: O(n) — в худшем случае храним все элементы

> 💡 Это **лучшее возможное решение** по времени.  
> Наивный вариант с двумя циклами — O(n²) — **не подходит для больших данных**.

---

### 🧪 Тесты
```php
// Пример из условия
assert(twoSum([2, 7, 11, 15], 9) === [0, 1]);

// Другие случаи
assert(twoSum([3, 2, 4], 6) === [1, 2]);
assert(twoSum([3, 3], 6) === [0, 1]);
assert(twoSum([1, 2, 3, 4, 5], 8) === [2, 4]); // 3 + 5

echo "Все тесты пройдены!\n";
```

---

### ❗ Важные нюансы
1. **Порядок индексов**: сначала меньший индекс, потом больший — как в примере.
2. **Один элемент нельзя использовать дважды**:  
   Для `[3, 3]` и `target=6` — ответ `[0,1]`, а не `[0,0]`.
3. **Отрицательные числа** тоже работают:  
   `twoSum([-1, -2, -3, -4, -5], -8)` → `[2, 4]`.

### 🚫 Наивное решение (O(n²)) — только для понимания
```php
function twoSumNaive(array $nums, int $target): array
{
    $n = count($nums);
    for ($i = 0; $i < $n; $i++) {
        for ($j = $i + 1; $j < $n; $j++) {
            if ($nums[$i] + $nums[$j] === $target) {
                return [$i, $j];
            }
        }
    }
    throw new Exception("No solution");
}
```
> ⚠️ Не используй это на собеседовании без оговорки — спросят: «А можно быстрее?»
