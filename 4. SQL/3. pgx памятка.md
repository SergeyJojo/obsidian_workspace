### **Памятка по работе с `pgx` (Go)**  

#### **1. Подключение к БД**  
```go
import "github.com/jackc/pgx/v5"  

conn, err := pgx.Connect(ctx, "postgres://user:pass@localhost:5432/db")  
if err != nil {  
    log.Fatal(err)  
}  
defer conn.Close(ctx)  
```  

#### **2. Выполнение запроса (без возврата строк)**  
```go
_, err := conn.Exec(ctx, "INSERT INTO users(name) VALUES($1)", "Alice")  
```  

#### **3. Запрос с возвратом одной строки**  
```go
var name string  
err := conn.QueryRow(ctx, "SELECT name FROM users WHERE id=$1", 1).Scan(&name)  
```  

#### **4. Запрос нескольких строк**  
```go
rows, err := conn.Query(ctx, "SELECT id, name FROM users")  
defer rows.Close()  

for rows.Next() {  
    var id int  
    var name string  
    err := rows.Scan(&id, &name)  
}  
```  

#### **5. Транзакции**  
```go
tx, err := conn.Begin(ctx)  
defer tx.Rollback(ctx)  

_, err = tx.Exec(ctx, "UPDATE accounts SET balance=balance-$1 WHERE id=$2", 100, 1)  
err = tx.Commit(ctx)  
```  

#### **6. Пул соединений (`pgxpool`)**  
```go
import "github.com/jackc/pgx/v5/pgxpool"  

pool, err := pgxpool.New(ctx, "postgres://user:pass@localhost:5432/db")  
defer pool.Close()  

// Использование  
conn, err := pool.Acquire(ctx)  
defer conn.Release()  
```  

#### **7. JSON (получение/отправка)**  
```go
// Чтение JSON в структуру  
var data map[string]interface{}  
err := conn.QueryRow(ctx, "SELECT json_data FROM table").Scan(&data)  

// Запись JSON  
_, err := conn.Exec(ctx, "INSERT INTO table(json_data) VALUES($1)", map[string]any{"key": "value"})  
```  

#### **8. Обработка ошибок**  
```go
if errors.Is(err, pgx.ErrNoRows) {  
    log.Println("Нет строк")  
}  
```  

---

**Коротко:**  
- `Connect` – подключение.  
- `Exec` – запрос без результата.  
- `QueryRow` – одна строка.  
- `Query` – множество строк.  
- `Begin` – транзакция.  
- `pgxpool` – пул соединений.  
- `Scan` – парсинг данных.  

Оптимизировано для быстрого использования. 🚀
