В PHP работа с коллекциями осуществляется в основном через **функции для работы с массивами** и **классы вроде ArrayObject**. Вот полный обзор методов:

## 🎯 Основные функции для работы с массивами

### 1. **Создание и преобразование**
```php
$collection = ['a', 'b', 'c'];

// Из диапазона
$numbers = range(1, 5); // [1, 2, 3, 4, 5]

// Из строки
$chars = str_split('hello'); // ['h', 'e', 'l', 'l', 'o']

// В объект
$object = (object)$collection;
```

### 2. **Итерация и обход**
```php
$users = ['Alice', 'Bob', 'Charlie'];

// foreach (основной)
foreach ($users as $user) {
    echo $user;
}

// foreach с ключами
foreach ($users as $index => $user) {
    echo "$index: $user";
}

// array_map - применяет функцию к каждому элементу
$uppercased = array_map('strtoupper', $users); // ['ALICE', 'BOB', 'CHARLIE']

// array_walk - модифицирует исходный массив
array_walk($users, function(&$value, $key) {
    $value = strtoupper($value);
});
```

### 3. **Фильтрация**
```php
$numbers = [1, 2, 3, 4, 5, 6];

// array_filter - фильтрация по условию
$even = array_filter($numbers, function($n) {
    return $n % 2 === 0;
}); // [2, 4, 6]

// С callback и сохранением ключей
$filtered = array_filter($numbers, fn($n) => $n > 3); // [4, 5, 6]
```

### 4. **Поиск**
```php
$users = ['Alice', 'Bob', 'Charlie'];

// in_array - проверка существования
$exists = in_array('Bob', $users); // true

// array_search - поиск ключа
$key = array_search('Bob', $users); // 1

// array_key_exists - проверка ключа
$hasKey = array_key_exists(1, $users); // true
```

### 5. **Сортировка**
```php
$numbers = [3, 1, 4, 1, 5, 9, 2];

// sort - по значениям
sort($numbers); // [1, 1, 2, 3, 4, 5, 9]

// asort - с сохранением ключей
asort($numbers);

// ksort - по ключам
ksort($numbers);

// usort - пользовательская сортировка
usort($numbers, fn($a, $b) => $a <=> $b);
```

### 6. **Агрегация и редукция**
```php
$numbers = [1, 2, 3, 4, 5];

// array_sum - сумма
$sum = array_sum($numbers); // 15

// array_product - произведение
$product = array_product($numbers); // 120

// array_reduce - сворачивание
$total = array_reduce($numbers, fn($carry, $item) => $carry + $item, 0);

// count - количество
$count = count($numbers); // 5
```

### 7. **Комбинирование и разделение**
```php
$first = ['a', 'b'];
$second = ['c', 'd'];

// array_merge - объединение
$merged = array_merge($first, $second); // ['a', 'b', 'c', 'd']

// array_chunk - разделение на части
$chunks = array_chunk($merged, 2); // [['a', 'b'], ['c', 'd']]

// array_slice - получение среза
$slice = array_slice($merged, 1, 2); // ['b', 'c']
```

### 8. **Ключи и значения**
```php
$user = ['name' => 'Alice', 'age' => 25, 'city' => 'London'];

// array_keys - получение ключей
$keys = array_keys($user); // ['name', 'age', 'city']

// array_values - получение значений
$values = array_values($user); // ['Alice', 25, 'London']

// array_flip - обмен ключей и значений
$flipped = array_flip($user); // ['Alice' => 'name', 25 => 'age', ...]
```

## 🚀 Класс ArrayObject

**ArrayObject** - это объект-обертка для работы с массивами в ООП стиле.

```php
$collection = new ArrayObject(['a', 'b', 'c']);

// Основные методы
$collection->append('d');        // Добавить элемент
$collection->offsetSet(0, 'A');  // Установить значение
$value = $collection->offsetGet(1); // Получить значение
$collection->offsetUnset(2);     // Удалить элемент
$exists = $collection->offsetExists(0); // Проверить существование

// Итерация
$iterator = $collection->getIterator();
while ($iterator->valid()) {
    echo $iterator->current();
    $iterator->next();
}

// Преобразование
$array = $collection->getArrayCopy();
```

## 💡 Современный подход с Generator

**Генераторы** для работы с большими коллекциями:

```php
function largeCollectionGenerator($max) {
    for ($i = 0; $i < $max; $i++) {
        yield $i * 2;
    }
}

$collection = largeCollectionGenerator(1000000);

foreach ($collection as $item) {
    echo $item . "\n"; // Экономит память!
}
```

## 🛠️ Практические примеры

### Обработка пользователей
```php
$users = [
    ['name' => 'Alice', 'age' => 25, 'active' => true],
    ['name' => 'Bob', 'age' => 30, 'active' => false],
    ['name' => 'Charlie', 'age' => 35, 'active' => true],
];

// Фильтрация активных пользователей
$activeUsers = array_filter($users, fn($user) => $user['active']);

// Получение только имен
$names = array_map(fn($user) => $user['name'], $users);

// Группировка по возрасту
$grouped = array_reduce($users, function($carry, $user) {
    $ageGroup = $user['age'] < 30 ? 'young' : 'adult';
    $carry[$ageGroup][] = $user;
    return $carry;
}, []);
```

### Цепочка методов (эмуляция)
```php
function processCollection(array $data) {
    return array_reduce(
        [
            fn($arr) => array_filter($arr, fn($x) => $x > 0),
            fn($arr) => array_map(fn($x) => $x * 2, $arr),
            fn($arr) => array_unique($arr),
        ],
        fn($carry, $transform) => $transform($carry),
        $data
    );
}

$result = processCollection([-1, 2, 2, 3, -5, 4]); // [4, 6, 8]
```

## 🎯 Полезные комбинации

### Поиск с преобразованием
```php
$users = [...];
$user = current(array_filter(
    array_map(fn($u) => [...$u, 'name_lower' => strtolower($u['name'])], $users),
    fn($u) => $u['name_lower'] === 'alice'
));
```

### Группировка с агрегацией
```php
$orders = [...];
$totalByCategory = array_reduce($orders, function($carry, $order) {
    $category = $order['category'];
    $carry[$category] = ($carry[$category] ?? 0) + $order['amount'];
    return $carry;
}, []);
```

## 💎 Лучшие практики

1. **Используйте arrow functions** для простых операций
2. **Комбинируйте функции** для сложных преобразований
3. **Используйте генераторы** для больших данных
4. **ArrayObject** для ООП подхода
5. **array_column** для извлечения данных из многомерных массивов

```php
// Вместо:
$names = [];
foreach ($users as $user) {
    $names[] = $user['name'];
}

// Используйте:
$names = array_column($users, 'name');
```

Эти методы дают мощный инструментарий для эффективной работы с коллекциями в PHP! 🚀
