
Для того чтобы объединить несколько каналов в один, нужно использовать горутину, которая будет читать данные из всех переданных каналов и передавать их в объединённый канал. Важно, чтобы читатели не блокировали друг друга, поэтому используем несколько горутин для каждого канала и передаем их данные в один объединённый канал.

Решение будет следующим:

1. Мы создаём объединённый канал.
2. Для каждого канала создаём отдельную горутину, которая будет читать из этого канала и передавать данные в объединённый канал.
3. После того как все данные будут переданы, горутина завершит работу.

Вот как может выглядеть код:

```go
package main

import (
    "fmt"
    "sync"
)

// merge объединяет несколько каналов в один
func merge(chs ...chan int) chan int {
    out := make(chan int)
    var wg sync.WaitGroup

    // Если входной срез пустой, сразу закрываем out и возвращаем
    if len(chs) == 0 {
        close(out)
        return out
    }

    wg.Add(len(chs)) // Добавляем количество горутин в WaitGroup

    // Создаем горутину для каждого канала
    for _, ch := range chs {
        go func(c chan int) {
            defer wg.Done() // Уменьшаем счётчик при завершении горутины
            for el := range c {
                out <- el // Отправляем элемент в объединённый канал
            }
        }(ch)
    }

    // Горутина для закрытия out после завершения всех входных каналов
    go func() {
        wg.Wait()   // Ждём завершения всех горутин
        close(out)  // Закрываем выходной канал
    }()

    return out
}

// Пример функции, создающей первый канал с данными
func startProducerA() chan int {
    ch := make(chan int)
    go func() {
        for i := 0; i < 5; i++ {
            ch <- i
        }
        close(ch) // Закрываем канал после завершения отправки
    }()
    return ch
}

// Пример функции, создающей второй канал с данными
func startProducerB() chan int {
    ch := make(chan int)
    go func() {
        for i := 5; i < 10; i++ {
            ch <- i
        }
        close(ch) // Закрываем канал после завершения отправки
    }()
    return ch
}

func main() {
    // Запускаем два производителя
    ch1 := startProducerA()
    ch2 := startProducerB()

    // Получаем объединённый канал и выводим данные из него
    for el := range merge(ch1, ch2) {
        fmt.Println(el) // Выводим элементы из объединённого канала
    }
    fmt.Println("Done")
}
```

### Пояснение:

1. **merge**:
    
    - Создаёт новый канал `out`.
    - Для каждого канала из переданных аргументов (`chs ...chan int`) запускается горутина, которая читает из этого канала и передает данные в канал `out`.
2. **startProducerA и startProducerB**:
    
    - Это примеры функций, которые создают каналы и отправляют в них данные. В этих функциях используется горутина для асинхронной отправки значений и закрытия канала после завершения работы.
3. **main**:
    
    - Мы запускаем два производителя с каналами `ch1` и `ch2`.
    - Используем `merge`, чтобы объединить эти каналы в один, и затем выводим все элементы из объединённого канала с помощью цикла `for`.

### Важные моменты:

- Каждая горутина читает данные из одного канала и передаёт их в общий канал.
- Каналы закрываются внутри горутин после того, как все данные отправлены. Это гарантирует, что цикл `range` в `main` завершится, когда все данные будут переданы.

Таким образом, мы можем объединить произвольное количество каналов в один и безопасно передавать данные между ними.
