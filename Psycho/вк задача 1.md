
Вот решение задачи **свёртки списка чисел в диапазоны** на **Go** и **Python**, как ты просил.

---

## ✅ Условие:

Вход: массив целых чисел без повторений (неотсортирован).  
Выход: строка, где последовательные числа свёрнуты в диапазоны: `a-b`, а одиночные числа — просто `a`.

Пример:

```go
Input:  [1,4,5,2,3,9,8,11,0,13]  
Output: "0-5,8-9,11,13"
```

---

## 🦫 Go (Golang)

```go
package main

import (
	"fmt"
	"sort"
	"strconv"
)

func summarizeRanges(nums []int) string {
	if len(nums) == 0 {
		return ""
	}

	sort.Ints(nums)

	var result []string
	start := nums[0]
	end := nums[0]

	for i := 1; i < len(nums); i++ {
		if nums[i] == end+1 {
			end = nums[i]
		} else {
			if start == end {
				result = append(result, strconv.Itoa(start))
			} else {
				result = append(result, fmt.Sprintf("%d-%d", start, end))
			}
			start = nums[i]
			end = nums[i]
		}
	}

	// Добавляем последний диапазон
	if start == end {
		result = append(result, strconv.Itoa(start))
	} else {
		result = append(result, fmt.Sprintf("%d-%d", start, end))
	}

	return join(result, ",")
}

func join(arr []string, sep string) string {
	res := ""
	for i, s := range arr {
		if i > 0 {
			res += sep
		}
		res += s
	}
	return res
}

func main() {
	nums := []int{1, 4, 5, 2, 3, 9, 8, 11, 0, 13}
	fmt.Println(summarizeRanges(nums)) // "0-5,8-9,11,13"
}
```

## 🐍 Python

```python
def summarize_ranges(nums):
    if not nums:
        return ""

    nums = sorted(nums)
    result = []
    start = nums[0]
    end = nums[0]

    for num in nums[1:]:
        if num == end + 1:
            end = num
        else:
            if start == end:
                result.append(str(start))
            else:
                result.append(f"{start}-{end}")
            start = end = num

    # Добавить последний диапазон
    if start == end:
        result.append(str(start))
    else:
        result.append(f"{start}-{end}")

    return ",".join(result)

# Пример:
nums = [1,4,5,2,3,9,8,11,0,13]
print(summarize_ranges(nums))  # "0-5,8-9,11,13"
```

---

## 🔍 Принцип работы:

1. Сначала **сортируем** входной список.
    
2. Идём по числам, сравнивая текущее с предыдущим.
    
3. Если последовательность продолжается — расширяем диапазон.
    
4. Как только последовательность обрывается — сохраняем диапазон (или одно число).
    
5. Повторяем до конца.
