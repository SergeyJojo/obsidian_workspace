
Запросы в MongoDB строятся с использованием **MongoDB Query Language (MQL)**, который позволяет взаимодействовать с базой данных с помощью различных операций. Вот базовые принципы построения запросов в MongoDB:

### 1. **Поиск документов (Find)**

Чтобы извлечь документы из коллекции, используется метод `find()`. Запросы могут быть очень простыми или сложными, в зависимости от потребностей.

#### Простой запрос:

```javascript
db.collection.find({ field: value })
```

Пример: Найти все документы, где поле `age` равно 30:

```javascript
db.users.find({ age: 30 })
```

#### Запрос с несколькими условиями:

```javascript
db.collection.find({ field1: value1, field2: value2 })
```

Пример: Найти пользователей, у которых `age` равен 30 и `status` равен "active":

```javascript
db.users.find({ age: 30, status: "active" })
```

#### Запрос с условиями сравнения:

MongoDB поддерживает операторы сравнения, например:

- `$eq`: равно
- `$ne`: не равно
- `$gt`: больше
- `$lt`: меньше
- `$gte`: больше или равно
- `$lte`: меньше или равно

Пример: Найти документы, где `age` больше 30:

```javascript
db.users.find({ age: { $gt: 30 } })
```

#### Логические операторы:

- `$and`: логическое "И"
- `$or`: логическое "ИЛИ"
- `$not`: отрицание
- `$nor`: логическое "НИ"

Пример: Найти документы, где `age` больше 20 и `status` равен "active":

```javascript
db.users.find({ $and: [{ age: { $gt: 20 } }, { status: "active" }] })
```

#### Использование регулярных выражений:

```javascript
db.users.find({ name: { $regex: /^John/ } })
```

Этот запрос ищет все имена, начинающиеся с "John".

### 2. **Выборка определённых полей**

По умолчанию метод `find()` возвращает все поля документа. Если вы хотите вернуть только определённые поля, вы можете использовать второй параметр метода `find()` для указания полей.

Пример: Возвращать только поля `name` и `age`:

```javascript
db.users.find({}, { name: 1, age: 1 })
```

Здесь `{ name: 1, age: 1 }` означает, что мы выбираем только поля `name` и `age`, остальные поля будут исключены. Поле `_id` всегда будет возвращено по умолчанию, если явно не указано `{ _id: 0 }` для исключения.

### 3. **Агрегации**

MongoDB имеет мощный **агрегатный фреймворк**, который позволяет выполнять сложные операции над данными, такие как группировка, сортировка, фильтрация и вычисления.

#### Пример агрегации:

Группировка пользователей по статусу и подсчёт их количества:

```javascript
db.users.aggregate([
  { $group: { _id: "$status", count: { $sum: 1 } } }
])
```

Этот запрос сгруппирует документы по полю `status` и подсчитает количество пользователей в каждом статусе.

#### Пример агрегации с несколькими этапами:

1. Фильтруем документы с возрастом больше 20.
2. Группируем их по статусу и считаем количество.

```javascript
db.users.aggregate([
  { $match: { age: { $gt: 20 } } },
  { $group: { _id: "$status", count: { $sum: 1 } } }
])
```

### 4. **Обновление документов**

Для обновления данных используется метод `updateOne()`, `updateMany()` или `replaceOne()`.

#### Пример обновления одного документа:

```javascript
db.users.updateOne({ name: "John" }, { $set: { age: 35 } })
```

Этот запрос обновит первый документ с именем "John" и установит его возраст в 35.

#### Пример обновления нескольких документов:

```javascript
db.users.updateMany({ status: "inactive" }, { $set: { status: "active" } })
```

Этот запрос обновит все документы с `status` "inactive" и изменит их статус на "active".

#### Пример использования оператора инкремента:

```javascript
db.users.updateOne({ name: "John" }, { $inc: { age: 1 } })
```

Этот запрос увеличит возраст пользователя с именем "John" на 1.

### 5. **Удаление документов**

Для удаления документов в MongoDB используются методы `deleteOne()` и `deleteMany()`.

#### Пример удаления одного документа:

```javascript
db.users.deleteOne({ name: "John" })
```

#### Пример удаления нескольких документов:

```javascript
db.users.deleteMany({ age: { $lt: 18 } })
```

Этот запрос удалит все документы, где возраст меньше 18.

### 6. **Индексы**

MongoDB поддерживает создание индексов для улучшения производительности запросов. Индексы могут быть созданы для одного или нескольких полей.

Пример создания индекса:

```javascript
db.users.createIndex({ name: 1 })
```

Этот индекс ускоряет поиск по полю `name`.

### 7. **Пагинация**

Для обработки больших объёмов данных часто используется пагинация через методы `skip()` и `limit()`.

#### Пример пагинации:

```javascript
db.users.find().skip(10).limit(10)
```

Этот запрос пропустит первые 10 документов и вернёт следующие 10.

### 8. **Запросы с вложенными данными (массивами и объектами)**

MongoDB поддерживает запросы по вложенным документам и массивам.

Пример: Найти всех пользователей с адресом в городе "New York":

```javascript
db.users.find({ "address.city": "New York" })
```

Пример: Найти всех пользователей, у которых есть хотя бы один элемент в массиве `hobbies` равный "sports":

```javascript
db.users.find({ hobbies: "sports" })
```

---

Это лишь базовые примеры, MongoDB предоставляет множество других возможностей для работы с данными, включая сложные агрегатные операции, транзакции, работу с геопространственными данными и другие функциональные возможности.
