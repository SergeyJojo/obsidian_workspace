### 1. **KVM (Kernel-based Virtual Machine)**

KVM — это технология виртуализации для Linux, которая позволяет запускать несколько виртуальных машин (VM), каждая из которых имеет свой собственный процессор, память и устройства. KVM использует возможности процессоров с поддержкой виртуализации (например, Intel VT-x или AMD-V) и интегрируется с ядром Linux для обеспечения производительности и безопасности.

- **KVM host** — это физическая машина, на которой работает гипервизор.
    
- **KVM guest** — это виртуальная машина, которая работает на KVM хосте.
    

### 2. **SDS диск (Software Defined Storage)**

SDS (Software Defined Storage) — это подход к управлению хранилищем данных, при котором управление данными осуществляется через программные инструменты, а не через специализированное оборудование. SDS позволяет абстрагировать физические диски и массивы хранения, предоставляя гибкость и масштабируемость.

- Это может быть полезно для построения крупных и гибких хранилищ данных, таких как в облачных системах, где нужно быстро масштабировать ресурсы в зависимости от нужд.
    

### 3. **iSCSI (Internet Small Computer Systems Interface)**

iSCSI — это сетевой протокол, который позволяет компьютерам и серверным системам обмениваться данными с удалёнными хранилищами через сеть TCP/IP. Он часто используется для подключения серверов к удалённым хранилищам, создавая виртуализированные "жёсткие диски", которые выглядят как локальные устройства, но физически находятся в другом месте.

- Протокол iSCSI используется для передачи данных с блоками данных (например, для SCSI-дисков) через сеть.
    

### 4. **IQN (iSCSI Qualified Name)**

IQN — это уникальное имя, которое используется в iSCSI для идентификации устройств и инициаторов (например, серверов или устройств хранения). Оно стандартизировано и имеет вид:

```
iqn.yyyy-mm.com.example:server1
```

- **yyyy-mm** — год и месяц, когда был создан IQN.
    
- **com.example** — доменное имя, которое использовалось для создания IQN.
    
- **server1** — имя устройства или хоста.
    

IQN используется для аутентификации в iSCSI и помогает различать устройства в сети.

### 5. **CHAP (Challenge-Handshake Authentication Protocol)**

CHAP — это протокол аутентификации, который используется для проверки подлинности между клиентом и сервером. Он часто используется в сочетании с iSCSI для безопасной аутентификации устройств перед передачей данных.

- Протокол использует трёхэтапный процесс аутентификации, в котором сервер генерирует "вопрос" (challenge), а клиент должен предоставить правильный ответ. Это предотвращает атаки повторного воспроизведения.
    

### 6. **Netplan**

Netplan — это утилита в Linux (особенно популярна в Ubuntu), которая используется для настройки сетевых интерфейсов. Она предоставляет единый способ конфигурации сети через файлы YAML.

- **Netplan** позволяет легко управлять сетевыми интерфейсами, поддерживает как статические IP-адреса, так и DHCP, а также может использовать различные бэкенды, такие как `NetworkManager` или `systemd-networkd`.
    

Пример конфигурации с Netplan для статического IP:

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: no
      addresses:
        - 192.168.1.100/24
      gateway4: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
```

Этот конфигурационный файл задаёт статический IP для интерфейса `eth0`.
