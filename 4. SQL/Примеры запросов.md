- В каждой из таблиц добавляется дополнительная колонка `source`, чтобы указать источник данных.

### 17. **Использование `INTERSECT` для нахождения общих клиентов между двумя списками**

**Пример: Найти клиентов, которые сделали заказы в 2024 году и оставили отзывы в 2024 году:**

```sql
SELECT customer_id
FROM orders
WHERE YEAR(order_date) = 2024

INTERSECT

SELECT customer_id
FROM reviews
WHERE YEAR(review_date) = 2024;
```

Здесь:

- `INTERSECT` находит общие строки между двумя подзапросами (в данном случае, общие клиенты).
- Это используется, когда нужно найти пересечение данных.

### 18. **Запрос с `NOT EXISTS` для исключения определённых данных**

**Пример: Получить список клиентов, которые не делали заказов в последние 6 месяцев:**

```sql
SELECT c.customer_id, c.customer_name
FROM customers c
WHERE NOT EXISTS (
    SELECT 1
    FROM orders o
    WHERE o.customer_id = c.customer_id
    AND o.order_date > DATE_SUB(CURRENT_DATE, INTERVAL 6 MONTH)
);
```

Здесь:

- `NOT EXISTS` исключает клиентов, у которых есть заказ за последние 6 месяцев.
- Мы используем подзапрос, чтобы проверить наличие заказов за этот период.

### 19. **Запрос с `GROUP BY` и вычислением суммарных данных по нескольким столбцам**

**Пример: Получить общее количество заказов и общую сумму покупок для каждого клиента в 2024 году:**

```sql
SELECT customer_id, COUNT(order_id) AS total_orders, SUM(order_amount) AS total_spent
FROM orders
WHERE YEAR(order_date) = 2024
GROUP BY customer_id;
```

Здесь:

- Используем `COUNT()` и `SUM()` для вычисления общего количества заказов и общей суммы для каждого клиента за 2024 год.
- Группируем по `customer_id` для получения данных по каждому клиенту.

### 20. **Запрос с оконной функцией для вычисления скользящей суммы (Running Total)**

**Пример: Вычислить накопленную сумму заказов для каждого клиента по времени:**

```sql
SELECT customer_id, order_date, order_amount,
       SUM(order_amount) OVER (PARTITION BY customer_id ORDER BY order_date) AS running_total
FROM orders;
```

Здесь:

- `SUM()` в оконной функции используется для вычисления накопленной суммы по заказам каждого клиента.
- `PARTITION BY` разделяет данные по клиентам, а `ORDER BY` сортирует их по дате заказа.
