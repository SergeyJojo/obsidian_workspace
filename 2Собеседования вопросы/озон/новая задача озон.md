## 📄 Условие задачи (текстом)

Реализуй сервис в Go, который получает события от пользователей в реальном времени и позволяет узнать, **сколько событий конкретный пользователь совершил за последние 5 минут**.

### Интерфейс сервиса:

```go
type Service interface {
    HandleEvent(userName string, currentTime time.Time)
    GetCount(userName string, currentTime time.Time) int
}
```

### Подробности:

- `HandleEvent` вызывается каждый раз, когда пользователь совершает событие. Аргументы:
    
    - `userName` — имя пользователя
        
    - `currentTime` — текущее время (обычно `time.Now()`)
        
- `GetCount` вызывается, чтобы узнать, сколько событий этот пользователь совершил за последние 5 минут относительно `currentTime`.

## ✅ Решение на Go (с использованием очереди на пользователя)

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type Service interface {
	HandleEvent(userName string, currentTime time.Time)
	GetCount(userName string, currentTime time.Time) int
}

// Реализация

type eventService struct {
	mu       sync.Mutex
	userData map[string][]time.Time
}

func NewEventService() Service {
	return &eventService{
		userData: make(map[string][]time.Time),
	}
}

const window = 5 * time.Minute

func (s *eventService) HandleEvent(userName string, currentTime time.Time) {
	s.mu.Lock()
	defer s.mu.Unlock()

	s.userData[userName] = append(s.userData[userName], currentTime)
}

func (s *eventService) GetCount(userName string, currentTime time.Time) int {
	s.mu.Lock()
	defer s.mu.Unlock()

	events := s.userData[userName]
	cutoff := currentTime.Add(-window)

	// отфильтровать только последние 5 минут
	i := 0
	for i < len(events) && events[i].Before(cutoff) {
		i++
	}
	s.userData[userName] = events[i:] // очистить старые
	return len(s.userData[userName])
}
```

## 🔧 Пример использования

```go
func main() {
	s := NewEventService()

	now := time.Now()

	s.HandleEvent("alice", now.Add(-4*time.Minute))
	s.HandleEvent("alice", now.Add(-3*time.Minute))
	s.HandleEvent("alice", now.Add(-6*time.Minute)) // старое событие, не будет учитываться

	count := s.GetCount("alice", now)
	fmt.Printf("alice made %d events in the last 5 minutes\n", count) // должно быть 2
}
```

---

## 🧠 Объяснение

- Мы используем `map[string][]time.Time`, чтобы для каждого пользователя хранить временные метки его событий.
    
- В `GetCount` удаляем старые события, оставляя только те, что за последние 5 минут.
    
- `sync.Mutex` — чтобы поддерживать потокобезопасность, если сервис будет вызываться из нескольких горутин.
