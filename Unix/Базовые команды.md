## **1. Навигация по файловой системе**

### **`pwd` (Print Working Directory)**
- Показывает текущую директорию.
- Пример:
  ```bash
  pwd
  # /home/user
  ```

### **`ls` (List)**
- Показывает содержимое директории.
- Пример:
  ```bash
  ls
  ls -l  # Подробный вывод
  ls -a  # Показать скрытые файлы
  ```

### **`cd` (Change Directory)**
- Переход в другую директорию.
- Пример:
  ```bash
  cd /home/user
  cd ..  # Переход на уровень выше
  cd ~   # Переход в домашнюю директорию
  ```

---

## **2. Работа с файлами и директориями**

### **`touch`**
- Создаёт пустой файл или обновляет время последнего изменения существующего файла.
- Пример:
  ```bash
  touch file.txt
  ```

### **`mkdir` (Make Directory)**
- Создаёт новую директорию.
- Пример:
  ```bash
  mkdir new_folder
  mkdir -p parent/child  # Создать вложенные директории
  ```

### **`rm` (Remove)**
- Удаляет файлы или директории.
- Пример:
  ```bash
  rm file.txt
  rm -r folder  # Удалить директорию рекурсивно
  rm -f file.txt  # Принудительное удаление без подтверждения
  ```

### **`cp` (Copy)**
- Копирует файлы или директории.
- Пример:
  ```bash
  cp file.txt file_copy.txt
  cp -r folder folder_copy  # Копировать директорию рекурсивно
  ```

### **`mv` (Move)**
- Перемещает или переименовывает файлы или директории.
- Пример:
  ```bash
  mv file.txt new_location/file.txt
  mv old_name.txt new_name.txt  # Переименование
  ```

## **3. Просмотр и редактирование файлов**

### **`cat` (Concatenate)**
- Показывает содержимое файла.
- Пример:
  ```bash
  cat file.txt
  ```

### **`less`**
- Позволяет просматривать файл постранично.
- Пример:
  ```bash
  less file.txt
  ```

### **`head`**
- Показывает первые строки файла.
- Пример:
  ```bash
  head file.txt
  head -n 10 file.txt  # Показать первые 10 строк
  ```

### **`tail`**
- Показывает последние строки файла.
- Пример:
  ```bash
  tail file.txt
  tail -n 10 file.txt  # Показать последние 10 строк
  tail -f file.txt  # Режим реального времени (для логов)
  ```

### **`nano` / `vim`**
- Текстовые редакторы для редактирования файлов.
- Пример:
  ```bash
  nano file.txt
  vim file.txt
  ```

## **4. Поиск файлов и текста**

### **`find`**
- Ищет файлы и директории по имени, размеру, времени и другим критериям.
- Пример:
  ```bash
  find /home/user -name "*.txt"
  find /var/log -size +1M  # Файлы больше 1 МБ
  ```

### **`grep`**
- Ищет текст в файлах.
- Пример:
  ```bash
  grep "search_text" file.txt
  grep -r "search_text" /home/user  # Рекурсивный поиск
  grep -i "search_text" file.txt  # Игнорировать регистр
  ```

## **5. Управление процессами**

### **`ps` (Process Status)**
- Показывает запущенные процессы.
- Пример:
  ```bash
  ps aux  # Показать все процессы
  ```

### **`top` / `htop`**
- Показывает информацию о процессах и использовании ресурсов в реальном времени.
- Пример:
  ```bash
  top
  htop
  ```

### **`kill`**
- Завершает процесс по его ID.
- Пример:
  ```bash
  kill 1234
  kill -9 1234  # Принудительное завершение
  ```

### **`bg` / `fg`**
- Управляет фоновыми и приостановленными процессами.
- Пример:
  ```bash
  bg  # Перевести процесс в фоновый режим
  fg  # Вернуть процесс на передний план
  ```

---

## **6. Работа с архивами**

### **`tar`**
- Создаёт и распаковывает архивы.
- Пример:
  ```bash
  tar -cvf archive.tar folder  # Создать архив
  tar -xvf archive.tar  # Распаковать архив
  tar -czvf archive.tar.gz folder  # Создать сжатый архив (gzip)
  tar -xzvf archive.tar.gz  # Распаковать сжатый архив
  ```

### **`zip` / `unzip`**
- Создаёт и распаковывает ZIP-архивы.
- Пример:
  ```bash
  zip archive.zip file.txt
  unzip archive.zip
  ```

## **7. Сеть**

### **`ping`**
- Проверяет доступность хоста.
- Пример:
  ```bash
  ping google.com
  ```

### **`ifconfig` / `ip`**
- Показывает информацию о сетевых интерфейсах.
- Пример:
  ```bash
  ifconfig
  ip addr show
  ```

### **`netstat`**
- Показывает сетевые соединения и статистику.
- Пример:
  ```bash
  netstat -tuln  # Показать открытые порты
  ```

### **`ssh`**
- Подключение к удалённому серверу.
- Пример:
  ```bash
  ssh user@hostname
  ```

## **8. Управление пакетами**

### **`apt` (Debian/Ubuntu)**
- Управление пакетами в Debian-подобных системах.
- Пример:
  ```bash
  sudo apt update
  sudo apt install package_name
  sudo apt remove package_name
  ```

### **`yum` / `dnf` (CentOS/RHEL/Fedora)**
- Управление пакетами в Red Hat-подобных системах.
- Пример:
  ```bash
  sudo yum install package_name
  sudo dnf remove package_name
  ```

---

## **9. Права доступа**

### **`chmod`**
- Изменяет права доступа к файлам и директориям.
- Пример:
  ```bash
  chmod 755 file.txt  # Установить права rwxr-xr-x
  chmod +x script.sh  # Сделать файл исполняемым
  ```

### **`chown`**
- Изменяет владельца файла или директории.
- Пример:
  ```bash
  sudo chown user:group file.txt
  ```

---

## **10. Системная информация**

### **`uname`**
- Показывает информацию о системе.
- Пример:
  ```bash
  uname -a  # Вся информация
  ```

### **`df` (Disk Free)**
- Показывает информацию о свободном месте на диске.
- Пример:
  ```bash
  df -h  # Человеко-читаемый формат
  ```

### **`du` (Disk Usage)**
- Показывает использование диска для файлов и директорий.
- Пример:
  ```bash
  du -sh folder  # Суммарный размер директории
  ```
