
Метрики в Go — это важный инструмент для мониторинга производительности, диагностики проблем и понимания поведения приложения в реальном времени. Они помогают собирать данные о работе программы, такие как количество запросов, время выполнения, использование памяти и другие ключевые показатели. Давайте разберем, как использовать метрики в Go, какие они бывают, и какие инструменты для этого существуют.

---

### Цели использования метрик
1. **Мониторинг производительности**:
   - Отслеживание времени выполнения запросов, использования CPU, памяти и других ресурсов.
2. **Диагностика проблем**:
   - Выявление узких мест, ошибок и аномалий в работе приложения.
3. **Анализ нагрузки**:
   - Понимание, как приложение справляется с увеличением нагрузки.
4. **Автоматизация**:
   - Использование метрик для автоматического масштабирования (autoscaling) и управления ресурсами.
5. **Отчетность**:
   - Сбор данных для анализа и отчетов о работе системы.

---

### Какие бывают метрики
Метрики можно разделить на несколько категорий:

#### 1. **Счетчики (Counters)**
   - Увеличиваются на определенное значение (например, количество запросов, ошибок).
   - Пример: `http_requests_total`.

#### 2. **Гистограммы (Histograms)**
   - Измеряют распределение значений (например, время выполнения запросов).
   - Пример: `http_request_duration_seconds`.

#### 3. **Градуировки (Gauges)**
   - Измеряют текущее значение (например, количество активных горутин, использование памяти).
   - Пример: `memory_usage_bytes`.

#### 4. **Суммы (Summaries)**
   - Аналогичны гистограммам, но позволяют вычислять процентили (например, 95-й процентиль времени выполнения запросов).
   - Пример: `http_request_duration_seconds_summary`.

### Инструменты для работы с метриками в Go

#### 1. **Prometheus**
   - Популярная система для сбора и анализа метрик.
   - Библиотека для Go: `github.com/prometheus/client_golang`.
   - Пример использования:
     ```go
     import (
         "net/http"
         "github.com/prometheus/client_golang/prometheus"
         "github.com/prometheus/client_golang/prometheus/promhttp"
     )

     var (
         httpRequests = prometheus.NewCounterVec(
             prometheus.CounterOpts{
                 Name: "http_requests_total",
                 Help: "Total number of HTTP requests.",
             },
             []string{"method", "status"},
         )
     )

     func init() {
         prometheus.MustRegister(httpRequests)
     }

     func handler(w http.ResponseWriter, r *http.Request) {
         httpRequests.WithLabelValues(r.Method, "200").Inc()
         w.Write([]byte("Hello, world!"))
     }

     func main() {
         http.HandleFunc("/", handler)
         http.Handle("/metrics", promhttp.Handler())
         http.ListenAndServe(":8080", nil)
     }
     ```

#### 2. **Expvar**
   - Встроенный пакет Go для экспорта метрик в формате JSON.
   - Пример:
     ```go
     import (
         "expvar"
         "net/http"
     )

     var (
         requests = expvar.NewInt("requests")
     )

     func handler(w http.ResponseWriter, r *http.Request) {
         requests.Add(1)
         w.Write([]byte("Hello, world!"))
     }

     func main() {
         http.HandleFunc("/", handler)
         http.ListenAndServe(":8080", nil)
     }
     ```
   - Метрики доступны по адресу `/debug/vars`.

#### 3. **OpenTelemetry**
   - Универсальная библиотека для сбора метрик, трейсов и логов.
   - Поддерживает интеграцию с Prometheus, Jaeger и другими системами.
   - Пример:
     ```go
     import (
         "go.opentelemetry.io/otel"
         "go.opentelemetry.io/otel/exporters/prometheus"
         "go.opentelemetry.io/otel/sdk/metric"
     )

     func main() {
         exporter, _ := prometheus.New()
         provider := metric.NewMeterProvider(metric.WithReader(exporter))
         otel.SetMeterProvider(provider)

         // Использование метрик
         meter := otel.Meter("example")
         counter, _ := meter.Int64Counter("requests")
         counter.Add(context.Background(), 1)
     }
     ```

#### 4. **StatsD**
   - Протокол для отправки метрик на сервер.
   - Библиотека для Go: `github.com/alexcesaro/statsd`.
   - Пример:
     ```go
     import (
         "github.com/alexcesaro/statsd"
         "time"
     )

     func main() {
         client, _ := statsd.New()
         defer client.Close()

         client.Increment("requests")
         client.Timing("request_duration", time.Second)
     }
     ```

### Как использовать метрики в Go

6. **Определение метрик**:
   - Создайте счетчики, гистограммы или градуировки с помощью библиотеки (например, Prometheus).

7. **Инкрементация метрик**:
   - Увеличивайте счетчики или обновляйте градуировки в ключевых местах кода (например, при обработке запросов).

8. **Экспорт метрик**:
   - Настройте endpoint для экспорта метрик (например, `/metrics` для Prometheus).

9. **Визуализация и анализ**:
   - Используйте инструменты, такие как Grafana, для визуализации метрик.

### Пример кода с Prometheus

```go
package main

import (
    "net/http"
    "github.com/prometheus/client_golang/prometheus"
    "github.com/prometheus/client_golang/prometheus/promhttp"
)

var (
    httpRequests = prometheus.NewCounterVec(
        prometheus.CounterOpts{
            Name: "http_requests_total",
            Help: "Total number of HTTP requests.",
        },
        []string{"method", "status"},
    )
    requestDuration = prometheus.NewHistogramVec(
        prometheus.HistogramOpts{
            Name:    "http_request_duration_seconds",
            Help:    "Duration of HTTP requests.",
            Buckets: prometheus.DefBuckets,
        },
        []string{"method"},
    )
)

func init() {
    prometheus.MustRegister(httpRequests)
    prometheus.MustRegister(requestDuration)
}

func handler(w http.ResponseWriter, r *http.Request) {
    timer := prometheus.NewTimer(requestDuration.WithLabelValues(r.Method))
    defer timer.ObserveDuration()

    httpRequests.WithLabelValues(r.Method, "200").Inc()
    w.Write([]byte("Hello, world!"))
}

func main() {
    http.HandleFunc("/", handler)
    http.Handle("/metrics", promhttp.Handler())
    http.ListenAndServe(":8080", nil)
}
```
