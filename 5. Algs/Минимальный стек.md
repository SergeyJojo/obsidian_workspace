Вот аккуратно отформатированный и читаемый Go-код с комментами:

```go
// Node представляет элемент стека.
type Node struct {
	Value int
	Next  *Node
}

// MinStack — стек с поддержкой получения минимального элемента за O(1).
type MinStack struct {
	main *Node // основной стек
	min  *Node // стек минимумов
}

// NewMinStack создает новый пустой MinStack.
func NewMinStack() *MinStack {
	return &MinStack{}
}

// Push добавляет элемент в стек.
func (s *MinStack) Push(val int) {
	// Добавляем в основной стек.
	s.main = &Node{Value: val, Next: s.main}

	// Если стек минимумов пуст или новое значение меньше или равно текущему минимуму.
	if s.min == nil || val <= s.min.Value {
		s.min = &Node{Value: val, Next: s.min}
	}
}

// Pop удаляет верхний элемент из стека и возвращает его.
func (s *MinStack) Pop() (int, bool) {
	if s.main == nil {
		return 0, false
	}

	val := s.main.Value
	s.main = s.main.Next

	// Если удаляемый элемент был минимумом — удаляем его и из стека минимумов.
	if val == s.min.Value {
		s.min = s.min.Next
	}

	return val, true
}

// Top возвращает верхний элемент стека.
func (s *MinStack) Top() (int, bool) {
	if s.main == nil {
		return 0, false
	}
	return s.main.Value, true
}

// GetMin возвращает текущий минимум в стеке.
func (s *MinStack) GetMin() (int, bool) {
	if s.min == nil {
		return 0, false
	}
	return s.min.Value, true
}
```

---

### Суть:

- Используется два стека:
    
    - **main** — обычный стек значений.
        
    - **min** — стек текущих минимумов (на каждом этапе на его вершине — минимум всех элементов в main).
        
- Все операции (`Push`, `Pop`, `Top`, `GetMin`) работают за **O(1)**.
