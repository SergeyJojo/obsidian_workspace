## 🏗️ **1. Основы HTML структуры**

### 📚 Теория
HTML (HyperText Markup Language) - это не язык программирования, а **язык разметки**, который определяет структуру веб-страницы.

**Базовые концепции:**
- **Элементы** - строительные блоки HTML
- **Теги** - маркеры, определяющие элементы
- **Атрибуты** - дополнительные свойства элементов
- **Древовидная структура** - вложенность элементов

### 💻 Синтаксис и примеры

#### Базовый каркас HTML-документа:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя первая страница</title>
</head>
<body>
    <!-- Содержимое страницы -->
    <h1>Привет, мир!</h1>
    <p>Это моя первая HTML-страница.</p>
</body>
</html>
```

#### Структура тега:
```html
<!-- Открывающий тег -->  <!-- Закрывающий тег -->
    <тег атрибут="значение">содержимое</тег>
<!--       ↑                          ↑
       атрибут                  содержимое элемента
-->
```

#### Основные элементы структуры:
```html
<!-- Заголовки (иерархия от h1 до h6) -->
<h1>Главный заголовок</h1>
<h2>Подзаголовок</h2>
<h3>Менее важный заголовок</h3>

<!-- Параграф текста -->
<p>Это абзац текста. Он может содержать <strong>жирный текст</strong> 
и <em>курсивный текст</em>.</p>

<!-- Ссылки -->
<a href="https://example.com">Это ссылка</a>

<!-- Изображения -->
<img src="photo.jpg" alt="Описание изображения">

<!-- Списки -->
<ul>
    <li>Элемент списка 1</li>
    <li>Элемент списка 2</li>
</ul>

<ol>
    <li>Первый пункт</li>
    <li>Второй пункт</li>
</ol>
```

### 🎯 Практическое применение

**Задача:** Создать простую страницу "О себе"
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>О себе</title>
</head>
<body>
    <h1>Иван Иванов</h1>
    <h2>Веб-разработчик</h2>
    
    <p>Занимаюсь разработкой веб-приложений более 2 лет.</p>
    
    <h3>Навыки:</h3>
    <ul>
        <li>HTML5 и CSS3</li>
        <li>JavaScript</li>
        <li>React</li>
    </ul>
    
    <h3>Контакты:</h3>
    <p>Email: <a href="mailto:ivan@example.com">ivan@example.com</a></p>
</body>
</html>
```

### ⚠️ Частые ошибки

1. **Незакрытые теги**
   ```html
   <!-- НЕПРАВИЛЬНО -->
   <p>Текст без закрытия
   
   <!-- ПРАВИЛЬНО -->
   <p>Текст с закрытием</p>
   ```

2. **Неправильная вложенность**
   ```html
   <!-- НЕПРАВИЛЬНО -->
   <p>Текст <strong>жирный</p></strong>
   
   <!-- ПРАВИЛЬНО -->
   <p>Текст <strong>жирный</strong></p>
   ```

3. **Отсутствие alt у изображений**
   ```html
   <!-- НЕПРАВИЛЬНО -->
   <img src="photo.jpg">
   
   <!-- ПРАВИЛЬНО -->
   <img src="photo.jpg" alt="Описание фото">
   ```
