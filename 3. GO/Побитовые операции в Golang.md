
Отлично! Побитовые операции — важная часть низкоуровневой работы с числами, флагами и масками. В Go они применяются к **целочисленным типам** (`int`, `uint`, `int64`, и т.д.) и работают по тем же законам, что и в других языках.

---

## 🧠 Побитовые операции в Go

|Оператор|Название|Описание|
|---|---|---|
|`&`|AND|Побитовая конъюнкция (и)|
|`|`|OR|
|`^`|XOR|Побитовая исключающая дизъюнкция|
|`&^`|AND NOT (bit clear)|Побитовое И с отрицанием второго операнда|
|`<<`|Сдвиг влево|Сдвигает биты влево (умножение на 2^N)|
|`>>`|Сдвиг вправо|Сдвигает биты вправо (деление на 2^N)|

---

## 📘 Примеры

### 1. `&` — AND

```go
a := 6        // 0110
b := 3        // 0011
c := a & b    // 0010 -> 2
```

Только те биты, которые включены и в `a`, и в `b`, останутся.

---

### 2. `|` — OR

```go
a := 6        // 0110
b := 3        // 0011
c := a | b    // 0111 -> 7
```

Все биты, включённые хотя бы в одном из операндов.

---

### 3. `^` — XOR

```go
a := 6        // 0110
b := 3        // 0011
c := a ^ b    // 0101 -> 5
```

Биты, включённые только в одном операнде.

---

### 4. `&^` — AND NOT (bit clear)

```go
a := 6        // 0110
b := 3        // 0011
c := a &^ b   // 0100 -> 4
```

Удаляет (обнуляет) биты из `a`, которые установлены в `b`.

---

### 5. `<<` и `>>` — Сдвиги

```go
a := 3        // 0011

b := a << 1   // 0110 -> 6
c := a >> 1   // 0001 -> 1
```

- `<<` — умножает на 2 в степени `n`
    
- `>>` — целочисленное деление на 2 в степени `n`
    

---

## 🛠 Применение

### ✅ 1. Установка и снятие флагов (битовая маска)

```go
const (
    FlagRead  = 1 << 0 // 0001
    FlagWrite = 1 << 1 // 0010
    FlagExec  = 1 << 2 // 0100
)

var perms uint8

// Установить флаг:
perms |= FlagRead | FlagWrite

// Проверить флаг:
if perms&FlagWrite != 0 {
    fmt.Println("Write enabled")
}

// Сбросить флаг:
perms &^= FlagWrite
```

---

### ✅ 2. Счёт битов

```go
import "math/bits"

count := bits.OnesCount(uint(x))
```

- `bits` — стандартная библиотека для работы с битами.
    

---

### ✅ 3. Четность / нечётность

```go
if x&1 == 0 {
    fmt.Println("even")
} else {
    fmt.Println("odd")
}
```

## 🧪 Визуализация

Можно использовать [https://calcbit.com](https://calcbit.com/) или `printf` в бинарном формате:

```go
fmt.Printf("%08b\n", a) // печать в виде 8-битного бинарного числа
```

---

## ⚠️ Советы

- Побитовые операции **работают только с целыми числами**.
    
- С `int` и `uint` будь осторожен: при `>>` знаковость важна (`int` сохраняет знак при сдвиге).
    
- Для **флагов и масок** лучше использовать `uint8`, `uint16`, `uint32`, `uint64`.
