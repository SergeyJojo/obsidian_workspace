### 🔧 Что такое `container/list` в Go?

Это реализация **двусвязного списка** — структура данных, в которой каждый элемент знает о своём предыдущем и следующем. Звучит скучно? На деле — чертовски удобно, когда нужно:

- быстро вставить что-то **в начало или конец**;
    
- **удалить элемент**, не перетряхивая весь список;
    
- иметь **упорядоченные элементы**, но без гемора с массивами и слайсами.
    

---

### 📦 Когда ты реально это используешь?

Представь себе кэш — у тебя ограниченное место. Ты хочешь, чтобы самые старые данные удалялись первыми. Что делать? Мапа даёт тебе быстрый доступ по ключу, а список — быстрый доступ к «старейшему» элементу. Всё! Вместе они дают супер-быстрый кэш.

---

### 📐 Как оно работает?

```go
import "container/list"

func main() {
	l := list.New()

	// Вставляем элементы
	e1 := l.PushBack("чай")
	e2 := l.PushFront("кофе")
	l.InsertAfter("молоко", e1)
	l.InsertBefore("вода", e2)

	// Выводим
	for el := l.Front(); el != nil; el = el.Next() {
		fmt.Println(el.Value)
	}

	// Удаляем элемент
	l.Remove(e1)
}
```

---

### 🔄 У тебя мапа с *list.Element?

Тогда удаление — одно удовольствие:

```go
l := list.New()
m := map[string]*list.Element{}

m["ключ"] = l.PushBack("значение")

// удаляем
if el, ok := m["ключ"]; ok {
	l.Remove(el)
	delete(m, "ключ")
}
```

Никаких поисков по списку. Удалил и забыл. Быстро. Красиво. Как будто Go говорит: «брат, я тебя понял».

---

### 🤖 А чего там под капотом?

`Element` — это узел:

```go
type Element struct {
    Value      any
    Next, Prev *Element
}
```

То есть, ты можешь и назад, и вперёд идти. А `List` просто держит `Front`, `Back`, и считает длину.

---

### 🧠 И когда лучше не использовать?

Когда ты хочешь:

- Быстрый доступ по индексу (`list` будет тормозить, потому что нужно идти от начала);
    
- Просто массив — тебе проще и быстрее слайс.
