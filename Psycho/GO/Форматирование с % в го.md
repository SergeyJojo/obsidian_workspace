
В Go при использовании функций форматирования (`fmt.Printf`, `fmt.Sprintf`, `fmt.Errorf`, и т.д.) символ `%` используется для **указания формата вывода значений**. Вот полный и понятный разбор:

---

### 📌 Основной синтаксис:

```
%[флаг][ширина][.точность][verb]
```

- **Флаг** — модифицирует поведение (например, выравнивание)
    
- **Ширина** — минимальное количество символов
    
- **.точность** — количество знаков после запятой или ограничение длины строки
    
- **Verb (буква)** — что и как форматировать
    

---

### 🔤 Основные `verb` (буквы):

#### 📦 Общие

|Verb|Описание|Пример|
|---|---|---|
|`%v`|Значение в default формате|`%v` → `123`|
|`%+v`|Включает имена полей (структуры)|`%+v` → `{Name: Вася}`|
|`%#v`|Go-синтаксис|`%#v` → `main.User{Name:"Вася"}`|
|`%T`|Тип переменной|`%T` → `int`|
|`%%`|Буквально символ `%`|`%%` → `%`|

#### 🔢 Числа

|Verb|Описание|
|---|---|
|`%d`|Десятичное целое|
|`%b`|Двоичное|
|`%o`|Восьмеричное|
|`%x`|Шестнадцатеричное (строчн.)|
|`%X`|Шестнадцатеричное (ЗАГЛАВН.)|
|`%f`|Число с плавающей точкой|
|`%e`|Научная запись (строчн.)|
|`%E`|Научная запись (ЗАГЛАВН.)|
|`%g`|%e или %f, что короче|

#### 🧵 Строки и байты

|Verb|Описание|
|---|---|
|`%s`|Строка|
|`%q`|Заключённая в кавычки строка|
|`%x`|hex-представление строки|
|`%c`|Unicode символ|

#### 🔘 Логические

|Verb|Описание|
|---|---|
|`%t`|true / false|

#### 📦 Указатели

|Verb|Описание|
|---|---|
|`%p`|Указатель (hex)|

---

### 🧪 Примеры:

```go
i := 42
fmt.Printf("%d\n", i)     // 42
fmt.Printf("%08d\n", i)   // 00000042
fmt.Printf("%x\n", i)     // 2a

s := "GoLang"
fmt.Printf("%s\n", s)     // GoLang
fmt.Printf("%10s\n", s)   //     GoLang (выравнено вправо)
fmt.Printf("%-10s\n", s)  // GoLang     (влево)

f := 3.14159
fmt.Printf("%.2f\n", f)   // 3.14
```

---

### 📌 Часто используемые флаги:

|Флаг|Значение|
|---|---|
|`-`|Выравнивание влево|
|`+`|Показать знак у чисел|
|`0`|Заполнение нулями|
|`#`|Альтернативный формат (hex с `0x`, `q` с экранированием и т.д.)|

---

### 🧠 Чтобы запомнить:

- `%v` — универсальное "покажи что есть"
    
- `%+v` — с именами полей
    
- `%#v` — как в Go-коде
    
- `%s`, `%d`, `%f` — строки, числа, числа с точкой
