В Laravel маршрутизация (routing) — это механизм, который определяет, **какие действия (контроллеры, замыкания и т.д.) должны быть выполнены при получении HTTP-запроса** по определённому URI и методу (GET, POST и др.).

Laravel предоставляет **гибкие и мощные опции маршрутизации**, которые можно разделить на несколько категорий:

---

## 🔹 1. **Базовые типы маршрутов**

### ✅ Замыкания (Closure)
```php
Route::get('/hello', function () {
    return 'Hello, world!';
});
```

### ✅ Контроллеры
```php
Route::get('/users', [UserController::class, 'index']);
```

### ✅ Resource-контроллеры (RESTful)
```php
Route::resource('posts', PostController::class);
```
→ Автоматически создаёт 7 маршрутов (`index`, `create`, `store`, `show`, `edit`, `update`, `destroy`).

---

## 🔹 2. **HTTP-методы**

Laravel поддерживает все основные методы:
- `Route::get()`
- `Route::post()`
- `Route::put()` / `patch()`
- `Route::delete()`
- `Route::options()`

Также:
- `Route::match(['get', 'post'], ...)` — для нескольких методов
- `Route::any()` — для любого HTTP-метода (использовать осторожно!)

---

## 🔹 3. **Параметры маршрутов**

### Обязательные:
```php
Route::get('/user/{id}', function ($id) {
    return "User ID: $id";
});
```

### Необязательные (с дефолтным значением):
```php
Route::get('/user/{name?}', function ($name = 'Guest') {
    return "Hello, $name";
});
```

### Ограничения (where):
```php
Route::get('/user/{id}', function ($id) {
    // ...
})->where('id', '[0-9]+');
```

Или глобально в `App\Providers\RouteServiceProvider`:
```php
Route::pattern('id', '[0-9]+');
```

---

## 🔹 4. **Именованные маршруты (named routes)**

Позволяют ссылаться на маршрут по имени (удобно для редиректов и генерации URL):
```php
Route::get('/profile', [ProfileController::class, 'show'])->name('profile.show');

// Генерация URL
route('profile.show'); // → /profile
```

---

## 🔹 5. **Группировка маршрутов**

Позволяет применять общие настройки к набору маршрутов.

### Префиксы:
```php
Route::prefix('admin')->group(function () {
    Route::get('/users', [AdminController::class, 'users']);
});
// → /admin/users
```

### Пространства имён (в Laravel ≤8; в 9+ обычно не нужно):
```php
Route::namespace('Admin')->group(...);
```

### Middleware:
```php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::get('/dashboard', ...);
});
```

### Имена (name prefix):
```php
Route::name('admin.')->group(function () {
    Route::get('/users', ...)->name('users'); // → admin.users
});
```

Комбинирование:
```php
Route::prefix('api')
    ->middleware('auth:sanctum')
    ->name('api.')
    ->group(function () {
        Route::get('/me', ...)->name('me');
    });
```

---

## 🔹 6. **Маршрутизация по домену**

```php
Route::domain('{account}.example.com')->group(function () {
    Route::get('/dashboard', ...);
});
```

---

## 🔹 7. **Fallback и обработка 404**

- `Route::fallback()` — срабатывает, если ни один маршрут не совпал (должен быть последним в группе).
- Глобальный обработчик 404 настраивается через исключения (`App\Exceptions\Handler`).

---

## 🔹 8. **API и Singleton-ресурсы**

- `Route::apiResource()` — resource-маршруты без `create` и `edit` (только JSON).
- `Route::singleton()` (начиная с Laravel 8) — для singleton-ресурсов (например, `/profile` вместо `/profiles/{id}`).

---

## 🔹 9. **Подстановка контроллеров (implicit binding)**

Laravel автоматически подставляет модель по ID:
```php
Route::get('/users/{user}', [UserController::class, 'show']);
// → $user будет экземпляром User с id = {user}
```

Можно кастомизировать через метод `resolveRouteBinding()` в модели.

---

## 🔹 10. **Условная маршрутизация**

Использование замыканий или условий:
```php
if (config('app.debug')) {
    Route::get('/debug-info', ...);
}
```

Или через `Route::when()` (в RouteServiceProvider) — редко используется.

---

## 🔹 11. **Кэширование маршрутов**

В продакшене:
```bash
php artisan route:cache
```
→ Ускоряет загрузку приложения (но **нельзя использовать замыкания в маршрутах** при кэшировании).

---

## ✅ Итог

Laravel предлагает **очень гибкую систему маршрутизации**, включающую:
- Простые и RESTful маршруты
- Группы с middleware, префиксами, именами
- Параметры с валидацией
- Именованные маршруты для удобной генерации URL
- Поддержку API и микросервисных сценариев

Это особенно полезно при построении **модульных, легковесных или микросервисных Laravel-приложений**, где маршруты часто изолируются по контексту (API, админка, клиентская часть и т.д.).
