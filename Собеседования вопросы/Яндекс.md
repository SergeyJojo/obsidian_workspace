Ось симметрии

Вот решение задачи на Go, которое проверяет наличие вертикальной симметрии для набора точек:

```go
package main

import (
	"fmt"
)

// Point структура для представления точки с координатами (x, y)
type Point struct {
	x, y int
}

// isVertSym проверяет, существует ли вертикальная ось симметрии для набора точек
func isVertSym(points []Point) bool {
	// Создаем множество для хранения уникальных точек
	pointSet := make(map[Point]struct{})

	// Находим минимальное и максимальное значение x
	var minX, maxX int
	for i, point := range points {
		if i == 0 || point.x < minX {
			minX = point.x
		}
		if i == 0 || point.x > maxX {
			maxX = point.x
		}
	}

	// Определяем возможную ось симметрии
	c := float64(minX+maxX) / 2.0

	// Добавляем все точки в множество
	for _, point := range points {
		pointSet[point] = struct{}{}
	}

	// Проверяем для каждой точки, есть ли зеркальная точка
	for _, point := range points {
		// Рассчитываем зеркальную точку по оси c
		symmetricPoint := Point{x: int(2*c) - point.x, y: point.y}
		// Если зеркальная точка отсутствует, значит симметрия не выполняется
		if _, found := pointSet[symmetricPoint]; !found {
			return false
		}
	}

	return true
}

func main() {
	points := []Point{
		{0, 0},
		{0, 0},
		{1, 1},
		{2, 2},
		{3, 1},
		{4, 0},
		{4, 0},
	}

	// Проверка на вертикальную симметрию
	fmt.Println(isVertSym(points)) // Выведет: true
}
```

### Пояснение к решению:

1. **Структура `Point`**: используется для представления точек с целочисленными координатами xx и yy.
    
2. **Функция `isVertSym`**:
    
    - Находит минимальное и максимальное значения xx в наборе точек.
        
    - Вычисляется возможная ось симметрии cc как среднее значение минимального и максимального xx.
        
    - Далее для каждой точки проверяется, существует ли её зеркальная пара относительно оси симметрии. Если хотя бы одна пара отсутствует, функция возвращает `false`.
        
3. **Основная функция**:
    
    - Создает массив точек и вызывает функцию для проверки вертикальной симметрии.
        

### Как это работает:

- Пример с точками, который мы проверяем, имеет симметричную ось через x=2x = 2.
    
- Все точки по одну сторону от этой оси имеют зеркальные точки по другую сторону.
    
- Если так происходит для всех точек, выводим `true`, иначе — `false`.
    

Этот код работает эффективно и использует хеш-таблицу для быстрого поиска зеркальных точек.
