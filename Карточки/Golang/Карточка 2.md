
### **🔵 Базовый уровень (25 карточек)**  
**1. Как объявить переменную в Go?**  
```go
var x int = 42          // Явное объявление с типом
y := "hello"            // Краткая форма (тип выводится)
const pi = 3.14         // Константа
```
**Пояснение**:  
- `:=` работает только внутри функций.  
- Константы вычисляются на этапе компиляции.  

---

**2. Чем отличается `array` от `slice`?**  
```go
arr := [3]int{1, 2, 3}  // Массив (фиксированный размер)
s := arr[:]             // Срез (динамический вид)
```
**Ключевые отличия**:  
- `array` передаётся по значению (копируется), `slice` — по ссылке.  
- `slice` имеет `len` (длина) и `cap` (ёмкость).  

---

**3. Как работает `for`?**  
```go
for i := 0; i < 5; i++ {}  // Классический цикл
for idx, val := range s {} // Итерация по slice
for { break }              // Бесконечный цикл
```
**Нюансы**:  
- `range` возвращает (индекс, значение) для слайсов.  
- Используйте `break`/`continue` для управления.  

---

**4. Как объявить функцию с возвратом ошибки?**  
```go
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("деление на ноль")
    }
    return a / b, nil
}
```
**Совет**:  
- Ошибки — последний возвращаемый параметр.  
- `nil` означает отсутствие ошибки.  

---

**5. Что такое `defer` и порядок вызовов?**  
```go
func example() {
    defer fmt.Println("1")
    defer fmt.Println("2") 
    fmt.Println("3")
}
// Вывод: 3 2 1
```
**Правило**:  
- `defer` выполняются в обратном порядке (LIFO).  
- Полезно для закрытия ресурсов (файлов, соединений).  

---

**6. Как работают анонимные функции?**  
```go
func() {
    fmt.Println("анонимная")
}()  // Вызов сразу

add := func(a, b int) int {
    return a + b
}
```
**Применение**:  
- Колбэки.  
- Замыкания (доступ к внешним переменным).

**7. Как создать и использовать структуру?**  
```go
type User struct {
    Name string
    Age  int
}

u := User{Name: "Alice", Age: 25}
fmt.Println(u.Name)  // Доступ к полям
```
**Методы**:  
```go

    fmt.Printf("Привет, %s!", u.Name)

```

**8. Что такое интерфейсы?**  
```go
type Speaker interface {
    Speak() string
}

type Dog struct{}
func (d Dog) Speak() string { return "Гав!" }
```
**Особенности**:  
- Неявная реализация (достаточно методов).  
- Пустой интерфейс `interface{}` — любой тип.

**9. Как обрабатывать ошибки?**  
```go
file, err := os.Open("test.txt")
if err != nil {
    log.Fatal(err)
}
defer file.Close()
```
**Паттерны**:  
- Проверяйте `err != nil` сразу.  
- `defer` для гарантированного закрытия.

**10. Как работать с файлами?**  
```go

file.WriteString("Текст")
```

- Закрывайте файлы через `defer`.

**Особенности**:  
- `rune` = `int32` (кодовая точка Unicode).  
- Строки в Go — неизменяемые байты.
