Вот "железобетонная" шпаргалка по работе с датами и временем в PostgreSQL. Я собрал самые полезные функции и операторы, которые ты можешь "повесить на стену" и использовать как справочник. Всё с примерами, пояснениями и акцентом на практичность — чтобы ты мог управлять временем как "владелец вселенной дат"!

---

Типы данных для дат в PostgreSQL

- DATE — Только дата: 2025-03-29.
    
- TIME — Только время: 14:30:00.
    
- TIMESTAMP — Дата и время: 2025-03-29 14:30:00.
    
- TIMESTAMPTZ — То же, но с часовым поясом: 2025-03-29 14:30:00+03.
    
- INTERVAL — Разница времени: 1 year 2 months 3 days.
    

---

Операторы для дат

1. + — Сложение даты и интервала.
    
    - SELECT '2025-03-29'::DATE + INTERVAL '1 day' → 2025-03-30.
        
    - Зачем: Добавление времени.
        
2. - — Вычитание (дата - интервал или дата - дата).
    
    - SELECT '2025-03-29'::DATE - INTERVAL '1 month' → 2025-02-28.
        
    - SELECT '2025-03-29'::DATE - '2025-03-01'::DATE → 28 (дней).
        
    - Зачем: Расчёт разницы или сдвиг назад.
        
3. =, !=, <, >, <=, >= — Сравнение дат.
    
    - WHERE created_at > '2025-01-01' — Записи после 1 января 2025.
        
    - Зачем: Фильтрация по времени.
        

---

Функции для работы с датами

Получение текущего времени

1. NOW() — Текущий TIMESTAMP с поясом.
    
    - SELECT NOW() → 2025-03-29 14:30:00+03.
        
    - Зачем: Логирование, метки.
        
2. CURRENT_DATE — Текущая дата.
    
    - SELECT CURRENT_DATE → 2025-03-29.
        
    - Зачем: Работа только с датой.
        
3. CURRENT_TIME — Текущее время с поясом.
    
    - SELECT CURRENT_TIME → 14:30:00+03.
        
4. LOCALTIMESTAMP — TIMESTAMP без пояса.
    
    - SELECT LOCALTIMESTAMP → 2025-03-29 14:30:00.
        

---

Извлечение частей даты

5. DATE_PART('field', date) — Извлекает часть даты/времени.
    
    - SELECT DATE_PART('year', NOW()) → 2025.
        
    - SELECT DATE_PART('hour', NOW()) → 14.
        
    - Поля: year, month, day, hour, minute, second, week, dow (день недели, 0-6).
        
    - Зачем: Анализ по годам, часам и т.д.
        
6. EXTRACT(field FROM date) — То же, что DATE_PART.
    
    - SELECT EXTRACT(MONTH FROM '2025-03-29'::DATE) → 3.
        
    - Зачем: Альтернативный синтаксис, стандарт SQL.
        

---

Обрезка и округление

7. DATE_TRUNC('field', date) — Обрезает дату до указанной части.
    
    - SELECT DATE_TRUNC('month', NOW()) → 2025-03-01 00:00:00+03.
        
    - Поля: year, month, day, hour, minute, second.
        
    - Зачем: Группировка по месяцам, дням.
        

---

Преобразование строк и форматов

8. TO_TIMESTAMP(str, format) — Строку в TIMESTAMP.
    
    - SELECT TO_TIMESTAMP('29-03-2025 14:30', 'DD-MM-YYYY HH24:MI') → 2025-03-29 14:30:00.
        
    - Формат: YYYY (год), MM (месяц), DD (день), HH24 (часы 0-23), MI (минуты).
        
    - Зачем: Парсинг ввода.
        
9. TO_DATE(str, format) — Строку в DATE.
    
    - SELECT TO_DATE('29-03-2025', 'DD-MM-YYYY') → 2025-03-29.
        
10. TO_CHAR(date, format) — Дата в строку с форматированием.
    
    - SELECT TO_CHAR(NOW(), 'DD Mon YYYY') → 29 Mar 2025.
        
    - Зачем: Форматированный вывод.
        

---

Работа с интервалами

11. AGE(date) — Разница между датой и текущей датой.
    
    - SELECT AGE('1990-01-01'::DATE) → 35 years 2 months 28 days.
        
    - Зачем: Расчёт возраста.
        
12. INTERVAL 'value' — Создание интервала.
    
    - SELECT NOW() + INTERVAL '1 year' → 2026-03-29 14:30:00+03.
        
    - Значения: 1 year, 2 months, 3 days, 4 hours.
        
13. JUSTIFY_INTERVAL(interval) — Нормализует интервал.
    
    - SELECT JUSTIFY_INTERVAL('35 days') → 1 month 5 days.
        
    - Зачем: Упрощение разницы.
        

---

Дополнительные утилиты

14. MAKE_DATE(year, month, day) — Создаёт дату из чисел.
    
    - SELECT MAKE_DATE(2025, 3, 29) → 2025-03-29.
        
    - Зачем: Генерация дат.
        
15. MAKE_TIMESTAMP(year, month, day, hour, min, sec) — Создаёт TIMESTAMP.
    
    - SELECT MAKE_TIMESTAMP(2025, 3, 29, 14, 30, 0) → 2025-03-29 14:30:00.
        
16. CURRENT_TIMESTAMP AT TIME ZONE 'zone' — Преобразование часового пояса.
    
    - SELECT NOW() AT TIME ZONE 'UTC' → 2025-03-29 11:30:00+00.
        
    - Зачем: Работа с поясами.

Шпаргалка "на стену" для PostgreSQL

```text
Типы:
- DATE: 2025-03-29
- TIMESTAMP: 2025-03-29 14:30:00
- TIMESTAMPTZ: 2025-03-29 14:30:00+03
- INTERVAL: 1 year 2 days

Операторы:
- +: '2025-03-29' + INTERVAL '1 day' → 2025-03-30
- -: '2025-03-29' - '2025-03-01' → 28 дней
- >, <, =: WHERE created_at > '2025-01-01'

Текущее время:
- NOW()                    // 2025-03-29 14:30:00+03
- CURRENT_DATE            // 2025-03-29
- CURRENT_TIME            // 14:30:00+03
- LOCALTIMESTAMP          // 2025-03-29 14:30:00

Извлечение:
- DATE_PART('year', date) // 2025
- EXTRACT(MONTH FROM date)// 3

Обрезка:
- DATE_TRUNC('month', date)// 2025-03-01 00:00:00+03

Преобразование:
- TO_TIMESTAMP('29-03-2025', 'DD-MM-YYYY') // 2025-03-29 00:00:00
- TO_DATE('29-03-2025', 'DD-MM-YYYY')     // 2025-03-29
- TO_CHAR(date, 'DD Mon YYYY')            // "29 Mar 2025"

Интервалы:
- AGE('1990-01-01')       // 35 years 2 months 28 days
- INTERVAL '1 year'       // +1 год к дате
- JUSTIFY_INTERVAL('35 days') // 1 month 5 days

Утилиты:
- MAKE_DATE(2025, 3, 29)  // 2025-03-29
- MAKE_TIMESTAMP(2025, 3, 29, 14, 30, 0) // 2025-03-29 14:30:00
- NOW() AT TIME ZONE 'UTC'// 2025-03-29 11:30:00+00
```

Почему это важно?

- Текущее время: Основа для логов, отчётов.
    
- Извлечение: Анализ по годам, месяцам, дням.
    
- Обрезка: Группировка данных (например, по неделям).
    
- Преобразование: Парсинг и вывод в нужном формате.
    
- Интервалы: Расчёт разниц, сдвигов.
