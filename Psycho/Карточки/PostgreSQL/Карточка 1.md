## 🃏 PostgreSQL + Go карточки (в формате: **вопрос → ответ**)

---

### 🟦 **Карточка 1**

**Q:** Что такое `sql.ErrNoRows` в контексте `pgx`?  
**A:** Это ошибка, возвращаемая при запросе, который не находит ни одной строки. В `pgx` это `pgx.ErrNoRows`. Её нужно проверять отдельно: `if errors.Is(err, pgx.ErrNoRows) {}`.

---

### 🟦 **Карточка 2**

**Q:** Как безопасно выполнить SQL-запрос в Go с подстановкой параметров (pgx)?  
**A:** Используй `QueryRow(ctx, "SELECT name FROM users WHERE id=$1", userID)` — `$1` защищает от SQL-инъекций. Значения подставляются отдельно.

---

### 🟦 **Карточка 3**

**Q:** Что делает метод `Scan()` в Go?  
**A:** Считывает значения из строки результата запроса и записывает их в переменные. Аналог `row.Scan(&name, &age)`.

---

### 🟦 **Карточка 4**

**Q:** Как выполнить транзакцию в Go с pgx?  
**A:**

```go
tx, _ := db.Begin(ctx)
defer tx.Rollback(ctx)

_, _ = tx.Exec(ctx, "UPDATE ...")
return tx.Commit(ctx)
```

---

### 🟦 **Карточка 5**

**Q:** Что такое CTE и как его использовать в Go?  
**A:** CTE (Common Table Expression) — временное имя для вложенного запроса:

```sql
WITH recent AS (SELECT * FROM logs WHERE ts > now() - interval '1h')
SELECT * FROM recent WHERE status = 'error';
```

В Go можно передать как обычный SQL через `Exec/Query`.

---

### 🟦 **Карточка 6**

**Q:** Как правильно использовать `IN` с параметрами в pgx?  
**A:** Используй `pgx.NamedArgs` или собирай `ANY($1)` и передавай `[]int{}`:

```go
rows, _ := db.Query(ctx, "SELECT * FROM users WHERE id = ANY($1)", ids)
```

---

### 🟦 **Карточка 7**

**Q:** Как вставить несколько строк пачкой (`batch insert`) в pgx?  
**A:** Через `pgx.Batch`:

```go
batch := &pgx.Batch{}
for _, u := range users {
  batch.Queue("INSERT INTO users(name) VALUES($1)", u.Name)
}
br := db.SendBatch(ctx, batch)
_ = br.Close()
```

---

### 🟦 **Карточка 8**

**Q:** Чем отличается `QueryRow()` от `Query()` в Go?  
**A:** `QueryRow()` возвращает одну строку (`Row`), `Query()` — несколько (`Rows`). Если данных нет, `QueryRow().Scan()` вернёт `pgx.ErrNoRows`.

---

### 🟦 **Карточка 9**

**Q:** Какой тип Go переменной лучше использовать для `NULL` в базе?  
**A:** Используй `sql.NullString`, `sql.NullInt64`, `pgtype.Text` и аналоги, чтобы обрабатывать `NULL`.

---

### 🟦 **Карточка 10**

**Q:** Как вернуть ID после вставки записи?  
**A:**

```go
var id int
err := db.QueryRow(ctx, "INSERT INTO users(name) VALUES($1) RETURNING id", name).Scan(&id)
```
