### 1) **Вопросы по опыту**

Здесь речь идет о вопросах, которые могут касаться предыдущего опыта работы. Нужно быть готовым рассказать о своих проектах, проблемах, с которыми столкнулся, и решениях, которые применялись.

### 2) **На каких командах редиса был организован кеш?**

Кеш Redis может использоваться для хранения часто запрашиваемых данных, таких как сессии, кэшированные результаты запросов, статистика. Важно настроить ключи и экспирацию так, чтобы они автоматически удалялись, когда больше не нужны.

### 3) **Как замерять пропускную способность на кафке?**

Пропускная способность Kafka может быть измерена с помощью метрик, таких как количество сообщений, отправленных за секунду, размер сообщений, задержка между продюсером и консюмером. Использовать инструменты, такие как `kafka-consumer-perf-test` и `kafka-producer-perf-test`, для проведения нагрузочных тестов и замера пропускной способности.

### 4) **Что такое оффсет в кафке?**

Оффсет в Kafka — это индекс в журнале, который указывает на позицию сообщения в партиции. Оффсет важен для отслеживания, какое сообщение было обработано, и для продолжения чтения с нужной позиции.

### 5) **Максимальное количество потребителей для партиции в одной группе?**

Максимальное количество потребителей в одной группе зависит от количества партиций в теме Kafka. Каждому потребителю в группе может быть назначена только одна партиция, так что количество потребителей не может превышать количество партиций. Если потребителей больше, чем партиций, некоторые потребители останутся неактивными.

### 6) **Если мы записываем историю действий пользователя и хочу агрегировать их, чтобы там обновлялся счёт пользователя. Как лучше организовать балансировку отправки событий на кафку?**

В Kafka можно использовать ключи для балансировки сообщений по партициям. Для агрегации действий пользователей, можно использовать идентификатор пользователя как ключ сообщения, чтобы все события этого пользователя попадали в одну партицию. Это обеспечит консистентность и правильную агрегацию.

### 7) **В потоке синхронно приходит количество списаний по пользователю. Как организовать асинхронную работу в данном случае? На что надо обращать внимание в случае использования Kafka настроек подписчика и настроек продюсера?**

Чтобы организовать асинхронную работу, можно использовать асинхронные вызовы в Kafka для записи данных, чтобы не блокировать основной поток. Важно настроить очередь сообщений и обработку ошибок (retry). Нужно контролировать настройки продюсера, такие как время ожидания подтверждения, и настройки подписчика, такие как автоматическое подтверждение сообщений или ручное.

### 8) **Что такое rest api?**

REST (Representational State Transfer) — это архитектурный стиль для создания веб-сервисов. API, использующие REST, работают через HTTP, отправляют запросы с использованием стандартных HTTP методов (GET, POST, PUT, DELETE), и могут использовать различные форматы данных, например, JSON.

### 9) **Что такое http?**

HTTP (HyperText Transfer Protocol) — это протокол передачи данных в интернете, который используется для обмена данными между клиентами и серверами. HTTP работает на основе запроса и ответа, где клиент отправляет запрос, а сервер возвращает ответ.

### 10) **Каким образом http запрос приходит от клиента до сервера? Описать весь flow**

1. Клиент отправляет HTTP-запрос на сервер, указав URL, метод (GET, POST и т.д.), заголовки и данные.
2. Запрос передается через интернет с помощью протоколов передачи данных.
3. Сервер обрабатывает запрос, выполняет необходимые операции (например, извлечение данных из базы данных).
4. Ответ отправляется обратно клиенту с данными, статусом выполнения и другими метаинформациями.

### 11) **Какие хендлеры можешь предложить при tcp коннекшне?**

При обработке TCP соединений можно использовать хендлеры для:

- Чтения данных из сокета.
- Записи данных в сокет.
- Обработки ошибок соединения.
- Таймаутов соединений.

### 12) **Отправляем запрос на rutube.ru, как он доходит до tcp уровня, когда он отправит запрос? Как этот запрос сервер обрабатывает?**

Запрос от клиента через HTTP поступает в DNS для разрешения домена. Затем используется IP-адрес для установления TCP-соединения. HTTP-запрос отправляется через TCP-соединение, и сервер обрабатывает его с помощью обработчика, который может включать веб-сервер и другие компоненты.

### 13) **В чём отличие 80 и 443 порты, принимающих клиентские запросы?**

Порт 80 используется для незашифрованного HTTP-трафика, а порт 443 — для HTTPS, который использует SSL/TLS для шифрования соединений.

### 14) **Что такое gRPC? Как называется формат передачи данных в gRPC?**

gRPC — это фреймворк для удаленных вызовов процедур (RPC), разработанный Google. Он использует HTTP/2 для связи и Protobuf (Protocol Buffers) как формат сериализации данных.

### 15) **Что означает поле Reserved?**

Поле "Reserved" обычно используется для зарезервированных значений в протоколах или структурах данных, чтобы избежать конфликтов с будущими версиями или расширениями.

### 16) **Зачем нужен int32 чем отличается от обычного int32?**

`int32` — это целое число, занимающее 32 бита. В Go тип `int` зависит от архитектуры системы (например, на 32-битных системах это тоже 32 бита, а на 64-битных системах — 64 бита). Таким образом, `int32` гарантирует фиксированную ширину, независимо от архитектуры.

### 17) **Чем отличается http2 от http1?**

HTTP/2 улучшает производительность по сравнению с HTTP/1, используя мультиплексирование (несколько запросов через одно соединение), сжатие заголовков, а также улучшенную приоритетизацию запросов.

### 18) **Какие кеши включаются http вносит для инфраструктуры?**

HTTP-кеши (например, в браузерах или на промежуточных прокси-серверах) могут использовать кеширование с помощью заголовков, таких как `Cache-Control`, `ETag`, `Last-Modified`. Это помогает уменьшить нагрузку на сервер и ускорить работу клиента.

### 19) **Что такое маска подсети?**

Маска подсети (или subnet mask) используется для разделения IP-адресов на сеть и хостовую часть. Она определяет, какая часть IP-адреса относится к сети, а какая — к хосту.

### 20) **Что такое - netcore?**

NetCore — это фреймворк для создания кроссплатформенных приложений от Microsoft, который включает в себя ASP.NET Core, Entity Framework Core и другие компоненты.

### 21) **Какие знаешь заголовки в http? И что они означают?**

Примеры HTTP-заголовков:

- `Content-Type` — указывает тип данных в теле запроса/ответа.
- `Authorization` — передает данные для аутентификации.
- `User-Agent` — информация о клиенте (например, браузер).
- `Accept` — типы данных, которые клиент готов принять.

### 22) **Что такое JWT токен?**

JSON Web Token (JWT) — это компактный и самостоятельный способ передачи данных между сторонами как JSON-объект. Он используется для аутентификации и авторизации в веб-приложениях.

### 23) **Какой образ осуществляет валидность JWT токен? Как бы ты сам без библиотек реализовал валидацию JWT?**

Для валидации JWT проверяется подпись токена с помощью секрета или публичного ключа, а также проверяются истечение срока действия и другие метаинформации. Без библиотек нужно вручную декодировать и проверить подпись и данные.
