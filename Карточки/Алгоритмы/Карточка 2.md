## 🧠 Алгоритмы — Карточки (26–50)

---

### 🟦 26

**Q:** Что такое "жадный алгоритм" (Greedy)?  
**A:** Алгоритм, который принимает локально оптимальные решения в надежде на глобальный максимум/минимум. Пример: задача о рюкзаке (без дробления), покрытие интервалов, сдача монет.

---

### 🟦 27

**Q:** Как распознать, что задачу можно решить жадно?  
**A:** Если можно доказать, что после локального выбора решение всё ещё оптимально (гарантированно). Часто — после сортировки.

---

### 🟦 28

**Q:** Что такое динамическое программирование (DP)?  
**A:** Метод решения задач, где результат зависит от подзадач. Использует кэширование (`memoization`) или таблицу (`tabulation`).

---

### 🟦 29

**Q:** Пример задачи с DP — лестница:

> Можно подниматься на 1 или 2 ступени. Сколько способов добраться до вершины?  
> **A:**

```go
func climbStairs(n int) int {
    if n <= 2 {
        return n
    }
    a, b := 1, 2
    for i := 3; i <= n; i++ {
        a, b = b, a+b
    }
    return b
}
```

---

### 🟦 30

**Q:** Что такое "подмассив с максимальной суммой"?  
**A:** Задача на алгоритм Кадане. Решается за `O(n)` — отслеживаем текущую и глобальную сумму.

---

### 🟦 31

**Q:** Зачем нужна табуляция в DP?  
**A:** Чтобы избежать переполнения стека и улучшить производительность. Подходит для итеративных задач.

---

### 🟦 32

**Q:** Что такое "треугольная матрица DP"?  
**A:** Используется в задачах типа палиндромов, сегментов и подстрок (например, в разбиении строки на палиндромы).

---

### 🟦 33

**Q:** Как найти наибольшую общую подпоследовательность (LCS)?  
**A:** DP с таблицей `dp[i][j]`, где `i`, `j` — позиции в двух строках.  
**Go (скелет):**

```go
func lcs(a, b string) int {
    dp := make([][]int, len(a)+1)
    for i := range dp {
        dp[i] = make([]int, len(b)+1)
    }
    for i := 1; i <= len(a); i++ {
        for j := 1; j <= len(b); j++ {
            if a[i-1] == b[j-1] {
                dp[i][j] = dp[i-1][j-1] + 1
            } else {
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
            }
        }
    }
    return dp[len(a)][len(b)]
}
```

---

### 🟦 34

**Q:** Что такое Z-функция?  
**A:** Строит массив `Z[i]`, где `Z[i]` — длина наибольшего префикса, совпадающего с суффиксом, начиная с `i`. Используется в поиске подстроки.

---

### 🟦 35

**Q:** Алгоритм Кнута-Морриса-Пратта (KMP) — зачем нужен?  
**A:** Быстрый поиск подстроки за `O(n + m)`, предварительно строит таблицу префиксов.

---

### 🟦 36

**Q:** Как реализуется манипуляция битами в Go?  
**A:** Используются операторы `&`, `|`, `^`, `<<`, `>>`. Пример:

```go
// Проверить i-й бит:
isSet := (num & (1 << i)) != 0
```

---

### 🟦 37

**Q:** Как работает алгоритм Дейкстры?  
**A:** Поддерживает приоритетную очередь. Для каждой вершины находит кратчайший путь от старта. Сложность: `O((V+E) log V)`.

---

### 🟦 38

**Q:** Что такое A* алгоритм?  
**A:** Модификация Дейкстры с эвристикой (обычно — расстояние Манхэттена или Евклида).

---

### 🟦 39

**Q:** Что такое мосты и точки сочленения в графе?  
**A:** Рёбра/вершины, удаление которых увеличивает число компонент связности. Находятся с помощью DFS и low-link значений.

---

### 🟦 40

**Q:** Алгоритм Тарьяна — для чего?  
**A:** Поиск сильно связанных компонент (SCC) в ориентированном графе.

---

### 🟦 41

**Q:** Зачем использовать Disjoint Set Union (DSU)?  
**A:** Для объединения множеств и быстрого поиска представителя. Используется в Kruskal's алгоритме.

---

### 🟦 42

**Q:** Что такое Kruskal’s алгоритм?  
**A:** Строит минимальное остовное дерево (MST), используя сортировку рёбер и DSU.

---

### 🟦 43

**Q:** Алгоритм Прима — отличие от Крускала?  
**A:** Прим выбирает вершину и растёт от неё, Крускал — по рёбрам, сортируя их.

---

### 🟦 44

**Q:** Как сжать координаты (coordinate compression)?  
**A:** Присваиваем уникальные индексы отсортированным значениям. Часто используется в задачах с большими диапазонами.

---

### 🟦 45

**Q:** Алгоритм Манакера (Manacher’s)?  
**A:** Позволяет найти все палиндромы в строке за `O(n)`. Используется в сложных задачах на строки.

---

### 🟦 46

**Q:** Как находить наименьший положительный пропущенный элемент?  
**A:** Использовать `O(n)` алгоритм с индексацией и swap.

---

### 🟦 47

**Q:** Что такое Trie (префиксное дерево)?  
**A:** Структура для хранения набора строк. Эффективна при поиске префиксов, автодополнении.

---

### 🟦 48

**Q:** Зачем нужен алгоритм Флойда-Уоршелла?  
**A:** Вычисляет кратчайшие пути между всеми парами вершин. Сложность `O(n³)`.

---

### 🟦 49

**Q:** Что такое сегментное дерево?  
**A:** Дерево для эффективных операций обновления и запроса на отрезках массива. Альтернатива префиксным суммам для изменяемых массивов.

---

### 🟦 50

**Q:** Что такое Fenwick Tree (Binary Indexed Tree)?  
**A:** Структура для обновления и запроса суммы префикса за `O(log n)`. Легче в реализации, чем сегментное дерево.
