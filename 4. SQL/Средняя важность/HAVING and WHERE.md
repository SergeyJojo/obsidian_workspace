Чтобы выбрать минимальную дату в SQL, используется агрегатная функция **`MIN()`**, которая возвращает минимальное значение из указанного столбца.

---

### 1. **Простое получение минимальной даты**

Если вы хотите выбрать самую раннюю дату из таблицы, можно сделать так:

**Пример: Найти минимальную дату из столбца `order_date` в таблице `orders`:**

```sql
SELECT MIN(order_date) AS earliest_date
FROM orders;
```

**Результат:**  
Вы получите одну строку с минимальной датой (самой ранней датой) из всей таблицы.

---

### 2. **Минимальная дата в группах**

Если вам нужно найти минимальную дату для каждой группы, используйте `GROUP BY`.

**Пример: Найти минимальную дату заказа для каждого клиента:**

```sql
SELECT customer_id, MIN(order_date) AS earliest_order_date
FROM orders
GROUP BY customer_id;
```

**Результат:**  
Этот запрос вернёт минимальную дату заказа для каждого клиента, сгруппировав строки по `customer_id`.

---

### 3. **Минимальная дата с другими условиями**

Если вам нужно отфильтровать строки перед поиском минимальной даты, используйте `WHERE`.

**Пример: Найти минимальную дату среди заказов, сделанных после 1 января 2025 года:**

```sql
SELECT MIN(order_date) AS earliest_date
FROM orders
WHERE order_date >= '2025-01-01';
```

---

### 4. **Минимальная дата с дополнительными данными**

Если нужно получить не только минимальную дату, но и связанные с ней данные (например, заказ, которому она принадлежит), это требует подзапроса или оконной функции.

#### Пример с подзапросом:

**Найти заказ с самой ранней датой:**

```sql
SELECT order_id, customer_id, order_date
FROM orders
WHERE order_date = (SELECT MIN(order_date) FROM orders);
```

- Здесь подзапрос `SELECT MIN(order_date) FROM orders` находит самую раннюю дату.
- Внешний запрос выбирает все строки, у которых дата совпадает с минимальной.

#### Пример с оконной функцией:

Если есть несколько строк с одинаковой минимальной датой, оконные функции позволяют получить их без дополнительного подзапроса:

```sql
SELECT order_id, customer_id, order_date
FROM (
    SELECT order_id, customer_id, order_date,
           RANK() OVER (ORDER BY order_date ASC) AS rank
    FROM orders
) ranked_orders
WHERE rank = 1;
```

- `RANK() OVER (ORDER BY order_date ASC)` присваивает строкам ранг, начиная с самой ранней даты.
- Внешний запрос выбирает строки с `rank = 1`, то есть строки с минимальной датой.

---

### Итог

Используйте:

- **`MIN()`** для нахождения минимальной даты.
- **`GROUP BY`** для минимальной даты в каждой группе.
- **Подзапросы** или **оконные функции**, если нужны дополнительные данные, связанные с минимальной датой.
