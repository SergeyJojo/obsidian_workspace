
Отличный и продвинутый вопрос! 🙌 `polldesc` в `netpoll` — это внутренняя структура в рантайме Go, которая лежит **в основе неблокирующего ввода-вывода**. Давай разложим по полочкам:

---

## 🧠 Кратко: что такое `polldesc`?

`polldesc` (poll descriptor) — это **описание** файлового дескриптора, зарегистрированного в **poller-е ядра Go** (epoll, kqueue, IOCP и т.д.), чтобы **асинхронно ждать событий** (например, готовность на чтение/запись).

> Это фундаментальная часть **сетевого стека Go**: вся работа с `net.TCPConn`, `net.Listener`, `http.Server` и прочим сетевым I/O проходит через `polldesc`.

---

## 🏛 Где это находится?

`polldesc` определён в исходниках Go — файл `runtime/netpoll.go`.

Вот примерно как он выглядит:

```go
type polldesc struct {
    lock    mutex
    fd      uintptr    // файловый дескриптор
    rg      uintptr    // goroutine, ждущая чтение
    wg      uintptr    // goroutine, ждущая запись
    ...
}
```

---

## ⚙️ Зачем он нужен?

Когда ты используешь, например:

```go
conn.Read(buf)
```

Go:

1. Регистрирует дескриптор сокета в `netpoller` через `polldesc`
    
2. Проверяет, можно ли читать (poll)
    
3. Если **нет** — текущая горутина **блокируется**, а `polldesc.rg` запоминает, кто ждёт
    
4. Когда сокет готов к чтению (epoll или другой poller сообщает) — Go **разблокирует** горутину
    

То же для `Write()` — но через `polldesc.wg`.

---

## 📡 Как работает netpoll в Go?

1. При запуске Go создаёт **epoll (на Linux)** или **kqueue (на BSD/macOS)** или **IOCP (на Windows)**
    
2. Каждое подключение регистрируется через `netpollopen`, где создаётся `polldesc`
    
3. При каждом `Read()`/`Write()` Go:
    
    - проверяет, готов ли fd
        
    - если не готов → спит, пока событие не произойдёт
        
4. Когда событие наступает — Go пробуждает нужную горутину (через `netpollblock` → `netpollready`)
    

---

## 🧬 Почему это эффективно?

Go не делает 1:1 блокировку `Read()` как `read(2)` — вместо этого:

- Использует один поток-поллер (на уровне ядра)
    
- Асинхронно блокирует только нужные горутины
    
- Не нужен `select {}` или `poll()` руками
    

И всё это — благодаря `polldesc`.
