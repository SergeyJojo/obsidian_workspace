Вот краткая теория для быстрого воспроизведения LRU (Least Recently Used) cache — как он работает и что нужно создавать при реализации:

---

## Как работает LRU cache

- **Цель**: хранить только N последних использованных ключей/значений, чтобы при превышении лимита удалять самый давно не используемый элемент.
- **Принцип**: когда происходит доступ к элементу — он становится "самым новым" (recently used). Когда нужно удалить — удаляется "самый старый" (least recently used).

---

## Что нужно для быстрой реализации (O(1) операции)

1. **Хеш-таблица (map/dictionary)**
    - Быстрый доступ по ключу (`map[key] => *Node`)
    - Хранит пары "ключ — ссылка на элемент в двусвязном списке"

2. **Двусвязный список**
    - Узлы содержат ключи и значения
    - "Голова" списка — самый недавно использованный элемент
    - "Хвост" списка — самый давно не использованный (кандидат на удаление)
    - Легко перемещать элементы в начало/удалять из конца за O(1)
  
---

## Основные операции

- **Get(key)**:
    - Если ключ есть в map:
        - Достать узел из списка, переместить его в начало (он стал самым новым)
        - Вернуть значение
    - Если нет — вернуть miss

- **Put(key, value)**:
    - Если ключ уже есть:
        - Обновить значение в узле, переместить в начало
    - Если ключа нет:
        - Если размер == максимальный:
            - Удалить хвост (least recently used) и убрать соответствующий ключ из map
        - Добавить новый узел в начало списка, добавить в map

---

## Структуры данных, которые нужно создать

- **Node (узел списка)**:
    - key
    - value
    - prev, next (ссылки на соседей)

- **Hash map**:
    - key → *Node

- **Двусвязный список**:
    - head, tail (фиктивные или реальные)
    - Методы для перемещения узлов, вставки в начало, удаления из конца

---

## Визуальная схема

```
map: {
    "a": *NodeA,
    "b": *NodeB,
    ...
}

двусвязный список:
    head <-> NodeB <-> NodeA <-> NodeC <-> tail
             |         |         |
           new      ...      old (LRU)
```

---

### Минимальный набор для воспоминания:

- Map для поиска по ключу
- Двусвязный список для порядка использования (новые — впереди, старые — сзади)
- Операции: get, put, move to front, remove tail
