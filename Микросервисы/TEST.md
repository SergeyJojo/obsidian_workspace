## **Что такое профилирование?**

Профилирование — это процесс анализа производительности программы для выявления узких мест (bottlenecks). В Go профилирование помогает понять, где программа тратит больше всего времени (CPU), памяти (Memory) или других ресурсов.

---

## **Основные типы профилирования в Go**

1. **Профилирование CPU**:
   - Анализ использования процессора.
   - Показывает, какие функции потребляют больше всего CPU.

2. **Профилирование памяти (Heap)**:
   - Анализ использования оперативной памяти.
   - Показывает, какие функции выделяют больше всего памяти.

3. **Профилирование блокировок (Block)**:
   - Анализ блокировок (например, мьютексы, каналы).
   - Показывает, где программа тратит время на ожидание.

4. **Профилирование горутин (Goroutine)**:
   - Анализ состояния горутин.
   - Показывает, сколько горутин работает, ожидает или заблокировано.

5. **Профилирование трассировки (Trace)**:
   - Анализ выполнения программы с течением времени.
   - Показывает, как горутины взаимодействуют и как распределяются ресурсы.

## **Инструменты для профилирования в Go**

### **1. Встроенные инструменты Go**
Go предоставляет встроенные инструменты для профилирования через пакет `pprof`.

#### **Как использовать:**
1. Импортируйте пакет `net/http/pprof`:
   ```go
   import _ "net/http/pprof"
   ```
2. Запустите HTTP-сервер для доступа к профилям:
   ```go
   go func() {
       log.Println(http.ListenAndServe("localhost:6060", nil))
   }()
   ```
3. Откройте браузер и перейдите по адресу `http://localhost:6060/debug/pprof/`.

#### **Доступные профили:**
- **CPU**: `/debug/pprof/profile?seconds=30` (30 секунд профилирования CPU).
- **Memory**: `/debug/pprof/heap`.
- **Block**: `/debug/pprof/block`.
- **Goroutine**: `/debug/pprof/goroutine`.
- **Trace**: `/debug/pprof/trace?seconds=5` (5 секунд трассировки).

---

### **2. Утилита `go tool pprof`**
Утилита `go tool pprof` позволяет анализировать профили из командной строки или через веб-интерфейс.

#### **Пример использования:**
1. Соберите профиль CPU:
   ```bash
   go tool pprof http://localhost:6060/debug/pprof/profile?seconds=30
   ```
2. Соберите профиль памяти:
   ```bash
   go tool pprof http://localhost:6060/debug/pprof/heap
   ```
3. Откройте веб-интерфейс:
   ```bash
   go tool pprof -http=:8080 profile.out
   ```

---

### **3. Утилита `go tool trace`**
Утилита `go tool trace` позволяет анализировать трассировки выполнения программы.

#### **Пример использования:**
1. Соберите трассировку:
   ```bash
   curl http://localhost:6060/debug/pprof/trace?seconds=5 > trace.out
   ```
2. Откройте трассировку:
   ```bash
   go tool trace trace.out
   ```

---

### **4. Сторонние инструменты**
- **Pyroscope**: инструмент для непрерывного профилирования.
- **Datadog**: инструмент для мониторинга и профилирования в реальном времени.
- **Grafana**: визуализация метрик и профилей.

## **Примеры использования профилирования**

### **1. Профилирование CPU**
```go
package main

import (
    "log"
    "net/http"
    _ "net/http/pprof"
    "time"
)

func main() {
    go func() {
        log.Println(http.ListenAndServe("localhost:6060", nil))
    }()

    for {
        cpuIntensiveTask()
    }
}

func cpuIntensiveTask() {
    for i := 0; i < 1000000; i++ {
        _ = i * i
    }
    time.Sleep(100 * time.Millisecond)
}
```
- Запустите программу и откройте `http://localhost:6060/debug/pprof/`.
- Соберите профиль CPU:
  ```bash
  go tool pprof http://localhost:6060/debug/pprof/profile?seconds=30
  ```

### **2. Профилирование памяти**
```go
package main

import (
    "log"
    "net/http"
    _ "net/http/pprof"
    "time"
)

func main() {
    go func() {
        log.Println(http.ListenAndServe("localhost:6060", nil))
    }()

    for {
        memoryIntensiveTask()
    }
}

func memoryIntensiveTask() {
    var data []int
    for i := 0; i < 100000; i++ {
        data = append(data, i)
    }
    time.Sleep(100 * time.Millisecond)
}
```
- Соберите профиль памяти:
  ```bash
  go tool pprof http://localhost:6060/debug/pprof/heap
  ```
