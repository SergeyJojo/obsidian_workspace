## ✅ **1. Слияние двух отсортированных массивов**

### 🔹 Условие:

Даны два отсортированных массива `A` и `B`. Нужно объединить их в один отсортированный массив.

### 📌 Пример:

```go
A = [1, 2, 5]
B = [1, 2, 3, 4, 6]

// Вывод:
[1, 1, 2, 2, 3, 4, 5, 6]
```

---

## 🧠 Идея решения:

Используем два указателя: `i` — для массива `A`, `j` — для массива `B`.

На каждом шаге сравниваем `A[i]` и `B[j]`, и добавляем меньшее в результирующий массив.

Когда один массив закончится — просто добавляем остаток второго.

---

## ✅ Реализация на Go

```go
package main

import (
	"fmt"
)

func mergeSortedArrays(a, b []int) []int {
	result := make([]int, 0, len(a)+len(b))
	i, j := 0, 0

	for i < len(a) && j < len(b) {
		if a[i] <= b[j] {
			result = append(result, a[i])
			i++
		} else {
			result = append(result, b[j])
			j++
		}
	}

	// добавим остатки
	result = append(result, a[i:]...)
	result = append(result, b[j:]...)

	return result
}

func main() {
	a := []int{1, 2, 5}
	b := []int{1, 2, 3, 4, 6}
	merged := mergeSortedArrays(a, b)
	fmt.Println(merged) // [1 1 2 2 3 4 5 6]
}
```

---

## 📈 Сложность

- **Время**: `O(n + m)` — проходим оба массива один раз.
    
- **Память**: `O(n + m)` — создаётся новый массив.
