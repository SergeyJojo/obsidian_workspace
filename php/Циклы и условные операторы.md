Разберём базовые **элементы управления потоком** в PHP — то есть **циклы, условные операторы, ветвления, break/continue, switch** и т.д.

---

## 🧩 Условные операторы

### `if`, `elseif`, `else`

```php
$x = 10;

if ($x > 0) {
    echo "Положительное число";
} elseif ($x < 0) {
    echo "Отрицательное число";
} else {
    echo "Ноль";
}
```

Можно писать и в короткой форме:

```php
if ($x > 0) echo "Положительное";
```

---

### Тернарный оператор `?:`

```php
$result = ($x > 0) ? "Плюс" : "Минус";
```

---

### Оператор "null coalescing" (`??`)

Возвращает первый операнд, который **не равен null**.

```php
$name = $_GET['name'] ?? 'Гость';
```

---

### `switch`

```php
$day = 'Mon';

switch ($day) {
    case 'Mon':
        echo "Понедельник";
        break;
    case 'Tue':
        echo "Вторник";
        break;
    default:
        echo "Неизвестный день";
}
```

---

## 🔁 Циклы

### `while`

```php
$i = 0;
while ($i < 5) {
    echo $i;
    $i++;
}
```

---

### `do ... while`

Выполняется хотя бы один раз:

```php
$i = 0;
do {
    echo $i;
    $i++;
} while ($i < 5);
```

---

### `for`

```php
for ($i = 0; $i < 5; $i++) {
    echo $i;
}
```

---

### `foreach`

Используется для массивов и коллекций.

```php
$fruits = ['apple', 'banana', 'cherry'];

foreach ($fruits as $fruit) {
    echo $fruit;
}
```

С ключами:

```php
foreach ($fruits as $key => $value) {
    echo "$key => $value";
}
```

---

## ⛔ Управление циклом

### `break`

Прерывает выполнение цикла.

```php
for ($i = 0; $i < 10; $i++) {
    if ($i == 5) break;
    echo $i;
}
```

### `continue`

Переходит к следующей итерации.

```php
for ($i = 0; $i < 10; $i++) {
    if ($i % 2 == 0) continue;
    echo $i;
}
```

---

## 🧠 Полезно знать

- **Альтернативный синтаксис** (часто используется в шаблонах):
    
    ```php
    if ($x > 0):
        echo "Положительное";
    else:
        echo "Не положительное";
    endif;
    ```
    
- **Оператор `match`** (с PHP 8+ — аналог `switch`, но выражение):
    
    ```php
    $result = match ($day) {
        'Mon' => 'Понедельник',
        'Tue' => 'Вторник',
        default => 'Неизвестно',
    };
    ```
