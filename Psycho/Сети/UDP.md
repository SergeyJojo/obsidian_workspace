## 📌 Что такое UDP?

**UDP** — это транспортный протокол из семейства IP-протоколов. Он работает **без установления соединения** (в отличие от TCP) и предназначен для **максимально быстрой** доставки данных, **без гарантии** их получения, порядка или проверки ошибок на уровне транспорта.

UDP — это протокол из философии **“fire-and-forget”** — "отправь и забудь".

---

## 📚 Основные характеристики UDP

|Характеристика|Описание|
|---|---|
|Протокол|Без соединения (connectionless)|
|Надёжность|Нет гарантии доставки, порядка или защиты от дубликатов|
|Контроль потока и перегрузки|Нет|
|Производительность|Высокая, за счёт низких накладных расходов|
|Формат данных|Отправляются **датаграммы** (datagrams), по сути — независимые пакеты|
|Проверка целостности|Только простая контрольная сумма (CRC)|
|Поддержка многокаста|Есть (в отличие от TCP)|

---

## 📦 Структура заголовка UDP

Заголовок UDP очень простой — **всего 8 байт**:

|Поле|Размер|Назначение|
|---|---|---|
|Source Port|2 байта|Порт отправителя|
|Destination Port|2 байта|Порт получателя|
|Length|2 байта|Длина заголовка + данных|
|Checksum|2 байта|Контрольная сумма|

## 📈 Преимущества UDP

1. **Быстрее, чем TCP**, благодаря отсутствию:
    
    - подтверждений доставки,
        
    - установления соединения (handshake),
        
    - контроля потока,
        
    - повторных передач.
        
2. **Меньше накладных расходов** (заголовок всего 8 байт против 20 байт у TCP).
    
3. **Поддержка мультикаста** и **broadcast'а**, что важно для стриминга и вещания.
    
4. **Идеально подходит для real-time** приложений:
    
    - игры,
        
    - видеозвонки (VoIP),
        
    - стриминг аудио/видео,
        
    - DNS-запросы.
        

---

## ⚠️ Недостатки UDP

1. **Нет гарантии доставки** — потерянный пакет не будет повторно отправлен.
    
2. **Нет порядка** — пакеты могут прийти в любом порядке.
    
3. **Нет защиты от дубликатов**.
    
4. **Не масштабируется** при плохих сетевых условиях.
    
5. **Сложная реализация логики надёжности** на уровне приложения (если нужна).

## 🔄 UDP vs TCP

|Критерий|UDP|TCP|
|---|---|---|
|Надёжность|Нет|Да|
|Порядок доставки|Нет|Да|
|Повторная передача|Нет|Да|
|Мультикаст|Да|Нет|
|Используется для|DNS, стриминг, VoIP, игры|HTTP, FTP, SMTP, SSH|
|Заголовок|8 байт|20 байт|
|Подключение|Нет соединения|Handshake (3-way)|

---

## 📡 Примеры использования UDP

1. **DNS (53 порт)** — быстрые запросы на IP-адреса.
    
2. **VoIP (SIP, RTP)** — звонки по сети, важно быстро, не обязательно идеально.
    
3. **Онлайн-игры** — особенно шутеры, где "сейчас > точно".
    
4. **Видео-стриминг** — например, RTSP поверх UDP.
    
5. **Syslog** — отправка логов без гарантии.

## 📌 UDP в Go

### Пример UDP-сервера:

```go
package main

import (
	"fmt"
	"net"
)

func main() {
	addr, _ := net.ResolveUDPAddr("udp", ":9999")
	conn, _ := net.ListenUDP("udp", addr)
	defer conn.Close()

	buf := make([]byte, 1024)
	for {
		n, remoteAddr, _ := conn.ReadFromUDP(buf)
		fmt.Printf("Received from %s: %s\n", remoteAddr, string(buf[:n]))
	}
}
```

### Пример UDP-клиента:

```go
package main

import (
	"net"
)

func main() {
	conn, _ := net.Dial("udp", "localhost:9999")
	defer conn.Close()

	conn.Write([]byte("Hello via UDP"))
}
```
