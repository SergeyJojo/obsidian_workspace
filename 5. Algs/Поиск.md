
В языке Go можно реализовать различные алгоритмы поиска, которые позволяют находить элементы в данных. Здесь я представлю несколько распространённых алгоритмов поиска: линейный поиск, бинарный поиск и поиск в графах с использованием поиска в глубину (DFS) и поиска в ширину (BFS).

### 1. Линейный поиск (Linear Search)

Линейный поиск — это самый простой способ поиска элемента в массиве или срезе. Он проверяет каждый элемент по очереди, пока не найдёт искомый.

#### Пример реализации линейного поиска:

```go
package main

import "fmt"

// Линейный поиск
func linearSearch(arr []int, target int) int {
    for i, v := range arr {
        if v == target {
            return i // Возвращаем индекс элемента
        }
    }
    return -1 // Если элемент не найден, возвращаем -1
}

func main() {
    arr := []int{10, 20, 30, 40, 50}
    target := 30
    index := linearSearch(arr, target)

    if index != -1 {
        fmt.Printf("Элемент найден на индексе %d\n", index)
    } else {
        fmt.Println("Элемент не найден")
    }
}
```

**Оценка сложности**:

- Время: **O(n)**, где **n** — количество элементов в массиве.
- Пространство: **O(1)**.

### 2. Бинарный поиск (Binary Search)

Бинарный поиск — это эффективный алгоритм поиска элемента в отсортированном массиве. Он работает путём деления массива пополам и продолжения поиска в половине, в которой может находиться искомый элемент.

#### Пример реализации бинарного поиска:

```go
package main

import "fmt"

// Бинарный поиск
func binarySearch(arr []int, target int) int {
    left, right := 0, len(arr)-1
    for left <= right {
        mid := (left + right) / 2
        if arr[mid] == target {
            return mid // Элемент найден
        } else if arr[mid] < target {
            left = mid + 1 // Ищем справа
        } else {
            right = mid - 1 // Ищем слева
        }
    }
    return -1 // Элемент не найден
}

func main() {
    arr := []int{1, 3, 5, 7, 9, 11, 13, 15}
    target := 7
    index := binarySearch(arr, target)

    if index != -1 {
        fmt.Printf("Элемент найден на индексе %d\n", index)
    } else {
        fmt.Println("Элемент не найден")
    }
}
```

**Оценка сложности**:

- Время: **O(log n)**, где **n** — количество элементов в массиве.
- Пространство: **O(1)**.

### 3. Поиск в глубину (Depth-First Search, DFS) для графа

Поиск в глубину — это алгоритм для обхода графа. Он сначала посещает все возможные пути от текущей вершины до конца, а затем возвращается и переходит к другим вершинам.

#### Пример реализации поиска в глубину (DFS) на графе:

```go
package main

import "fmt"

// Поиск в глубину для графа
func dfs(graph map[int][]int, start int, visited map[int]bool) {
    // Отметить вершину как посещённую
    visited[start] = true
    fmt.Println(start) // Выводим вершину

    // Рекурсивно обходим соседей
    for _, neighbor := range graph[start] {
        if !visited[neighbor] {
            dfs(graph, neighbor, visited)
        }
    }
}

func main() {
    // Граф представлен в виде списка смежности
    graph := map[int][]int{
        1: {2, 3},
        2: {1, 4, 5},
        3: {1},
        4: {2},
        5: {2},
    }

    visited := make(map[int]bool)
    dfs(graph, 1, visited)
}
```

**Оценка сложности**:

- Время: **O(V + E)**, где **V** — количество вершин, **E** — количество рёбер в графе.
- Пространство: **O(V)** для хранения информации о посещённых вершинах.

### 4. Поиск в ширину (Breadth-First Search, BFS) для графа

Поиск в ширину — это алгоритм для обхода графа, который посещает все вершины на одном уровне (соседей) перед тем, как перейти к следующему уровню.

#### Пример реализации поиска в ширину (BFS) на графе:

```go
package main

import "fmt"

// Поиск в ширину для графа
func bfs(graph map[int][]int, start int) {
    visited := make(map[int]bool)
    queue := []int{start}

    visited[start] = true

    for len(queue) > 0 {
        current := queue[0]
        queue = queue[1:]
        fmt.Println(current) // Выводим вершину

        // Обрабатываем соседей текущей вершины
        for _, neighbor := range graph[current] {
            if !visited[neighbor] {
                visited[neighbor] = true
                queue = append(queue, neighbor)
            }
        }
    }
}

func main() {
    // Граф представлен в виде списка смежности
    graph := map[int][]int{
        1: {2, 3},
        2: {1, 4, 5},
        3: {1},
        4: {2},
        5: {2},
    }

    bfs(graph, 1)
}
```

**Оценка сложности**:

- Время: **O(V + E)**, где **V** — количество вершин, **E** — количество рёбер в графе.
- Пространство: **O(V)** для хранения информации о посещённых вершинах и очереди.

### Заключение

В Go можно реализовать различные алгоритмы поиска, включая линейный поиск, бинарный поиск, а также алгоритмы поиска в графах, такие как DFS и BFS. Каждый из них имеет своё предназначение и используется в зависимости от задачи. Линейный поиск подходит для небольших данных, бинарный поиск эффективен на отсортированных массивах, а DFS и BFS необходимы для работы с графами.
