## 🟩 **Задача 9 — Печать конечных узлов рубрикатора**

🔹 Аналог: задачи на **обход дерева**, например:  
[Leetcode 257. Binary Tree Paths](https://leetcode.com/problems/binary-tree-paths/) — вывод всех путей от корня до листа.

---

### 📋 Условие

Дано дерево рубрикатора (возможно, n-арное). У каждого узла есть:

```go
type Node struct {
	Text     string
	Children []*Node
}
```

Нужно **распечатать все пути от корня до конечных узлов**, т.е. **листьев** (узлов без детей), по формату:

```
Вещи/Одежда/Мужская
Хобби/Мангалы
Транспорт
```

---

## 🧠 Идея

Классический **DFS (обход в глубину)**.

- На каждом шаге передаём префикс пути.
    
- Если у узла нет детей — выводим путь.
    

---

## ✅ Реализация на Go

```go
package main

import (
	"fmt"
	"strings"
)

type Node struct {
	Text     string
	Children []*Node
}

func printLeafPaths(node *Node, path []string) {
	if node == nil {
		return
	}

	// Добавим текущий узел к пути
	path = append(path, node.Text)

	if len(node.Children) == 0 {
		// Это конечный узел
		fmt.Println(strings.Join(path, "/"))
		return
	}

	for _, child := range node.Children {
		printLeafPaths(child, path)
	}
}

func main() {
	// Пример рубрикатора
	root := &Node{Text: "Вещи", Children: []*Node{
		{Text: "Одежда", Children: []*Node{
			{Text: "Мужская"},
			{Text: "Женская"},
		}},
		{Text: "Мебель"},
		{Text: "Посуду"},
	}}

	hobby := &Node{Text: "Хобби", Children: []*Node{
		{Text: "Велосипеды", Children: []*Node{
			{Text: "Горные"},
		}},
		{Text: "Мангалы"},
	}}

	root2 := &Node{Text: "Каталог", Children: []*Node{
		root,
		hobby,
		{Text: "Транспорт"},
	}}

	// Печать всех конечных путей
	printLeafPaths(root2, []string{})
}
```

---

## 📈 Сложность

- **Время**: `O(N)` — N = число узлов
    
- **Память**: `O(H)` — глубина стека вызовов (максимальная глубина дерева)
    

---

## 🧪 Edge Cases

- Пустое дерево → ничего не печатаем
    
- Один узел (корень) → просто его имя
    
- Глубокое дерево — корректная рекурсия
    

---

## 🧩 Варианты улучшения

- Поддержка произвольных разделителей (`/`, `=>`, `->`)
    
- Возврат результата вместо печати (например, `[]string`)
    
- Сортировка путей
