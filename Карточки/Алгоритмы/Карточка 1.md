### 🟦 1

**Q:** Что такое «двойной указатель» в бинарном поиске и зачем он нужен?  
**A:** Это `left` и `right` — границы поиска. Такой подход используется для поиска элемента в отсортированном массиве.  
**Go:**

```go
func binarySearch(arr []int, target int) int {
    left, right := 0, len(arr)-1
    for left <= right {
        mid := left + (right-left)/2
        if arr[mid] == target {
            return mid
        } else if arr[mid] < target {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    return -1
}
```

### 🟦 2

**Q:** Как работает сортировка слиянием (Merge Sort)?  
**A:** Рекурсивно делит массив пополам, сортирует и сливает. Сложность `O(n log n)`.

### 🟦 3

**Q:** Когда использовать быструю сортировку (Quick Sort)?  
**A:** Если важна скорость в среднем случае. Худший случай — `O(n²)` без рандомизации.

### 🟦 4

**Q:** Как работает BFS?  
**A:** Обходит граф по уровням. Использует очередь.

---

### 🟦 5

**Q:** Как реализовать BFS в Go?

```go
func BFS(start int, graph map[int][]int) []int {
    visited := map[int]bool{}
    queue := []int{start}
    order := []int{}
    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        if visited[node] {
            continue
        }
        visited[node] = true
        order = append(order, node)
        queue = append(queue, graph[node]...)
    }
    return order
}
```

**Q:** Что такое DFS и чем он отличается от BFS?  
**A:** DFS (обход в глубину) использует стек (неявно — рекурсия), а BFS — очередь.

### 🟦 9

**Q:** Как решать задачу "сумма двух чисел" (`two sum`)?  
**A:** Использовать `map[int]int` для хранения дополняющего значения.  
**Go:**

```go
func twoSum(nums []int, target int) []int {
    m := map[int]int{}
    for i, num := range nums {
        if j, ok := m[target-num]; ok {
            return []int{j, i}
        }
        m[num] = i
    }
    return nil
}
```

### 🟦 15

**Q:** Как реализовать min-heap в Go?

```go
type IntHeap []int
func (h IntHeap) Len() int           { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *IntHeap) Push(x any)        { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[0 : n-1]
    return x
}
```

### 🟦 18

**Q:** Как реализовать DFS на дереве?

func dfs(node *TreeNode) {
    if node == nil { return }
    fmt.Println(node.Val)

### 🟦 19

**Q:** Как найти наибольший общий делитель (GCD)?  
**A:** Алгоритм Евклида.

```go
func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}
```

### 🟦 20

**Q:** Что такое topological sort?  
**A:** Линейная сортировка DAG (ориентированного ацикличного графа). Используется, например, в планировщиках задач.

### 🟦 21

**Q:** Как быстро возводить в степень?  
**A:** Binary exponentiation (разделяй и властвуй).

```go
func pow(a, b int) int {
    res := 1
    for b > 0 {
        if b%2 == 1 {
            res *= a
        }
        a *= a
        b /= 2
    }
    return res
}
```

### 🟦 23

**Q:** Как работают бинарные деревья поиска (BST)?  
**A:** Левое поддерево содержит меньшие элементы, правое — большие.

---

### 🟦 24

**Q:** Как проверить, является ли дерево BST?  
**A:** Проверить, что `Left < Node < Right` для всех узлов, рекурсивно.

---

**A:** Алгоритм полного перебора с откатом. Используется в задачах на генерацию комбинаций, N-Queens и др.
