
### 📌 **Основные команды Docker**

1. **Проверка версии Docker**:
    
    ```bash
    docker --version
    ```
    
2. **Запуск контейнера**: Чтобы запустить контейнер на основе образа:
    
    ```bash
    docker run [OPTIONS] IMAGE [COMMAND] [ARG...]
    ```
    
    Пример:
    
    ```bash
    docker run -d -p 8080:80 nginx
    ```
    
3. **Запуск контейнера в интерактивном режиме**: Если хотите получить доступ к контейнеру в интерактивном режиме:
    
    ```bash
    docker run -it ubuntu /bin/bash
    ```
    
4. **Просмотр запущенных контейнеров**: Чтобы увидеть все активные контейнеры:
    
    ```bash
    docker ps
    ```
    
5. **Просмотр всех контейнеров (включая остановленные)**: Чтобы увидеть все контейнеры:
    
    ```bash
    docker ps -a
    ```
    
6. **Остановка контейнера**: Чтобы остановить контейнер по его имени или ID:
    
    ```bash
    docker stop <container_name_or_id>
    ```
    
7. **Удаление контейнера**: Чтобы удалить контейнер:
    
    ```bash
    docker rm <container_name_or_id>
    ```
    
8. **Удаление всех остановленных контейнеров**: Чтобы удалить все остановленные контейнеры:
    
    ```bash
    docker container prune
    ```
    
9. **Просмотр логов контейнера**: Чтобы увидеть логи контейнера:
    
    ```bash
    docker logs <container_name_or_id>
    ```
    
10. **Запуск контейнера в фоновом режиме**: Чтобы запустить контейнер в фоновом режиме:
    
    ```bash
    docker run -d <image_name>
    ```
    
11. **Получение информации о контейнере**: Чтобы получить подробную информацию о контейнере:
    
    ```bash
    docker inspect <container_name_or_id>
    ```
    
12. **Посмотреть все образы**: Для того чтобы просматривать все образы:
    
    ```bash
    docker images
    ```
    
13. **Удаление образа**: Чтобы удалить образ:
    
    ```bash
    docker rmi <image_name_or_id>
    ```
    
14. **Сборка образа из Dockerfile**: Для создания нового образа:
    
    ```bash
    docker build -t <image_name> .
    ```
    
15. **Копирование файлов из контейнера**: Чтобы скопировать файлы из контейнера на хост:
    
    ```bash
    docker cp <container_name_or_id>:<path_in_container> <path_on_host>
    ```
    
16. **Копирование файлов в контейнер**: Чтобы скопировать файлы с хоста в контейнер:
    
    ```bash
    docker cp <path_on_host> <container_name_or_id>:<path_in_container>
    ```
    
17. **Запуск команды в работающем контейнере**: Для выполнения команды внутри контейнера:
    
    ```bash
    docker exec -it <container_name_or_id> <command>
    ```
    
    Пример:
    
    ```bash
    docker exec -it <container_name_or_id> bash
    ```
    
18. **Удаление неиспользуемых образов, контейнеров и томов**: Чтобы очистить систему от неиспользуемых ресурсов:
    
    ```bash
    docker system prune
    ```
    
19. **Просмотр использования ресурсов Docker**: Чтобы проверить использование памяти, процессора и других ресурсов:
    
    ```bash
    docker stats
    ```
    
20. **Работа с сетями Docker**: Чтобы увидеть все сети:
    
    ```bash
    docker network ls
    ```

### 📌 **Основные команды Docker Compose**

1. **Запуск сервисов**: Для запуска всех сервисов, описанных в `docker-compose.yml`:
    
    ```bash
    docker-compose up
    ```
    
2. **Запуск сервисов в фоновом режиме** (detached mode): Чтобы запустить контейнеры в фоновом режиме:
    
    ```bash
    docker-compose up -d
    ```
    
3. **Остановка сервисов**: Чтобы остановить сервисы:
    
    ```bash
    docker-compose down
    ```
    
4. **Остановка сервисов, но с сохранением данных**: Чтобы остановить сервисы, но не удалять их данные:
    
    ```bash
    docker-compose stop
    ```
    
5. **Запуск конкретного сервиса**: Чтобы запустить только один сервис (например, базу данных):
    
    ```bash
    docker-compose up <service_name>
    ```
    
6. **Просмотр логов**: Для просмотра логов всех сервисов:
    
    ```bash
    docker-compose logs
    ```
    
    Для просмотра логов конкретного сервиса:
    
    ```bash
    docker-compose logs <service_name>
    ```
    
7. **Перезапуск сервисов**: Чтобы перезапустить все сервисы:
    
    ```bash
    docker-compose restart
    ```
    
    Для перезапуска одного сервиса:
    
    ```bash
    docker-compose restart <service_name>
    ```
    
8. **Просмотр состояния сервисов**: Чтобы увидеть текущие состояния всех сервисов:
    
    ```bash
    docker-compose ps
    ```
    
9. **Сборка образов для сервисов**: Если у вас есть изменения в `Dockerfile`, нужно пересобрать образы:
    
    ```bash
    docker-compose build
    ```
    
10. **Запуск команд внутри контейнеров**: Для выполнения команды в контейнере, используя сервис из Compose:
    
    ```bash
    docker-compose exec <service_name> <command>
    ```
    
    Пример:
    
    ```bash
    docker-compose exec app bash
    ```
    
11. **Уничтожение контейнеров, образов и томов**: Чтобы полностью удалить все сервисы, тома и сети:
    
    ```bash
    docker-compose down --volumes --remove-orphans
    ```
    
12. **Проверка конфигурации Compose**: Для проверки корректности конфигурации в `docker-compose.yml`:
    
    ```bash
    docker-compose config
    ```
    
13. **Масштабирование сервисов**: Чтобы масштабировать сервисы (например, запустить несколько экземпляров приложения):
    
    ```bash
    docker-compose up --scale <service_name>=<number_of_instances>
    ```
    
14. **Создание и запуск контейнеров в одном шаге**: Это позволит вам сначала собрать все сервисы, а затем запустить их:
    
    ```bash
    docker-compose up --build
    ```
    
15. **Получение информации о сервисах**: Для получения подробной информации о текущих сервисах, их сети и контейнерах:
    
    ```bash
    docker-compose ps -a
    ```

### 📌 **Заключение**

Работа с **Docker** и **Docker Compose** предполагает множество команд для управления контейнерами, образами, сетями и томами. Чтобы эффективно использовать эти инструменты, важно освоить основные команды для:

- **Запуска и остановки контейнеров**.
- **Работы с образами и томами**.
- **Мониторинга логов и состояния сервисов**.
- **Масштабирования и управления многоконтейнерными приложениями** с помощью Docker Compose.

Этот список команд является основой для эффективной работы с Docker и Docker Compose.
