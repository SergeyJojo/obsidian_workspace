Вот PHP-версия вашего Go кода для задачи о суммаризации диапазонов:

```php
<?php

function summaryRanges($nums) {
    if (empty($nums)) {
        return [];
    }

    $result = [];
    $start = $nums[0];

    for ($i = 1; $i < count($nums); $i++) {
        if ($nums[$i] != $nums[$i - 1] + 1) {
            if ($start == $nums[$i - 1]) {
                $result[] = (string)$start;
            } else {
                $result[] = $start . "->" . $nums[$i - 1];
            }
            $start = $nums[$i];
        }
    }

    // Добавляем последний диапазон
    if ($start == $nums[count($nums) - 1]) {
        $result[] = (string)$start;
    } else {
        $result[] = $start . "->" . $nums[count($nums) - 1];
    }

    return $result;
}

// Тестирование
$nums = [1, 2, 3, 5, 8, 9, 10];
echo "Результат: " . implode(", ", summaryRanges($nums)) . "\n";

// Дополнительные тесты
$testCases = [
    [0, 1, 2, 4, 5, 7],
    [1, 3, 4, 6, 8, 9],
    [],
    [1],
    [1, 2, 3, 4, 5],
    [1, 3, 5, 7, 9]
];

foreach ($testCases as $testCase) {
    $result = summaryRanges($testCase);
    echo "[" . implode(", ", $testCase) . "] => [" . implode(", ", $result) . "]\n";
}
```

**Результат выполнения:**
```
Результат: 1->3, 5, 8->10
[0, 1, 2, 4, 5, 7] => [0->2, 4->5, 7]
[1, 3, 4, 6, 8, 9] => [1, 3->4, 6, 8->9]
[] => []
[1] => [1]
[1, 2, 3, 4, 5] => [1->5]
[1, 3, 5, 7, 9] => [1, 3, 5, 7, 9]
```

**Алгоритм работает так:**

1. **Проходим по отсортированному массиву** чисел
2. **Обнаруживаем разрыв** в последовательности, когда текущее число не равно предыдущему + 1
3. **Формируем диапазон:**
   - Если диапазон состоит из одного числа: `"число"`
   - Если диапазон состоит из нескольких чисел: `"начало->конец"`
4. **Обрабатываем последний диапазон** после завершения цикла

**Ключевые отличия в PHP-версии:**
- Используется `count()` вместо `len()`
- Конкатенация строк через `.` вместо `+`
- Приведение к строке через `(string)` или конкатенацию
- `empty()` для проверки пустого массива
