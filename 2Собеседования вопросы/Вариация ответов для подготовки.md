1. Принципы ООП

- Твой ответ: Чётко, но слишком кратко, как из учебника.
    
- Исправленный:
    
    - Инкапсуляция: Сокрытие деталей реализации через публичные интерфейсы и приватные поля. Например, в Go это достигается через экспорт/неэкспорт полей (Name vs name).
        
    - Наследование: Переиспользование кода через создание подклассов. В Go нет классического наследования, но можно встраивать структуры (embedding).
        
    - Полиморфизм: Один интерфейс — разные реализации. В Go это интерфейсы, например, io.Reader для чтения из разных источников.
        
    - Абстракция: Моделирование только ключевых свойств объекта. В Go — интерфейсы или абстрактные типы вроде map[string]interface{}.
        
- Дополнение: "В корпоративной разработке часто использую интерфейсы для полиморфизма, чтобы снизить связность между модулями."

func wrapItems(items []item) (result []*wrapper) {
    for i := range items {
        w := new(wrapper)
        w.wrap(&items[i]) // Копируем по индексу, а не ссылку на it

    }
    return result
}

func spawnMessages(n int) chan string {
