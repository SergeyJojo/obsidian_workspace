### 🟩 **Карточка 11**

**Q:** Что делает `EXPLAIN ANALYZE`, и зачем его использовать?  
**A:** Показывает реальный план выполнения запроса и время исполнения каждой операции. Используется для поиска узких мест (sequential scan, nested loops и т.п.).

---

### 🟩 **Карточка 12**

**Q:** Что такое `sequential scan`, и когда он вреден?  
**A:** Это полный перебор всех строк таблицы. Вреден на больших таблицах без индекса по нужному полю.

---

### 🟩 **Карточка 13**

**Q:** Как в Go выполнить `EXPLAIN ANALYZE` и получить план?  
**A:**

```go
rows, _ := db.Query(ctx, "EXPLAIN ANALYZE SELECT ...")
for rows.Next() {
  var line string
  _ = rows.Scan(&line)
  fmt.Println(line)
}
```

---

### 🟩 **Карточка 14**

**Q:** Что такое уровень изоляции `REPEATABLE READ` и как его активировать в Go?  
**A:** Изоляция, при которой видим один и тот же снимок данных в рамках транзакции.

```go
tx, _ := db.BeginTx(ctx, pgx.TxOptions{IsoLevel: pgx.RepeatableRead})
```

### 🟩 **Карточка 15**

**Q:** Как в Go реализовать retry при `serialization failure`?  
**A:**

```go
for i := 0; i < 3; i++ {
  tx, _ := db.Begin(ctx)
  err := doWork(tx)
  if err != nil && isSerializationErr(err) {
    _ = tx.Rollback(ctx)
    continue
  }
  tx.Commit(ctx)
}
```

### 🟩 **Карточка 16**

**Q:** Что такое `GIN` индекс и зачем он нужен?  
**A:** Индекс для поиска по массивам, JSONB, full-text. Быстрее, чем B-tree для contains-поисков.  
Например: `CREATE INDEX ON logs USING GIN(data jsonb_path_ops);`

### 🟩 **Карточка 17**

**Q:** Как вставить в JSONB поле в Go структуре и сохранить в БД?  
**A:**

```go
type Row struct {
  ID int
  Data map[string]interface{} // Marshalable в JSON
}
_, _ = db.Exec(ctx, "INSERT INTO table(data) VALUES($1)", row.Data)
```

### 🟩 **Карточка 18**

**Q:** Как обновить поле внутри JSONB в PostgreSQL?  
**A:**

```sql
UPDATE logs SET data = jsonb_set(data, '{error,count}', '5') WHERE id=1;
```

### 🟩 **Карточка 19**

**Q:** Как выбрать все записи, у которых в JSONB есть ключ `user_id`?  
**A:**

```sql
SELECT * FROM table WHERE data ? 'user_id';
```

**Q:** Что такое миграции в контексте Go и PostgreSQL?  
**A:** Управление схемой базы данных через версионируемые скрипты. Популярный инструмент — [golang-migrate](https://github.com/golang-migrate/migrate).

### 🟩 **Карточка 21**

**Q:** Как запустить миграции с помощью golang-migrate из кода?  
**A:**

```go
m, _ := migrate.New("file://migrations", "postgres://...")
_ = m.Up()
```

### 🟩 **Карточка 22**

**Q:** Как в Go сделать кастомный тип и сохранить его как JSONB?  
**A:** Реализуй интерфейсы `driver.Valuer` и `sql.Scanner`:

```go
func (j MyJSON) Value() (driver.Value, error) {
  return json.Marshal(j)
}
func (j *MyJSON) Scan(src interface{}) error {
  return json.Unmarshal(src.([]byte), j)
}
```
