
### **Задача: Максимальная длина подмассива из единиц с максимум одним нулем**

**Условие:**  
Дан бинарный массив `nums` (состоит из 0 и 1). Найдите максимальную длину подмассива, содержащего не более одного нуля. Если удалить один ноль, подмассив должен состоять только из единиц.

**Примеры:**
```go
Input: nums = [1,1,0,1,1,0,1,1,1]
Output: 5 
// Подмассив [1,1,0,1,1,1] после удаления одного нуля → [1,1,1,1,1]

Input: nums = [1,1,1,0,0,1]
Output: 4 
// Подмассив [1,1,1,0,1] → [1,1,1,1]
```

---

### **Решение на Go (метод скользящего окна)**

```go
func findMaxConsecutiveOnes(nums []int) int {
    maxLen := 0
    left := 0
    zeroCount := 0

    for right := 0; right < len(nums); right++ {
        if nums[right] == 0 {
            zeroCount++
        }

        // Сужаем окно, если нулей больше одного
        for zeroCount > 1 {
            if nums[left] == 0 {
                zeroCount--
            }
            left++
        }

        // Обновляем максимальную длину
        currentLen := right - left + 1
        if currentLen > maxLen {
            maxLen = currentLen
        }
    }

    return maxLen
}
```

---

### **Пошаговое пояснение:**

1. **Инициализация:**
   - `left` — начало окна.
   - `zeroCount` — счётчик нулей в текущем окне.
   - `maxLen` — максимальная длина валидного подмассива.

2. **Расширение окна (`right++`):**
   - Если встречаем `0`, увеличиваем `zeroCount`.

3. **Сужение окна (`left++`):**
   - Если `zeroCount > 1`, двигаем `left` до тех пор, пока не останется один ноль.

4. **Обновление результата:**
   - Вычисляем длину текущего окна `right - left + 1`.
   - Если она больше `maxLen`, обновляем `maxLen`.

---

### **Пример работы для `nums = [1,1,0,1,1,0,1,1,1]`:**

| Шаг | right | nums[right] | zeroCount | left | Текущее окно       | maxLen |
|-----|-------|-------------|-----------|------|--------------------|--------|
| 1   | 0     | 1           | 0         | 0    | [1]                | 1      |
| 2   | 1     | 1           | 0         | 0    | [1,1]              | 2      |
| 3   | 2     | 0           | 1         | 0    | [1,1,0]            | 3      |
| 4   | 3     | 1           | 1         | 0    | [1,1,0,1]          | 4      |
| 5   | 4     | 1           | 1         | 0    | [1,1,0,1,1]        | 5      |
| 6   | 5     | 0           | 2         | 1    | [1,0,1,1,0] → [0,1,1,0] | 5      |
| 7   | 6     | 1           | 2 → 1     | 2    | [1,1,0,1]          | 5      |
| 8   | 7     | 1           | 1         | 2    | [1,1,0,1,1]        | 5      |
| 9   | 8     | 1           | 1         | 2    | [1,1,0,1,1,1]      | 6      |

**Итог:** `maxLen = 6` (подмассив `[1,1,0,1,1,1]` после удаления нуля → 5 единиц).

---

### **Оптимизация:**
- **Сложность:** O(n) — каждый элемент обрабатывается один раз.
- **Память:** O(1) — используем только несколько переменных.

### **Тестирование:**
```go
func main() {
    fmt.Println(findMaxConsecutiveOnes([]int{1,1,0,1,1,0,1,1,1})) // 6
    fmt.Println(findMaxConsecutiveOnes([]int{1,1,1,0,0,1}))        // 4
    fmt.Println(findMaxConsecutiveOnes([]int{0,1,1,1,0,1}))        // 5
}
```

Это решение эффективно обрабатывает все крайние случаи и соответствует требованиям задачи.
