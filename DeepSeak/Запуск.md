### **Правильная установка DeepSeek Coder на Windows (WSL) с CMake**

#### **1. Установи зависимости**

```sh
sudo apt update && sudo apt install -y cmake g++ unzip curl git
```

#### **2. Клонируй репозиторий llama.cpp**

```sh
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
```

#### **3. Сконфигурируй и собери проект с CMake**

```sh
mkdir build
cd build
cmake ..
cmake --build . --config Release
cd ..
```

#### **4. Скачай модель DeepSeek**

```sh
mkdir models
cd models
wget https://huggingface.co/godolike/deepseek-coder-6.7b-instruct-Q4_K_M-GGUF/resolve/main/deepseek-coder-6.7b-instruct-q4_k_m.gguf
cd ..
```

#### **5. Запусти CLI**

```sh
./build/bin/main -m models/deepseek-coder-6.7b-instruct-q4_k_m.gguf -p "Напиши код на Go для..."
```

#### **6. Запусти сервер**

```sh
./build/bin/server -m models/deepseek-coder-6.7b-instruct-q4_k_m.gguf -c 2048
```

**Теперь ты можешь кидать запросы через API или через консоль.**
