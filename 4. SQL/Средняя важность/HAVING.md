

### 2. **`HAVING`** — применяется после группировки данных и работает с агрегатными функциями

**С `HAVING` можно использовать:**

- **Агрегатные функции** (например, `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`), так как они работают с группами данных после применения `GROUP BY`.
- Также можно использовать стандартные операторы сравнения (например, `>`, `<`, `=`, `IN`, `BETWEEN`), но **с результатами агрегатных функций**.

**Пример использования с `HAVING`:**

```sql
SELECT customer_id, COUNT(*) AS total_orders
FROM orders
GROUP BY customer_id
HAVING COUNT(*) > 5;  -- Фильтрация групп по количеству заказов
```

```sql
SELECT department_id, AVG(salary) AS avg_salary
FROM employees
GROUP BY department_id
HAVING AVG(salary) > 50000;  -- Фильтрация групп по среднему значению
```

---

### Ключевые различия:

1. **`WHERE`**:
    
    - Применяется **до группировки** данных (до `GROUP BY`).
    - **Не может** использовать агрегатные функции, потому что фильтрация происходит до выполнения агрегации.
2. **`HAVING`**:
    
    - Применяется **после группировки** данных (после `GROUP BY`).
    - **Использует агрегатные функции**, такие как `COUNT`, `SUM`, `AVG`, и так далее.

---

### Пример для объяснения:

Предположим, у нас есть таблица `orders` с полями `order_id`, `customer_id`, `order_amount`, `order_date`.

**Задача**: Найти клиентов, которые сделали больше 5 заказов, и при этом сумма всех их заказов превышает 5000.

```sql
SELECT customer_id, COUNT(*) AS total_orders, SUM(order_amount) AS total_spent
FROM orders
WHERE order_date >= '2025-01-01'  -- Фильтрация строк по дате
GROUP BY customer_id
HAVING COUNT(*) > 5 AND SUM(order_amount) > 5000;  -- Фильтрация групп по количеству заказов и сумме
```

- **`WHERE`** используется для фильтрации строк до группировки, чтобы учитывать только заказы после 1 января 2025 года.
- **`HAVING`** используется для фильтрации **групп** (по клиентам) после выполнения агрегации. Мы выбираем только тех клиентов, у которых больше 5 заказов и сумма заказов превышает 5000.

---

### Заключение:

- **`WHERE`** фильтрует **строки** до группировки и не использует агрегатные функции.
- **`HAVING`** фильтрует **группы** после группировки и используется для условий с агрегатными функциями.
