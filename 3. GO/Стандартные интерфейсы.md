
В Go есть несколько **стандартных интерфейсов** из пакетов `builtin` и стандартной библиотеки, которые часто используются в коде. Вот основные из них:

---

## **1. Пустые интерфейсы (`any` / `interface{}`)**
Используются для работы с любыми типами.
```go
type any = interface{} // начиная с Go 1.18

var data any = "hello" // можно присвоить что угодно
```

---

## **2. Интерфейсы для ошибок (`error`)**
### **`error` (базовый интерфейс для ошибок)**
```go
type error interface {
    Error() string
}
```
Пример:
```go
type MyError struct{ Msg string }

func (e *MyError) Error() string { return e.Msg }

func foo() error { return &MyError{"Oops!"} }
```

### **Дополнительные интерфейсы для ошибок (Go 1.20+)**
- **`interface { Unwrap() error }`** (для `errors.Unwrap`)  
- **`interface { Is(error) bool }`** (для `errors.Is`)  
- **`interface { As(any) bool }`** (для `errors.As`)  

---

## **3. Интерфейсы для строкового представления**
### **`fmt.Stringer`**
```go
type Stringer interface {
    String() string
}
```
Пример:
```go
type Point struct{ X, Y int }

func (p Point) String() string {
    return fmt.Sprintf("(%d, %d)", p.X, p.Y)
}

func main() {
    p := Point{1, 2}
    fmt.Println(p) // (1, 2)
}
```

### **`fmt.GoStringer`** (для `%#v`)  
```go
type GoStringer interface {
    GoString() string
}
```

---

## **4. Интерфейсы для сортировки**
### **`sort.Interface`**
```go
type Interface interface {
    Len() int
    Less(i, j int) bool
    Swap(i, j int)
}
```
Пример сортировки слайса:
```go
type ByAge []Person

func (a ByAge) Len() int           { return len(a) }
func (a ByAge) Less(i, j int) bool { return a[i].Age < a[j].Age }
func (a ByAge) Swap(i, j int)      { a[i], a[j] = a[j], a[i] }

func main() {
    people := []Person{{"Alice", 30}, {"Bob", 25}}
    sort.Sort(ByAge(people))
}
```

### **`sort.Slice` (упрощённая версия)**
```go
sort.Slice(people, func(i, j int) bool {
    return people[i].Age < people[j].Age
})
```

## **5. Интерфейсы для ввода/вывода**
### **`io.Reader`**
```go
type Reader interface {
    Read(p []byte) (n int, err error)
}
```
Пример:
```go
func readAll(r io.Reader) ([]byte, error) {
    return io.ReadAll(r)
}
```

### **`io.Writer`**
```go
type Writer interface {
    Write(p []byte) (n int, err error)
}
```
Пример:
```go
func writeHello(w io.Writer) error {
    _, err := w.Write([]byte("hello"))
    return err
}
```

### **Другие IO-интерфейсы**
- **`io.Closer`** (`Close() error`)  
- **`io.Seeker`** (`Seek(offset int64, whence int) (int64, error)`)  
- **`io.ReadWriter`** (`Reader` + `Writer`)  
- **`io.ReadCloser`** (`Reader` + `Closer`)  

---

## **6. Интерфейсы для JSON**
### **`json.Marshaler`**
```go
type Marshaler interface {
    MarshalJSON() ([]byte, error)
}
```
Пример:
```go
type CustomTime struct { time.Time }

func (ct CustomTime) MarshalJSON() ([]byte, error) {
    return []byte(fmt.Sprintf(`"%s"`, ct.Format("2006-01-02"))), nil
}
```

### **`json.Unmarshaler`**
```go
type Unmarshaler interface {
    UnmarshalJSON([]byte) error
}
```

---

## **7. Интерфейсы для работы с HTTP**
### **`http.Handler`**
```go
type Handler interface {
    ServeHTTP(ResponseWriter, *Request)
}
```
Пример:
```go
type MyHandler struct{}

func (h *MyHandler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Hello!")
}

func main() {
    http.ListenAndServe(":8080", &MyHandler{})
}
```

### **`http.ResponseWriter`**
```go
type ResponseWriter interface {
    Header() Header
    Write([]byte) (int, error)
    WriteHeader(statusCode int)
}
```

---

## **8. Интерфейс для сравнения (`comparable`)**
С Go 1.18+ появился встроенный интерфейс для дженериков:
```go
func Equal[T comparable](a, b T) bool {
    return a == b
}
```
Работает с типами, поддерживающими `==` и `!=` (числа, строки, указатели, структуры из сравнимых полей).

## **Вывод**
| Интерфейс          | Пакет       | Описание                          |
|--------------------|------------|----------------------------------|
| `any`              | `builtin`  | Любой тип (`interface{}`)        |
| `error`            | `builtin`  | Ошибки                           |
| `Stringer`         | `fmt`      | Строковое представление          |
| `sort.Interface`   | `sort`     | Сортировка                       |
| `Reader` / `Writer`| `io`       | Ввод-вывод                       |
| `Marshaler`        | `encoding/json` | Сериализация в JSON        |
| `Handler`          | `net/http` | HTTP-обработчик                  |

Эти интерфейсы — основа многих стандартных библиотек Go. 🚀
