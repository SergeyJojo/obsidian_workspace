Вот оптимальное решение задачи **LeetCode 238: Product of Array Except Self** на Go с подробными пояснениями:

---

### 📌 Условие:

- Дан массив `nums` длины `n`
    
- Нужно вернуть массив `res` той же длины, где `res[i]` — это произведение всех чисел в `nums`, кроме `nums[i]`
    
- **Без деления**, **за O(n) по времени** и **O(1) по памяти** (не считая `res`)
    

---

### ✅ Go-реализация:

```go
package main

import (
	"fmt"
)

func productExceptSelf(nums []int) []int {
	n := len(nums)
	res := make([]int, n)

	// Первый проход: слева направо, считаем префиксные произведения
	prefix := 1
	for i := 0; i < n; i++ {
		res[i] = prefix
		prefix *= nums[i]
	}

	// Второй проход: справа налево, считаем суффиксные произведения и умножаем на результат
	suffix := 1
	for i := n - 1; i >= 0; i-- {
		res[i] *= suffix
		suffix *= nums[i]
	}

	return res
}

func main() {
	nums := []int{1, 2, 3, 4}
	fmt.Println(productExceptSelf(nums)) // [24 12 8 6]
}
```

---

### 🧠 Пояснение:

#### Первый проход: слева направо

- `prefix` — произведение всех элементов слева от `i`
    
- На каждой итерации сохраняем `res[i] = prefix`, затем `prefix *= nums[i]`
    

```
nums:    [1  2  3  4]
prefix:  [1  1  2  6] → записываем в res
```

#### Второй проход: справа налево

- `suffix` — произведение всех элементов справа от `i`
    
- Умножаем `res[i] *= suffix`, затем `suffix *= nums[i]`
    

```
suffix (обратный): 1 → 4 → 12 → 24
res:              [1*24 1*12 2*4 6*1] = [24 12 8 6]
```

---

### 💡 Почему это O(1) по памяти?

- Мы не используем дополнительных массивов (кроме `res`)
    
- `prefix` и `suffix` — это две переменные, постоянное пространство
