
Задача, в которой нужно **удалить все нули из слайса (массива)**, соответствует **LeetCode 283. Move Zeroes**.  

### **Формулировка задачи:**
> Дан массив целых чисел `nums`. Необходимо **переместить все нули в конец**, сохраняя относительный порядок ненулевых элементов.  
> **Дополнительное условие:** Нельзя создавать копию массива, нужно изменить исходный массив **in-place**.  

### **Примеры:**
**Вход:** `[0, 1, 0, 3, 12]`  
**Выход:** `[1, 3, 12, 0, 0]`  

**Вход:** `[0]`  
**Выход:** `[0]`  

---

### **Решение (Two Pointers / In-place):**
Используем два указателя:
1. **`slow`** — указывает на позицию, куда будет записан следующий ненулевой элемент.
2. **`fast`** — итерируется по массиву и пропускает нули.

После переноса всех ненулевых элементов в начало, заполняем оставшуюся часть нулями.

#### **Код на Go:**
```go
func moveZeroes(nums []int) {
    slow := 0
    // Переносим все ненулевые элементы в начало
    for fast := 0; fast < len(nums); fast++ {
        if nums[fast] != 0 {
            nums[slow] = nums[fast]
            slow++
        }
    }
    // Заполняем оставшуюся часть нулями
    for i := slow; i < len(nums); i++ {
        nums[i] = 0
    }
}
```

#### **Альтернативный вариант (с обменами):**
```go
func moveZeroes(nums []int) {
    slow := 0
    for fast := 0; fast < len(nums); fast++ {
        if nums[fast] != 0 {
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow++
        }
    }
}
```

---

### **Сложность:**
- **Время:** `O(n)` (проход по массиву один раз).  
- **Память:** `O(1)` (изменяем массив in-place).
