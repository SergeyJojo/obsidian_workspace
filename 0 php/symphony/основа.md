**Symfony** — это полноценный фреймворк, состоящий из множества компонентов. Вот основные разделы для изучения:

## 🏗️ **Архитектура и основы**

### **1. Компоненты Symfony**
- **HttpFoundation** — работа с HTTP-запросами и ответами
- **HttpKernel** — ядро обработки запросов
- **DependencyInjection** — контейнер внедрения зависимостей
- **EventDispatcher** — система событий
- **Routing** — маршрутизация

### **2. Структура приложения**
```
symfony-project/
├── config/          # Конфигурация
├── src/             # Исходный код
├── templates/       # Шаблоны
├── translations/    # Переводы
├── public/          # Веб-корень
├── var/             # Кэш, логи
└── vendor/          # Зависимости
```

## 🎯 **Основные разделы для изучения**

### **1. Маршрутизация (Routing)**
```yaml
# config/routes.yaml
app_homepage:
    path: /blog/{slug}
    controller: App\Controller\BlogController::show
    requirements:
        slug: '[a-z-]+'
```

### **2. Контроллеры (Controllers)**
```php
<?php
namespace App\Controller;

use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;

class BlogController extends AbstractController
{
    public function show(string $slug): Response
    {
        // Логика контроллера
        return $this->render('blog/show.html.twig', [
            'slug' => $slug,
        ]);
    }
}
```

### **3. Шаблоны (Twig)**
```twig
{# templates/blog/show.html.twig #}
{% extends 'base.html.twig' %}

{% block body %}
    <h1>{{ slug }}</h1>
    <p>Post content here...</p>
{% endblock %}
```

### **4. Формы (Forms)**
```php
<?php
namespace App\Form;

use App\Entity\Post;
use Symfony\Component\Form\AbstractType;
use Symfony\Component\Form\FormBuilderInterface;
use Symfony\Component\OptionsResolver\OptionsResolver;

class PostType extends AbstractType
{
    public function buildForm(FormBuilderInterface $builder, array $options)
    {
        $builder
            ->add('title')
            ->add('content')
            ->add('publishedAt');
    }
}
```

### **5. Работа с базой данных (Doctrine ORM)**
#### **Сущности:**
```php
<?php
namespace App\Entity;

use Doctrine\ORM\Mapping as ORM;

#[ORM\Entity]
class Post
{
    #[ORM\Id]
    #[ORM\GeneratedValue]
    #[ORM\Column]
    private ?int $id = null;

    #[ORM\Column(length: 255)]
    private ?string $title = null;
    
    // Геттеры и сеттеры...
}
```

#### **Репозитории:**
```php
<?php
namespace App\Repository;

use App\Entity\Post;
use Doctrine\Bundle\DoctrineBundle\Repository\ServiceEntityRepository;
use Doctrine\Persistence\ManagerRegistry;

class PostRepository extends ServiceEntityRepository
{
    public function __construct(ManagerRegistry $registry)
    {
        parent::__construct($registry, Post::class);
    }
    
    public function findRecentPosts(int $maxResults = 10): array
    {
        return $this->createQueryBuilder('p')
            ->orderBy('p.publishedAt', 'DESC')
            ->setMaxResults($maxResults)
            ->getQuery()
            ->getResult();
    }
}
```

### **6. Валидация**
```php
<?php
namespace App\Entity;

use Symfony\Component\Validator\Constraints as Assert;

class Post
{
    #[Assert\NotBlank]
    #[Assert\Length(min: 5, max: 255)]
    private string $title;
    
    #[Assert\NotBlank]
    #[Assert\Length(min: 10)]
    private string $content;
}
```

### **7. Безопасность (Security)**
```yaml
# config/packages/security.yaml
security:
    firewalls:
        main:
            pattern: ^/
            form_login:
                login_path: app_login
                check_path: app_login
            logout:
                path: app_logout
```

## 🔧 **Продвинутые темы**

### **1. Сервисы и DI**
```yaml
# config/services.yaml
services:
    App\Service\EmailService:
        arguments:
            $mailer: '@mailer'
    
    App\EventListener\ExceptionListener:
        tags:
            - { name: kernel.event_listener, event: kernel.exception }
```
