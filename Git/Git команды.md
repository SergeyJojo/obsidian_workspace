

Вот список продвинутых команд Git, которые пригодятся при сложной работе с репозиторием, историей коммитов, ветками и исправлением ошибок.

### 🔥 Работа с историей коммитов

```bash
git log --oneline --graph --decorate --all
```

➜ Краткий журнал коммитов с визуализацией веток.

```bash
git log -S "фраза"
```

➜ Найти коммиты, в которых появилось или исчезло упоминание указанной фразы.

```bash
git reflog
```

➜ Показывает историю всех действий в репозитории (даже удаленных коммитов).

### 🏗 Работа с ветками

```bash
git branch -m old_name new_name
```

➜ Переименовать текущую ветку.

```bash
git branch --merged
```

➜ Показать ветки, которые уже слиты с текущей. Можно удалить ненужные:

```bash
git branch -d имя_ветки
```

```bash
git worktree add ../новая_папка имя_ветки
```

➜ Одновременно работать с несколькими ветками в разных папках.

### 🛠 Редактирование коммитов

```bash
git commit --amend --no-edit
```

➜ Внести изменения в последний коммит, не меняя его сообщение.

```bash
git rebase -i HEAD~5
```

➜ Интерактивный rebase для редактирования, объединения или удаления последних 5 коммитов.

```bash
git reset --soft HEAD~1
```

➜ Откатить последний коммит, оставив изменения в индексе.

```bash
git reset --hard HEAD~1
```

➜ Полностью удалить последний коммит (безвозвратно!).

### 🔄 Слияние и cherry-pick

```bash
git merge --no-ff имя_ветки
```

➜ Слить ветку с сохранением истории.

```bash
git cherry-pick хеш_коммита
```

➜ Взять конкретный коммит из другой ветки.

```bash
git revert хеш_коммита
```

➜ Создать новый коммит, отменяющий указанный.

### 🚑 Восстановление изменений

```bash
git checkout -- файл
```

➜ Восстановить файл из последнего коммита (до изменений).

```bash
git stash
```

➜ Спрятать все изменения (например, перед переключением ветки).

```bash
git stash pop
```

➜ Вернуть спрятанные изменения обратно.

```bash
git fsck
```

➜ Проверить репозиторий на ошибки.

### 🔗 Работа с удаленными репозиториями

```bash
git remote -v
```

➜ Показать список удаленных репозиториев.

```bash
git fetch --prune
```

➜ Удалить ссылки на удаленные ветки, которые больше не существуют.

```bash
git push origin :ветка
```

➜ Удалить ветку на удаленном репозитории.

```bash
git pull --rebase
```

➜ Перетаскивание новых коммитов с сервера без лишних merge-коммитов.

### 🚀 Оптимизация и чистка

```bash
git gc --prune=now
```

➜ Очистить ненужные объекты и оптимизировать репозиторий.

```bash
git bisect start
```

➜ Начать двоичный поиск бага (разделяя коммиты на хорошие и плохие).

```bash
git blame файл
```

➜ Показать, кто и когда изменял каждую строку в файле.
