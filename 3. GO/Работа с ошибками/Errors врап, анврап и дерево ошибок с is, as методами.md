Пакет `errors` реализует функции для работы с ошибками.

Функция `New` создаёт ошибки, содержащие только текстовое сообщение.

Ошибка `e` считается «оборачивающей» другую ошибку, если тип `e` имеет один из следующих методов:

- `Unwrap() error`
    
- `Unwrap() []error`
    

Если `e.Unwrap()` возвращает ненулевую ошибку `w` или срез, содержащий `w`, то считается, что `e` оборачивает ошибку `w`.  
Если метод `Unwrap` возвращает `nil`, это означает, что ошибка `e` не оборачивает другую ошибку.  
Метод `Unwrap` не должен возвращать `[]error`, содержащий `nil`.

Удобный способ создать обёрнутую ошибку — использовать `fmt.Errorf` с директивой `%w`:

```go
wrapsErr := fmt.Errorf("... %w ...", ..., err, ...)
```

Последовательное разворачивание обёрнутых ошибок формирует дерево.  
Функции `errors.Is` и `errors.As` просматривают это дерево, начиная с самой ошибки, затем переходят к дочерним (предварительный обход в глубину).

Функция `Is` просматривает дерево ошибок, переданных первым аргументом, и ищет в нём ошибку, совпадающую со второй. Возвращает `true`, если такая ошибка найдена.  
Эту функцию следует использовать вместо простого сравнения:

```go
errors.Is(err, fs.ErrExist)
```

предпочтительнее, чем:

```go
err == fs.ErrExist
```

потому что первый вариант работает даже в случае, если `err` оборачивает `fs.ErrExist`.

Функция `As` просматривает дерево ошибок, переданных первым аргументом, и ищет ошибку, которую можно присвоить указателю, переданному вторым аргументом.  
Если такая ошибка найдена, происходит присваивание и возвращается `true`. Иначе возвращается `false`.

Пример использования:

```go
var perr *fs.PathError
if errors.As(err, &perr) {
	fmt.Println(perr.Path)
}
```

предпочтительнее, чем:

```go
if perr, ok := err.(*fs.PathError); ok {
	fmt.Println(perr.Path)
}
```

потому что первый вариант сработает даже в случае, если `err` оборачивает `*fs.PathError`.

Функция `New(text string)` создаёт ошибку с заданным текстом. Каждый вызов создаёт уникальный экземпляр ошибки, даже если текст одинаков.

Тип `errorString` — это простая реализация интерфейса `error`.

Предопределённая переменная `ErrUnsupported` означает, что запрошенная операция не может быть выполнена, потому что она не поддерживается (например, вызов `os.Link` на файловой системе без поддержки жёстких ссылок).

Функции и методы **не должны напрямую возвращать** `ErrUnsupported`. Вместо этого нужно возвращать ошибку с контекстом, которая удовлетворяет:

```go
errors.Is(err, errors.ErrUnsupported)
```

Это можно сделать либо обернув `ErrUnsupported`, либо реализовав метод `Is`.  
Также необходимо документировать случаи, в которых может быть возвращена ошибка, оборачивающая `ErrUnsupported`.

В Go функции `errors.Is` и `errors.As` применяются для работы с обёрнутыми (wrapped) ошибками, но решают разные задачи:

---

### 📌 `errors.Is(err, targetError)` — **для проверки на конкретную ошибку**

Используется, когда ты хочешь узнать, является ли `err` конкретной ошибкой (или оборачивает её).

**Применяется:**

- Когда нужно узнать, _"произошла ли именно эта ошибка?"_
    
- Тип значения не важен, важна **сущность ошибки**.
    

**Пример:**

```go
if errors.Is(err, fs.ErrNotExist) {
    fmt.Println("Файл не существует")
}
```

Даже если `err` была обёрнута (например, через `fmt.Errorf("ошибка: %w", fs.ErrNotExist)`), `errors.Is` её найдёт.

---

### 📌 `errors.As(err, &target)` — **для извлечения ошибки по типу**

Используется, когда ты хочешь проверить, _является ли ошибка определённого **типа**_, и получить доступ к её полям.

**Применяется:**

- Когда нужен **доступ к данным внутри ошибки**, например к `Path` или `Timeout`.
    
- Тип важен, сравнивается с `interface{}` или конкретной структурой ошибки.
    

**Пример:**

```go
var pathErr *fs.PathError
if errors.As(err, &pathErr) {
    fmt.Println("Ошибка пути:", pathErr.Path)
}
```

Опять же, даже если `err` была обёрнута, `As` извлечёт нужный тип.

---

### 🔑 Резюме:

|Вопрос|Используй|Почему|
|---|---|---|
|Это конкретная ошибка?|`errors.Is`|Сравнивает по значению|
|Это ошибка такого-то типа?|`errors.As`|Извлекает по типу|
|Нужно проверить `Timeout()?`|`errors.As`|Интерфейс реализуется типом|
|Ошибка — `os.ErrPermission`?|`errors.Is`|Конкретная ошибка|
