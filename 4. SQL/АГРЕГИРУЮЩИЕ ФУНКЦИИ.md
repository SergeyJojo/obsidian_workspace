**Агрегирующие функции в SQL** — это функции, которые выполняют операции над набором строк и возвращают одно значение. Эти функции часто используются в сочетании с оператором `GROUP BY` для группировки данных, но также могут применяться без него.

---

## **Основные агрегирующие функции в SQL**

### **1. `COUNT()`**

- Возвращает количество строк в наборе данных.
    
- **Пример:**
    
    ```sql
    SELECT COUNT(*) AS total_rows
    FROM employees;
    ```
    
    **Результат:** количество всех строк в таблице `employees`.
    
- Подсчёт уникальных значений:
    
    ```sql
    SELECT COUNT(DISTINCT department_id) AS unique_departments
    FROM employees;
    ```
    

---

### **2. `SUM()`**

- Возвращает сумму значений в столбце.
- **Пример:**
    
    ```sql
    SELECT SUM(salary) AS total_salary
    FROM employees;
    ```
    
    **Результат:** общая сумма всех зарплат.

---

### **3. `AVG()`**

- Возвращает среднее значение.
- **Пример:**
    
    ```sql
    SELECT AVG(salary) AS average_salary
    FROM employees;
    ```
    
    **Результат:** средняя зарплата сотрудников.

---

### **4. `MIN()`**

- Возвращает минимальное значение в наборе данных.
- **Пример:**
    
    ```sql
    SELECT MIN(salary) AS minimum_salary
    FROM employees;
    ```
    
    **Результат:** минимальная зарплата среди сотрудников.

---

### **5. `MAX()`**

- Возвращает максимальное значение в наборе данных.
- **Пример:**
    
    ```sql
    SELECT MAX(salary) AS maximum_salary
    FROM employees;
    ```
    
    **Результат:** максимальная зарплата среди сотрудников.

---

## **Примеры с использованием `GROUP BY`**

### **Пример 1: Группировка по отделам**

```sql
SELECT department_id, COUNT(*) AS employee_count
FROM employees
GROUP BY department_id;
```

- Группирует сотрудников по отделам и подсчитывает их количество в каждом отделе.

---

### **Пример 2: Средняя зарплата по отделам**

```sql
SELECT department_id, AVG(salary) AS average_salary
FROM employees
GROUP BY department_id;
```

- Возвращает среднюю зарплату для каждого отдела.

---

### **Пример 3: Сумма продаж по месяцам**

```sql
SELECT MONTH(sale_date) AS month, SUM(amount) AS total_sales
FROM sales
GROUP BY MONTH(sale_date);
```

- Возвращает сумму продаж за каждый месяц.

---

## **Использование с `HAVING`**

Агрегирующие функции нельзя использовать в `WHERE`. Вместо этого применяется `HAVING`, чтобы фильтровать данные после выполнения агрегирующих операций.

### **Пример: Отделы с более чем 5 сотрудниками**

```sql
SELECT department_id, COUNT(*) AS employee_count
FROM employees
GROUP BY department_id
HAVING COUNT(*) > 5;
```

---

## **Особенности агрегирующих функций**

1. **`NULL` и агрегирующие функции:**
    
    - Агрегирующие функции игнорируют `NULL` (кроме `COUNT(*)`).
    - **Пример:**
        
        ```sql
        SELECT SUM(bonus) AS total_bonus
        FROM employees;
        ```
        
        Если в столбце `bonus` есть `NULL`, они не будут учитываться.
2. **Комбинирование функций:**
    
    - Можно использовать несколько агрегирующих функций в одном запросе.
    - **Пример:**
        
        ```sql
        SELECT
            COUNT(*) AS total_employees,
            AVG(salary) AS average_salary,
            MAX(salary) AS highest_salary
        FROM employees;
        ```

## **Расширенные примеры**

### **Пример 1: Процент от общего количества**

- Найти долю сотрудников каждого отдела от общего числа сотрудников:
    
    ```sql
    SELECT department_id,
           COUNT(*) AS employee_count,
           COUNT(*) * 100.0 / (SELECT COUNT(*) FROM employees) AS percentage
    FROM employees
    GROUP BY department_id;
    ```
    

---

### **Пример 2: Сравнение значений с общей средней**

- Вывести отделы, где средняя зарплата выше средней зарплаты по всей компании:
    
    ```sql
    SELECT department_id, AVG(salary) AS avg_salary
    FROM employees
    GROUP BY department_id
    HAVING AVG(salary) > (SELECT AVG(salary) FROM employees);
    ```
    

---

## **Итог**

Агрегирующие функции в SQL — это мощный инструмент для анализа данных. Они используются для:

- Подсчёта (`COUNT`),
- Суммирования (`SUM`),
- Нахождения среднего (`AVG`),
- Поиска максимума и минимума (`MAX`, `MIN`).

В сочетании с `GROUP BY` и `HAVING` они позволяют выполнять сложные запросы и групповые операции.
