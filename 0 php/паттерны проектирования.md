Паттерны проектирования — это типовые решения повторяющихся проблем в проектировании ПО. Они делятся на три основные категории. Вот полная классификация с конкретными представителями:

## 1. Порождающие паттерны (Creational)
**Решают проблемы создания объектов**

### 🔧 **Singleton (Одиночка)**
- **Назначение:** Гарантирует, что у класса есть только один экземпляр
- **Пример:** Логгер, подключение к БД, кеш
```php
class DatabaseConnection {
    private static $instance = null;
    
    private function __construct() {}
    
    public static function getInstance() {
        if (self::$instance === null) {
            self::$instance = new self();
        }
        return self::$instance;
    }
}
```

### 🏭 **Factory Method (Фабричный метод)**
- **Назначение:** Создает объекты без указания точного класса
- **Пример:** Создание разных типов документов
```php
interface Document {
    public function open();
}

class WordDocument implements Document {
    public function open() { /* ... */ }
}

class PdfDocument implements Document {
    public function open() { /* ... */ }
}

class DocumentFactory {
    public static function create($type): Document {
        return match($type) {
            'word' => new WordDocument(),
            'pdf' => new PdfDocument(),
            default => throw new Exception('Unknown document type')
        };
    }
}
```

### 🏭 **Abstract Factory (Абстрактная фабрика)**
- **Назначение:** Создание семейств связанных объектов
- **Пример:** Создание UI элементов для разных ОС
```php
interface Button {
    public function render();
}

interface Checkbox {
    public function check();
}

class WindowsButton implements Button {
    public function render() { echo "Windows button"; }
}

class MacButton implements Button {
    public function render() { echo "Mac button"; }
}

class GUIFactory {
    public function createButton(): Button;
    public function createCheckbox(): Checkbox;
}
```

### 👷 **Builder (Строитель)**
- **Назначение:** Пошаговое создание сложных объектов
- **Пример:** Построение SQL запроса, создание email
```php
class QueryBuilder {
    private $select = [];
    private $from = '';
    private $where = [];
    
    public function select($fields) {
        $this->select = $fields;
        return $this;
    }
    
    public function from($table) {
        $this->from = $table;
        return $this;
    }
    
    public function where($condition) {
        $this->where[] = $condition;
        return $this;
    }
    
    public function build() {
        return "SELECT " . implode(', ', $this->select) . 
               " FROM " . $this->from . 
               " WHERE " . implode(' AND ', $this->where);
    }
}

// Использование
$query = (new QueryBuilder())
    ->select(['name', 'email'])
    ->from('users')
    ->where('age > 18')
    ->build();
```

### 🐑 **Prototype (Прототип)**
- **Назначение:** Создание объектов через клонирование
- **Пример:** Клонирование сложных объектов с сохранением состояния
```php
class WebsiteTemplate implements Cloneable {
    private $header;
    private $content;
    private $footer;
    
    public function __clone() {
        // Глубокое копирование при необходимости
    }
}
```

## 2. Структурные паттерны (Structural)
**Решают проблемы композиции классов и объектов**

### 🔌 **Adapter (Адаптер)**
- **Назначение:** Преобразует интерфейс одного класса в интерфейс другого
- **Пример:** Адаптер для работы со старым API
```php
interface NewPaymentGateway {
    public function pay($amount);
}

class OldPaymentSystem {
    public function makePayment($sum) {
        echo "Paying $sum via old system";
    }
}

class PaymentAdapter implements NewPaymentGateway {
    private $oldSystem;
    
    public function __construct(OldPaymentSystem $oldSystem) {
        $this->oldSystem = $oldSystem;
    }
    
    public function pay($amount) {
        $this->oldSystem->makePayment($amount);
    }
}
```

### 🎁 **Decorator (Декоратор)**
- **Назначение:** Динамическое добавление новой функциональности объектам
- **Пример:** Добавление логирования, кеширования, сжатия
```php
interface Notifier {
    public function send($message);
}

class EmailNotifier implements Notifier {
    public function send($message) {
        echo "Sending email: $message\n";
    }
}

abstract class NotifierDecorator implements Notifier {
    protected $notifier;
    
    public function __construct(Notifier $notifier) {
        $this->notifier = $notifier;
    }
}

class SMSDecorator extends NotifierDecorator {
    public function send($message) {
        $this->notifier->send($message);
        echo "Sending SMS: $message\n";
    }
}

class SlackDecorator extends NotifierDecorator {
    public function send($message) {
        $this->notifier->send($message);
        echo "Sending Slack: $message\n";
    }
}

// Использование
$notifier = new SlackDecorator(new SMSDecorator(new EmailNotifier()));
$notifier->send("Hello!");
```

### 📦 **Composite (Компоновщик)**
- **Назначение:** Единообразная работа с отдельными объектами и их группами
- **Пример:** Файловая система, меню, DOM элементы
```php
interface FileSystemComponent {
    public function display($indent = '');
}

class File implements FileSystemComponent {
    private $name;
    
    public function display($indent = '') {
        echo $indent . "📄 " . $this->name . "\n";
    }
}

class Directory implements FileSystemComponent {
    private $name;
    private $children = [];
    
    public function add(FileSystemComponent $component) {
        $this->children[] = $component;
    }
    
    public function display($indent = '') {
        echo $indent . "📁 " . $this->name . "\n";
        foreach ($this->children as $child) {
            $child->display($indent . '  ');
        }
    }
}
```

### 🎭 **Proxy (Заместитель)**
- **Назначение:** Объект-заместитель контролирует доступ к другому объекту
- **Пример:** Ленивая загрузка, кеширование, защита доступа
```php
interface Image {
    public function display();
}

class RealImage implements Image {
    private $filename;
    
    public function __construct($filename) {
        $this->filename = $filename;
        $this->loadFromDisk();
    }
    
    private function loadFromDisk() {
        echo "Loading {$this->filename}\n";
    }
    
    public function display() {
        echo "Displaying {$this->filename}\n";
    }
}

class ImageProxy implements Image {
    private $filename;
    private $realImage = null;
    
    public function __construct($filename) {
        $this->filename = $filename;
    }
    
    public function display() {
        if ($this->realImage === null) {
            $this->realImage = new RealImage($this->filename);
        }
        $this->realImage->display();
    }
}
```

### ✈️ **Facade (Фасад)**
- **Назначение:** Упрощает интерфейс сложной подсистемы
- **Пример:** Простой API для сложной библиотеки
```php
class ComputerFacade {
    private $cpu;
    private $memory;
    private $hardDrive;
    
    public function __construct() {
        $this->cpu = new CPU();
        $this->memory = new Memory();
        $this->hardDrive = new HardDrive();
    }
    
    public function start() {
        $this->cpu->freeze();
        $this->memory->load();
        $this->hardDrive->read();
        $this->cpu->jump();
        $this->cpu->execute();
    }
}
```

### 🌉 **Bridge (Мост)**
- **Назначение:** Разделяет абстракцию и реализацию
- **Пример:** Разные реализации рендеринга для разных платформ
```php
interface Renderer {
    public function renderCircle($radius);
}

class VectorRenderer implements Renderer {
    public function renderCircle($radius) {
        echo "Drawing circle with radius $radius as vectors\n";
    }
}

class RasterRenderer implements Renderer {
    public function renderCircle($radius) {
        echo "Drawing circle with radius $radius as pixels\n";
    }
}

abstract class Shape {
    protected $renderer;
    
    public function __construct(Renderer $renderer) {
        $this->renderer = $renderer;
    }
    
    abstract public function draw();
}
```

### 🍃 **Flyweight (Легковес)**
- **Назначение:** Экономит память через разделение общего состояния
- **Пример:** Кеширование одинаковых данных (шрифты, текстуры)
```php
class TreeType {
    private $name;
    private $color;
    private $texture;
    
    public function __construct($name, $color, $texture) {
        $this->name = $name;
        $this->color = $color;
        $this->texture = $texture;
    }
    
    public function draw($x, $y) {
        echo "Drawing {$this->name} tree at ($x, $y)\n";
    }
}

class TreeFactory {
    private static $treeTypes = [];
    
    public static function getTreeType($name, $color, $texture) {
        $key = $name . $color . $texture;
        if (!isset(self::$treeTypes[$key])) {
            self::$treeTypes[$key] = new TreeType($name, $color, $texture);
        }
        return self::$treeTypes[$key];
    }
}
```

## 3. Поведенческие паттерны (Behavioral)
**Решают проблемы взаимодействия между объектами**

### 📡 **Observer (Наблюдатель)**
- **Назначение:** Уведомление зависимых объектов об изменениях
- **Пример:** События, подписки, уведомления
```php
interface Observer {
    public function update($data);
}

interface Subject {
    public function attach(Observer $observer);
    public function detach(Observer $observer);
    public function notify();
}

class NewsPublisher implements Subject {
    private $observers = [];
    private $news;
    
    public function attach(Observer $observer) {
        $this->observers[] = $observer;
    }
    
    public function setNews($news) {
        $this->news = $news;
        $this->notify();
    }
    
    public function notify() {
        foreach ($this->observers as $observer) {
            $observer->update($this->news);
        }
    }
}

class EmailSubscriber implements Observer {
    public function update($data) {
        echo "Sending email with news: $data\n";
    }
}
```

### 💼 **Strategy (Стратегия)**
- **Назначение:** Определяет семейство алгоритмов и делает их взаимозаменяемыми
- **Пример:** Способы оплаты, сортировки, сжатия
```php
interface PaymentStrategy {
    public function pay($amount);
}

class CreditCardPayment implements PaymentStrategy {
    public function pay($amount) {
        echo "Paying $amount via Credit Card\n";
    }
}

class PayPalPayment implements PaymentStrategy {
    public function pay($amount) {
        echo "Paying $amount via PayPal\n";
    }
}

class ShoppingCart {
    private $paymentStrategy;
    
    public function setPaymentStrategy(PaymentStrategy $strategy) {
        $this->paymentStrategy = $strategy;
    }
    
    public function checkout($amount) {
        $this->paymentStrategy->pay($amount);
    }
}
```

### 📝 **Command (Команда)**
- **Назначение:** Инкапсулирует запрос как объект
- **Пример:** Очереди команд, отмена операций, макросы
```php
interface Command {
    public function execute();
    public function undo();
}

class LightOnCommand implements Command {
    private $light;
    
    public function __construct(Light $light) {
        $this->light = $light;
    }
    
    public function execute() {
        $this->light->turnOn();
    }
    
    public function undo() {
        $this->light->turnOff();
    }
}

class RemoteControl {
    private $command;
    
    public function setCommand(Command $command) {
        $this->command = $command;
    }
    
    public function pressButton() {
        $this->command->execute();
    }
}
```

### 🏃 **Chain of Responsibility (Цепочка обязанностей)**
- **Назначение:** Передает запрос по цепочке обработчиков
- **Пример:** Middleware, обработка запросов, валидация
```php
abstract class Logger {
    const ERROR = 1;
    const DEBUG = 2;
    const INFO = 3;
    
    protected $level;
    protected $nextLogger;
    
    public function setNext(Logger $nextLogger) {
        $this->nextLogger = $nextLogger;
    }
    
    public function logMessage($level, $message) {
        if ($this->level <= $level) {
            $this->write($message);
        }
        if ($this->nextLogger !== null) {
            $this->nextLogger->logMessage($level, $message);
        }
    }
    
    abstract protected function write($message);
}
```

### 🎮 **State (Состояние)**
- **Назначение:** Позволяет объекту изменять поведение при изменении состояния
- **Пример:** Редактор с разными состояниями, плеер
```php
interface State {
    public function play(Player $player);
    public function pause(Player $player);
}

class PlayingState implements State {
    public function play(Player $player) {
        echo "Already playing\n";
    }
    
    public function pause(Player $player) {
        echo "Pausing playback\n";
        $player->setState(new PausedState());
    }
}
```

### 🔄 **Iterator (Итератор)**
- **Назначение:** Последовательный доступ к элементам коллекции
- **Пример:** Обход деревьев, коллекций
```php
class BookCollection implements Iterator {
    private $books = [];
    private $position = 0;
    
    public function current() {
        return $this->books[$this->position];
    }
    
    public function next() {
        $this->position++;
    }
    
    public function valid() {
        return isset($this->books[$this->position]);
    }
    // ... другие методы Iterator
}
```

### 🗣️ **Mediator (Посредник)**
- **Назначение:** Управляет взаимодействием между объектами
- **Пример:** Чат-комната, диспетчер сообщений
```php
class ChatRoom {
    public static function showMessage(User $user, $message) {
        echo date('Y-m-d H:i:s') . " [{$user->getName()}]: {$message}\n";
    }
}
```

### 💾 **Memento (Снимок)**
- **Назначение:** Сохраняет и восстанавливает состояние объекта
- **Пример:** Отмена действий, сохранение игры
```php
class EditorMemento {
    private $content;
    
    public function __construct($content) {
        $this->content = $content;
    }
    
    public function getContent() {
        return $this->content;
    }
}
```

### 🧮 **Template Method (Шаблонный метод)**
- **Назначение:** Определяет скелет алгоритма в методе
- **Пример:** Алгоритмы приготовления напитков
```php
abstract class Beverage {
    final public function prepareRecipe() {
        $this->boilWater();
        $this->brew();
        $this->pourInCup();
        $this->addCondiments();
    }
    
    abstract protected function brew();
    abstract protected function addCondiments();
}
```

### 💰 **Visitor (Посетитель)**
- **Назначение:** Добавляет новые операции к объектам без их изменения
- **Пример:** Анализ AST, экспорт данных
```php
interface Animal {
    public function accept(AnimalOperation $operation);
}

class Lion implements Animal {
    public function accept(AnimalOperation $operation) {
        $operation->visitLion($this);
    }
}

interface AnimalOperation {
    public function visitLion(Lion $lion);
    public function visitMonkey(Monkey $monkey);
}
```

## Когда какие паттерны использовать?


| **Проблема** | **Паттерн** |
|--------------|-------------|
| Создание сложных объектов | Builder, Abstract Factory |
| Управление зависимостями | Dependency Injection, Factory |
| Добавление функциональности | Decorator, Strategy |
| Взаимодействие компонентов | Mediator, Observer |
| Работа с коллекциями | Iterator, Composite |
| Управление состоянием | State, Memento |
| Оптимизация памяти | Flyweight, Prototype |

Паттерны — это инструменты, а не серебряные пули. Выбирайте их в зависимости от конкретной проблемы, а не пытайтесь "впихнуть" паттерн в проект любой ценой.
