## 1. Создание таблицы (`CREATE TABLE`)

Базовый синтаксис:

```sql
CREATE TABLE имя_таблицы (
    имя_столбца тип_данных [ограничения],
    ...
    [ограничения_таблицы]
);
```

### Пример:

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,              -- автоинкрементный PK
    username VARCHAR(50) NOT NULL,      -- строка до 50 символов
    email VARCHAR(100) UNIQUE,          -- уникальный индекс
    created_at TIMESTAMP DEFAULT now()  -- значение по умолчанию
);
```

👉 Важные типы: `SERIAL`, `BIGSERIAL`, `INTEGER`, `TEXT`, `BOOLEAN`, `DATE`, `TIMESTAMP`, `UUID`, `JSONB`.

---

## 2. Создание таблицы с внешними ключами (`FOREIGN KEY`)

```sql
CREATE TABLE orders (
    id SERIAL PRIMARY KEY,
    user_id INT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    amount NUMERIC(10,2) NOT NULL,
    created_at TIMESTAMP DEFAULT now()
);
```

- `REFERENCES users(id)` — связь с `users.id`.
    
- `ON DELETE CASCADE` — если удалить пользователя, удалятся и его заказы.
    

---

## 3. Изменение таблицы (`ALTER TABLE`)

### Добавить новый столбец:

```sql
ALTER TABLE users
ADD COLUMN age INT;
```

### Удалить столбец:

```sql
ALTER TABLE users
DROP COLUMN age;
```

### Переименовать столбец:

```sql
ALTER TABLE users
RENAME COLUMN username TO login;
```

### Изменить тип столбца:

```sql
ALTER TABLE users
ALTER COLUMN age TYPE BIGINT;
```

### Добавить ограничение:

```sql
ALTER TABLE users
ADD CONSTRAINT email_unique UNIQUE (email);
```

### Удалить ограничение:

```sql
ALTER TABLE users
DROP CONSTRAINT email_unique;
```

---

## 4. Индексы

### Создание индекса:

```sql
CREATE INDEX idx_users_email ON users(email);
```

### Уникальный индекс:

```sql
CREATE UNIQUE INDEX idx_users_login ON users(login);
```

### Удаление индекса:

```sql
DROP INDEX idx_users_email;
```

---

## 5. Удаление и переименование таблиц

### Переименовать таблицу:

```sql
ALTER TABLE users RENAME TO customers;
```

### Удалить таблицу:

```sql
DROP TABLE orders;
```

### Удалить таблицу со всеми зависимостями:

```sql
DROP TABLE users CASCADE;
```

---

## 6. Просмотр структуры

- Все таблицы в текущей схеме:
    

```sql
\dt
```

(в psql)

- Описание таблицы:
    

```sql
\d users
```

- SQL-описание:
    

```sql
\d+ users
```

---

⚡ Итог:

- **Создание**: `CREATE TABLE ...`
    
- **Изменение**: `ALTER TABLE ...`
    
- **Удаление**: `DROP TABLE ...`
    
- **Связи**: `FOREIGN KEY`, `REFERENCES`, `ON DELETE/UPDATE`
    
- **Оптимизация**: индексы (`CREATE INDEX`)
