
### **Задача 11. Container With Most Water (LeetCode)**

**Условие задачи:**  
Дан массив целых чисел `height` длиной `n`, где `height[i]` — это высота вертикальной линии на позиции `i`. Найдите две линии, которые вместе с осью X образуют контейнер, содержащий наибольшее количество воды.  

**Пример:**  
```go
height := []int{1, 8, 6, 2, 5, 4, 8, 3, 7}
// Ответ: 49 (между линиями height[1]=8 и height[8]=7)
// Ширина = 8-1 = 7, Высота = min(8,7) = 7 → Площадь = 7*7 = 49
```

---

### **Решение на Go (метод двух указателей)**
#### **Алгоритм:**  
1. **Инициализация**: Два указателя — `left` (начало массива) и `right` (конец массива).  
2. **Вычисление площади**:  
   - Площадь = `min(height[left], height[right]) * (right - left)`.  
3. **Перемещение указателей**:  
   - Сдвигаем указатель с **меньшей** высотой (так как только увеличение минимума даст потенциально большую площадь).  
4. **Завершение**: Когда `left` и `right` встречаются.  

#### **Код:**
```go
func maxArea(height []int) int {
    left, right := 0, len(height)-1
    maxWater := 0

    for left < right {
        // Вычисляем текущую площадь
        currentHeight := min(height[left], height[right])
        width := right - left
        currentWater := currentHeight * width

        // Обновляем максимум
        if currentWater > maxWater {
            maxWater = currentWater
        }

        // Сдвигаем указатель с меньшей высотой
        if height[left] < height[right] {
            left++
        } else {
            right--
        }
    }

    return maxWater
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```

---

### **Пошаговое пояснение для примера `[1,8,6,2,5,4,8,3,7]`:**

| Шаг | left | right | height[left] | height[right] | Площадь (min(h[l],h[r]) * width) | maxWater | Действие         |
|-----|------|-------|--------------|---------------|------------------------------------|----------|------------------|
| 1   | 0    | 8     | 1            | 7             | min(1,7)*8 = 8                     | 8        | left++ (1 < 7)   |
| 2   | 1    | 8     | 8            | 7             | min(8,7)*7 = 49                    | 49       | right-- (8 > 7)  |
| 3   | 1    | 7     | 8            | 3             | min(8,3)*6 = 18                    | 49       | right-- (8 > 3)  |
| ... | ...  | ...   | ...          | ...           | ...                                | ...      | ...              |
| Итог: maxWater = 49 (между height[1]=8 и height[8]=7) |

---

### **Оптимизация:**
- **Сложность**: O(n) — каждый элемент посещается один раз.  
- **Память**: O(1) — используем только два указателя.  

### **Почему это работает?**  
- **Инвариант**: Максимальная площадь зависит от **минимума высот** и **ширины**.  
- **Сдвиг меньшего указателя**: Позволяет "испытать" более высокие линии, сохраняя максимальную ширину.  

### **Тестирование:**
```go
func main() {
    fmt.Println(maxArea([]int{1, 8, 6, 2, 5, 4, 8, 3, 7})) // 49
    fmt.Println(maxArea([]int{1, 1}))                      // 1
    fmt.Println(maxArea([]int{4, 3, 2, 1, 4}))             // 16
}
```
