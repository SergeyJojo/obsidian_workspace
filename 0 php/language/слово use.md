# ✔️ **1. use для импортов (namespaces)**

Это **самое известное применение** — импортировать классы, интерфейсы, трейты, функции или константы в текущий файл.

### Пример:

```php
use App\Services\UserService;
use App\Models\User;
```

Это упрощает длинные имена:

```php
$service = new UserService();
```

Вместо:

```php
$service = new \App\Services\UserService();
```

### Важное:

- `use` тут работает только **на уровне файла**, не внутри функций.
    
- Можно задавать алиасы:
    

```php
use App\Services\UserService as Service;
```

# ✔️ **2. use в анонимных функциях (closures)**

Это почти всегда вызывает вопросы.

Когда ты создаёшь **анонимную функцию**, она **не имеет доступа к внешним переменным**, как это есть в Python или JS.  
Чтобы передать внутрь переменные из внешней области — используешь **use (...)**.

### Пример:

```php
$count = 10;

$fn = function () use ($count) {
    echo $count;
};

$fn();  // выведет 10
```

Без `use ($count)` — будет ошибка “undefined variable”.

### Важные моменты:

#### ✔ Значения копируются (pass-by-value)

```php
$count = 10;
$fn = function () use ($count) {
    $count = 20;
};
$fn();
echo $count; // Все равно 10
```

#### ✔ Чтобы передать по ссылке — ставим & :

```php
$count = 10;

$fn = function () use (&$count) {
    $count = 20;
};

$fn();
echo $count; // 20
```

#### ✔ Так работает замыкание (closure) в PHP

`use` определяет, какие **переменные из родительского скоупа** нужно «замкнуть» в анонимку.

# ✔️ **3. use в трейтах**

Ещё один контекст `use` — трейт внутри класса.

```php
class User {
    use HasUuid, SoftDeletes;
}
```

Здесь `use` подключает **реализацию методов и свойств** из трейта в класс.

### Важные детали:

- если два трейта содержат методы с одинаковыми именами — конфликт
    
- PHP позволяет разрулить конфликт через `insteadof` и `as`
    

```php
trait A {
    public function run() { echo "A"; }
}

trait B {
    public function run() { echo "B"; }
}

class C {
    use A, B {
        A::run insteadof B; // берём run из A
        B::run as runFromB; // но даём доступ к run из B
    }
}
```

# ✔ Итог: что делает **use** в PHP?

|Контекст|Что делает|
|---|---|
|**use Namespace**|Импортирует классы, интерфейсы, трейты, функции, константы|
|**use ($var) в closure**|Передаёт переменные внешнего скоупа в анонимную функцию|
|**use Trait**|Включает набор методов/свойств трейта в класс|

# ✔️ Частые ошибки:

### 1. `use` в closure не работает внутри цикла

Он работает, но **копирует значение**, поэтому многие думают, что не работает.

### 2. Думают, что use импортирует файлы

Нет — за автозагрузку отвечает **composer autoload**, а не `use`.

### 3. Думают, что `use` для трейтов — то же самое, что импорт классов

Нет, это механически внедряет их методы.

### 4. Путают `use` и `use function` / `use const`

Например:

```php
use function App\Helpers\str_slug;
use const App\Constants\PI;
```
