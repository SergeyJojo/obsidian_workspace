
В Linux справедливое разделение времени для процессов реализуется с помощью планировщиков задач (CPU schedulers), которые распределяют процессорное время между процессами. Главное, чтобы каждый процесс получал справедливую долю ресурсов в зависимости от его приоритета, нагрузки и других факторов.

---

### **Основные концепции справедливого разделения времени**

1. **Контекст переключения (Context Switching):**  
   - Процессор быстро переключается между задачами, создавая иллюзию параллельного выполнения.
   - Для каждого процесса выделяется **квант времени** (обычно несколько миллисекунд), после чего управление передаётся следующему процессу.

2. **Планировщики задач:**
   - Планировщик (scheduler) отвечает за выбор следующего процесса, который будет выполнять работу на процессоре.
   - В современных системах Linux используется **CFS** (Completely Fair Scheduler), который стремится равномерно распределить процессорное время между процессами.

3. **Приоритеты:**  
   - Каждый процесс имеет **приоритет**, который влияет на его долю процессорного времени.
   - Процессы с более высоким приоритетом получают больше процессорного времени.

4. **Nice и приоритет:**  
   - Значение `nice` позволяет пользователю задавать относительный приоритет процесса. Чем выше значение `nice`, тем меньше процессорного времени получает процесс.

---

### **Completely Fair Scheduler (CFS)**

**CFS** — это планировщик задач, используемый по умолчанию в современных ядрах Linux. Его цель — обеспечить максимально **справедливое** распределение процессорного времени между процессами.

1. **Как работает CFS:**
   - У каждого процесса есть **виртуальное время выполнения** (vruntime), которое увеличивается, когда процесс работает.
   - Процессы с меньшим `vruntime` получают больше процессорного времени, чтобы их "догнать" до справедливого уровня.
   - Чем больше нагрузка на процессор, тем меньше времени выделяется каждому процессу.

2. **Ключевые параметры:**
   - **Квант времени:** Время, в течение которого процесс может выполняться до переключения.
   - **Cgroups:** Позволяют ограничивать использование CPU группами процессов.

3. **Преимущество CFS:**
   - Все процессы получают процессорное время, пропорциональное их приоритету.
   - Процессы с низким приоритетом (высоким `nice`) получают меньше процессорного времени, но всё равно не голодают.

---

### **Распределение времени для процессов**

1. **Процессы реального времени:**
   - Процессы с высоким приоритетом (реального времени) выполняются перед всеми другими процессами.
   - Используют политики **SCHED_FIFO** и **SCHED_RR** (описаны ниже).

2. **Обычные процессы:**
   - Используют политику **SCHED_OTHER** (дефолтная политика CFS).
   - Их приоритет определяется значением `nice` (от -20 до 19).

3. **Балансировка нагрузки:**
   - Если система имеет несколько ядер, Linux автоматически балансирует процессы между ядрами.

---

### **Политики планирования**

Linux поддерживает несколько политик планирования задач:

1. **SCHED_OTHER (CFS):**
   - Политика по умолчанию для обычных процессов.
   - Справедливое распределение процессорного времени.

2. **SCHED_FIFO (First In, First Out):**
   - Подходит для процессов реального времени.
   - Процессы выполняются в порядке очереди, пока не завершатся или не перейдут в состояние ожидания.
   - Более высокий приоритет, чем у SCHED_OTHER.

3. **SCHED_RR (Round Robin):**
   - Подобно SCHED_FIFO, но каждому процессу выделяется фиксированный квант времени.

4. **SCHED_IDLE:**
   - Используется для процессов с самым низким приоритетом.
   - Процессы выполняются только тогда, когда система простаивает.

---

### **Примеры справедливого разделения времени**

1. **Запуск двух процессов с одинаковым приоритетом:**
   Если вы запускаете два процесса с одинаковым приоритетом (например, `nice = 0`), они будут получать равное количество процессорного времени.

   ```bash
   dd if=/dev/zero of=/dev/null &
   dd if=/dev/zero of=/dev/null &
   ```

   Команда `top` покажет, что оба процесса используют примерно **50%** CPU на 2-ядерной системе.

2. **Запуск процессов с разными приоритетами:**
   Если у одного процесса `nice = -10`, а у другого `nice = 10`, то первый процесс будет получать больше процессорного времени.

   ```bash
   nice -n -10 dd if=/dev/zero of=/dev/null &
   nice -n 10 dd if=/dev/zero of=/dev/null &
   ```

---

### **Управление процессами и справедливостью**

1. **Изменение приоритета процесса:**

   - Команда `renice`:
     ```bash
     renice -10 -p 1234  # Повысить приоритет процесса с PID 1234
     renice 10 -p 5678   # Понизить приоритет процесса с PID 5678
     ```

2. **Отображение приоритетов:**
   - Используйте `ps` или `top`:
     ```bash
     ps -o pid,ni,comm -p 1234
     top
     ```

3. **Использование Cgroups для контроля групп процессов:**
   - Cgroups позволяют ограничивать ресурсы для группы процессов.
   - Пример создания ограничения:
     ```bash
     sudo cgcreate -g cpu:/mygroup
     echo 512 | sudo tee /sys/fs/cgroup/cpu/mygroup/cpu.shares
     cgexec -g cpu:/mygroup your_command
     ```

---

### **Ключевые параметры конфигурации ядра**

1. **`kernel.sched_latency_ns`:**
   - Определяет общее время, в течение которого все задачи должны получить процессорное время.

2. **`kernel.sched_min_granularity_ns`:**
   - Минимальный квант времени для процесса.

---

### **Итог**

В Linux справедливое разделение времени между процессами достигается за счёт:

- Использования планировщика CFS, который распределяет процессорное время между процессами в зависимости от их приоритетов (`nice`).
- Поддержки различных политик для задач реального времени.
- Возможности настройки приоритетов процессов и ограничения ресурсов через `nice`, `renice` и cgroups.

Эти механизмы обеспечивают баланс между производительностью системы и её справедливостью для всех процессов.
