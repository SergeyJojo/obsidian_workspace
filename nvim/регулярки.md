# **Гайд по регулярным выражениям (RegExp) в Vim/NeoVim**  
Регулярные выражения (regex) — мощный инструмент для поиска и замены текста. Здесь только **практика без лишней теории**.  

---

## **1. Базовый синтаксис замены**  
```vim  
:[диапазон]s/паттерн/замена/[флаги]  
```  
- **`диапазон`**:  
  - `%` — весь файл.  
  - `'<,'>` — выделенный текст (визуальный режим).  
  - `10,20` — строки с 10 по 20.  
- **`флаги`**:  
  - `g` — заменить все вхождения в строке.  
  - `c` — подтверждать каждую замену.  
  - `i` — игнорировать регистр.  

**Пример**:  
```vim  
:%s/foo/bar/g      " Заменить все 'foo' на 'bar' в файле  
:'<,'>s/old/new/g  " Заменить в выделенном тексте  
```

---

## **2. Спецсимволы (метасимволы)**  
| Символ | Что означает                  | Пример                     |  
|--------|-------------------------------|----------------------------|  
| `.`    | Любой символ, кроме `\n`      | `a.c` → `abc`, `a c`       |  
| `*`    | 0 или больше повторений       | `a*b` → `b`, `aaab`        |  
| `\+`   | 1 или больше повторений       | `a\+b` → `ab`, `aaab`      |  
| `\?`   | 0 или 1 повторение            | `a\?b` → `b`, `ab`         |  
| `^`    | Начало строки                 | `^foo` → `foo` в начале    |  
| `$`    | Конец строки                  | `bar$` → `bar` в конце     |  
| `\s`   | Пробельный символ (пробел, таб)| `\s\+` → 1+ пробелов       |  
| `\w`   | Буква, цифра или `_`          | `\w\+` → слово (`hello`)   |  
| `\d`   | Цифра                        | `\d\+` → число (`42`)      |  
| `[...]`| Любой символ из скобок        | `[aeiou]` → гласная        |  

---

## **3. Группы захвата `\( \)` и подстановки `\1`, `\2`**  
- **`\(группа\)`** — захватывает текст для повторного использования.  
- **`\1`, `\2`** — вставляют захваченный текст.  

**Пример**:  
```vim  
:%s/\(\w\+\) \(\w\+\)/\2 \1/  " Меняет местами два слова  
```  
**До**: `John Doe`  
**После**: `Doe John`  

---

## **4. Жадные (`.*`) и ленивые (`.\{-}`) квантификаторы**  
- **`.*`** — жадный (захватывает максимум).  
- **`.\{-}`** — ленивый (захватывает минимум).  

**Пример**:  
```vim  
:%s/\(a.\{-}b\)/(\1)/g  
```  
**Текст**: `aXb aYYb aZZZb`  
**Результат**: `(aXb) (aYYb) (aZZZb)`  

---

## **5. Продвинутые примеры**  

### **🔹 Замена с условиями**  
```vim  
:%s/\<foo\>/bar/g      " Только целые слова 'foo'  
:%s/\d\+/\=submatch(0)*2/g  " Умножить все числа на 2  
```  

### **🔹 Многострочные замены**  
```vim  
:%s/start\_.\{-}end/NEW/g  " Замена текста между 'start' и 'end'  
```  

### **🔹 Форматирование кода**  
```vim  
:%s/\(\w\+\) = \(\w\+\);/const \1 = \2;/g  " JS: var → const  
```  

---

## **6. Практические задания**  
1. **Заменить все даты `YYYY-MM-DD` на `DD.MM.YYYY`**:  
   ```vim  
   :%s/\(\d\{4\}\)-\(\d\{2\}\)-\(\d\{2\}\)/\3.\2.\1/g  
   ```  

2. **Удалить все комментарии `// ...`**:  
   ```vim  
   :%s/\/\/.*$//g  
   ```  

3. **Обернуть все числа в скобки**:  
   ```vim  
   :%s/\(\d\+\)/(\1)/g  
   ```  

---

## **7. Полезные команды**  
- **`:set hlsearch`** — подсвечивать совпадения.  
- **`:noh`** — убрать подсветку.  
- **`/паттерн`** — поиск.  
- **`:%s///gn`** — подсчитать количество совпадений.  

---

## **Вывод**  
1. **Паттерн** — что ищем.  
2. **Замена** — на что меняем.  
3. **Группы `\( \)`** — переиспользование текста.  
4. **Флаги `g`, `c`** — глобально или с подтверждением.  

Практикуйтесь на реальных файлах, и через неделю будете писать сложные regex как профессионал! 🚀
