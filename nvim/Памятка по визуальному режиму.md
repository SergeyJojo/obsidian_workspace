
Вот две **памятки по визуальному и обычному режиму в Neovim**, но без банальных команд (`h`, `j`, `yy`, `dd` и т.п.). Это шпаргалка **для уверенного использования Vim как мощного редактора кода**, особенно в Go, Rust и других системных языках.

---

## 🧲 Памятка по ВИЗУАЛЬНОМУ режиму (Visual Mode)

Вход в режим:

- `v` — **символьный режим**
    
- `V` — **строчный режим**
    
- `Ctrl+v` — **блочный (column / rectangular) режим**
    

### 📋 Копирование / удаление / вставка

|Команда|Описание|
|---|---|
|`y`|Yank — копировать выделенное|
|`d`|Delete — удалить выделенное|
|`x`|То же, что и `d`, но используется чаще для символов|
|`c`|Change — удалить и перейти в вставку|
|`>` / `<`|Сдвинуть блок вправо / влево (табуляция)|
|`=`|Авто-форматировать выделенный код (`go fmt`, и т.п.)|

### 🎯 Изменение по шаблону

|Команда|Описание|
|---|---|
|`:s/old/new/g`|Заменить `old` на `new` в выделении|
|`:norm`|Выполнить нормальные команды над каждой строкой|
|`:sort`|Отсортировать выделение|
|`gU` / `gu`|Преобразовать в ВЕРХНИЙ / нижний регистр|
|`J`|Объединить строки|
|`!command`|Пропустить текст через внешнюю команду (например, `!sort`)|

### 🔥 Крутые штуки

|Команда|Описание|
|---|---|
|`:'<,'>normal I//`|Добавить `//` в начало каждой строки|
|`:'<,'>sort`|Сортировать выделенные строки|
|`:'<,'>g/^$/d`|Удалить пустые строки в выделении|
|`:'<,'>s/\s\+$//e`|Удалить пробелы в конце строк|
|`:'<,'>!jq .`|Отформатировать JSON через `jq`|

## ⚙ Памятка по ОБЫЧНОМУ режиму (Normal Mode, без тривиальных команд)

### 🧭 Движение по коду **(умное)**

|Команда|Описание|
|---|---|
|`]m` / `[m`|К следующей / предыдущей функции (ctags)|
|`]]` / `[[`|К следующему / предыдущему разделу кода|
|`]}` / `[}`|Переход между параграфами|
|`gd`|Переход к локальному определению|
|`gD`|Переход к глобальному определению|
|`Ctrl-o`|Назад по истории переходов|
|`Ctrl-i`|Вперёд по истории переходов|

### 🔍 Поиск и замена

|Команда|Описание|
|---|---|
|`*` / `#`|Найти следующее / предыдущее вхождение слова|
|`:g/word/d`|Удалить все строки, содержащие `word`|
|`:v/word/d`|Удалить все строки, **не** содержащие `word`|
|`:%s/foo/bar/gc`|Заменить `foo` на `bar`, спрашивая подтверждение|

### 💡 Контекстное редактирование

|Команда|Описание|
|---|---|
|`ci"`|Change inside кавычек|
|`ci(`|Change inside скобок|
|`di[`|Delete inside квадратных скобок|
|`va{`|Visual around `{...}`|
|`yi'`|Yank inside кавычек|
|`:normal @q`|Выполнить макрос `q` над каждой строкой|

### 🛠 Макросы и регистры

|Команда|Описание|
|---|---|
|`q<reg>`|Начать запись макроса в регистр `<reg>` (напр. `qa`)|
|`q`|Закончить запись макроса|
|`@<reg>`|Выполнить макрос|
|`@@`|Повторить последний макрос|
|`"ayw`|Yank слово в регистр `a`|
|`:reg`|Показать содержимое регистров|

### 📂 Буферы / окна / вкладки

|Команда|Описание|
|---|---|
|`:bn` / `:bp`|Следующий / предыдущий буфер|
|`:ls` / `:buffers`|Список буферов|
|`:sp` / `:vsp`|Горизонтальный / вертикальный сплит|
|`Ctrl-w r`|Поменять окна местами|
|`:tabnew`|Новая вкладка|
|`gt` / `gT`|Вперёд / назад по вкладкам|

Если ты работаешь с Go и Rust, то рекомендую:

### 🔌 Полезные плагины для нормального режима

- `nvim-treesitter` — структурная навигация по AST
    
- `telescope.nvim` — поиск по буферам, файлам, командам
    
- `gitsigns.nvim` — команды `]c` и `[c` для прыжков по изменениям
    
- `vim-surround` — мощная работа с обёртками (`cs"'`, `ds"`, `ysiw)`, и т.п.)
    
- `which-key.nvim` — показать доступные команды и комбинации
