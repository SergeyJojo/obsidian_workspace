**LRU (Least Recently Used)** — это алгоритм замещения страниц, который используется в кэшировании для управления памятью. Он помогает эффективно удалять наименее используемые данные, чтобы освободить место для новых. Основная идея LRU заключается в том, чтобы хранить в кэше только те данные, которые были использованы недавно, и удалять те, которые не использовались дольше всего.

### Как работает LRU кэш?

1. **Основная идея**: Когда кэш переполнен и требуется место для новых данных, старые данные, которые не использовались долго, удаляются, а новые данные вставляются в кэш. Это помогает гарантировать, что наиболее часто используемые данные остаются в памяти.
    
2. **Данные отсортированы по времени последнего использования**. Когда мы обращаемся к элементу в кэше, он становится "самым недавно использованным" и перемещается в начало очереди или списка. Если элемент не был использован недавно, он остается в конце и будет удален, когда потребуется освободить место.
    

### Алгоритм LRU

LRU обычно реализуется с использованием двух структур данных:

- **Хеш-таблица** для быстрого поиска элементов по ключу.
- **Двунаправленный список** для отслеживания порядка использования элементов.

#### Как это работает:

1. Когда происходит доступ к элементу, мы перемещаем его в начало списка (это означает, что он был использован недавно).
2. Когда кэш заполняется, мы удаляем элемент из конца списка, так как он является наименее недавно использованным.

### Реализация LRU кэша в Go

Для реализации LRU кэша в Go можно использовать `map` (для быстрого поиска) и **двунаправленный список** (для хранения порядка использования).

Пример реализации:

```go
package main

import (
	"container/list"
	"fmt"
)

type LRUCache struct {
	capacity int
	cache    map[int]*list.Element
	order    *list.List
}

type CacheItem struct {
	key   int
	value int
}

func NewLRUCache(capacity int) *LRUCache {
	return &LRUCache{
		capacity: capacity,
		cache:    make(map[int]*list.Element),
		order:    list.New(),
	}
}

func (lru *LRUCache) Get(key int) int {
	if element, found := lru.cache[key]; found {
		// Перемещаем элемент в начало списка (обновляем его как самый недавно использованный)
		lru.order.MoveToFront(element)
		return element.Value.(*CacheItem).value
	}
	return -1 // Элемент не найден
}

func (lru *LRUCache) Put(key, value int) {
	if element, found := lru.cache[key]; found {
		// Если элемент существует, обновляем его значение и перемещаем в начало
		element.Value.(*CacheItem).value = value
		lru.order.MoveToFront(element)
	} else {
		// Если элемент не существует, добавляем новый
		if lru.order.Len() == lru.capacity {
			// Удаляем самый старый элемент
			lru.removeOldest()
		}
		item := &CacheItem{key, value}
		element := lru.order.PushFront(item)
		lru.cache[key] = element
	}
}

func (lru *LRUCache) removeOldest() {
	// Удаляем последний элемент из списка
	oldest := lru.order.Back()
	if oldest != nil {
		lru.order.Remove(oldest)
		delete(lru.cache, oldest.Value.(*CacheItem).key)
	}
}

func main() {
	cache := NewLRUCache(3)

	cache.Put(1, 1)
	cache.Put(2, 2)
	cache.Put(3, 3)
	fmt.Println(cache.Get(1)) // Вернет 1
	cache.Put(4, 4)           // Удалит ключ 2
	fmt.Println(cache.Get(2)) // Вернет -1 (не найдено)
	cache.Put(5, 5)           // Удалит ключ 3
	fmt.Println(cache.Get(3)) // Вернет -1 (не найдено)
	fmt.Println(cache.Get(4)) // Вернет 4
	fmt.Println(cache.Get(5)) // Вернет 5
}
```

### Объяснение:

1. **Структура `CacheItem`**: Это элемент кэша, содержащий ключ и значение
2. **Структура `LRUCache`**:
    
    - `capacity`: максимальная вместимость кэша.
    - `cache`: хеш-таблица, где ключи — это ключи кэша, а значения — это элементы списка.
    - `order`: двунаправленный список, который отслеживает порядок использования элементов. Новый элемент добавляется в начало списка, а старый удаляется из конца.
3. **Метод `Get`**:
    
    - Пытается найти элемент в кэше по ключу. Если элемент найден, его перемещают в начало списка, что означает, что он был использован недавно.
4. **Метод `Put`**:
    
    - Если элемент существует, его значение обновляется, и он перемещается в начало списка.
    - Если элемент не существует, добавляется новый. Если кэш переполнен, удаляется старейший элемент (из конца списка).
5. **Метод `removeOldest`**:
    
    - Удаляет самый старый элемент из списка и хеш-таблицы, когда кэш переполнен.

### Пример работы:

В данном примере:

- Когда мы добавляем элементы 1, 2 и 3, кэш заполняется.
- Когда добавляется новый элемент с ключом 4, элемент с ключом 2 удаляется, потому что он был наименее недавно использован.
- При дальнейших добавлениях кэш обновляется, и самые старые элементы удаляются.

### Преимущества:

- **Быстрый доступ**: Операции `Get` и `Put` выполняются за **O(1)** благодаря использованию хеш-таблицы и двунаправленного списка.
- **Автоматическое удаление старых данных**: Кэш автоматически удаляет наименее используемые элементы при переполнении.

LRU-кэш является отличным инструментом для работы с ограниченными ресурсами (например, памятью) и широко используется в системах, где необходимо хранить только последние часто используемые данные.
