
### **Задача 14. Longest Common Prefix (LeetCode)**

**Условие задачи:**  
Напишите функцию, которая находит **наибольший общий префикс** среди массива строк. Если общего префикса нет, верните пустую строку `""`.

**Примеры:**
```go
Input: strs = ["flower","flow","flight"]
Output: "fl"

Input: strs = ["dog","racecar","car"]
Output: ""
```

---

### **Решение на Go (вертикальное сравнение)**

#### **Алгоритм:**
1. **Проверка на пустые данные**: Если массив пуст, сразу возвращаем `""`.
2. **Итерация по символам первой строки**: Берём каждый символ первой строки и сравниваем его с соответствующими символами остальных строк.
3. **Прерывание при несовпадении**: Как только находим несоответствие, возвращаем префикс до этого символа.
4. **Успешное завершение**: Если все символы первой строки совпали во всех строках, возвращаем первую строку как префикс.

#### **Код:**
```go
func longestCommonPrefix(strs []string) string {
    if len(strs) == 0 {
        return ""
    }

    // Берём первую строку как основу для сравнения
    first := strs[0]

    for i := 0; i < len(first); i++ {
        currentChar := first[i]

        // Проверяем текущий символ во всех строках
        for j := 1; j < len(strs); j++ {
            if i >= len(strs[j]) || strs[j][i] != currentChar {
                return first[:i]  // Возвращаем префикс до несовпадения
            }
        }
    }

    return first  // Если все символы совпали
}
```

---

### **Пошаговое пояснение для примера `["flower","flow","flight"]`:

1. **Первая строка**: `"flower"` (длина 6).
2. **Сравниваем посимвольно**:
   - `i=0`: `'f'` vs `'f'` (в `"flow"`) и `'f'` (в `"flight"`) → совпадает.
   - `i=1`: `'l'` vs `'l'` и `'l'` → совпадает.
   - `i=2`: `'o'` vs `'o'` и `'i'` → **не совпадает** (`'o' != 'i'`).
3. **Результат**: `first[:2] = "fl"`.

---

### **Оптимизация:**
- **Сложность**: O(S), где S — сумма длин всех строк (в худшем случае).  
- **Память**: O(1) — не используем дополнительную память.  

### **Альтернативные подходы:**
1. **Горизонтальное сравнение** (последовательно сокращаем префикс):  
   ```go
   func longestCommonPrefix(strs []string) string {
       if len(strs) == 0 {
           return ""
       }
       prefix := strs[0]
       for _, s := range strs {
           for strings.Index(s, prefix) != 0 {
               prefix = prefix[:len(prefix)-1]
               if prefix == "" {
                   return ""
               }
           }
       }
       return prefix
   }
   ```
2. **Двоичный поиск** по длине префикса (оптимально для очень длинных строк).

---

### **Тестирование:**
```go
func main() {
    fmt.Println(longestCommonPrefix([]string{"flower", "flow", "flight"}))  // "fl"
    fmt.Println(longestCommonPrefix([]string{"dog", "racecar", "car"}))     // ""
    fmt.Println(longestCommonPrefix([]string{"ab", "a"}))                   // "a"
}
```

### **Вывод:**
Решение эффективно обрабатывает все краевые случаи и является оптимальным для большинства сценариев. Главное — **ранний выход при несовпадении символов**, что ускоряет работу.
