Отличный вопрос, Сергей — в PHP **коллекции** в стандартной библиотеке реализованы в виде **массивов**, и подавляющее большинство “функций коллекций” — это функции работы с массивами (`array_*`).  
Всё, что в других языках зовётся `map`, `filter`, `reduce`, `sort`, `groupBy`, в PHP делается стандартными средствами.  
Разберём системно 👇

## 🧠 9. **“Функциональные” аналоги в коллекциях (PHP 7+)**

PHP сам по себе процедурный, но позволяет **цепочки вызовов** через `array_map/filter/reduce`.  
Пример — мини-коллекция в стиле JavaScript:

```php
$nums = [1, 2, 3, 4, 5];
$result = array_reduce(
    array_map(fn($x) => $x * 2, array_filter($nums, fn($x) => $x % 2)),
    fn($a, $b) => $a + $b,
    0
);
// → (2*1 + 2*3 + 2*5) = 18
```

## 🧩 10. **С объектами (`ArrayObject`, `Iterator`)**

PHP также даёт OO-обёртки над массивами:

```php
$coll = new ArrayObject([1,2,3]);
$coll->append(4);
```

Можно использовать `Iterator`, `Traversable`, `Generator` для ленивых коллекций.

Хочешь, я покажу тебе, как собрать **мини-библиотеку “Collection”** (с методами `map()`, `filter()`, `reduce()`, `sort()`) в PHP — в стиле Laravel Collections, но без фреймворка?

Отличный вопрос! В PHP есть **множество встроенных функций** для работы с массивами и «коллекциями» (в PHP нет отдельного типа «коллекция» — всё делается через **массивы** и **итераторы**).

Разберём по порядку:

---

## 🔍 1. **`isset()` — проверяет, существует ли переменная и не равна ли `null`**

```php
$var = null;
isset($var); // false

$var = 0;
isset($var); // true

$arr = ['a' => 1];
isset($arr['a']); // true
isset($arr['b']); // false
```

> ✅ Используется для **проверки существования ключа в массиве** или переменной.  
> ❌ Не подходит для проверки значения `0`, `""`, `false` — они **существуют**, но `empty()` вернёт `true`.

---

## 🔍 2. **`is_array()` — проверяет, является ли переменная массивом**

```php
is_array([1, 2, 3]); // true
is_array("hello");   // false
is_array(null);      // false
```

> ✅ Нужно, чтобы **избежать ошибок** при работе с данными неизвестного типа.  
> 💡 В PHP 8+ можно использовать **`array` в типах**:  
> ```php
> function process(array $data) { }
> ```

---

## 📦 3. **Основные функции для работы с массивами**

### 🔹 **Проверка и информация**
| Функция | Назначение |
|--------|-----------|
| `count($arr)` | Количество элементов |
| `array_key_exists('key', $arr)` | Есть ли **ключ** (даже если значение `null`) |
| `in_array($value, $arr)` | Есть ли **значение** |
| `array_keys($arr)` | Вернуть все ключи |
| `array_values($arr)` | Вернуть все значения |

> 💡 Разница:  
> - `isset($arr['key'])` → `false`, если ключа нет **или значение `null`**  
> - `array_key_exists('key', $arr)` → `true`, даже если `$arr['key'] = null`

---

### 🔹 **Добавление / удаление**
| Функция | Пример |
|--------|--------|
| `$arr[] = $value` | Добавить в конец |
| `array_push($arr, $val1, $val2)` | То же самое |
| `array_pop($arr)` | Удалить и вернуть последний элемент |
| `array_shift($arr)` | Удалить и вернуть первый элемент |
| `array_unshift($arr, $val)` | Добавить в начало |
| `unset($arr['key'])` | Удалить по ключу |

---

### 🔹 **Поиск и фильтрация**
| Функция | Пример |
|--------|--------|
| `array_search($value, $arr)` | Найти **ключ** по значению |
| `array_filter($arr, $callback)` | Отфильтровать по условию |
| `array_column($arr, 'field')` | Извлечь столбец из массива объектов/ассоц. массивов |

```php
$users = [
    ['name' => 'Alice', 'age' => 30],
    ['name' => 'Bob', 'age' => 25]
];

$names = array_column($users, 'name'); // ['Alice', 'Bob']
```

---

### 🔹 **Преобразование и объединение**
| Функция | Пример |
|--------|--------|
| `array_map($callback, $arr)` | Применить функцию ко всем элементам |
| `array_merge($arr1, $arr2)` | Объединить массивы |
| `array_unique($arr)` | Убрать дубликаты |
| `array_reverse($arr)` | Развернуть массив |
| `array_slice($arr, $offset, $length)` | Вырезать часть |
| `array_splice($arr, $offset, $length, $replacement)` | Заменить часть |

```php
$squares = array_map(fn($x) => $x ** 2, [1, 2, 3]); // [1, 4, 9]
```

---

### 🔹 **Сортировка**
| Функция | Сортировка |
|--------|-----------|
| `sort($arr)` | По значениям (индексы сбрасываются) |
| `rsort($arr)` | По значениям в обратном порядке |
| `asort($arr)` | По значениям, **сохраняя ключи** |
| `ksort($arr)` | По ключам |
| `usort($arr, $callback)` | По пользовательской функции |

```php
usort($users, fn($a, $b) => $a['age'] <=> $b['age']);
```

## 🔄 4. **Работа с итераторами (для больших данных)**

Если массив **очень большой**, лучше использовать **генераторы** или **итераторы**:

```php
// Генератор (экономит память)
function getLines($file) {
    $handle = fopen($file, 'r');
    while (!feof($handle)) {
        yield fgets($handle);
    }
}

foreach (getLines('huge.log') as $line) {
    // обработка по одной строке
}
```

> 💡 Встроенные итераторы: `ArrayIterator`, `DirectoryIterator`, `RecursiveIterator`.

## 📌 6. **Современные альтернативы (PHP 7.4+)**

### Arrow functions + array_map/filter
```php
$evens = array_filter($numbers, fn($n) => $n % 2 === 0);
$squares = array_map(fn($n) => $n ** 2, $numbers);
```

### Nullsafe и null coalescing
```php
$name = $user['profile']['name'] ?? 'Anonymous';
// или в PHP 8+
$name = $user?->profile?->name ?? 'Anonymous';
```

## ⚠️ Важные нюансы

1. **Ассоциативные массивы = хеш-таблицы** — порядок вставки сохраняется.
2. **`array_merge()` с числовыми ключами** — сбрасывает ключи!
   ```php
   array_merge([1 => 'a'], [2 => 'b']); // [0 => 'a', 1 => 'b']
   ```
   → Используй `+` для сохранения ключей: `[1 => 'a'] + [2 => 'b']`.
3. **`array_filter()` не сбрасывает ключи** — если нужно, оберни в `array_values()`.
