
В Linux для управления и мониторинга процессов существует множество команд. Вот основные команды для работы с процессами:

---

### **Мониторинг процессов**

1. **`ps`**  
   - Выводит список процессов.
   - Примеры:
     ```bash
     ps aux            # Список всех процессов с подробной информацией
     ps -ef            # Список процессов в другом формате
     ps -u username    # Список процессов конкретного пользователя
     ```

2. **`top`**  
   - Позволяет в реальном времени отслеживать использование ресурсов процессами.
   - Полезные клавиши в `top`:
     - `q`: Выход.
     - `h`: Справка.
     - `k`: Завершение процесса (ввод PID).
     - `r`: Изменение приоритета процесса.

3. **`htop`**  
   - Более удобная и интерактивная версия `top`.
   - Позволяет использовать мышь для управления процессами.
   - Установка: 
     ```bash
     sudo apt install htop  # Ubuntu/Debian
     ```

4. **`pidof`**  
   - Показывает PID (идентификатор процесса) заданной программы.
   - Пример:
     ```bash
     pidof firefox
     ```

5. **`pgrep`**  
   - Ищет процессы по имени и возвращает их PID.
   - Примеры:
     ```bash
     pgrep nginx          # Найти PID процессов с именем "nginx"
     pgrep -u username    # Найти процессы конкретного пользователя
     ```

---

### **Завершение процессов**

1. **`kill`**  
   - Завершает процесс по его PID.
   - Примеры:
     ```bash
     kill 1234            # Завершить процесс с PID 1234
     kill -9 1234         # Принудительное завершение процесса (SIGKILL)
     kill -15 1234        # Стандартное завершение процесса (SIGTERM)
     ```

2. **`pkill`**  
   - Завершает процесс по его имени.
   - Примеры:
     ```bash
     pkill chrome         # Завершить все процессы с именем "chrome"
     pkill -u username    # Завершить процессы конкретного пользователя
     ```

3. **`xkill`**  
   - Позволяет завершить графический процесс, кликнув на его окно.
   - Установка:
     ```bash
     sudo apt install x11-utils  # Для Ubuntu/Debian
     ```

4. **`killall`**  
   - Завершает все процессы с указанным именем.
   - Пример:
     ```bash
     killall firefox
     ```

---

### **Управление приоритетами процессов**

1. **`nice`**  
   - Запускает процесс с заданным приоритетом.
   - Пример:
     ```bash
     nice -n 10 ./script.sh  # Запустить процесс с приоритетом 10
     ```

2. **`renice`**  
   - Изменяет приоритет уже запущенного процесса.
   - Пример:
     ```bash
     renice 5 -p 1234        # Установить приоритет 5 для процесса с PID 1234
     ```

---

### **Фоновая и приостановленная работа**

1. **`&`**  
   - Запускает процесс в фоновом режиме.
   - Пример:
     ```bash
     ./script.sh &          # Запустить скрипт в фоне
     ```

2. **`jobs`**  
   - Показывает список всех фоновых процессов текущей сессии.
   - Пример:
     ```bash
     jobs
     ```

3. **`fg`**  
   - Возвращает фоновый процесс в передний план.
   - Пример:
     ```bash
     fg %1                  # Вернуть первый процесс из списка jobs
     ```

4. **`bg`**  
   - Возобновляет приостановленный процесс в фоновом режиме.
   - Пример:
     ```bash
     bg %1                  # Возобновить процесс из списка jobs
     ```

5. **`Ctrl + Z`**  
   - Приостанавливает текущий процесс и отправляет его в фон.

---

### **Отображение дерева процессов**

1. **`pstree`**  
   - Показывает дерево процессов.
   - Пример:
     ```bash
     pstree
     pstree -p             # Отобразить PID процессов
     pstree username       # Дерево процессов конкретного пользователя
     ```

---

### **Ограничение ресурсов процесса**

1. **`ulimit`**  
   - Устанавливает ограничения на использование ресурсов процессами.
   - Пример:
     ```bash
     ulimit -u 100         # Ограничить количество процессов до 100
     ulimit -n 1024        # Ограничить количество открытых файлов до 1024
     ```

2. **`cpulimit`**  
   - Ограничивает использование CPU процессом.
   - Установка:
     ```bash
     sudo apt install cpulimit
     ```
   - Пример:
     ```bash
     cpulimit -p 1234 -l 50  # Ограничить процесс с PID 1234 до 50% CPU
     ```

3. **`nice`/`renice`**  
   - Используется для управления приоритетом процесса.

---

### **Отладка и диагностика**

1. **`strace`**  
   - Отображает системные вызовы, выполняемые процессом.
   - Пример:
     ```bash
     strace -p 1234        # Отследить системные вызовы процесса с PID 1234
     ```

2. **`lsof`**  
   - Показывает открытые файлы процесса.
   - Пример:
     ```bash
     lsof -p 1234          # Открытые файлы процесса с PID 1234
     ```

3. **`dstat`**  
   - Мониторинг использования ресурсов.
   - Установка:
     ```bash
     sudo apt install dstat
     ```
   - Пример:
     ```bash
     dstat
     ```

4. **`vmstat`**  
   - Показывает общую статистику системы (процессы, память, ввод/вывод и т.д.).
   - Пример:
     ```bash
     vmstat 1              # Обновление статистики каждую секунду
     ```

---

### **Примеры полезных комбинаций**

1. **Найти и завершить процесс по имени:**
   ```bash
   pgrep firefox | xargs kill -9
   ```

2. **Список процессов, использующих больше всего CPU:**
   ```bash
   ps aux --sort=-%cpu | head -n 10
   ```

3. **Список процессов, использующих больше всего памяти:**
   ```bash
   ps aux --sort=-%mem | head -n 10
   ```

---

Эти команды помогут вам эффективно управлять процессами и мониторить их работу в Linux.
