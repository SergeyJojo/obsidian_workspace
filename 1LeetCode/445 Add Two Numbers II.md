## 🟩 **Задача 4 — [445. Add Two Numbers II](https://leetcode.com/problems/add-two-numbers-ii)**

### 🔹 Твоя формулировка: «Сумма чисел двух массивов»

---

### 📋 Условие

Даны два массива неотрицательных цифр `arr1` и `arr2`.  
Они представляют два числа: старшие разряды — в начале массива.  
Нужно вернуть сумму этих чисел в **таком же формате**.

---

### 📌 Пример 1

```go
arr1 = [1, 2, 3] // 123
arr2 = [4, 5, 6] // 456

// Вывод:
[5, 7, 9] // 579
```

---

### 📌 Пример 2

```go
arr1 = [5, 4, 4] // 544
arr2 = [4, 5, 6] // 456

// Вывод:
[1, 0, 0, 0] // 1000
```

---

## 🧠 Идея алгоритма

1. Мы складываем как в столбик: справа налево.
    
2. Чтобы не разворачивать массивы — используем **два указателя**, начиная с конца.
    
3. Поддерживаем **перенос** (`carry`), складываем поразрядно.
    
4. Ответ строим **в обратном порядке**, затем разворачиваем.
    

---

## ✅ Реализация на Go

```go
package main

import (
	"fmt"
)

func addArrays(a, b []int) []int {
	i, j := len(a)-1, len(b)-1
	carry := 0
	result := []int{}

	for i >= 0 || j >= 0 || carry > 0 {
		sum := carry

		if i >= 0 {
			sum += a[i]
			i--
		}
		if j >= 0 {
			sum += b[j]
			j--
		}

		result = append([]int{sum % 10}, result...) // prepend
		carry = sum / 10
	}

	return result
}

func main() {
	arr1 := []int{5, 4, 4}
	arr2 := []int{4, 5, 6}
	fmt.Println("Sum:", addArrays(arr1, arr2)) // [1 0 0 0]
}
```

---

## 📈 Сложность

- **Время**: `O(max(len(arr1), len(arr2)))`
    
- **Память**: `O(N)` — на результат (может быть длиннее на 1)
    

---

## 🧪 Edge Cases

- Один массив пустой → вернуть другой
    
- `carry` в конце: `[9, 9] + [1] → [1, 0, 0]`
    
- Неизменяемость входных слайсов
