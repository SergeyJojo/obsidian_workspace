
В Go с помощью **pgx** можно делать `CopyFrom` из CSV-файла, если прочитать CSV-файл и передавать строки в виде `[]interface{}` для вставки в таблицу. Вот подробная инструкция и пример кода:

---

## **1. Прочитай CSV-файл**

Используй стандартный пакет `encoding/csv` для чтения строк.

```go
import (
    "encoding/csv"
    "os"
)

file, err := os.Open("data.csv")
if err != nil {
    // обработка ошибки
}
defer file.Close()
reader := csv.NewReader(file)
```

---

## **2. Преобразуй строки в [][]interface{}**

Считай все строки, пропусти заголовок (если есть), и приведи их к нужным типам:

```go
var rows [][]interface{}
records, err := reader.ReadAll()
if err != nil {
    // обработка ошибки
}
// Пропусти заголовок, если он есть
for _, record := range records[1:] {
    // Пример: первая колонка int, вторая строка
    id, _ := strconv.Atoi(record[0])
    name := record[1]
    rows = append(rows, []interface{}{id, name})
}
```

---

## **3. Вызови CopyFrom**

```go
inserted, err := conn.CopyFrom(
    ctx,
    pgx.Identifier{"users"},
    []string{"id", "name"},
    pgx.CopyFromRows(rows),
)
if err != nil {
    // обработка ошибки
}
fmt.Printf("Вставлено строк: %d\n", inserted)
```

---

## **4. Пример полного кода**

```go name=copy_from_csv.go
package main

import (
    "context"
    "encoding/csv"
    "fmt"
    "log"
    "os"
    "strconv"

    "github.com/jackc/pgx/v5"
)

func main() {
    ctx := context.Background()
    conn, err := pgx.Connect(ctx, "postgres://postgres:password@localhost:5432/mydb")
    if err != nil {
        log.Fatal(err)
    }
    defer conn.Close(ctx)

    file, err := os.Open("data.csv")
    if err != nil {
        log.Fatal(err)
    }
    defer file.Close()

    reader := csv.NewReader(file)
    records, err := reader.ReadAll()
    if err != nil {
        log.Fatal(err)
    }

    var rows [][]interface{}
    for _, record := range records[1:] { // если есть заголовок
        id, _ := strconv.Atoi(record[0])
        name := record[1]
        rows = append(rows, []interface{}{id, name})
    }

    n, err := conn.CopyFrom(
        ctx,
        pgx.Identifier{"users"},
        []string{"id", "name"},
        pgx.CopyFromRows(rows),
    )
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("Вставлено строк: %d\n", n)
}
```

## **5. Прямая загрузка (стриминг из файла)**

Если файл очень большой, можно реализовать свой `pgx.CopyFromSource`, читающий CSV “на лету”, чтобы не держать всё в памяти:

```go name=csv_source.go
package main

import (
    "encoding/csv"
    "io"
    "os"
    "strconv"
)

type CsvSource struct {
    r       *csv.Reader
    current []interface{}
    err     error
}

func NewCsvSource(f *os.File) *CsvSource {
    return &CsvSource{r: csv.NewReader(f)}
}

func (c *CsvSource) Next() bool {
    record, err := c.r.Read()
    if err != nil {
        if err != io.EOF {
            c.err = err
        }
        return false
    }
    id, _ := strconv.Atoi(record[0])
    name := record[1]
    c.current = []interface{}{id, name}
    return true
}
func (c *CsvSource) Values() ([]interface{}, error) { return c.current, nil }
func (c *CsvSource) Err() error                    { return c.err }
```

Использование:

```go
file, _ := os.Open("data.csv")
defer file.Close()
src := NewCsvSource(file)
conn.CopyFrom(ctx, pgx.Identifier{"users"}, []string{"id", "name"}, src)
```

---

**Итого:**  
- Читаешь CSV → преобразуешь строки в []interface{} → `pgx.CopyFrom`.
- Для больших файлов лучше использовать собственный CopyFromSource.
