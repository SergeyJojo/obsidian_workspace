**Магические методы в PHP** — это специальные методы, которые автоматически вызываются при определенных событиях в жизни объекта. Вот полный обзор:

## 🎯 **Список магических методов**

| Метод | Когда вызывается | Пример использования |
|-------|------------------|---------------------|
| **`__construct()`** | При создании объекта | Инициализация объекта |
| **`__destruct()`** | При уничтожении объекта | Освобождение ресурсов |
| **`__get()`** | При чтении недоступного свойства | Геттеры для приватных свойств |
| **`__set()`** | При записи в недоступное свойство | Сеттеры с валидацией |
| **`__isset()`** | При вызове `isset()` на недоступном свойстве | Кастомная логика проверки |
| **`__unset()`** | При вызове `unset()` на недоступном свойстве | Кастомное удаление |
| **`__call()`** | При вызове недоступного метода | Магические методы-обработчики |
| **`__callStatic()`** | При вызове недоступного статического метода | Статические магические методы |
| **`__toString()`** | При преобразовании объекта в строку | Строковое представление |
| **`__invoke()`** | При вызове объекта как функцию | Объекты-функции |
| **`__clone()`** | При клонировании объекта | Глубокая копия |
| **`__sleep()`** | При сериализации | Подготовка к сериализации |
| **`__wakeup()`** | При десериализации | Восстановление после десериализации |
| **`__serialize()`** | При сериализации (PHP 7.4+) | Современная сериализация |
| **`__unserialize()`** | При десериализации (PHP 7.4+) | Современная десериализация |
| **`__debugInfo()`** | При вызове `var_dump()` | Кастомная отладочная информация |

## 💻 **Практические примеры**

### **1. Конструктор и деструктор**
```php
class DatabaseConnection {
    private $connection;
    
    public function __construct($host, $user, $pass) {
        $this->connection = new PDO("mysql:host=$host", $user, $pass);
        echo "Подключение к БД установлено\n";
    }
    
    public function __destruct() {
        $this->connection = null;
        echo "Подключение к БД закрыто\n";
    }
}

$db = new DatabaseConnection('localhost', 'root', 'password');
// При завершении скрипта автоматически вызовется __destruct()
```

### **2. Магические геттеры и сеттеры**
```php
class User {
    private $data = [];
    
    public function __get($name) {
        if (isset($this->data[$name])) {
            return $this->data[$name];
        }
        return null;
    }
    
    public function __set($name, $value) {
        // Валидация при установке значения
        if ($name === 'email' && !filter_var($value, FILTER_VALIDATE_EMAIL)) {
            throw new InvalidArgumentException("Некорректный email");
        }
        $this->data[$name] = $value;
    }
    
    public function __isset($name) {
        return isset($this->data[$name]);
    }
    
    public function __unset($name) {
        unset($this->data[$name]);
    }
}

$user = new User();
$user->name = 'Иван';        // Вызовет __set()
$user->email = 'test@test.ru'; // Вызовет __set() с валидацией
echo $user->name;            // Вызовет __get()
isset($user->name);          // Вызовет __isset()
unset($user->name);          // Вызовет __unset()
```

### **3. Магические методы вызова**
```php
class ApiClient {
    private $endpoints = ['users', 'posts', 'comments'];
    
    public function __call($name, $arguments) {
        if (strpos($name, 'get') === 0) {
            $endpoint = strtolower(substr($name, 3));
            if (in_array($endpoint, $this->endpoints)) {
                return $this->request('GET', $endpoint, $arguments[0] ?? []);
            }
        }
        throw new BadMethodCallException("Метод $name не существует");
    }
    
    public static function __callStatic($name, $arguments) {
        if (strpos($name, 'create') === 0) {
            $endpoint = strtolower(substr($name, 6));
            return (new self())->request('POST', $endpoint, $arguments[0] ?? []);
        }
    }
    
    private function request($method, $endpoint, $data) {
        return "Вызван $method /$endpoint с данными: " . json_encode($data);
    }
}

$api = new ApiClient();
echo $api->getUsers(['page' => 1]);     // Вызовет __call()
echo $api->getPosts(['limit' => 10]);   // Вызовет __call()

echo ApiClient::createUser(['name' => 'John']); // Вызовет __callStatic()
```

### **4. Преобразование в строку и вызов как функция**
```php
class Calculator {
    private $value;
    
    public function __construct($initial = 0) {
        $this->value = $initial;
    }
    
    public function __toString() {
        return "Текущее значение: " . $this->value;
    }
    
    public function __invoke($number) {
        $this->value += $number;
        return $this;
    }
    
    public function getValue() {
        return $this->value;
    }
}

$calc = new Calculator(10);
echo $calc; // Вызовет __toString(): "Текущее значение: 10"

$calc(5)(3)(2); // Вызовет __invoke() несколько раз
echo $calc; // "Текущее значение: 20"
```

### **5. Сериализация и десериализация**
```php
class SessionData {
    private $data = [];
    private $secretKey;
    
    public function __construct($key) {
        $this->secretKey = $key;
    }
    
    public function set($key, $value) {
        $this->data[$key] = $value;
    }
    
    public function __sleep() {
        // Указываем, какие свойства сериализовать
        return ['data']; // secretKey не сериализуем!
    }
    
    public function __wakeup() {
        // Восстанавливаем secretKey после десериализации
        $this->secretKey = 'default_key';
    }
    
    // PHP 7.4+ современный подход
    public function __serialize(): array {
        return [
            'data' => $this->data,
            'checksum' => md5(serialize($this->data) . $this->secretKey)
        ];
    }
    
    public function __unserialize(array $data): void {
        $this->data = $data['data'];
        $this->secretKey = 'default_key';
        
        // Проверяем целостность данных
        $checksum = md5(serialize($this->data) . $this->secretKey);
        if ($checksum !== $data['checksum']) {
            throw new RuntimeException("Данные повреждены");
        }
    }
}
```

### **6. Клонирование и отладочная информация**
```php
class Config {
    private $settings = [];
    private $cache = [];
    
    public function set($key, $value) {
        $this->settings[$key] = $value;
        $this->cache[$key] = $value; // Кешируем
    }
    
    public function __clone() {
        // При клонировании очищаем кеш
        $this->cache = [];
    }
    
    public function __debugInfo() {
        // Показываем только settings при var_dump()
        return ['settings' => $this->settings];
    }
}

$config = new Config();
$config->set('db.host', 'localhost');
$config->set('db.user', 'root');

$config2 = clone $config; // Вызовет __clone()
var_dump($config);        // Вызовет __debugInfo()
```

## 🚀 **Практическое применение в реальных проектах**

### **Active Record Pattern:**
```php
class Model {
    protected $attributes = [];
    protected $original = [];
    
    public function __get($name) {
        return $this->attributes[$name] ?? null;
    }
    
    public function __set($name, $value) {
        $this->attributes[$name] = $value;
    }
    
    public function save() {
        // Сохраняем изменения в БД
        if ($this->attributes !== $this->original) {
            // Логика сохранения...
            $this->original = $this->attributes;
        }
    }
}

class User extends Model {
    protected $table = 'users';
}

$user = new User();
$user->name = 'John';     // __set()
$user->email = 'john@example.com'; // __set()
echo $user->name;         // __get()
$user->save();
```

## ⚠️ **Важные предупреждения**

1. **Не злоупотребляйте магическими методами** - они усложняют отладку
2. **Документируйте поведение** - другие разработчики могут не ожидать магии
3. **Тестируйте тщательно** - магические методы могут скрывать ошибки
4. **Используйте умеренно** - только когда это действительно упрощает код

## 💡 **Лучшие практики:**

- Используйте магические методы для создания **DSL (Domain Specific Language)**
- Применяйте для **динамического API** (как в ORM, Query Builder)
- Используйте для **интерцепции операций** с объектами
- Избегайте в **простых DTO объектах**

Магические методы — это мощный инструмент, который делает PHP гибким и выразительным, но требует ответственного использования!
