
Метод **"два указателя" (two pointers)** — это популярная техника в программировании, которая используется для решения задач, связанных с последовательностями (массивами, строками или списками). Она включает использование двух указателей, которые перемещаются по последовательности с определённой логикой. Эта техника позволяет оптимизировать сложность алгоритмов, часто снижая её с \(O(n^2)\) до \(O(n)\).

---

### **Типы задач, решаемых с помощью two pointers**

1. **Поиск пары элементов в массиве/строке:**
   - Поиск двух чисел, сумма которых равна заданному значению.
   - Пример: Задача "Two Sum" в отсортированном массиве.

2. **Удаление/уплотнение элементов в массиве:**
   - Удаление дубликатов, перемещение нулей в конец, фильтрация массива.

3. **Поиск подмассивов:**
   - Поиск подмассива с определённой суммой.
   - Задачи на поиск максимальной/минимальной длины подмассива с определёнными свойствами.

4. **Работа с палиндромами:**
   - Проверка, является ли строка палиндромом.
   - Поиск палиндромных подстрок.

5. **Сравнение двух строк/массивов:**
   - Решение задач, где нужно одновременно итерироваться по двум массивам/строкам.

6. **Слияние массивов:**
   - Слияние двух отсортированных массивов в один.

7. **Задачи на интервалы:**
   - Поиск пересечений интервалов.
   - Проверка, накрывают ли интервалы определённые точки.

### **Примеры задач и решений**

#### **1. Поиск двух чисел с заданной суммой в отсортированном массиве**
```go
func twoSum(nums []int, target int) []int {
    left, right := 0, len(nums)-1
    for left < right {
        sum := nums[left] + nums[right]
        if sum == target {
            return []int{nums[left], nums[right]}
        } else if sum < target {
            left++
        } else {
            right--
        }
    }
    return []int{}
}
```
- **Описание:**
  - Используем два указателя: один начинает с начала массива (`left`), другой — с конца (`right`).
  - Если сумма текущих элементов меньше целевой, сдвигаем `left` вправо. Если больше — `right` влево.

---

#### **2. Удаление дубликатов из отсортированного массива**
```go
func removeDuplicates(nums []int) int {
    if len(nums) < 2 {
        return len(nums)
    }
    slow := 0
    for fast := 1; fast < len(nums); fast++ {
        if nums[fast] != nums[slow] {
            slow++
            nums[slow] = nums[fast]
        }
    }
    return slow + 1
}
```
- **Описание:**
  - Используем два указателя: `slow` для уникальных элементов и `fast` для итерации по массиву.
  - Если `nums[fast]` отличается от `nums[slow]`, обновляем `nums[slow+1]`.

#### **3. Проверка, является ли строка палиндромом**
```go
func isPalindrome(s string) bool {
    left, right := 0, len(s)-1
    for left < right {
        for left < right && !isAlphaNumeric(s[left]) {
            left++
        }
        for left < right && !isAlphaNumeric(s[right]) {
            right--
        }
        if toLower(s[left]) != toLower(s[right]) {
            return false
        }
        left++
        right--
    }
    return true
}

func isAlphaNumeric(c byte) bool {
    return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || (c >= '0' && c <= '9')
}

func toLower(c byte) byte {
    if c >= 'A' && c <= 'Z' {
        return c + ('a' - 'A')
    }
    return c
}
```
- **Описание:**
  - Два указателя (`left`, `right`) двигаются навстречу друг другу.
  - Пропускаем неалфавитные символы и сравниваем символы в нижнем регистре.

#### **4. Поиск максимальной суммы в подмассиве фиксированной длины**
```go
func maxSumSubarray(nums []int, k int) int {
    windowSum, maxSum := 0, 0
    for i := 0; i < len(nums); i++ {
        windowSum += nums[i]
        if i >= k-1 {
            maxSum = max(maxSum, windowSum)
            windowSum -= nums[i-(k-1)]
        }
    }
    return maxSum
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```
- **Описание:**
  - Используем технику скользящего окна.
  - Размер окна фиксирован, указатели помогают обновлять сумму окна.

#### **5. Слияние двух отсортированных массивов**
```go
func merge(nums1 []int, m int, nums2 []int, n int) {
    i, j, k := m-1, n-1, m+n-1
    for i >= 0 && j >= 0 {
        if nums1[i] > nums2[j] {
            nums1[k] = nums1[i]
            i--
        } else {
            nums1[k] = nums2[j]
            j--
        }
        k--
    }
    for j >= 0 {
        nums1[k] = nums2[j]
        j--
        k--
    }
}
```
- **Описание:**
  - Два указателя (`i` и `j`) идут с конца массивов `nums1` и `nums2`.
  - Третий указатель (`k`) используется для записи в результирующий массив.

#### **6. Поиск пересечений интервалов**
```go
func intervalIntersection(A [][]int, B [][]int) [][]int {
    res := [][]int{}
    i, j := 0, 0
    for i < len(A) && j < len(B) {
        start := max(A[i][0], B[j][0])
        end := min(A[i][1], B[j][1])
        if start <= end {
            res = append(res, []int{start, end})
        }
        if A[i][1] < B[j][1] {
            i++
        } else {
            j++
        }
    }
    return res
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```
- **Описание:**
  - Два указателя (`i`, `j`) движутся по двум спискам интервалов.
  - Находим пересечение текущих интервалов, если они перекрываются.

### **Когда использовать two pointers**
- Когда задача связана с последовательностями (массивами, строками, списками).
- Когда требуется оптимизировать задачу с \(O(n^2)\) до \(O(n)\).
- Когда элементы сравниваются, фильтруются или объединяются по определённым правилам.

### **Преимущества метода**
- Простота реализации.
- Снижает временную сложность.
- Эффективно для работы с отсортированными данными.

Метод "два указателя" — это мощный инструмент для решения задач, связанных с последовательностями, и он является одним из самых часто используемых подходов в алгоритмах.
