## 🟩 **Задача 8 — [70. Climbing Stairs](https://leetcode.com/problems/climbing-stairs)**

🔹 **Твоя формулировка**: «Чемпионат по шагам»

> Можно подниматься на 1 или 2 ступеньки за раз. Сколько существует способов дойти до `n`-й ступеньки?

---

### 📋 Условие

У тебя есть лестница из `n` ступеней. На каждом шаге ты можешь сделать либо **один**, либо **два шага**.  
Нужно посчитать, **сколькими способами** ты можешь достичь вершины.

---

### 📌 Пример:

```go
n = 5

// Возможные пути:
// 1+1+1+1+1
// 1+1+1+2
// 1+2+1+1
// 2+1+1+1
// 1+2+2
// 2+1+2
// 2+2+1

// Ответ: 8 способов
```

---

## 🧠 Идея алгоритма

Это задача **динамического программирования**.  
Она эквивалентна подсчёту чисел Фибоначчи:

> `ways(n) = ways(n-1) + ways(n-2)`

Потому что:

- чтобы прийти на `n`-ую ступень, ты мог:
    
    - сделать шаг на 1 ступень с `n-1` (способов: `ways(n-1)`)
        
    - сделать шаг на 2 ступени с `n-2` (способов: `ways(n-2)`)
        

---

## ✅ Реализация на Go

```go
package main

import "fmt"

func climbStairs(n int) int {
	if n <= 2 {
		return n
	}
	a, b := 1, 2
	for i := 3; i <= n; i++ {
		a, b = b, a+b
	}
	return b
}

func main() {
	n := 5
	fmt.Printf("Способов подняться на %d ступеней: %d\n", n, climbStairs(n)) // 8
}
```

---

## 📈 Сложность

- **Время**: `O(n)`
    
- **Память**: `O(1)` — используем только два переменных (`a` и `b`)
    

---

## 🧪 Edge Cases

- `n = 0` → 0 способов
    
- `n = 1` → 1 способ
    
- `n = 2` → 2 способа
