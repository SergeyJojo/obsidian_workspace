
В стандартной библиотеке Go есть множество интерфейсов, которые определяют абстрактное поведение для работы с различными сущностями. Вот список некоторых ключевых интерфейсов, организованных по категориям:

---

### **1. Базовые интерфейсы**
- **`error`** (пакет `builtin`):
  ```go
  type error interface {
      Error() string
  }
  ```
  - Используется для представления ошибок.

- **`Stringer`** (пакет `fmt`):
  ```go
  type Stringer interface {
      String() string
  }
  ```
  - Определяет, как объект должен быть представлен в виде строки.

---

### **2. Интерфейсы для ввода/вывода (I/O)** (пакет `io`)
- **`Reader`**:
  ```go
  type Reader interface {
      Read(p []byte) (n int, err error)
  }
  ```
  - Для чтения данных.

- **`Writer`**:
  ```go
  type Writer interface {
      Write(p []byte) (n int, err error)
  }
  ```
  - Для записи данных.

- **`Closer`**:
  ```go
  type Closer interface {
      Close() error
  }
  ```
  - Для закрытия ресурсов.

- **`ReaderAt`** и **`WriterAt`**:
  ```go
  type ReaderAt interface {
      ReadAt(p []byte, off int64) (n int, err error)
  }
  type WriterAt interface {
      WriteAt(p []byte, off int64) (n int, err error)
  }
  ```
  - Для чтения/записи по конкретному смещению.

- **`Seeker`**:
  ```go
  type Seeker interface {
      Seek(offset int64, whence int) (int64, error)
  }
  ```
  - Для установки позиции чтения/записи.

- **`ReadWriter`**, **`ReadCloser`**, **`WriteCloser`**, **`ReadWriteCloser`**:
  - Комбинации интерфейсов для удобства.

---

### **3. Интерфейсы для работы с коллекциями**
- **`sort.Interface`** (пакет `sort`):
  ```go
  type Interface interface {
      Len() int
      Less(i, j int) bool
      Swap(i, j int)
  }
  ```
  - Определяет поведение для сортировки коллекций.

---

### **4. Интерфейсы для потоков данных**
- **`io.Reader` и производные** (см. выше).
- **`io.Writer` и производные** (см. выше).
- **`io.PipeReader` и `io.PipeWriter`**:
  - Для работы с потоками через `io.Pipe`.

---

### **5. Сетевые интерфейсы** (пакет `net`)
- **`net.Conn`**:
  ```go
  type Conn interface {
      Read(b []byte) (n int, err error)
      Write(b []byte) (n int, err error)
      Close() error
      LocalAddr() Addr
      RemoteAddr() Addr
      SetDeadline(t time.Time) error
      SetReadDeadline(t time.Time) error
      SetWriteDeadline(t time.Time) error
  }
  ```
  - Определяет поведение сетевого соединения.

- **`net.Listener`**:
  ```go
  type Listener interface {
      Accept() (Conn, error)
      Close() error
      Addr() Addr
  }
  ```
  - Определяет поведение для прослушивания соединений.

---

### **6. Интерфейсы для работы с HTTP** (пакет `net/http`)
- **`http.Handler`**:
  ```go
  type Handler interface {
      ServeHTTP(w ResponseWriter, r *Request)
  }
  ```
  - Основной интерфейс для обработки HTTP-запросов.

- **`http.ResponseWriter`**:
  ```go
  type ResponseWriter interface {
      Header() Header
      Write([]byte) (int, error)
      WriteHeader(statusCode int)
  }
  ```

---

### **7. Интерфейсы для работы с временем** (пакет `time`)
- **`time.Duration`**:
  - Хотя это не интерфейс, часто используется в функциях для работы с задержками и интервалами.

---

### **8. Интерфейсы для работы с синхронизацией** (пакет `sync`)
- **`sync.Locker`**:
  ```go
  type Locker interface {
      Lock()
      Unlock()
  }
  ```
  - Определяет поведение блокировки.

---

### **9. Интерфейсы для сериализации** (пакеты `encoding/json`, `encoding/xml`)
- **`json.Marshaler`**:
  ```go
  type Marshaler interface {
      MarshalJSON() ([]byte, error)
  }
  ```

- **`json.Unmarshaler`**:
  ```go
  type Unmarshaler interface {
      UnmarshalJSON([]byte) error
  }
  ```

- Аналогичные интерфейсы для XML:
  - `xml.Marshaler`
  - `xml.Unmarshaler`

---

### **10. Интерфейсы для работы с ошибками**
- **`errors.Wrapper`** (пакет `errors` в Go 1.13+):
  ```go
  type Wrapper interface {
      Unwrap() error
  }
  ```
  - Для работы с вложенными ошибками.

---

### **11. Интерфейсы для работы с контекстами** (пакет `context`)
- **`context.Context`**:
  ```go
  type Context interface {
      Deadline() (deadline time.Time, ok bool)
      Done() <-chan struct{}
      Err() error
      Value(key interface{}) interface{}
  }
  ```

---

### **12. Интерфейсы для работы с криптографией** (пакет `crypto`)
- **`crypto.Hash`**, **`crypto.Signer`**, **`crypto.Decrypter`**:
  - Определяют поведение для хэширования, подписи и расшифровки.

---

### **13. Интерфейсы для работы с буферами** (пакет `bytes`)
- **`bytes.Buffer`**:
  - Хотя это структура, она реализует интерфейсы `io.Reader`, `io.Writer`, `io.ReaderFrom`, `io.WriterTo`.

---

### Итог

Стандартная библиотека Go предоставляет множество интерфейсов, которые позволяют создавать гибкие и абстрактные программы. Большинство из них связано с вводом/выводом, обработкой HTTP-запросов, сериализацией данных, синхронизацией и обработкой ошибок.
