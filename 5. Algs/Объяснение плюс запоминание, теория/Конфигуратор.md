
Конфигуратор (или **Configurator**, иногда называют **Options pattern**/**Functional Options**) — это паттерн проектирования, который позволяет гибко и удобно настраивать объект при его создании, не усложняя конструктор большим количеством параметров и не создавая множество конструкторов для разных вариантов.

---

## Основная идея

**Конфигуратор** — это объект или функция, который задаёт или изменяет параметры настраиваемого объекта.  
Вместо того чтобы передавать в конструктор десятки параметров (или создавать множество конструкторов), вы создаёте объект с разумными дефолтами, а потом "конфигурируете" его через методы или функции.

---

## Когда применять

- Когда у объекта есть много опциональных параметров.
- Когда хочется расширяемость без изменения интерфейса конструктора.
- Когда хочется читабельную и гибкую инициализацию объекта.

---

## Примеры реализации

### 1. **Functional Options (на Go, самый популярный способ)**

```go
type Server struct {
    Port       int
    Host       string
    EnableTLS  bool
    TimeoutSec int
}

type ServerOption func(*Server)

func WithPort(port int) ServerOption {
    return func(s *Server) { s.Port = port }
}
func WithTLS(enabled bool) ServerOption {
    return func(s *Server) { s.EnableTLS = enabled }
}
func WithTimeout(timeout int) ServerOption {
    return func(s *Server) { s.TimeoutSec = timeout }
}

func NewServer(host string, opts ...ServerOption) *Server {
    s := &Server{
        Host: host,
        Port: 80,
        TimeoutSec: 30,
    }
    for _, opt := range opts {
        opt(s)
    }
    return s
}

// Использование:
srv := NewServer("127.0.0.1", WithPort(8080), WithTLS(true), WithTimeout(60))
```

**Плюсы:**
- Нет взрывного роста количества конструкторов.
- Параметры по умолчанию.
- Удобно расширять без изменения интерфейса.

---

### 2. **Строитель (Builder)**

В ООП-языках часто реализуют через паттерн "Builder":

```go
type Config struct {
    Host string
    Port int
}

type ConfigBuilder struct {
    cfg Config
}

func (b *ConfigBuilder) SetHost(host string) *ConfigBuilder {
    b.cfg.Host = host
    return b
}
func (b *ConfigBuilder) SetPort(port int) *ConfigBuilder {
    b.cfg.Port = port
    return b
}
func (b *ConfigBuilder) Build() Config {
    return b.cfg
}

// Использование:
cfg := (&ConfigBuilder{}).SetHost("localhost").SetPort(1234).Build()
```
**Минус:** больше кода, чем функциональные опции, но удобно для сложных конфигураций.

---

### 3. **Через методы Set (Setter)**

```go
c := NewConfig()
c.SetHost("localhost")
c.SetPort(9000)
```
**Минус:** может быть сложно для потокобезопасности, если объект используется сразу после создания.

---

## Итоги

- **Configurator** — способ гибко настраивать объект, не перегружая конструкторы.
- В Go часто делают через **functional options** (см. пример выше).
- В Java/C#/C++ — чаще используют Builder.
- Позволяет добавлять новые настройки без изменения интерфейса конструктора.

---

**Как реализовывать:**
1. Определить структуру объекта с параметрами по умолчанию.
2. Создать функции/методы, которые умеют изменять эти параметры.
3. Конструктор вызывает эти функции/методы для применения опций.
4. Пользователь создает объект через конструктор + опции, только те, что нужны.
