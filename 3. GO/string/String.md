В языке Go для сборки строк из различных частей используется функция `fmt.Sprintf` или её аналоги, такие как `fmt.Sprint`, `fmt.Fprintf` и другие.

Функция `fmt.Sprintf` позволяет форматировать строки с использованием спецификаторов формата. Она принимает строку формата и аргументы, которые подставляются в строку вместо спецификаторов. Спецификаторы начинаются со знака процента (`%`) и могут содержать дополнительные символы, указывающие на тип данных и способ их представления.

Вот несколько примеров использования `fmt.Sprintf`:

1. **Базовый пример:**

```
    name := "Иван"
    age := 30
    message := fmt.Sprintf("Имя: %s, возраст: %d", name, age)
    fmt.Println(message) // Имя: Иван, возраст: 30
```

Здесь мы используем спецификаторы `%s` для строки и `%d` для целого числа. Функция `fmt.Printf` выводит отформатированную строку.

2. **Пример с дополнительными опциями форматирования:**

```
    pi := 3.14159
    formattedPi := fmt.Sprintf("Значение π: %.2f", pi)
    fmt.Println(formattedPi) // Значение π: 3.14
```

В этом примере мы используем спецификатор `%.2f` для форматирования числа с плавающей точкой до двух знаков после запятой.

3. **Пример использования функции `Sprintf` внутри другой функции:**

```
    func createGreeting(name string) string {
        greeting := fmt.Sprintf("Здравствуйте, %s!", name)
        return greeting
    }

    message := createGreeting("Анна")
    fmt.Println(message) // Здравствуйте, Анна!
```

Этот пример показывает, как можно использовать `fmt.Sprintf` внутри пользовательской функции для создания динамических строк.

Для сборки строк также можно использовать функцию `strings.Builder`, которая предоставляет более эффективный способ работы со строками по сравнению с конкатенацией через оператор `+`.

Пример использования `strings.Builder`:

```
    package main

    import (
        "fmt"
        "strings"
    )

    func main() {
        // Создание экземпляра strings.Builder
        builder := strings.Builder{}

        // Добавление данных в builder
        builder.WriteString("Привет, ")
        builder.WriteString("мир!")

        // Преобразование builder в строку
        greeting := builder.String()
        fmt.Println(greeting) // Привет, мир!
    }
```

Это лишь некоторые примеры использования функций форматирования строк в Go. Они позволяют эффективно работать с данными и создавать гибкие и мощные приложения.
