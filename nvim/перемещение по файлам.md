Вот команды в стиле **Vim motions / Neovim**, которые помогут тебе перемещаться **между файлами и буферами**. Они не требуют `:` и подходят для тренировки печати и muscle memory:

---

### 📄 Перемещение между **буферами** (открытые файлы):

```
:bn     → следующий буфер (buffer next)
:bp     → предыдущий буфер (buffer previous)
:bd     → удалить (закрыть) текущий буфер (buffer delete)
:ls     → список всех буферов
```

🧠 Мнемоника: `b` — buffer, `n/p/d` — next/prev/delete

---

### 🪟 Перемещение между **окнами** (splits):

```
<C-w>h  → влево
<C-w>j  → вниз
<C-w>k  → вверх
<C-w>l  → вправо
```

🧠 Это удобно тренировать как `hjkl`, но с `<C-w>`

---

### 🔲 Перемещение между **tab-страницами**:

```
gt      → следующий tab
gT      → предыдущий tab
:tabn   → следующий tab (аналогично gt)
:tabp   → предыдущий tab (аналогично gT)
```

---

### ✨ Быстрые команды для работы с файлами (если установлен `telescope.nvim`):

```
<C-p>   → fuzzy поиск по файлам (Telescope find_files)
<C-b>   → список открытых буферов (Telescope buffers)
```

Если не используешь `telescope`, то полезны ещё:

```
:e <filename>    → открыть файл
:sp <filename>   → открыть в horizontal split
:vs <filename>   → открыть в vertical split
```

---

### 💡 Вариант для тренировки (для печати, без пояснений):

```
<C-w>h <C-w>l <C-w>j <C-w>k gt gT :bn :bp :bd :ls :e :sp :vs <C-p> <C-b>
```

Хочешь — сгенерирую из этого список случайных комбинаций для скоростной печати.
