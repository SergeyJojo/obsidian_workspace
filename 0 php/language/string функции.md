## 🧩 1. **Получение информации о строке**

|Функция|Назначение|Пример|
|---|---|---|
|`strlen($s)`|длина строки в байтах|`strlen("Привет")` → 12 (UTF-8: по 2 байта)|
|`mb_strlen($s)`|длина в символах (мультибайтовая)|`mb_strlen("Привет")` → 6|
|`strcmp($a, $b)`|лексикографическое сравнение (учитывает регистр)|`strcmp("a","A")` → 1|
|`strcasecmp($a, $b)`|сравнение без учёта регистра||
|`strncmp($a,$b,$n)`|сравнивает первые N байт||
|`mb_substr_count($s,$needle)`|количество вхождений подстроки||

---

## ✂️ 2. **Извлечение и разбиение**

|Функция|Назначение|Пример|
|---|---|---|
|`substr($s, $start, $len)`|подстрока|`substr("abcdef",1,3)` → `"bcd"`|
|`mb_substr($s, $start, $len)`|версия для UTF-8||
|`explode($delimiter,$s)`|разбивает строку в массив|`explode(",", "a,b,c")` → `["a","b","c"]`|
|`implode($glue,$arr)`|соединяет элементы массива в строку|`implode("-",["a","b"])` → `"a-b"`|
|`str_split($s,$len)`|разбивает на куски фикс. длины||

---

## 🔄 3. **Поиск и замена**

|Функция|Назначение|Пример|
|---|---|---|
|`strpos($s,$needle)`|позиция первого вхождения||
|`strrpos($s,$needle)`|позиция последнего вхождения||
|`stripos($s,$needle)`|без учёта регистра||
|`str_replace($from,$to,$s)`|замена подстроки||
|`str_ireplace()`|замена без учёта регистра||
|`substr_replace($s,$replacement,$start,$len)`|замена части строки||

---

## ⚙️ 8. **Совет по UTF-8**

Если ты работаешь со строками, где есть кириллица или другие многобайтовые символы — **всегда используй `mb_*`-версии** (`mb_strlen`, `mb_substr`, `mb_strtolower` и т.п.),  
и не забудь активировать:

```php
mb_internal_encoding("UTF-8");
```
