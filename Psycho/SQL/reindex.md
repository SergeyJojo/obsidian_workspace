
Команда `REINDEX` в PostgreSQL **перестраивает индекс заново**. Это как "пересобрать" индекс с нуля, но без удаления таблицы или остановки сервиса. Она используется для:

---

## 🔧 Что делает `REINDEX`

1. **Создаёт новый индекс** временно.
    
2. **Заполняет его** свежими данными из таблицы.
    
3. **Заменяет старый индекс новым.**
    
4. Старый индекс **удаляется автоматически**.
    

Это похоже на `DROP INDEX` + `CREATE INDEX`, но:

- Делается **автоматически, безопасно и без ручного вмешательства**.
    
- Возможен `CONCURRENTLY` в версии PostgreSQL 12+ (в некоторых случаях).
    

---

## 🛠️ Когда использовать `REINDEX`

### ✅ Рекомендуется, если:

1. **Индекс фрагментирован** (много удалённых строк → "пустоты").
    
2. **Индекс сильно раздут**: занимает больше места, чем должен.
    
3. Были **ошибки или баги**, вызванные повреждённым индексом.
    
4. После **массовых операций** (например, `DELETE`, `UPDATE` большого количества строк).
    
5. После `pg_upgrade` — чтобы использовать новый формат индексов.
    

---

## 🔍 Пример использования

```sql
-- Перестроить конкретный индекс
REINDEX INDEX my_index;

-- Перестроить все индексы таблицы
REINDEX TABLE my_table;

-- Перестроить все индексы в базе
REINDEX DATABASE my_database;
```

> ⚠️ По умолчанию `REINDEX` блокирует таблицу или индекс, т.е. **не может выполняться параллельно с записью**. Чтобы этого избежать, в PostgreSQL 12+ можно использовать `REINDEX CONCURRENTLY`.

---

## 🔄 REINDEX vs VACUUM vs CLUSTER

|Команда|Что делает|Блокировки|Когда применять|
|---|---|---|---|
|`VACUUM`|Удаляет "мертвые" строки|Нет (обычно)|Регулярно, для всех таблиц|
|`REINDEX`|Перестраивает индекс с нуля|Да|При фрагментации или повреждении индекса|
|`CLUSTER`|Перестраивает таблицу **в порядке индекса**|Да|Для ускорения доступа по определённому ключу|

---

## 📌 Вывод

**`REINDEX` полезен для:**

- Повышения производительности (уменьшение bloated-индексов)
    
- Исправления сломанных или неэффективных индексов
    
- Обслуживания больших баз (в рамках регулярного обслуживания)
