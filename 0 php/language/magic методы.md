# 🧙‍♂️ **Что такое магические методы в PHP**

Это специальные методы, имена которых **начинаются с `__`**, и которые вызываются **автоматически**, когда с объектом происходит определённое событие.

Ты их **не вызываешь напрямую** — они срабатывают как хук.

Они помогают контролировать:

- создание объекта
    
- уничтожение
    
- сериализацию
    
- обращение к несуществующим полям
    
- вызов несуществующих методов
    
- поведение объекта при приведении к строке
    
- клонирование
    
- работу как массива
    
- работу как функцией
    

---

# 📘 **Список основных магических методов**

## 🔵 **1. `__construct()` — конструктор**

Вызывается при создании объекта.

```php
class A {
    function __construct() {
        echo "Object created";
    }
}
```

---

## 🔵 **2. `__destruct()` — деструктор**

Вызывается при уничтожении объекта.

Используют для очистки ресурсов:

- закрыть файл,
    
- закрыть соединение,
    
- освободить локи.
    

---

## 🔵 **3. `__call($name, $args)` — вызов несуществующего метода**

Срабатывает, если метод не найден.

```php
class A {
    function __call($name, $args) {
        echo "Method $name not found";
    }
}
```

### Когда полезно:

- проксирование вызовов
    
- динамические методы
    
- адаптеры
    

---

## 🔵 **4. `__callStatic($name, $args)` — как `__call`, но для статических**

```php
A::undefined();
```

---

## 🔵 **5. `__get($name)` — попытка прочитать несуществующее свойство**

```php
class A {
    function __get($name) {
        return "Trying to access $name";
    }
}
```

---

## 🔵 **6. `__set($name, $value)` — запись в несуществующее свойство**

Триггерится при:

- защищённых (`protected`)
    
- приватных (`private`)
    
- несуществующих полях
    

Используется в ORM (Laravel models).

---

## 🔵 **7. `__isset($name)` — вызывается при `isset()` или `empty()`**

```php
isset($obj->unknown);
```

## 🔵 **9. `__toString()` — когда объект приводят к строке**

```php
class A {
    function __toString() {
        return "A-object";
    }
}

echo new A();
```

### ⚠️ Ограничение

Метод **обязан** вернуть строку.

---

## 🔵 **10. `__invoke()` — делает объект вызываемым как функцию**

```php
class A {
    function __invoke($x) {
        return $x * 2;
    }
}

$a = new A();
echo $a(5); // вывод: 10
```

---

## 🔵 **11. `__clone()` — вызывается при клонировании**

```php
$b = clone $a;
```

Используется, если нужно клонировать _глубоко_ или сбрасывать состояние.

---

## 🔵 **12. `__debugInfo()` — управляет выводом var_dump**

```php
class A {
    public $a = 1;
    public $b = 2;

    function __debugInfo() {
        return ['a' => $this->a];
    }
}

var_dump(new A());
```

# 🌪 Подводные камни магических методов

## ❗ 1. Медленнее обычных методов

Магия = интерпретатор вызывает обход наследования → чуть дороже.

## ❗ 2. Ошибки легко спрятать

Если структура моделей неправильная — магия схавает ошибку.

Например Laravel Eloquent:

```php
$post->unknown   // вернёт null через __get — ошибки не видно
```

## ❗ 3. `__toString()` не может бросать исключения

Иначе фатальная ошибка.

## ❗ 4. Ломают IDE-интеллисенс

Потому что свойства виртуальные.
