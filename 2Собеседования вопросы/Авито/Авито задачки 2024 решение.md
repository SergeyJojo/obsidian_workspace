с# 1)
Для решения задачи по сбору "ровной" команды из инженеров, фронтендеров, тестировщиков и дизайнеров, мы можем использовать метод скользящего окна (sliding window). Мы будем использовать указатели на текущие элементы каждого из массивов, чтобы в процессе сканирования массивов выбрать наименьшее возможное различие между максимальным и минимальным уровнем выбранных участников.

Вот пример реализации:

### Решение:

```go
package main

import (
	"fmt"
	"math"
)

func selectTeam(engineers map[string][]int) map[string]int {
	// Извлекаем отсортированные списки уровней
	backend := engineers["backend"]
	frontend := engineers["frontend"]
	qa := engineers["qa"]
	design := engineers["design"]

	// Инициализация указателей
	bPtr, fPtr, qPtr, dPtr := 0, 0, 0, 0
	bestTeam := make(map[string]int)
	minDiff := math.MaxInt32

	// Основной цикл поиска оптимальной команды
	for bPtr < len(backend) && fPtr < len(frontend) && qPtr < len(qa) && dPtr < len(design) {
		// Текущие уровни
		b, f, q, d := backend[bPtr], frontend[fPtr], qa[qPtr], design[dPtr]

		// Находим min и max среди текущих уровней
		currentMin := min4(b, f, q, d)
		currentMax := max4(b, f, q, d)
		currentDiff := currentMax - currentMin

		// Обновляем лучшую команду, если нашли более сбалансированный вариант
		if currentDiff < minDiff {
			minDiff = currentDiff
			bestTeam = map[string]int{
				"backend":  b,
				"frontend": f,
				"qa":       q,
				"design":   d,
			}
		}

		// Если разница 0 - это идеальный вариант, можно завершить
		if minDiff == 0 {
			break
		}

		// Сдвигаем указатель для минимального элемента
		switch currentMin {
		case b:
			bPtr++
		case f:
			fPtr++
		case q:
			qPtr++
		case d:
			dPtr++
		}
	}

	return bestTeam
}

// Оптимизированные функции для сравнения 4 чисел
func min4(a, b, c, d int) int {
	min := a
	if b < min { min = b }
	if c < min { min = c }
	if d < min { min = d }
	return min
}

func max4(a, b, c, d int) int {
	max := a
	if b > max { max = b }
	if c > max { max = c }
	if d > max { max = d }
	return max
}

func main() {
	// Тестовые данные
	testCases := []map[string][]int{
		{
			"backend":  {1, 2, 2, 3},
			"frontend": {1, 3},
			"qa":       {3, 4, 4},
			"design":   {2, 3},
		},
		{
			"backend":  {5},
			"frontend": {3, 6, 7, 10},
			"qa":       {3, 9, 11, 18},
			"design":   {20},
		},
		{
			"backend":  {1, 4, 7},
			"frontend": {2, 5, 8},
			"qa":       {3, 6, 9},
			"design":   {4, 7, 10},
		},
	}

	// Запуск тестов
	for i, tc := range testCases {
		fmt.Printf("Test case %d:\n", i+1)
		fmt.Printf("Input: %v\n", tc)
		result := selectTeam(tc)
		fmt.Printf("Best team: %v\n\n", result)
	}
}
```

### Объяснение решения:

1. **Алгоритм скользящего окна**:
    
    - Мы используем четыре указателя (по одному для каждого массива) и начинаем с первого элемента каждого массива.
    - В каждом шаге мы вычисляем разницу между максимальным и минимальным элементом среди текущих выбранных элементов.
    - Для того, чтобы минимизировать разницу, мы сдвигаем указатель на минимальный элемент, так как это приведет к увеличению минимального значения в следующем шаге.
    - Мы продолжаем это, пока не дойдем до конца хотя бы одного из массивов.
2. **Преимущества этого подхода**:
    
    - Алгоритм работает с временной сложностью O(N), где N — это суммарное количество элементов в массивах (для каждой категории).
    - Место для хранения данных — O(1), поскольку мы используем только несколько указателей и переменную для хранения лучшего результата.
3. **Возможности улучшений**:
    
    - Можно использовать параллельное вычисление или другие методы оптимизации для обработки больших объемов данных, если это необходимо.

### Итог:

Этот подход позволяет собирать команду с минимальной разницей в уровнях, эффективно используя алгоритм сдвига указателей, что позволяет избежать излишней сложности и улучшить производительность.

# 2)

Для решения задачи извлечения **K самых больших чисел** из массива можно использовать несколько подходов, и мы будем стремиться к оптимизации по времени выполнения. Рассмотрим два основных подхода: сортировка массива и использование структуры данных, которая обеспечивает быстрый доступ к K наибольшим элементам — **min-heap**.

### Подход 1: Сортировка массива (O(N * log N))

Самый простой способ — отсортировать массив по убыванию и взять первые K элементов.

```go
package main

import (
	"fmt"
	"sort"
)

func findKLargest(nums []int, k int) []int {
	// Сортируем массив по убыванию
	sort.Sort(sort.Reverse(sort.IntSlice(nums)))

	// Возвращаем первые K элементов
	return nums[:k]
}

func main() {
	nums := []int{100, 50, 0, 150, 100, 0, -30, 70}
	k := 3
	result := findKLargest(nums, k)
	fmt.Println(result) // Ожидаемый вывод: [150, 100, 70] или любой другой порядок
}
```

- **Алгоритмическая сложность**: O(N * log N), так как для сортировки требуется время O(N * log N).
- **Потребление памяти**: O(N), так как сортировка требует выделения памяти для хранения всего массива.

Этот подход достаточно прост, но его сложность можно улучшить.

### Подход 2: Использование min-heap (O(N * log K))

Другим подходом является использование структуры данных **min-heap**, которая позволит поддерживать только K наибольших элементов в массиве.

**Алгоритм**:

1. Построим мин-кучу из первых K элементов массива.
2. Для каждого следующего элемента в массиве:
    - Если элемент больше корня мин-кучи, заменим корень на этот элемент.
3. После того, как пройдем весь массив, в куче останется K наибольших элементов.

```go
package main  
  
import (  
    "container/heap"  
    "fmt")  
  
type IntHeap []int  
  
func (h IntHeap) Len() int           { return len(h) }  
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }  
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }  
  
func (h *IntHeap) Push(x interface{}) {  
    *h = append(*h, x.(int))  
}  
  
func (h *IntHeap) Pop() interface{} {  
    old := *h  
    n := len(old)  
    x := old[n-1]  
    *h = old[0 : n-1]  
    return x  
}  
  
// findKLargestUnique извлекает K уникальных наибольших элементовfunc 
    findKLargestUnique(nums []int, k int) []int {  
    if k <= 0 || len(nums) == 0 {  
       return []int{}  
    }  
    if k > len(nums) {  
       k = len(nums)  
    }  
  
    // Удаляем дубликаты и сортируем (для уникальности)  
    uniqueMap := make(map[int]struct{})  
    for _, num := range nums {  
       uniqueMap[num] = struct{}{}  
    }  
    uniqueSlice := make([]int, 0, len(uniqueMap))  
    for num := range uniqueMap {  
       uniqueSlice = append(uniqueSlice, num)  
    }  
  
    // Создаём минимальную кучу  
    h := &IntHeap{}  
    heap.Init(h)  
  
    // Заполняем кучу первыми k уникальными элементами  
    for i := 0; i < k && i < len(uniqueSlice); i++ {  
       heap.Push(h, uniqueSlice[i])  
    }  
  
    // Обрабатываем оставшиеся элементы  
    for i := k; i < len(uniqueSlice); i++ {  
       if uniqueSlice[i] > (*h)[0] {  
          heap.Pop(h)  
          heap.Push(h, uniqueSlice[i])  
       }  
    }  
  
    // Извлекаем результат  
    result := make([]int, k)  
    for i := k - 1; i >= 0; i-- {  
       result[i] = heap.Pop(h).(int)  
    }  
  
    return result  
}
```

- **Алгоритмическая сложность**: O(N * log K), где N — это размер массива, а K — количество наибольших элементов. Это улучшает производительность при больших значениях N и небольших K.
- **Потребление памяти**: O(K), так как мы храним только K элементов в куче.

### Итоги:

- **Подход 1 (сортировка)**: Просто и интуитивно понятно, но сложность O(N * log N) может быть неоптимальной, если K значительно меньше N.
- **Подход 2 (min-heap)**: Это более эффективный метод с временем работы O(N * log K), что предпочтительнее, если K значительно меньше N. Этот подход использует меньше памяти, так как мы храним только K элементов.

# 3)

Задача заключается в нахождении всех пар чисел в списке, сумма которых равна заданному числу. Рассмотрим несколько возможных решений этой задачи.

### Подход 1: Перебор всех пар (O(n^2))

Наиболее прямолинейное решение — это просто перебрать все возможные пары в списке и проверить, равна ли их сумма заданному числу. В этом случае сложность будет O(n^2).

```go
package main

import "fmt"

func findPairs(nums []int, target int) [][]int {
    var pairs [][]int
    for i := 0; i < len(nums); i++ {
        for j := i + 1; j < len(nums); j++ {
            if nums[i]+nums[j] == target {
                pairs = append(pairs, []int{nums[i], nums[j]})
            }
        }
    }
    return pairs
}

func main() {
    nums := []int{2, 4, 5, 3}
    target := 7
    result := findPairs(nums, target)
    fmt.Println(result) // [[2, 5], [4, 3]]
}
```

### Подход 2: Использование хэш-таблицы (O(n))

Этот подход более эффективен. Мы используем хэш-таблицу (или `map` в Go), чтобы за один проход по массиву находить пары, сумма которых равна заданному числу. Мы будем хранить элементы в хэш-таблице и проверять, есть ли для каждого числа пара, сумма которой равна целевому числу.

```go
package main

import "fmt"

func findPairs(nums []int, target int) [][]int {
    var pairs [][]int
    seen := make(map[int]bool)

    for _, num := range nums {
        complement := target - num
        if seen[complement] {
            pairs = append(pairs, []int{complement, num})
        }
        seen[num] = true
    }

    return pairs
}

func main() {
    nums := []int{2, 4, 5, 3}
    target := 7
    result := findPairs(nums, target)
    fmt.Println(result) // [[2, 5], [4, 3]]
}
```

### Подход 3: Использование сортировки и двух указателей (O(n log n))

Для оптимизации времени поиска можно отсортировать массив, а затем использовать два указателя для поиска нужных пар. Один указатель будет указывать на начало массива, а второй — на конец. Мы будем двигать указатели в зависимости от того, больше ли их сумма или меньше целевого числа.

```go
package main

import (
	"fmt"
	"sort"
)

func findPairs(nums []int, target int) [][]int {
	var pairs [][]int
	sort.Ints(nums) // Сортируем массив

	left, right := 0, len(nums)-1

	for left < right {
		sum := nums[left] + nums[right]
		if sum == target {
			pairs = append(pairs, []int{nums[left], nums[right]})
			left++
			right--
		} else if sum < target {
			left++
		} else {
			right--
		}
	}

	return pairs
}

func main() {
	nums := []int{2, 4, 5, 3} // 2 3 4 5
	target := 7
	result := findPairs(nums, target)
	fmt.Println(result) // [[2, 5], [4, 3]]
}
```

### Сравнение подходов:

- **Подход 1 (перебор всех пар)**:
    
    - **Время**: O(n^2)
    - **Память**: O(1)
    - Простое решение, но неэффективное при большом количестве элементов.
- **Подход 2 (использование хэш-таблицы)**:
    
    - **Время**: O(n)
    - **Память**: O(n)
    - Более эффективное решение, позволяет находить пары за один проход по массиву.
- **Подход 3 (сортировка и два указателя)**:
    
    - **Время**: O(n log n) (из-за сортировки)
    - **Память**: O(1)
    - Хорошее решение, которое работает быстрее, чем перебор всех пар, и использует меньше памяти, чем хэш-таблица.

### Итог:

Для задачи, где важно время выполнения, **лучше использовать подход с хэш-таблицей**, так как он имеет линейную сложность. Если же нам важна экономия памяти, а время не так критично, то можно использовать подход с сортировкой и двумя указателями.

# 4)

Для задачи сложения двух чисел, представленных в виде массивов, можно использовать следующий алгоритм:

1. Начинаем складывать числа с конца (по аналогии с тем, как складывают числа вручную).
2. Для каждого разряда (индекса массива) складываем цифры из обоих массивов и учитываем возможное перенесенное значение (перенос).
3. Если длина массивов различна, нужно учесть, что один из массивов может закончиться раньше, и добавлять оставшиеся цифры из другого массива с учетом возможного переноса.

Вот как это можно реализовать:

### Реализация

```go
package main

import "fmt"

// Функция для сложения двух больших чисел, представленных в виде массивов
func addArrays(arr1, arr2 []int) []int {
    // Определим длину результирующего массива
    n1, n2 := len(arr1), len(arr2)
    maxLen := max(n1, n2) // Максимальная длина массивов
    res := make([]int, maxLen+1) // Результат с дополнительным разрядом для возможного переноса
    carry := 0 // Перенос
    
    // Индексы для обхода массивов с конца
    i, j, k := n1-1, n2-1, maxLen
    
    // Складываем числа, начиная с младших разрядов
    for i >= 0 || j >= 0 || carry != 0 {
        sum := carry // Начинаем с текущего переноса
        
        if i >= 0 {
            sum += arr1[i] // Добавляем цифру из первого массива
            i--
        }
        if j >= 0 {
            sum += arr2[j] // Добавляем цифру из второго массива
            j--
        }
        
        res[k] = sum % 10 // Сохраняем текущую цифру
        carry = sum / 10   // Вычисляем новый перенос
        
        k-- // Переходим к следующему разряду
    }

    // Возвращаем результат без ведущих нулей
    if res[0] == 0 {
        return res[1:]
    }
    return res
}

// Вспомогательная функция для нахождения максимального из двух чисел
func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

func main() {
    arr1 := []int{1, 2, 3} // число 123
    arr2 := []int{4, 5, 6} // число 456

    res := addArrays(arr1, arr2)
    fmt.Println(res) // [5 7 9]
}
```

### Объяснение:

1. **Инициализация:** Мы создаем новый массив `res`, в котором будет храниться результат сложения. Размер этого массива — это максимальная длина двух входных массивов плюс один (для возможного переноса).
    
2. **Алгоритм:**
    
    - Используем два указателя `i` и `j` для обхода массивов `arr1` и `arr2` с конца, начиная с младших разрядов.
    - В цикле добавляем цифры из обоих массивов и учитываем возможный перенос.
    - Результат сохраняется в массив `res`, начиная с младших разрядов.
3. **Перенос:** После сложения цифр мы вычисляем новый перенос с помощью оператора `% 10` (для получения текущей цифры) и `/ 10` (для вычисления переноса).
    
4. **Обработка ведущих нулей:** После завершения вычислений, если первый элемент массива `res` равен нулю, мы возвращаем срез массива без этого элемента, чтобы избежать ведущих нулей.
    

### Пример выполнения:

Для ввода:

```go
arr1 := []int{1, 2, 3} // число 123
arr2 := []int{4, 5, 6} // число 456
```

Результат:

```go
[5 7 9]
```

Для ввода:

```go
arr1 := []int{5, 4, 4} // число 544
arr2 := []int{4, 5, 6} // число 456
```

Результат:

```go
[1 0 0 0]
```

### Сложность:

- **Время**: O(N), где N — это максимальная длина из двух массивов. Мы проходим по каждому элементу обоих массивов один раз.
- **Память**: O(N), где N — это максимальная длина из двух массивов + 1 для переноса.

### 1. Генерация правильных скобочных последовательностей

Для решения задачи генерации всех правильных скобочных последовательностей из N пар скобок можно использовать рекурсию с бэктреккингом.

#### Решение:

```go
package main

import "fmt"

func generateParenthesis(n int) []string {
    result := []string{}
    generate(&result, "", n, n)
    return result
}

func generate(result *[]string, current string, open, close int) {
    if open == 0 && close == 0 {
        *result = append(*result, current)
        return
    }
    if open > 0 {
        generate(result, current+"(", open-1, close)
    }
    if close > open {
        generate(result, current+")", open, close-1)
    }
}

func main() {
    n := 3
    fmt.Println(generateParenthesis(n))
    // Вывод: [((())) (()()) (())() ()(()] ()()())]
}


```
```go
var sb strings.Builder
func generate(result *[]string, sb *strings.Builder, open, close int) {
    if open == 0 && close == 0 {
        *result = append(*result, sb.String())
        return
    }
    if open > 0 {
        sb.WriteByte('(')
        generate(result, sb, open-1, close)
        sb.Truncate(sb.Len()-1)
    }
    if close > open {
        sb.WriteByte(')')
        generate(result, sb, open, close-1)
        sb.Truncate(sb.Len()-1)
    }
}
```

**Объяснение**:

- Мы используем рекурсивный подход, чтобы добавить скобки в строку, начиная с открывающих и закрывающих скобок.
- Рекурсия завершается, когда длина текущей строки равна `2 * n`, т.е. все скобки добавлены.
- Убедитесь, что всегда соблюдается условие, что закрывающих скобок не больше открывающих на каждом шаге.

### 2. Печать конечных узлов рубрикатора

Задача состоит в том, чтобы пройти по дереву и напечатать только те узлы, которые не имеют потомков (конечные узлы), с полным путем.

#### Решение:

```go
package main

import "fmt"

type Node struct {
    text     string
    children []*Node
}

func printLeafNodes(node *Node, path string) {
    if node == nil {
        return
    }
    // Если у узла нет детей, это конечный узел
    if len(node.children) == 0 {
        fmt.Println(path + node.text)
    } else {
        // Для каждого дочернего узла продолжаем рекурсивный обход
        for _, child := range node.children {
            printLeafNodes(child, path+node.text+" => ")
        }
    }
}

func main() {
    // Пример дерева
    root := &Node{"Вещи", []*Node{
        {"Одежда", []*Node{
            {"Мужская", nil},
            {"Женская", nil},
        }},
        {"Мебель", nil},
        {"Посуду", nil},
    }}
    hobby := &Node{"Хобби", []*Node{
        {"Вязание", nil},
        {"Фигурное катание", nil},
    }}
    transport := &Node{"Транспорт", nil}

    // Печатаем конечные узлы
    printLeafNodes(root, "")
    printLeafNodes(hobby, "")
    printLeafNodes(transport, "")
}
```

**Объяснение**:

- Мы рекурсивно проходим по дереву, добавляя путь к каждому дочернему узлу.
- Если у узла нет детей, то это конечный узел, и мы печатаем путь.

### 3. Удаление нулей из массива (inplace)

Задача заключается в том, чтобы удалить все нули из массива и сдвинуть их в конец, сохраняя порядок остальных элементов. Это нужно сделать за O(n) времени и O(1) дополнительной памяти.

#### Решение:

```go
package main

import "fmt"

func moveZeros(nums []int) {
    nonZeroIndex := 0
    for i := 0; i < len(nums); i++ {
        if nums[i] != 0 {
            // Явный свап значений
            nums[nonZeroIndex], nums[i] = nums[i], nums[nonZeroIndex]
            nonZeroIndex++
        }
    }
}

func main() {
    testCases := [][]int{
        {7, 3, 0, 0, 0, 2, 4, 0, 5, 19},
        {0, 1, 0, 3, 12},
        {0, 0, 0, 1},
        {1, 2, 3, 4},
        {0},
        {1},
    }

    for _, arr := range testCases {
        moveZeros(arr)
        fmt.Println(arr)
    }
}
```

**Объяснение**:

- Мы используем два указателя: один для перебора массива (`i`), а второй (`nonZeroIndex`) для хранения позиции следующего ненулевого элемента.
- Каждый раз, когда встречается ненулевой элемент, мы перемещаем его на позицию `nonZeroIndex` и увеличиваем этот индекс.

### 4. Сравнение версий

Задача заключается в том, чтобы сравнить две версии, которые представлены строками в формате `vX.Y.Z`.

#### Решение:

```go
package main

import (
	"fmt"
	"strings"
	"strconv"
)

func compareVersions(version1 string, version2 string) int {
	v1 := strings.Split(version1[1:], ".")
	v2 := strings.Split(version2[1:], ".")

	// Проходим по каждому сегменту версии
	for i := 0; i < max(len(v1), len(v2)); i++ {
		num1, num2 := 0, 0
		if i < len(v1) {
			num1, _ = strconv.Atoi(v1[i])
		}
		if i < len(v2) {
			num2, _ = strconv.Atoi(v2[i])
		}

		if num1 > num2 {
			return -1
		} else if num1 < num2 {
			return 1
		}
	}

	return 0
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func main() {
	fmt.Println(compareVersions("v11.22.44", "v11.22.45")) // 1
	fmt.Println(compareVersions("v1.12.3", "v1.3.4"))    // -1
	fmt.Println(compareVersions("v11.22.44", "v11.22.44")) // 0
}
```

**Объяснение**:

- Мы разбиваем каждую версию на компоненты с помощью `strings.Split`, затем сравниваем их по очереди.
- Если одна версия имеет дополнительные компоненты, их значения считаются равными 0.

### Итоги:

Каждое из решений работает в свою очередь с определёнными типами данных и структурой задач:

- **Генерация правильных скобочных последовательностей** решается через рекурсию с бэктреккингом.
- **Печать конечных узлов рубрикатора** использует рекурсию для обхода дерева.
- **Удаление нулей из массива** решается с помощью двух указателей.
- **Сравнение версий** использует разбиение строк и сравнение сегментов.

Эти решения демонстрируют разные подходы к решению задач с использованием стандартных алгоритмов и структур данных в Go.

Задача заключается в слиянии двух отсортированных массивов в один отсортированный массив. Мы можем использовать два указателя для этого слияния, так как оба массива отсортированы.

Алгоритм будет таким:

1. Мы создаем новый массив для результата.
2. Используем два указателя для перебора обоих массивов: один указатель будет для массива A, другой — для массива B.
3. Сравниваем элементы, добавляем наименьший в результат и сдвигаем указатель на тот массив, из которого был выбран элемент.
4. После того как один из массивов будет исчерпан, добавляем оставшиеся элементы другого массива в результат.

### Решение:

```go
package main

import "fmt"

func mergeArrays(A []int, B []int) []int {
    m, n := len(A), len(B)
    result := make([]int, m+n) // Заранее выделяем память нужного размера
    i, j := m-1, n-1           // Индексы с конца массивов A и B
    k := m + n - 1             // Индекс для вставки в result с конца

    // Пока не пройдем по одному из массивов
    for i >= 0 && j >= 0 {
        if A[i] > B[j] {
            result[k] = A[i]
            i--
        } else {
            result[k] = B[j]
            j--
        }
        k--
    }

    // Добавляем оставшиеся элементы из A
    for i >= 0 {
        result[k] = A[i]
        i--
        k--
    }

    // Добавляем оставшиеся элементы из B
    for j >= 0 {
        result[k] = B[j]
        j--
        k--
    }

    return result
}

func main() {
    A1 := []int{1, 2, 5}
    B1 := []int{1, 2, 3, 4, 6}
    result1 := mergeArrays(A1, B1)
    fmt.Println(result1) // Вывод: [1, 1, 2, 2, 3, 4, 5, 6]

    A2 := []int{4, 7, 13}
    B2 := []int{3, 5, 8, 9, 11}
    result2 := mergeArrays(A2, B2)
    fmt.Println(result2) // Вывод: [3, 4, 5, 7, 8, 9, 11, 13]
}
```

### Пояснение:

1. **Инициализация переменных**:
    
    - `m` и `n` — это длины массивов `A` и `B` соответственно.
    - Мы создаём пустой массив `result` с ёмкостью, равной сумме длин двух массивов, чтобы избежать лишних перераспределений памяти.
    - `i` и `j` — это индексы для массивов `A` и `B`, соответственно.
2. **Основной цикл**:
    
    - Мы проходим по массивам, сравнивая текущие элементы. Добавляем наименьший элемент в результат и сдвигаем указатель для массива, из которого был выбран элемент.
3. **Дополнение массива**:
    
    - После того как один из массивов будет полностью пройден, оставшиеся элементы другого массива добавляются в результат.

### Алгоритмическая сложность:

- **Время**: O(N + M), где N и M — длины массивов A и B. Мы проходим по каждому элементу только один раз.
- **Память**: O(N + M) для хранения результата.

Этот подход идеально подходит для задачи, где оба массива уже отсортированы, и позволяет эффективно выполнить слияние.
