## 1. Фундамент: Два типа ядра

### Legacy Ядро (Процедурное)
```php
// Устаревший, но до сих пор используемый подход
CModule::IncludeModule("iblock");
$iblock = new CIBlockElement();
$res = $iblock->GetList($arSort, $arFilter);
while ($arItem = $res->GetNext()) {
    // обработка
}
```

### Современное Ядро D7 (ООП)
```php
// Современный подход
use Bitrix\Main\Loader;
use Bitrix\Iblock\ElementTable;

Loader::includeModule('iblock');
$result = ElementTable::getList([
    'select' => ['ID', 'NAME'],
    'filter' => ['=IBLOCK_ID' => 1],
    'order' => ['ID' => 'DESC']
]);
while ($row = $result->fetch()) {
    // обработка
}
```

## 2. Инфоблоки — "сердце" хранения данных

Инфоблоки — это НЕ таблицы в БД, а сложная абстракция:

```php
// Структура инфоблока в коде
$arFields = [
    "NAME" => "Новый элемент",
    "IBLOCK_ID" => 1,
    "PROPERTY_VALUES" => [
        "COLOR" => "красный",      // свойство типа "строка"
        "PRICE" => 1000,          // свойство типа "число"  
        "PHOTOS" => $_FILES['photos'] // свойство типа "файл"
    ]
];
$elementId = (new CIBlockElement)->Add($arFields);
```

**Физическая структура в БД:**
- `b_iblock_element` — основные данные элементов
- `b_iblock_property` — свойства инфоблоков
- `b_iblock_element_property` — значения свойств
- `b_iblock_section` — разделы

## 5. Обработчики событий (Event Handlers)

## 9. Кеширование

### Использование тегового кеширования
```php
use Bitrix\Main\Data\Cache;

$cache = Cache::createInstance();
$cacheId = 'your_cache_id';
$cacheDir = '/your/cache/dir/';
$cacheTtl = 3600;

if ($cache->initCache($cacheTtl, $cacheId, $cacheDir)) {
    $arResult = $cache->getVars();
} elseif ($cache->startDataCache()) {
    $arResult = $this->getExpensiveData();
    
    // Привязка к тегам для автоматической очистки
    $taggedCache = \Bitrix\Main\Application::getInstance()->getTaggedCache();
    $taggedCache->startTagCache($cacheDir);
    $taggedCache->registerTag('iblock_id_1');
    $taggedCache->endTagCache();
    
    $cache->endDataCache($arResult);
}
```

## Ключевые особенности для разработчика

### Сильные стороны:
- ✅ Готовые бизнес-модули (CRM, задачи, документы)
- ✅ Мощная компонентная система
- ✅ Интеграция с 1С, телефонией, почтой
- ✅ Бизнес-процессы и автоматизация
- ✅ Большое комьюнити и рынок вакансий

### Слабые стороны:
- ❌ Сложная кривая обучения
- ❌ Смесь старого и нового API
- ❌ Vendor lock-in
- ❌ Производительность требует тонкой настройки
- ❌ Сложности с современными практиками (Composer, CI/CD)

Bitrix24 — это целая экосистема, требующая глубокого понимания не только PHP, но и бизнес-логики платформы. Успешный разработчик в этой среде сочетает знание технических особенностей с пониманием бизнес-процессов предприятия.
