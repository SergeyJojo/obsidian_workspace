Вот решение задачи **LeetCode №9 – Palindrome Number** на Go с подробными пояснениями.

---

## 🧠 Условие:

Определите, является ли заданное целое число палиндромом.

Целое число является палиндромом, если оно читается одинаково в прямом и обратном направлении, например: `121` или `12321`.

**Примеры:**

- `121` → true
    
- `-121` → false (отрицательные не палиндромы)
    
- `10` → false (обратное число `01` ≠ `10`)
    

---

## ✅ Алгоритм:

Мы можем **перевернуть половину числа**, а не всё число — это безопасно и экономит ресурсы.

### 🧩 Идея:

- Отрицательные числа сразу → `false`.
    
- Если число оканчивается на `0`, но не является `0`, оно **не** палиндром.
    
- Пока `reversed < x`, переворачиваем последнюю цифру `x`, убираем её у `x`, добавляем к `reversed`.
    

### ⏱️ Сложность:

- **Время:** O(log₁₀N), где N — число (по числу цифр).
    
- **Память:** O(1)
    

---

## 🧾 Код на Go с пояснениями:

```go
package main

import (
	"fmt"
)

func isPalindrome(x int) bool {
	// Отрицательные числа не палиндромы
	// Также если число заканчивается на 0, но само не ноль — не палиндром
	if x < 0 || (x%10 == 0 && x != 0) {
		return false
	}

	reversed := 0

	for x > reversed {
		lastDigit := x % 10             // Получаем последнюю цифру
		reversed = reversed*10 + lastDigit // Добавляем её к перевернутому числу
		x /= 10                          // Убираем последнюю цифру
	}

	// Сравниваем левую и правую половины
	// Если кол-во цифр чётное → x == reversed
	// Если нечётное → отбросим последнюю цифру reversed/10
	return x == reversed || x == reversed/10
}

func main() {
	fmt.Println(isPalindrome(121))   // true
	fmt.Println(isPalindrome(-121))  // false
	fmt.Println(isPalindrome(10))    // false
	fmt.Println(isPalindrome(12321)) // true
}
```

---

## 📌 Пример работы:

Для `x = 12321`:

- первая итерация: reversed = 1, x = 1232
    
- вторая: reversed = 12, x = 123
    
- третья: reversed = 123, x = 12  
    `x < reversed`, значит `x == reversed/10` (12 == 123/10) → true ✅
