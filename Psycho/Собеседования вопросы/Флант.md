
 

### 1) **Какими способами можно посмотреть файлы, которые были открыты процессом?**

- В Linux можно использовать команду `lsof` (list open files), чтобы просмотреть файлы, открытые процессом. Например:
    
    ```bash
    lsof -p <PID>
    ```
    
    Это покажет все файлы, открытые процессом с указанным PID. Также можно использовать `/proc/<PID>/fd/`, чтобы проверить дескрипторы файлов, которые процесс использует.

### 2) **Как определить, почему тормозит приложение, если это бинарник без логов?**

- Для диагностики можно использовать следующие инструменты:
    - **`strace`** — для отслеживания системных вызовов и сигналов.
    - **`perf`** — для анализа производительности на уровне процессора.
    - **`top`** или **`htop`** — для мониторинга загрузки CPU и памяти.
    - **`gdb`** — для дебага бинарника в режиме реального времени.

### 3) **Как преобразовать строку в число в Go?**

- В Go для преобразования строки в число можно использовать функцию `strconv.Atoi` (для целых чисел) или `strconv.ParseFloat` (для чисел с плавающей точкой):
    
    ```go
    import "strconv"
    str := "123"
    num, err := strconv.Atoi(str)
    if err != nil {
        fmt.Println("Error:", err)
    }
    fmt.Println(num)
    ```
    

### 4) **Для чего select в Go?**

- `select` используется для многократного выбора между несколькими каналами. Он блокирует выполнение, пока один из каналов не получит данные, и затем выполняет соответствующий блок кода:
    
    ```go
    select {
    case msg1 := <-ch1:
        fmt.Println("Received from ch1:", msg1)
    case msg2 := <-ch2:
        fmt.Println("Received from ch2:", msg2)
    case <-time.After(1 * time.Second):
        fmt.Println("Timeout")
    }
    ```
    

### 5) **Значение LoadAverage в top = 1 15 5. Что это значит?**

- Эти значения показывают среднюю нагрузку на систему за последние 1, 5 и 15 минут соответственно. Нагрузка — это количество процессов, которые находятся в состоянии выполнения или готовы к выполнению. Чем выше значение, тем более загружена система:
    - Если значение больше числа ядер, это может означать перегрузку системы.

### 6) **Чем Soft Link отличается от Hard Link?**

- **Soft Link** (символическая ссылка) — это файл, который ссылается на другой файл или директорию, как ярлык. Если исходный файл удален, ссылка становится недействительной.
- **Hard Link** — это дополнительная ссылка на существующий файл в файловой системе. Он не зависит от исходного файла, и даже если исходный файл удален, данные остаются доступными через хард-линк.

### 7) **Потребляет ли память основной процесс?**

- Да, основной процесс, как и все его дочерние процессы, потребляет память для хранения данных, стека и кучи. Однако точное использование памяти зависит от характера работы процесса.

### 8) **CPU Steal time = 10% что это значит?**

- **CPU Steal time** — это время, когда виртуальная машина не может получить доступ к CPU, потому что ресурсы системы заблокированы другими виртуальными машинами на гипервизоре. 10% означает, что 10% времени процессор был недоступен для текущей виртуальной машины.

### 9) **TCP это протокол какого уровня модели OSI?**

- **TCP (Transmission Control Protocol)** — это протокол **транспортного уровня (Level 4)** в модели OSI. Он обеспечивает надежную, ориентированную на соединение передачу данных между узлами.

### 10) **Сколько минимальных узлов нужно, чтобы поднять кластер Кубера?**

- Минимальное количество узлов для развертывания кластера Kubernetes — это **2**: один мастер-узел и один рабочий узел. Однако для повышения отказоустойчивости рекомендуется использовать минимум 3 мастер-узла.

### 11) **Чем отличается висит в состоянии Терминейт уже сутки — причины?**

- Если процесс или контейнер "висит" в состоянии **Terminating** слишком долго, это может быть связано с:
    - Проблемами с завершением работы контейнера (например, процессы не завершаются корректно).
    - Зависаниями при очищении ресурсов (например, томов или сетевых подключений).
    - Проблемами с управлением памятью или системными ресурсами.
    - Нужно проверять логи и статус зависших ресурсов.

### 12) **Что такое глобальные переменные в Go?**

- Глобальные переменные в Go — это переменные, объявленные за пределами всех функций (в основном, в пакете), которые доступны для использования в разных частях программы. Хотя их использование может быть удобным, следует избегать чрезмерного использования глобальных переменных из-за проблем с тестируемостью и возможной запутанностью.

### 13) **Что такое минимизация ошибок и функции?**

- Минимизация ошибок (в контексте программирования) относится к использованию принципов, которые помогают избежать ошибок в коде, например, проверка на ошибки после вызова функций, использование типизации и статического анализа.
- "Функции" могут относиться к малым, независимым блокам кода, которые выполняют конкретную задачу и могут быть повторно использованы.

### 14) **Можно ли на Go писать драйвера для Ядра Линукс?**

- Нет, Go не является языком, предназначенным для написания драйверов ядра Linux. Обычно для написания драйверов используется C, поскольку он предоставляет прямой доступ к аппаратным ресурсам и работает непосредственно с ядром ОС.

### 15) **Какие аббревиатуры означают: GVK, CFQ, MTTR, MTU?**

- **GVK** — Group-Version-Kind: аббревиатура, используемая в Kubernetes для идентификации объектов в API, состоящая из группы, версии и типа.
- **CFQ** — Completely Fair Queuing: алгоритм планирования ввода-вывода в Linux, который регулирует доступ к дисковому вводу/выводу для процессов.
- **MTTR** — Mean Time to Recovery (Среднее время восстановления): среднее время, которое требуется для восстановления системы после сбоя.
- **MTU** — Maximum Transmission Unit (Максимальный размер передачи): максимальный размер пакета, который может быть передан по сети.
