
### Общие вопросы

#### 1. Принципы ООП
- **Инкапсуляция**: Сокрытие внутренней реализации и предоставление интерфейса для взаимодействия.
- **Наследование**: Возможность создания новых классов на основе существующих.
- **Полиморфизм**: Возможность объектов с одинаковым интерфейсом иметь разную реализацию.
- **Абстракция**: Упрощение сложных систем путем выделения ключевых характеристик.

#### 2. SOLID
- **S**ingle Responsibility: Класс должен иметь только одну причину для изменения.
- **O**pen/Closed: Класс должен быть открыт для расширения, но закрыт для модификации.
- **L**iskov Substitution: Объекты в программе должны быть заменяемы экземплярами их подтипов.
- **I**nterface Segregation: Много специализированных интерфейсов лучше, чем один общий.
- **D**ependency Inversion: Зависимости должны строиться на абстракциях, а не на деталях.

#### 3. Как храните протофайлы
- Обычно протофайлы хранятся в отдельной репозитории или в папке `proto` внутри проекта.

#### 4. Как бы реализовывал in-memory cache
- Использовал бы структуру данных типа `map` для хранения ключей и значений.
- Добавил бы механизмы для управления размером кэша (например, LRU).

#### 5. Как бы реализовывал LRU cache
- Использовал бы двусвязный список для хранения порядка использования и `map` для быстрого доступа к элементам.
- При доступе к элементу перемещал бы его в начало списка, а при превышении размера кэша удалял бы последний элемент.

#### 6. Есть 3 инстанса приложения, какой бы кэш использовал
- Использовал бы распределенный кэш, например Redis, чтобы данные были доступны на всех инстансах.

#### 7. Почему кириллица занимает 2 байта
- Кириллица кодируется в UTF-8, где каждый символ может занимать от 1 до 4 байт. В UTF-16 символы кириллицы занимают 2 байта.

### Вопросы по Go

#### 2. Нюансы с типом int
- `int` зависит от разрядности системы: 32 бита на 32-битных системах и 64 бита на 64-битных.

#### 3. Что представляют из себя строки? Как посчитать количество символов?
- Строки в Go — это неизменяемые последовательности байт. Для подсчета символов используйте `utf8.RuneCountInString`.

#### 4. Различия слайса и массива. Из чего состоит слайс?
- Массив — это фиксированная последовательность элементов, а слайс — это динамическая обертка вокруг массива. Слайс состоит из указателя на массив, длины и емкости.

#### 5. Как растет слайс?
- При добавлении элементов, если емкость недостаточна, создается новый массив с удвоенной емкостью, и данные копируются в него.

#### 6. Если не присвоить результат append к изначальному слайсу, изменится ли он?
- Нет, изначальный слайс не изменится. `append` возвращает новый слайс.

#### 7. Что можешь рассказать про тип map?
- `map` — это коллекция пар ключ-значение. Ключи должны быть сравниваемыми типами.

#### 14. Как работать с мапой в условиях конкурентности?
- Использовать `sync.Mutex` или `sync.RWMutex` для синхронизации доступа.

#### 16. Какие типы каналов бывают и как с ними работать?
- Буферизированные и небуферизированные каналы. Работают с помощью операторов `<-` для отправки и получения данных.

#### 20. Что произойдет, если записать в канал, у которого нет читателя?
- Для небуферизированного канала — deadlock. Для буферизированного — данные будут добавлены в буфер, пока он не заполнится.

#### 29. Пакет context, какие бывают, для чего нужны, какие есть методы?
- `context` используется для управления временем жизни, отмены и передачи данных между горутинами. Основные методы: `WithCancel`, `WithTimeout`, `WithDeadline`, `WithValue`.

#### 30. Зачем нужен defer? Всегда ли он выполнится?
- `defer` используется для отложенного выполнения функции. Выполнится всегда, кроме случаев аварийного завершения программы.

#### 34. Какие бывают примитивы синхронизации?
- `Mutex`, `RWMutex`, `WaitGroup`, `Cond`, `Once`, `Pool`.

#### 35. RWMutex vs Mutex
- `RWMutex` позволяет множественное чтение, но эксклюзивную запись. `Mutex` — эксклюзивный доступ для чтения и записи.

#### 36. Какая команда помогает проверить есть ли гонки или дедлоки
- `go run -race`.

#### 37. Где бы ты объявил интерфейс и почему
- Интерфейс объявляется в том месте, где он используется, чтобы уменьшить связанность и повысить гибкость.

#### 38. Data race и Race condition
- Data race — это когда несколько горутин одновременно обращаются к данным, и хотя бы одна из них пишет. Race condition — это более общее понятие, когда поведение программы зависит от порядка выполнения операций.

#### 39. Чем отличается concurrency от параллелизма, можем ли быть параллелизм на 1 ядре?
- Concurrency — это выполнение нескольких задач одновременно, но не обязательно в одно и то же время. Параллелизм — это выполнение задач одновременно. На 1 ядре возможен только concurrency.

### Вопросы по PostgreSQL

#### 6. Что делать, если запрос тормозит?
- Использовать `EXPLAIN ANALYZE` для анализа запроса, добавить индексы, оптимизировать запрос, увеличить ресурсы сервера.

#### 7. Чем отличается `EXPLAIN` от `EXPLAIN ANALYZE`?
- `EXPLAIN` показывает план выполнения запроса, а `EXPLAIN ANALYZE` выполняет запрос и показывает фактическое время выполнения.

#### 8. На основании чего работает `EXPLAIN`, если он не выполняет запрос?
- `EXPLAIN` использует статистику и метаданные таблиц для построения плана выполнения.

#### 17. Какие есть уровни изоляции?
- Read Uncommitted, Read Committed, Repeatable Read, Serializable.

#### 18. На уровне Serializable две транзакции апдейтят одну строку, что произойдет?
- Одна из транзакций будет завершена с ошибкой, чтобы предотвратить аномалии.

#### 19. Как бы делал инсерт 1000000000 строк
- Использовал бы `COPY` для массовой вставки, разбивал бы данные на пакеты и использовал бы транзакции.

```go
type item struct { name string }
type wrapper struct { item *item }

func (b *wrapper) unwrap() item {
  return *b.item
}

func (b *wrapper) wrap(item *item) {
  b.item = item
}

func wrapItems(items []item) (result []*wrapper) {
  for _, it := range items {
    w := new(wrapper)
    w.wrap(&it)
    result = append(result, w)
  }
  return result
}

func main()  {
  items := []item{
    {"a"},
    {"b"},
    {"c"},
  }

  wrappers := wrapItems(items)
  for _, w := range wrappers {
    fmt.Println(w.unwrap()) // a, b, c
  }
}
```

func spawnMessages(n int) chan string {
  ch := make(chan string, n)
  go func() {
    defer close(ch)
    for i := 0; i < n; i++ {
      ch <- fmt.Sprintf("msg %d", i+1)
    }
  }()
  return ch
}

func main() {
  n := 10

  for msg := range spawnMessages(n) {
    fmt.Println("received: ", msg)
  }
}
