# 🧠 Памятка: Работа с `go-redis` (github.com/redis/go-redis/v9)

> Официальная документация: [https://redis.uptrace.dev/](https://redis.uptrace.dev/)  
> Поддерживает Redis 6+, кластер, sentinel, TLS, пайплайны, контексты.

---

## 1. 🔧 Установка

```bash
go get github.com/redis/go-redis/v9
```

---

## 2. 🚀 Подключение к Redis

### Простое подключение (standalone)

```go
import "github.com/redis/go-redis/v9"

rdb := redis.NewClient(&redis.Options{
    Addr:     "localhost:6379",
    Password: "", // no password set
    DB:       0,  // use default DB
})

ctx := context.Background()
```

### С TLS
```go
rdb := redis.NewClient(&redis.Options{
    Addr: "rediss://:password@host:port", // rediss = с TLS
})
```

### С паролем
```go
rdb := redis.NewClient(&redis.Options{
    Addr:     "localhost:6379",
    Password: "secret",
})
```

## 4. 📦 Основные команды (CRUD)

| Действие          | Код                                                  |
| ----------------- | ---------------------------------------------------- |
| Установить ключ   | `rdb.Set(ctx, "key", "value", 0).Err()`              |
| Установить с TTL  | `rdb.Set(ctx, "key", "value", 10*time.Second).Err()` |
| Получить значение | `val, err := rdb.Get(ctx, "key").Result()`           |
| Удалить ключ      | `rdb.Del(ctx, "key").Err()`                          |
| Проверить наличие | `exists, _ := rdb.Exists(ctx, "key").Result()`       |
| TTL ключа         | `ttl, _ := rdb.TTL(ctx, "key").Result()`             |
| Увеличить число   | `rdb.Incr(ctx, "counter").Result()`                  |
| Увеличить с шагом | `rdb.IncrBy(ctx, "counter", 5).Result()`             |

## 5. 🧩 Работа с типами данных

### ✅ Строки
```go
rdb.Set(ctx, "name", "Alice", 0)
name, _ := rdb.Get(ctx, "name").Result()
```

### ✅ Хэши (Hash)
```go
// HSET
rdb.HSet(ctx, "user:1", "name", "Bob")
rdb.HSet(ctx, "user:1", "age", "30")

// HGETALL
user, _ := rdb.HGetAll(ctx, "user:1").Result()
// map[name:Bob age:30]

// HMSet
rdb.HMSet(ctx, "user:2", map[string]interface{}{
    "name": "Charlie",
    "age":  "25",
})
```

### ✅ Списки (List)
```go
// LPUSH
rdb.LPush(ctx, "tasks", "task1", "task2")

// RPOP
task, _ := rdb.RPop(ctx, "tasks").Result()

// LRANGE
tasks, _ := rdb.LRange(ctx, "tasks", 0, -1).Result()
```

### ✅ Наборы (Set)
```go
rdb.SAdd(ctx, "tags", "go", "redis", "dev")
members, _ := rdb.SMembers(ctx, "tags").Result()
exists := rdb.SIsMember(ctx, "tags", "go").Val()
```

### ✅ Сортированные наборы (ZSet)
```go
rdb.ZAdd(ctx, "leaderboard", redis.Z{Score: 100, Member: "Alice"})
rdb.ZAdd(ctx, "leaderboard", redis.Z{Score: 90, Member: "Bob"})

// Топ-10
top, _ := rdb.ZRevRangeWithScores(ctx, "leaderboard", 0, 9).Result()
```

## 6. 🔄 Пайплайны (Pipelining)

Уменьшает количество round-trip запросов.

### Простой пайплайн
```go
pipe := rdb.Pipeline()
pipe.Set(ctx, "key1", "hello1", 0)
pipe.Set(ctx, "key2", "hello2", 0)
_, err := pipe.Exec(ctx)
```

### Транзакционный пайплайн (MULTI/EXEC)
```go
pipe := rdb.TxPipeline()
pipe.Set(ctx, "key1", "hello1", 0)
pipe.Set(ctx, "key2", "hello2", 0)
_, err := pipe.Exec(ctx)
```

## 7. 📡 Pub/Sub (публикация/подписка)

### Подписка
```go
pubsub := rdb.Subscribe(ctx, "news")
defer pubsub.Close()

for {
    msg, err := pubsub.ReceiveMessage(ctx)
    if err != nil {
        break
    }
    fmt.Printf("Получено: %s\n", msg.Payload)
}
```

### Публикация
```go
rdb.Publish(ctx, "news", "Новость 1")
```

## 10. ⚠️ Обработка ошибок

```go
val, err := rdb.Get(ctx, "key").Result()
if err == redis.Nil {
    fmt.Println("Ключ не существует")
} else if err != nil {
    fmt.Printf("Ошибка Redis: %v", err)
} else {
    fmt.Printf("Значение: %s", val)
}
```

> `redis.Nil` — это **не ошибка**, а отсутствие значения.

## 11. 🧰 Полезные функции

| Функция | Назначение |
|--------|-----------|
| `rdb.FlushDB(ctx)` | Очистить текущую БД |
| `rdb.Keys(ctx, "pattern*")` | Получить ключи по шаблону (только для отладки!) |
| `rdb.Scan(ctx, 0, "prefix:*", 10).Val()` | Постраничное сканирование |
| `rdb.Info(ctx).Val()` | Информация о сервере |
| `rdb.ClientList(ctx).Val()` | Список клиентов |

---

## 12. 🧠 Best Practices

| Практика | Почему |
|--------|--------|
| Всегда используй `context` | Для таймаутов и отмены |
| Устанавливай таймауты | `DialTimeout`, `ReadTimeout`, `WriteTimeout` |
| Не используй `Keys("*")` в production | Блокирует сервер |
| Используй `Scan` вместо `Keys` | Безопасно для больших БД |
| Закрывай клиент при завершении | `rdb.Close()` |
| Используй пайплайны для множества операций | Повышает производительность |
| Храни структуры как JSON | `json.Marshal(user)` → `Set("user:1", json, 0)` |

## 13. 🛠 Конфигурация с таймаутами

```go
rdb := redis.NewClient(&redis.Options{
    Addr:         "localhost:6379",
    DialTimeout:  10 * time.Second,
    ReadTimeout:  3 * time.Second,
    WriteTimeout: 3 * time.Second,
    PoolSize:     10,
    PoolTimeout:  5 * time.Second,
})
```

## 14. 🧩 Пример: кэширование

```go
func GetUser(ctx context.Context, id int) (*User, error) {
    key := fmt.Sprintf("user:%d", id)

    // Попробовать из кэша
    cached, err := rdb.Get(ctx, key).Result()
    if err == nil {
        var user User
        json.Unmarshal([]byte(cached), &user)
        return &user, nil
    }

    // Получить из БД
    user := fetchFromDB(id)

    // Сохранить в кэш
    data, _ := json.Marshal(user)
    rdb.Set(ctx, key, data, 5*time.Minute)

    return user, nil
}
```
