Вот решение задачи **сравнения версий** на Go — когда версии представлены строками вида `"1.0.2"` и `"1.0.10"` и нужно определить, какая **больше**, **меньше** или **равна**.

---

## ✅ Условия задачи (например, LeetCode 165):

> Сравни две версии версии `version1` и `version2`.  
> Версии состоят из подверсий, разделённых точками.  
> Версия больше, если первая несовпадающая подверсия больше.  
> Вернуть:
> 
> - `1`, если `version1 > version2`,
>     
> - `-1`, если `version1 < version2`,
>     
> - `0`, если они равны.
>     

---

## 📦 Пример:

```go
compareVersion("1.01", "1.001") // → 0
compareVersion("1.0", "1.0.0")  // → 0
compareVersion("0.1", "1.1")    // → -1
compareVersion("1.0.1", "1")    // → 1
```

---

## 🧠 Алгоритм:

1. Разбить обе строки на массивы чисел по `"."`.
    
2. Проходить по ним параллельно.
    
3. Сравнивать численно каждую часть (например, "01" → `1`).
    
4. Если части не равны — вернуть результат.
    
5. Если все части равны — вернуть `0`.
    

---

## ✅ Go-реализация:

```go
package main

import (
	"fmt"
	"strconv"
	"strings"
)

func compareVersion(version1 string, version2 string) int {
	parts1 := strings.Split(version1, ".")
	parts2 := strings.Split(version2, ".")

	maxLen := len(parts1)
	if len(parts2) > maxLen {
		maxLen = len(parts2)
	}

	for i := 0; i < maxLen; i++ {
		var v1, v2 int

		if i < len(parts1) {
			v1, _ = strconv.Atoi(parts1[i])
		}
		if i < len(parts2) {
			v2, _ = strconv.Atoi(parts2[i])
		}

		if v1 > v2 {
			return 1
		} else if v1 < v2 {
			return -1
		}
	}

	return 0
}

func main() {
	fmt.Println(compareVersion("1.01", "1.001"))   // 0
	fmt.Println(compareVersion("1.0", "1.0.0"))    // 0
	fmt.Println(compareVersion("0.1", "1.1"))      // -1
	fmt.Println(compareVersion("1.0.1", "1"))      // 1
	fmt.Println(compareVersion("7.5.2.4", "7.5.3")) // -1
}
```

## 📌 Задача:

Реализовать функцию:

```go
// CompareVersions сравнивает версии v1 и v2.
// Возвращает:
// -1 если v1 < v2
//  1 если v1 > v2
//  0 если v1 == v2
func CompareVersions(v1, v2 string) int
```

Версии — строки вида `"1.2.3"`, `"1.0.1"`, `"2"` и т.д.

---

## ✅ Рабочее решение:

```go
package main

import (
	"fmt"
	"strconv"
)

func CompareVersions(v1, v2 string) int {
	i, j := 0, 0
	n1, n2 := len(v1), len(v2)

	for i < n1 || j < n2 {
		// получить следующее число из v1
		num1 := 0
		for i < n1 && v1[i] != '.' {
			num1 = num1*10 + int(v1[i]-'0')
			i++
		}
		// пропустить точку
		if i < n1 && v1[i] == '.' {
			i++
		}

		// получить следующее число из v2
		num2 := 0
		for j < n2 && v2[j] != '.' {
			num2 = num2*10 + int(v2[j]-'0')
			j++
		}
		if j < n2 && v2[j] == '.' {
			j++
		}

		if num1 < num2 {
			return -1
		}
		if num1 > num2 {
			return 1
		}
	}

	return 0
}
```

---

## 💡 Пример использования:

```go
func main() {
	fmt.Println(CompareVersions("1.2.3", "1.2.4"))  // -1
	fmt.Println(CompareVersions("1.2.3", "1.2.3"))  // 0
	fmt.Println(CompareVersions("2.0", "1.9.9"))    // 1
	fmt.Println(CompareVersions("1.0", "1"))        // 0
	fmt.Println(CompareVersions("1", "1.0.1"))      // -1
	fmt.Println(CompareVersions("1.01", "1.001.0")) // -1
}
```

---

## 🔍 Почему это решение хорошее:

- ⚡️ **O(n)** по длине строки
    
- 🧠 Не выделяет памяти на сплиты
    
- 🔒 Устойчиво к ведущим нулям (`"01"` = `1`)
    
- ✅ Работает для версий разной длины (например, `"1"` и `"1.0.0"`)
