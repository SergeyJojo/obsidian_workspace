
В этой задаче нам нужно реализовать прерываемую версию `time.Sleep`, которая будет проверять контекст на отмену во время ожидания. Если контекст был отменен (например, по истечении таймаута), мы должны вернуть `false` и прекратить ожидание.

Для того чтобы корректно обработать отмену, используем `select` с каналом `Done()` контекста, который будет закрыт, если контекст будет отменен.

Вот решение:

```go
package main

import (
	"context"
	"log"
	"time"
)

// Sleep is the interruptible version of time.Sleep.
// Returns false if context was cancelled.
func Sleep(ctx context.Context, d time.Duration) bool {
	// Создаем новый канал, который будет использоваться для "просыпания"
	select {
	case <-time.After(d): // Если таймер истечет до отмены контекста, Sleep завершится успешно
		return true
	case <-ctx.Done(): // Если контекст отменен, Sleep завершится раньше
		return false
	}
}

func main() {
	// Создаем контекст с тайм-аутом 1 миллисекунда
	ctx, _ := context.WithTimeout(context.Background(), time.Millisecond)

	// Вызываем нашу прерываемую версию time.Sleep с таймаутом в 1 секунду
	if !Sleep(ctx, time.Second) {
		log.Print("interrupted")
	}
}
```

### Пояснение:

1. **`Sleep`**:
    
    - Функция принимает контекст и продолжительность времени для сна.
    - Используем конструкцию `select`, которая позволяет ожидать два канала одновременно:
        - **`time.After(d)`** — создаёт канал, который сработает через указанное время `d`. Когда этот канал срабатывает, функция возвращает `true`, что означает успешное завершение сна.
        - **`ctx.Done()`** — канал, который будет закрыт, если контекст будет отменён (например, по таймауту). Если контекст отменён, функция возвращает `false`.
2. **Контекст с таймаутом**:
    
    - В `main` мы создаём контекст с таймаутом в 1 миллисекунду: `context.WithTimeout(context.Background(), time.Millisecond)`.
    - Затем вызываем `Sleep` с таймаутом в 1 секунду, но поскольку контекст отменяется раньше (по истечении 1 миллисекунды), результат будет `"interrupted"`, так как функция не успеет "уснуть" на 1 секунду.

### Что выводится:

```
interrupted
```

Это ожидаемое поведение, так как контекст отменяется через 1 миллисекунду, и выполнение не успевает завершиться через `Sleep`.
