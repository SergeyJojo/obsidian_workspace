# Жизненный цикл запроса в Laravel

Laravel имеет четко определенный жизненный цикл обработки HTTP-запроса. Вот подробное описание каждого этапа:

## 📋 Общая схема жизненного цикла

```
HTTP Request
    ↓
public/index.php
    ↓
Bootstrap/App Creation
    ↓
HTTP Kernel
    ↓
Middleware Stack
    ↓
Router → Controller/Method
    ↓
Business Logic
    ↓
Response
    ↓
Middleware (Response)
    ↓
HTTP Response
```

## 🔍 Детальное описание каждого этапа

### 1. **Точка входа - public/index.php**

```php
<?php
// public/index.php

// 1. Регистрация времени начала
define('LARAVEL_START', microtime(true));

// 2. Подключение автозагрузчика Composer
require __DIR__.'/../vendor/autoload.php';

// 3. Создание экземпляра приложения
$app = require_once __DIR__.'/../bootstrap/app.php';

// 4. Получение ядра HTTP из контейнера
$kernel = $app->make(Illuminate\Contracts\Http\Kernel::class);

// 5. Обработка входящего запроса
$response = $kernel->handle(
    $request = Illuminate\Http\Request::capture()
);

// 6. Отправка ответа
$response->send();

// 7. Завершающие операции
$kernel->terminate($request, $response);
```

### 2. **Создание приложения (bootstrap/app.php)**

```php
<?php
// bootstrap/app.php

$app = new Illuminate\Foundation\Application(
    $_ENV['APP_BASE_PATH'] ?? dirname(__DIR__)
);

// Привязка основных интерфейсов
$app->singleton(
    Illuminate\Contracts\Http\Kernel::class,
    App\Http\Kernel::class
);

$app->singleton(
    Illuminate\Contracts\Console\Kernel::class,
    App\Console\Kernel::class
);

$app->singleton(
    Illuminate\Contracts\Debug\ExceptionHandler::class,
    App\Exceptions\Handler::class
);

return $app;
```

### 3. **HTTP Kernel - ядро обработки**

```php
<?php
// app/Http/Kernel.php

class Kernel extends HttpKernel
{
    /**
     * Глобальный middleware
     */
    protected $middleware = [
        \App\Http\Middleware\TrustProxies::class,
        \App\Http\Middleware\PreventRequestsDuringMaintenance::class,
        \App\Http\Middleware\ValidatePostSize::class,
        \App\Http\Middleware\TrimStrings::class,
        \App\Http\Middleware\ConvertEmptyStringsToNull::class,
    ];

    /**
     * Группы middleware
     */
    protected $middlewareGroups = [
        'web' => [
            \App\Http\Middleware\EncryptCookies::class,
            \Illuminate\Cookie\Middleware\AddQueuedCookiesToResponse::class,
            \Illuminate\Session\Middleware\StartSession::class,
            \Illuminate\View\Middleware\ShareErrorsFromSession::class,
            \App\Http\Middleware\VerifyCsrfToken::class,
            \Illuminate\Routing\Middleware\SubstituteBindings::class,
        ],

        'api' => [
            'throttle:api',
            \Illuminate\Routing\Middleware\SubstituteBindings::class,
        ],
    ];
}
```

### 4. **Обработка через Middleware Stack**

**Порядок выполнения middleware:**

```
Request → 
TrustProxies → 
PreventRequestsDuringMaintenance → 
ValidatePostSize → 
TrimStrings → 
ConvertEmptyStringsToNull → 
Route Middleware → 
Controller
```

**Пример middleware:**
```php
<?php
// app/Http/Middleware/TrimStrings.php

class TrimStrings extends Middleware
{
    protected $except = [
        'password',
        'password_confirmation',
    ];

    public function handle($request, Closure $next)
    {
        // ДО выполнения контроллера
        $this->clean($request);

        $response = $next($request);

        // ПОСЛЕ выполнения контроллера
        return $response;
    }
}
```



### 7. **Service Providers - поставщики услуг**

**Порядок загрузки провайдеров:**
```php
<?php
// config/app.php

'providers' => [
    /*
     * Laravel Framework Service Providers...
     */
    Illuminate\Auth\AuthServiceProvider::class,
    Illuminate\Broadcasting\BroadcastServiceProvider::class,
    // ...
    
    /*
     * Application Service Providers...
     */
    App\Providers\AppServiceProvider::class,
    App\Providers\AuthServiceProvider::class,
    App\Providers\EventServiceProvider::class,
    App\Providers\RouteServiceProvider::class,
],
```

**Пример провайдера:**
```php
<?php
// app/Providers/AppServiceProvider.php

class AppServiceProvider extends ServiceProvider
{
    public function register()
    {
        // Регистрация в контейнере
        $this->app->singleton(Service::class, function ($app) {
            return new Service($app->make(Dependency::class));
        });
    }

    public function boot()
    {
        // Загрузка после регистрации всех провайдеров
        View::share('key', 'value');
    }
}
```

### 8. **Контейнер зависимостей (DI Container)**

```php
<?php
// Автоматическое разрешение зависимостей
class UserController extends Controller
{
    public function __construct(
        private UserRepository $users,
        private Mailer $mailer
    ) {}

    public function store(CreateUserRequest $request)
    {
        // $request автоматически валидируется
        // Зависимости автоматически внедряются
        $user = $this->users->create($request->validated());
        
        return response()->json($user, 201);
    }
}
```

### 9. **Обработка исключений**

```php
<?php
// app/Exceptions/Handler.php

class Handler extends ExceptionHandler
{
    public function render($request, Throwable $exception)
    {
        if ($exception instanceof ModelNotFoundException) {
            return response()->json(['error' => 'Not found'], 404);
        }

        return parent::render($request, $exception);
    }
}
```

### 11. **Terminable Middleware**

```php
<?php
class LogRequestMiddleware
{
    public function handle($request, Closure $next)
    {
        return $next($request);
    }

    public function terminate($request, $response)
    {
        // Выполняется после отправки ответа
        Log::info('Request completed', [
            'url' => $request->url(),
            'status' => $response->status(),
            'duration' => microtime(true) - LARAVEL_START
        ]);
    }
}
```

## ⚡ Оптимизация жизненного цикла

```bash

# Кеш маршрутов
php artisan route:cache

# Кеш событий
php artisan event:cache

# Кеш вьюх
php artisan view:cache
```

### Профилирование:
```php

// Добавьте в AppServiceProvider
public function boot()
{
    if (app()->environment('local')) {
        DB::listen(function ($query) {
            logger($query->sql, $query->bindings);
        });
    }
}
```

## 🎯 Ключевые точки расширения

1. **Middleware** - для перехвата запросов/ответов
2. **Service Providers** - для регистрации сервисов
3. **Macros** - для расширения core-классов
4. **Events/Listeners** - для асинхронной обработки
5. **Form Requests** - для кастомной валидации

**Итог:** Понимание жизненного цикла Laravel позволяет эффективно отлаживать приложения, правильно размещать бизнес-логику и создавать расширяемую архитектуру.
