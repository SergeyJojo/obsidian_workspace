## ✅ Что такое Base64

**Base64** — это способ **кодирования бинарных данных в текстовый вид** (ASCII), чтобы их можно было безопасно передавать по текстовым протоколам (HTTP, email, JSON, XML и т.д.).

- Это **не шифрование** и **не сжатие**.
    
- Это просто перевод бинарных данных в строку из **64 символов**:  
    `A-Z`, `a-z`, `0-9`, `+`, `/` (или `- _` в URL-friendly варианте).
    

---

## ✅ Для чего нужен Base64

| Где используется       | Зачем                                             |
| ---------------------- | ------------------------------------------------- |
| 📧 Email (MIME)        | Передача вложений (картинки, файлы)               |
| 🌐 HTTP API            | Передача изображений, файлов, сертификатов в JSON |
| 📄 XML / SOAP          | Встраивание бинарных данных (картинки, подписи)   |
| 🔐 JWT / OAuth         | Кодировка payload (header.payload.signature)      |
| 📥 Data URL в браузере | Встраивание картинок в HTML/CSS как строки        |
| 🗃 Базы данных         | Хранение бинарных данных в текстовых полях        |

---

## ✅ Как выполняется кодирование Base64 (механика)

🔹 Алгоритм:

1. Входные данные делятся на блоки по **3 байта (24 бита)**.
    
2. Эти 24 бита разбиваются на **4 группы по 6 бит**.
    
3. Каждая группа (6 бит) заменяется символом из алфавита Base64.
    
4. Если данных не хватает до 3 байт → добавляются **паддинги (`=`)**.
    

🔹 Пример:  
Строка: `Man` → ASCII → `M`=77, `a`=97, `n`=110

| Шаг | Биты     |
| --- | -------- |
| `M` | 01001101 |
| `a` | 01100001 |
| `n` | 01101110 |

Общий поток битов:  
`01001101 01100001 01101110` → 24 бита.

Разбиваем на 6-битные группы:  
`010011 010110 000101 101110`

Теперь заменяем по таблице Base64:

|Биты|Значение|Base64|
|---|---|---|
|010011|19|T|
|010110|22|W|
|000101|5|F|
|101110|46|u|

Итого:  
`Man` → `TWFu`

🔹 Если передать `Ma`:

- Данных только 2 байта → 16 бит → паддинг.
    
- В результате будет `TWE=`.

## ✅ Пример в коде (Go):

```go
import (
    "encoding/base64"
    "fmt"
)

func main() {
    data := []byte("Hello, world!")
    encoded := base64.StdEncoding.EncodeToString(data)
    fmt.Println("Base64:", encoded)

    decoded, _ := base64.StdEncoding.DecodeString(encoded)
    fmt.Println("Decoded:", string(decoded))
}
```

➡️ Вывод:

```
Base64: SGVsbG8sIHdvcmxkIQ==
Decoded: Hello, world!
```

---

## ✅ Виды Base64

|Тип|Отличия|
|---|---|
|`StdEncoding`|Стандартный Base64 (+, /, =)|
|`URLEncoding`|Для URL (+ → -, / → _, без =)|
|`RawStdEncoding`|Без паддингов (`=`)|

---

## ✅ Важно:

- **Base64 увеличивает размер данных ~на 33%**.
    
    - Пример: 1 МБ → станет ~1.37 МБ.
        
- Не защищает данные, это не безопасность, а просто текстовая обёртка.
