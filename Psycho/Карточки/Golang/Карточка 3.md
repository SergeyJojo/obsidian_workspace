#### **26. Что такое Data Race и как его обнаружить?**  
**Проблема**:  
```go
var counter int
go func() { counter++ }()
go func() { counter++ }()
```  
**Решение**:  
- Используйте `-race` флаг при тестировании:  
  ```bash
  go test -race ./...
  ```  
- Применяйте `sync.Mutex` или `atomic` операции.  

---

#### **27. Как работает `sync.Pool` и когда его использовать?**  
**Для чего**:  
- Пул объектов для уменьшения нагрузки на GC (например, буферы).  

**Пример**:  
```go
var pool = sync.Pool{
    New: func() interface{} { return make([]byte, 1024) },
}

buf := pool.Get().([]byte)
defer pool.Put(buf)
```  

---

#### **28. Что такое `sync.Once` и зачем он нужен?**  
**Использование**:  
- Гарантирует однократное выполнение (например, инициализация).  

```go
var once sync.Once
once.Do(func() { fmt.Println("Один раз") })
```

#### **29. Как устроены каналы внутри?**  
**Реализация**:  
- Кольцевой буфер (`hchan` структура в runtime).  
- При блокировке горутина попадает в очередь ожидания.  

**Важно**:  
- Закрытый канал возвращает нулевые значения.

#### **30. Что такое «Голодание» (Starvation) в Go?**  
**Пример**:  
- Долгая работа в горутине без вызова `Gosched()` блокирует другие.  

**Решение**:  
```go
runtime.Gosched()  // Уступить поток
```  

---

#### **31. Как работает `select` с каналами?**  
**Особенности**:  
- Случайный выбор из готовых каналов.  
- `default` — для неблокирующих операций.  

```go
select {
case msg := <-ch1: fmt.Println(msg)
case ch2 <- 42:   fmt.Println("Отправлено")
default:          fmt.Println("Ничего")
}
```

#### **35. Что такое «Теневые» переменные (Variable Shadowing)?**  
**Ошибка**:  
```go
x := 1
if true {
    x := 2  // Новая переменная!
    fmt.Println(x)  // 2
}
fmt.Println(x)  // 1
```  
**Как избежать**:  
- Используйте `go vet`:  
  ```bash
  go vet -shadow ./...
  ```

#### **36. Как реализовать Graceful Shutdown?**  
**Шаблон**:  
```go
ctx, cancel := context.WithCancel(context.Background())
go func() {
    sig := <-signal.Notify(make(chan os.Signal), syscall.SIGTERM)
    cancel()
}()

server.Shutdown(ctx)
```

#### **37. Что такое `sync.WaitGroup` и как им пользоваться?**  
**Пример**:  
```go
var wg sync.WaitGroup
wg.Add(2)
go func() { defer wg.Done() }()
go func() { defer wg.Done() }()
wg.Wait()
```

#### **38. Как работают семафоры в Go?**  
**Через `channel`**:  
```go
sem := make(chan struct{}, 3)  // Макс 3 горутины
sem <- struct{}{}  // Захват
defer func() { <-sem }()  // Освобождение
```
