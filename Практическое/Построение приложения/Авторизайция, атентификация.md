
Добавление аутентификации и авторизации в проект на Go требует реализации нескольких ключевых компонентов. Вот пошаговое руководство, как это сделать:

---

### 1. **Аутентификация (Authentication)**
Аутентификация — это процесс проверки, что пользователь действительно тот, за кого себя выдает. Обычно это делается через логин и пароль.

#### Шаги:
1. **Создайте таблицу для пользователей**:
   - Добавьте таблицу `users` в PostgreSQL, где будут храниться данные пользователей (логин, хэш пароля и т.д.).
   - Пример структуры:
     ```sql
     CREATE TABLE users (
         id SERIAL PRIMARY KEY,
         username VARCHAR(50) UNIQUE NOT NULL,
         password_hash VARCHAR(255) NOT NULL
     );
     ```

2. **Реализуйте регистрацию и вход**:
   - Используйте библиотеку для хэширования паролей, например, `golang.org/x/crypto/bcrypt`.
   - Пример регистрации:
     ```go
     func registerUser(db *gorm.DB, username, password string) error {
         hashedPassword, err := bcrypt.GenerateFromPassword([]byte(password), bcrypt.DefaultCost)
         if err != nil {
             return err
         }
         user := User{Username: username, PasswordHash: string(hashedPassword)}
         result := db.Create(&user)
         return result.Error
     }
     ```
   - Пример входа:
     ```go
     func loginUser(db *gorm.DB, username, password string) (bool, error) {
         var user User
         result := db.Where("username = ?", username).First(&user)
         if result.Error != nil {
             return false, result.Error
         }
         err := bcrypt.CompareHashAndPassword([]byte(user.PasswordHash), []byte(password))
         return err == nil, nil
     }
     ```

3. **Генерация токенов**:
   - Используйте JWT (JSON Web Tokens) для генерации токенов после успешной аутентификации.
   - Пример с библиотекой `github.com/golang-jwt/jwt`:
     ```go
     func generateToken(username string) (string, error) {
         token := jwt.NewWithClaims(jwt.SigningMethodHS256, jwt.MapClaims{
             "username": username,
             "exp":      time.Now().Add(time.Hour * 24).Unix(),
         })
         return token.SignedString([]byte("your-secret-key"))
     }
     ```

### 2. **Авторизация (Authorization)**
Авторизация — это процесс проверки, имеет ли пользователь право на выполнение определенных действий.

#### Шаги:
4. **Проверка токенов**:
   - Создайте middleware для проверки JWT-токенов.
   - Пример:
     ```go
     func authMiddleware(next http.Handler) http.Handler {
         return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
             tokenString := r.Header.Get("Authorization")
             if tokenString == "" {
                 http.Error(w, "Unauthorized", http.StatusUnauthorized)
                 return
             }
             token, err := jwt.Parse(tokenString, func(token *jwt.Token) (interface{}, error) {
                 return []byte("your-secret-key"), nil
             })
             if err != nil || !token.Valid {
                 http.Error(w, "Unauthorized", http.StatusUnauthorized)
                 return
             }
             next.ServeHTTP(w, r)
         })
     }
     ```

5. **Роли и разрешения**:
   - Добавьте таблицу `roles` и свяжите ее с пользователями.
   - Пример структуры:
     ```sql
     CREATE TABLE roles (
         id SERIAL PRIMARY KEY,
         name VARCHAR(50) UNIQUE NOT NULL
     );

     CREATE TABLE user_roles (
         user_id INT REFERENCES users(id),
         role_id INT REFERENCES roles(id),
         PRIMARY KEY (user_id, role_id)
     );
     ```
   - Проверяйте роли пользователя перед выполнением действий:
     ```go
     func isAdmin(db *gorm.DB, userID uint) (bool, error) {
         var count int64
         result := db.Model(&UserRole{}).Where("user_id = ? AND role_id = ?", userID, 1).Count(&count)
         return count > 0, result.Error
     }
     ```

### 3. **Интеграция с проектом**

#### Пример регистрации и входа:
```go
func registerHandler(db *gorm.DB, w http.ResponseWriter, r *http.Request) {
    var req struct {
        Username string `json:"username"`
        Password string `json:"password"`
    }
    if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
        http.Error(w, "Invalid request", http.StatusBadRequest)
        return
    }
    if err := registerUser(db, req.Username, req.Password); err != nil {
        http.Error(w, "Failed to register", http.StatusInternalServerError)
        return
    }
    w.WriteHeader(http.StatusCreated)
}

func loginHandler(db *gorm.DB, w http.ResponseWriter, r *http.Request) {
    var req struct {
        Username string `json:"username"`
        Password string `json:"password"`
    }
    if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
        http.Error(w, "Invalid request", http.StatusBadRequest)
        return
    }
    valid, err := loginUser(db, req.Username, req.Password)
    if err != nil || !valid {
        http.Error(w, "Invalid credentials", http.StatusUnauthorized)
        return
    }
    token, err := generateToken(req.Username)
    if err != nil {
        http.Error(w, "Failed to generate token", http.StatusInternalServerError)
        return
    }
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(map[string]string{"token": token})
}
```

#### Пример защищенного маршрута:
```go
func protectedHandler(w http.ResponseWriter, r *http.Request) {
    w.Write([]byte("You are authorized!"))
}

func main() {
    db := connectToDB()
    r := mux.NewRouter()
    r.HandleFunc("/register", func(w http.ResponseWriter, r *http.Request) {
        registerHandler(db, w, r)
    }).Methods("POST")
    r.HandleFunc("/login", func(w http.ResponseWriter, r *http.Request) {
        loginHandler(db, w, r)
    }).Methods("POST")
    r.Handle("/protected", authMiddleware(http.HandlerFunc(protectedHandler))).Methods("GET")
    http.ListenAndServe(":8080", r)
}
```
