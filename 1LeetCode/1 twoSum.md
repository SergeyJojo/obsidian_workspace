## ✅ 1. **Two Sum (№1)** — Уровень: Easy

**Условие:**  
Дан массив чисел `nums` и число `target`. Нужно вернуть индексы двух чисел, сумма которых равна `target`.

### 🧠 Идея:

- Используем хэш-таблицу `map[int]int`, где ключ — это `target - num`, а значение — индекс.
    
- Идём по массиву, если `num` уже в мапе — значит найдено второе число, возвращаем индекс текущего и сохранённого.
    

### ✅ Решение на Go:

```go
func twoSum(nums []int, target int) []int {
    seen := make(map[int]int)

    for i, num := range nums {
        if j, ok := seen[target - num]; ok {
            return []int{j, i}
        }
        seen[num] = i
    }
    return nil
}
```

### 📈 Сложность:

- Время: `O(n)`
    
- Память: `O(n)`
