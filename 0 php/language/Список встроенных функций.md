Отличная идея! Вот структурированный список **ключевых встроенных функций PHP**, который идеально подойдет для вашей вкладки в Obsidian. Я выделил самые важные для старта и сгруппировал их по назначению, чтобы было проще ориентироваться.

### 1. Работа с массивами (Важно! В PHP массивы — это и списки, и словари)

| Функция | Описание (аналог в Go) | Пример |
| :--- | :--- | :--- |
| **`count()`** | Посчитать количество элементов (`len()`) | `count([1,2,3]) // 3` |
| **`array_push()` / `$arr[] =`** | Добавить элемент в конец ( `append()`) | `$arr[] = 4;` |
| **`array_pop()`** | Удалить и вернуть последний элемент | `array_pop($arr)` |
| **`array_merge()`** | Объединить массивы | `array_merge($a, $b)` |
| **`array_map()`** | Применить функцию к каждому элементу | `array_map(fn($x) => $x*2, $arr)` |
| **`array_filter()`** | Отфильтровать элементы по условию | `array_filter($arr, fn($x) => $x > 2)` |
| **`array_key_exists()`** | Проверить, есть ли ключ в массиве | `array_key_exists('key', $arr)` |
| **`in_array()`** | Проверить, есть ли значение в массиве | `in_array('value', $arr)` |
| **`array_search()`** | Найти ключ по значению | `array_search('needle', $arr)` |

### 2. Работа со строками

| Функция | Описание | Пример |
| :--- | :--- | :--- |
| **`strlen()`** | Длина строки (`len()`) | `strlen("Hello") // 5` |
| **`strpos()`** | Найти позицию первого вхождения подстроки | `strpos("Hello", "e") // 1` |
| **`substr()`** | Взять часть строки (срез) | `substr("Hello", 1, 3) // "ell"` |
| **`explode()`** | Разбить строку в массив по разделителю (`strings.Split()`) | `explode(",", "a,b,c") // ['a','b','c']` |
| **`implode()`** | Объединить массив в строку (`strings.Join()`) | `implode("-", ['a','b']) // "a-b"` |
| **`trim()`** | Убрать пробелы/символы с краев | `trim(" hello ") // "hello"` |
| **`str_replace()`** | Заменить все вхождения подстроки | `str_replace("foo", "bar", $str)` |
| **`strtolower()` / `strtoupper()`** | Привести к нижнему/верхнему регистру | `strtolower("HELLO") // "hello"` |

### 3. Функции вывода и отладки (замените `fmt.Print`)

| Функция | Описание | Особенности |
| :--- | :--- | :--- |
| **`echo`** | Вывести строку (конструкция языка) | **Быстрее `print`**, можно несколько аргументов |
| **`print`** | Вывести строку (конструкция языка) | Всегда возвращает 1, один аргумент |
| **`var_dump()`** | **Вывести структурированную информацию** о переменной (тип, значение, длина) | **Главный инструмент отладки!** |
| **`print_r()`** | Вывести информацию в удобочитаемом виде | Для массивов/объектов, менее детально |

### 4. Работа с файловой системой

| Функция | Описание | Пример |
| :--- | :--- | :--- |
| **`file_get_contents()`** | Прочитать весь файл в строку (`os.ReadFile`) | `$data = file_get_contents('file.txt')` |
| **`file_put_contents()`** | Записать строку в файл (`os.WriteFile`) | `file_put_contents('file.txt', $data)` |
| **`file_exists()`** | Проверить существование файла/директории | `file_exists('/path')` |
| **`is_dir()`** | Проверить, является ли путь директорией | `is_dir('/path')` |
| **`scandir()`** | Получить список файлов в директории | `scandir('/path')` |

### 5. Важные утилиты и проверки

| Функция | Описание | Пример |
| :--- | :--- | :--- |
| **`isset()`** | Проверить, объявлена ли переменная и не `null` | `isset($undefinedVar) // false` |
| **`empty()`** | Проверить, пустое ли значение (false, 0, "", [], null) | `empty(0) // true` |
| **`is_null()`** | Проверить, точно ли `null` | `is_null($var)` |
| **`gettype()`** | Получить тип переменной | `gettype(10) // "integer"` |
| **`json_encode()`** | Преобразовать в JSON (`json.Marshal`) | `json_encode($array)` |
| **`json_decode()`** | Преобразовать JSON в объект/массив (`json.Unmarshal`) | `json_decode($jsonString, true)` |
| **`date()`** | Форматировать дату/время | `date('Y-m-d H:i:s') // 2023-10-05 12:30:45` |

### 6. Функции для работы с HTTP (для веб-контекста)

| Функция | Описание |
| :--- | :--- |
| **`header()`** | Отправить HTTP-заголовок (`w.Header().Set()` в Go) |
| **`http_response_code()`** | Установить HTTP-код ответа (`w.WriteHeader()` в Go) |
| **`$_GET`, `$_POST`, `$_SERVER`** | **Суперглобальные массивы** для доступа к запросу (не функции, но критически важны) |

1.  **Создайте отдельные заметки-челситы** для каждой группы функций (например, `PHP: Array Functions`, `PHP: String Functions`).
2.  **Добавьте примеры из Go**, где это уместно, чтобы провести параллели.
3.  **Выделите цветом или тегами** функции, которые вы используете чаще всего.
4.  **Добавьте секцию "Частые ошибки"**:
    *   `==` vs `===` (нестрогое vs строгое сравнение)

**Главный акцент для вас как для Go-разработчика:** обратите особое внимание на **`array_*` функции и `var_dump()`**. Это те вещи, которые будут вашими основными инструментами на старте.
