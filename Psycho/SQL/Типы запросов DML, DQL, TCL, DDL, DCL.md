
Вот полный список категорий SQL-запросов, которые используются для работы с данными, структурой базы данных, правами доступа и транзакциями.

### 1. **DML (Data Manipulation Language)** — Язык манипуляции данными

DML-запросы используются для изменения данных в базе данных (вставка, обновление, удаление и выборка данных).

- **SELECT** — выборка данных из базы данных.
- **INSERT** — вставка новых данных в таблицу.
- **UPDATE** — обновление существующих данных.
- **DELETE** — удаление данных из таблицы.
- **MERGE** — обновление данных или вставка новых, если данных с таким ключом не существует.

### 2. **DQL (Data Query Language)** — Язык запросов к данным

DQL-запросы используются для выборки данных из базы данных. На практике, **SELECT** запрос является частью DML, но выделяется в отдельную категорию.

- **SELECT** — выборка данных из одной или нескольких таблиц базы данных.

### 3. **DCL (Data Control Language)** — Язык управления данными

DCL-запросы используются для управления правами доступа к данным в базе данных.

- **GRANT** — предоставляет пользователю определенные права на выполнение операций в базе данных.
- **REVOKE** — отзывает ранее предоставленные права доступа.

### 4. **TCL (Transaction Control Language)** — Язык управления транзакциями

TCL-запросы управляют транзакциями в базе данных.

- **COMMIT** — подтверждает транзакцию, сохраняя изменения.
- **ROLLBACK** — отменяет транзакцию, откатывая все изменения.
- **SAVEPOINT** — устанавливает точку сохранения в транзакции, позволяя откатиться до этой точки, а не до начала транзакции.
- **SET TRANSACTION** — настраивает параметры текущей транзакции.

### 5. **DDL (Data Definition Language)** — Язык определения данных

DDL-запросы используются для изменения структуры базы данных, например, для создания или удаления таблиц и других объектов.

- **CREATE** — создание нового объекта в базе данных (таблицы, базы данных, индексов и т.д.).
- **ALTER** — изменение существующих объектов базы данных (например, добавление столбцов в таблицу).
- **DROP** — удаление объектов из базы данных.
- **TRUNCATE** — удаление всех записей в таблице, но без удаления самой таблицы.

### 6. **DML (Data Modification Language)** — Язык модификации данных

- **UPDATE** — модификация данных в существующих строках.
- **INSERT** — вставка новых строк в таблицы.
- **DELETE** — удаление строк из таблиц.

### 7. **CL (Cluster Control Language)** — Язык управления кластером

Этот тип запросов используется для управления распределенными кластерами.

- **JOIN** — объединяет таблицы в запросах для выполнения операций с несколькими таблицами.
- **WITH** — используется для определения временных таблиц или запросов для более сложных операций.

### Примеры:

#### 1. **DML**:

```sql
SELECT * FROM customers;
INSERT INTO customers (name, age) VALUES ('John', 30);
UPDATE customers SET age = 31 WHERE name = 'John';
DELETE FROM customers WHERE name = 'John';
```

#### 2. **DQL**:

```sql
SELECT name, age FROM customers WHERE age > 25;
```

#### 3. **DCL**:

```sql
GRANT SELECT, INSERT ON customers TO user1;
REVOKE DELETE ON customers FROM user2;
```

#### 4. **TCL**:

```sql
BEGIN TRANSACTION;
UPDATE customers SET age = 32 WHERE name = 'Alice';
COMMIT;

-- Или откат
ROLLBACK;
```

#### 5. **DDL**:

```sql
CREATE TABLE customers (id INT, name VARCHAR(50), age INT);
ALTER TABLE customers ADD COLUMN email VARCHAR(100);
DROP TABLE customers;
```

### Заключение:

- **DML**: Используется для манипуляции данными (выборка, вставка, обновление, удаление).
- **DQL**: Основная операция — выборка данных (обычно с помощью `SELECT`).
- **DCL**: Управление правами доступа.
- **TCL**: Управление транзакциями.
- **DDL**: Изменение структуры базы данных (создание, изменение и удаление объектов).

Каждая категория запросов решает разные задачи, такие как модификация данных, управление доступом или изменение структуры базы данных.
