## ✅ 8. **Climbing Stairs** (LeetCode №70)

**Уровень:** Easy / Medium

---

### 🧾 Условие:

Дана лестница с `n` ступеньками.  
Ты можешь за один шаг подняться либо на 1 ступеньку, либо на 2.  
Сколько существует **различных способов подняться на вершину**?

---

### 📌 Пример:

```text
Input: n = 3
Output: 3
Explanation: Три способа подняться:
1) 1 + 1 + 1
2) 1 + 2
3) 2 + 1
```

---

## 🧠 Идея: Динамическое программирование (фибоначчи)

- Кол-во способов добраться до ступеньки `i` — сумма способов добраться до `i-1` и до `i-2`, потому что:
    
    - Чтобы попасть на ступеньку `i`, ты мог прийти с `i-1` (шаг на 1)
        
    - Или с `i-2` (шаг на 2)
        

---

## ✅ Реализация на Go:

```go
func climbStairs(n int) int {
    if n <= 2 {
        return n
    }

    dp := make([]int, n+1)
    dp[1] = 1
    dp[2] = 2

    for i := 3; i <= n; i++ {
        dp[i] = dp[i-1] + dp[i-2]
    }

    return dp[n]
}
```

---

## 📈 Сложность:

- **Время:** `O(n)`
    
- **Память:** `O(n)` (можно оптимизировать до `O(1)`)
    

---

### Оптимизированный вариант по памяти:

```go
func climbStairsOptimized(n int) int {
    if n <= 2 {
        return n
    }

    first, second := 1, 2
    for i := 3; i <= n; i++ {
        first, second = second, first+second
    }
    return second
}
```
