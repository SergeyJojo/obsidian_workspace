# 📚 Типы данных в PHP (полное руководство)

В PHP **все переменные хранятся как `zval`** — структура, содержащая тип, значение и счётчик ссылок. PHP — **слабо типизированный язык**, но начиная с PHP 7 появились строгие типы.

---

## 🔢 1. **Скалярные типы (Scalar Types)**

### 🟢 `int` (целое число)

- Диапазон зависит от архитектуры (обычно 32-бит / 64-бит):
    
    - `32-bit`: −2,147,483,648 to 2,147,483,647
        
    - `64-bit`: −9,223,372,036,854,775,808 to 9,223,372,036,854,775,807
        

```php
$a = 42;
$b = -7;
```

📌 В PHP нет unsigned int.

---

### 🔵 `float` (число с плавающей точкой)

- Плавает по IEEE 754 double precision.
    
- Поддерживает `INF`, `-INF`, `NAN`.
    

```php
$pi = 3.1415;
$e = 2.71e0;
```

---

### 🟣 `string` (строка)

- Строки — это **массив байтов**, нет char.
    
- Одинарные ('') и двойные ("") кавычки различаются:
    
    - **"двойные"** позволяют интерполяцию (`"$name"` → значение)
        
    - **'одинарные'** — нет интерполяции
        

```php
$name = "John";
$greeting = "Hello, $name";
```

✅ С PHP 7.0: поддержка `Unicode` через `mb_*` функции.

---

### 🟠 `bool` (логический тип)

- Принимает `true` и `false`.
    
- Конвертация:
    
    - `0`, `""`, `"0"`, `null`, `[]` → `false`
        
    - Остальное → `true`
        

```php
$is_valid = true;
```

---

## 🧩 2. **Смешанные / compound types**

### 🟡 `array` (массивы)

- В PHP массив — это **упорядоченный хеш-таблицей**: и индексные, и ассоциативные.
    
- `int` и `string` ключи — всё остальное преобразуется.
    

```php
$arr = [1, 2, 3];                  // индексный
$user = ["name" => "Alex", "age" => 25]; // ассоциативный
```

📌 В PHP нет различия между списком и словарём (dictionary) как в других языках — всё `array`.

---

### 🟢 `object` (объекты)

- Объект — экземпляр класса.
    
- Внутри — ассоциативный массив свойств и методы.
    

```php
class User {
    public $name;
    function __construct($name) {
        $this->name = $name;
    }
}

$user = new User("Anna");
```

📌 Объекты по умолчанию передаются по **ссылке**.

---

## 🌫️ 3. **Специальные типы (Special Types)**

### ⚪ `null`

- Обозначает отсутствие значения.
    
- Присваивается явно: `$var = null;`
    

```php
$name = null;
```

📌 У переменной, не получившей значение, значение по умолчанию `null`.

---

### 🔴 `resource`

- Указатель на внешний ресурс: файл, соединение, сокет, curl, БД и т.д.
    
- Создаётся встроенными функциями.
    

```php
$fp = fopen("file.txt", "r"); // resource of type stream
```

📌 Нужно **освобождать вручную**, например `fclose($fp)`.

---

## 🧬 4. **Типы с PHP 7 и выше**

### 🔹 `callable`

- Переменная, которую можно вызвать как функцию: имя функции, замыкание, массив `[obj, method]`.
    

```php
function sayHello() { echo "Hi"; }
$fn = 'sayHello';
$fn(); // вызывает функцию
```

---

### 🔸 `iterable`

- Супертайп для `array` и `Traversable`.
    
- Для `foreach`, генераторов, итераторов.
    

```php
function show(iterable $data) {
    foreach ($data as $item) echo $item;
}
```

---

## 📐 5. **Типы данных в контексте базы данных**

|SQL|PHP|
|---|---|
|INT|int|
|BIGINT|string (!) — если больше 64-бит|
|FLOAT / DOUBLE|float|
|VARCHAR, TEXT|string|
|BOOLEAN / TINYINT|bool|
|NULL|null|
|BLOB|string|

> 🔥 `BIGINT` в MySQL часто нужно **хранить как строку в PHP**, чтобы не потерять точность.

---

## 🔍 Проверка типов в PHP

```php
is_int($x)
is_string($x)
is_bool($x)
is_null($x)
is_array($x)
is_object($x)
is_resource($x)
```

---

## ✅ Строгая типизация

С PHP 7+ можно включать строгую типизацию:

```php
declare(strict_types=1);

function add(int $a, int $b): int {
    return $a + $b;
}
```

---

## 🎁 Дополнительно

- **Type hinting** для аргументов и возвращаемого значения (PHP 7+)
    
- **Union types** (`int|float`, `string|null`) — с PHP 8
    
- **Mixed** — любой тип (PHP 8.0+)
    
- **Intersection types** — с PHP 8.1
    
- **readonly**, **enum**, **attributes** — с PHP 8.1+

## 📌 Заключение

Типы в PHP:

- очень **гибкие**, но требуют внимательности
    
- с PHP 7+ стали **строже и удобнее для разработки**
    
- при использовании с БД — важно учитывать **границы типов** и **автоматические преобразования**
