
### Первый вопрос: что выведет этот код?

```go
package main

import "fmt"

type BasicStruct struct {
	Value string
}

func (b BasicStruct) Set(s string) {
	b.Value = s
}

func (b BasicStruct) Get() string {
	return b.Value
}

type Doer interface {
	Set(string)
	Get() string
}

func doChangeAndPrint(d Doer) {
	d.Set("bar")
	fmt.Println(d.Get())
}

func main() {
	bs := BasicStruct{Value: "foo"}
	doChangeAndPrint(bs)
}
```

**Ответ**:

В этом коде будет напечатано **"foo"**.

### Почему?

1. Метод `Set` в типе `BasicStruct` использует **value receiver** (принимает копию объекта), а значит, метод работает с копией объекта, а не с самим объектом. Когда мы вызываем `d.Set("bar")`, изменение происходит в копии объекта, а не в оригинальном объекте, который был передан в функцию.
    
2. Таким образом, при вызове `d.Set("bar")` значение в `BasicStruct` не изменяется, так как метод изменяет копию структуры, а не сам объект.
    
3. Когда мы вызываем `d.Get()`, структура остаётся с исходным значением `Value`, которое равно "foo". Поэтому на экране будет напечатано **"foo"**.

### Второй вопрос: что будет напечатано при передаче указателя?

```go
    bs := &BasicStruct{Value: "foo"} // взят указатель 
    doChangeAndPrint(bs)
```

**Ответ**:

В этом случае будет напечатано **"foo"**, а не **"bar"**. Причина заключается в том, что в интерфейсе `Doer` метод `Set` определён как **value receiver**.

### Почему?

1. Когда мы передаём указатель на `BasicStruct` (например, `bs := &BasicStruct{Value: "foo"}`), это указывает на объект, и изменения должны быть сделаны в объекте, а не в его копии.
    
2. Однако метод `Set` определён с **value receiver**, что означает, что метод работает с копией объекта, а не с самим указателем. Поэтому, несмотря на то, что передается указатель, Go создает копию структуры при вызове метода, и изменения происходят в копии, а не в оригинальном объекте.
    
3. Как результат, значение остаётся "foo" и на экране будет напечатано **"foo"**, а не **"bar"**.
    

---

### Третий вопрос: как исправить?

**Ответ**:

Чтобы изменения происходили в самом объекте, нужно изменить метод `Set` на **pointer receiver**. Это означает, что метод будет работать с указателем на структуру, и изменения будут отражаться на самом объекте, а не на его копии.

```go
func (b *BasicStruct) Set(s string) {
	b.Value = s
}
```

**Объяснение**:

- При использовании **pointer receiver** (`*BasicStruct`), Go будет работать с оригинальным объектом, а не с его копией, что позволяет изменять данные внутри структуры.
- Теперь при передаче указателя на объект, метод будет изменять значение в оригинальном объекте, и при вызове `d.Get()` будет возвращаться значение "bar".
