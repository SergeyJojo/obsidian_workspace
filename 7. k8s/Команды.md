
### **Основные команды Kubernetes, покрывающие 90% повседневных задач**

---

#### **1. Просмотр ресурсов**
```bash
# Показать все поды (с дополнительной информацией)
kubectl get pods -o wide

# Показать все поды в конкретном неймспейсе
kubectl get pods -n <namespace>

# Показать все ноды (узлы) кластера
kubectl get nodes

# Показать сервисы
kubectl get svc

# Показать деплойменты
kubectl get deployments

# Показать все ресурсы в неймспейсе
kubectl get all -n <namespace>
```

---

#### **2. Детальная информация**
```bash
# Подробное описание пода (включая события)
kubectl describe pod <pod-name>

# Логи пода (можно указать контейнер)
kubectl logs <pod-name> [-c <container-name>]

# Логи пода с потоковым выводом (как tail -f)
kubectl logs -f <pod-name>

# Получить информацию о кластере
kubectl cluster-info
```

---

#### **3. Управление подами**
```bash
# Запустить под из образа
kubectl run <pod-name> --image=<image> --restart=Never

# Удалить под
kubectl delete pod <pod-name>

# Выполнить команду в поде
kubectl exec -it <pod-name> -- /bin/bash

# Копировать файлы в/из пода
kubectl cp <pod-name>:/path/to/file ./local-file  # Из пода
kubectl cp ./local-file <pod-name>:/path/to/file  # В под
```

---

#### **4. Управление деплойментами**
```bash
# Создать деплоймент
kubectl create deployment <name> --image=<image>

# Масштабировать деплоймент
kubectl scale deployment <name> --replicas=3

# Обновить образ в деплойменте
kubectl set image deployment/<name> <container>=<new-image>

# Откатить деплоймент
kubectl rollout undo deployment/<name>

# Показать историю изменений
kubectl rollout history deployment/<name>
```

---

#### **5. Сервисы и доступ**
```bash
# Создать сервис для доступа к подам
kubectl expose deployment <name> --port=80 --target-port=8080 --type=ClusterIP

# Пробросить порт пода локально
kubectl port-forward <pod-name> 8080:80

# Получить внешний IP сервиса (для LoadBalancer)
kubectl get svc <service-name> -o jsonpath='{.status.loadBalancer.ingress[0].ip}'
```

---

#### **6. Конфигурация и контексты**
```bash
# Показать текущий контекст
kubectl config current-context

# Переключиться на другой контекст
kubectl config use-context <context-name>

# Показать все доступные контексты
kubectl config get-contexts

# Показать текущую конфигурацию
kubectl config view
```

---

#### **7. Работа с конфигами**
```bash
# Применить конфигурацию из файла
kubectl apply -f config.yaml

# Удалить ресурсы из файла
kubectl delete -f config.yaml

# Проверить конфигурацию без применения
kubectl diff -f config.yaml

# Генерировать манифест для деплоймента (без создания)
kubectl create deployment <name> --image=<image> --dry-run=client -o yaml > deploy.yaml
```

---

#### **8. Мониторинг и отладка**
```bash
# Показать потребление ресурсов подами
kubectl top pods

# Показать потребление ресурсов нодами
kubectl top nodes

# Проверить доступность API
kubectl get --raw /healthz

# Проверить метрики кластера
kubectl get --raw /metrics
```

---

#### **9. Полезные команды для Helm**
```bash
# Установить чарт
helm install <release-name> <chart>

# Обновить релиз
helm upgrade <release-name> <chart>

# Показать установленные релизы
helm list

# Удалить релиз
helm uninstall <release-name>
```

---

#### **10. Команды для быстрой отладки**
```bash
# Показать все события в неймспейсе
kubectl get events --sort-by=.metadata.creationTimestamp

# Проверить DNS внутри кластера
kubectl run -it --rm --image=busybox:1.28 dns-test -- nslookup <service-name>

# Проверить доступность сервиса изнутри кластера
kubectl run -it --rm --image=curlimages/curl curl-test -- curl http://<service-name>
```

---

### **Вывод**
Эти команды покрывают большинство повседневных задач:
- Развертывание и управление приложениями
- Мониторинг и отладка
- Работа с конфигурациями
- Управление кластером

**Совет:** Создайте алиасы для часто используемых команд в `~/.bashrc` или `~/.zshrc`:
```bash
alias k='kubectl'
alias kgp='kubectl get pods'
alias kdp='kubectl describe pod'
alias klf='kubectl logs -f'
```
