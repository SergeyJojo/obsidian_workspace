### **Памятка по созданию таблиц в PostgreSQL**  

#### **1. Базовая структура**  
```sql
CREATE TABLE table_name (  
    column1 datatype [constraints],  
    column2 datatype [constraints],  
    ...  
);  
```  

#### **2. Основные типы данных**  
- **Целочисленные**: `INT`, `BIGINT`, `SMALLINT`  
- **Дробные**: `FLOAT`, `DOUBLE PRECISION`, `DECIMAL(p, s)`  
- **Текстовые**: `VARCHAR(n)`, `TEXT`, `CHAR(n)`  
- **Дата/время**: `DATE`, `TIME`, `TIMESTAMP`, `INTERVAL`  
- **Логические**: `BOOLEAN`  
- **JSON/XML**: `JSON`, `JSONB`, `XML`  
- **Бинарные**: `BYTEA`  

#### **3. Ограничения (Constraints)**  
- `PRIMARY KEY` – уникальный идентификатор  
- `UNIQUE` – уникальные значения  
- `NOT NULL` – запрет NULL  
- `CHECK` – проверка условия (`CHECK (age > 18)`)  
- `DEFAULT` – значение по умолчанию  
- `FOREIGN KEY` – ссылка на другую таблицу  

#### **4. Пример таблицы с ограничениями**  
```sql
CREATE TABLE users (  
    id SERIAL PRIMARY KEY,  
    username VARCHAR(50) UNIQUE NOT NULL,  
    email VARCHAR(100) UNIQUE,  
    age INT CHECK (age >= 18),  
    created_at TIMESTAMP DEFAULT NOW(),  
    is_active BOOLEAN DEFAULT TRUE  
);  
```  

#### **5. Внешние ключи (FOREIGN KEY)**  
```sql
CREATE TABLE orders (  
    id SERIAL PRIMARY KEY,  
    user_id INT REFERENCES users(id),  
    amount DECIMAL(10, 2)  
);  
```  

#### **6. Генерация ID (SERIAL, IDENTITY)**  
```sql
-- Автоинкремент (старый стиль)  
CREATE TABLE items (  
    id SERIAL PRIMARY KEY  
);  

-- Современный вариант (PostgreSQL 10+)  
CREATE TABLE items (  
    id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY  
);  
```  

#### **7. Создание таблицы из SELECT**  
```sql
CREATE TABLE new_table AS SELECT * FROM old_table;  
```  

#### **8. Изменение таблицы (ALTER TABLE)**  
```sql
-- Добавить столбец  
ALTER TABLE table_name ADD COLUMN new_column datatype;  

-- Удалить столбец  
ALTER TABLE table_name DROP COLUMN column_name;  

-- Переименовать столбец  
ALTER TABLE table_name RENAME COLUMN old_name TO new_name;  

-- Изменить тип данных  
ALTER TABLE table_name ALTER COLUMN column_name TYPE new_datatype;  
```  

#### **9. Удаление таблицы**  
```sql
DROP TABLE table_name;  
DROP TABLE IF EXISTS table_name;  -- Без ошибки, если таблицы нет  
```  

#### **10. Временные таблицы**  
```sql
CREATE TEMP TABLE temp_table (id INT);  
```  

---

**Коротко:**  
- Используйте `PRIMARY KEY` для уникальных идентификаторов.  
- `FOREIGN KEY` связывает таблицы.  
- `SERIAL` / `IDENTITY` – автоинкремент.  
- `ALTER TABLE` – для изменений.  
- `DROP TABLE` – удаление.
