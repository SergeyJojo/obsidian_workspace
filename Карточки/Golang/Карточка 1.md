
Вот **50 карточек по Go (Golang)**, разбитых на 3 уровня сложности (🔵 База, 🟡 Средний, 🔴 Продвинутый). Каждая содержит вопрос и краткий ответ на обороте.  

---

### **🔵 Базовый уровень (20 карточек)**  
**1. Как объявить переменную?**  
```go 
var x int = 10 // Явно
y := 20        // Сокращённо
```

**2. Что такое `:=`?**  
Короткое объявление переменной с автоматическим выводом типа.

**3. Как работает `for`?**  
```go
for i := 0; i < 10; i++ {} // Классический
for {}                     // Бесконечный
```

**4. Как объявить функцию?**  
```go
func sum(a, b int) int {
    return a + b
}
```

**5. Что такое `package main`?**  
Точка входа в программу. Функция `main()` выполняется первой.

**6. Как вывести текст?**  
```go
fmt.Println("Hello!")
```

**7. Что такое `slice`?**  
Динамический массив (ссылка на часть массива + длина + ёмкость).

**8. Чем `slice` отличается от `array`?**  
`Array` — фиксированный размер, `slice` — может расти.

**9. Как создать `map`?**  
```go
m := make(map[string]int)
m["key"] = 42
```

**10. Что вернёт `len()` для `nil` slice?**  
`0` (но `panic` при попытке доступа к элементам).

**11. Как проверить наличие ключа в `map`?**  
```go
if val, ok := m["key"]; ok {}
```

**12. Что такое `defer`?**  
Откладывает выполнение функции до выхода из текущей.

**13. Как объявить структуру?**  
```go
type User struct {
    Name string
    Age  int
}
```

**14. Что такое `interface{}`?**  
Пустой интерфейс — может хранить любой тип (аналог `any`).

**15. Как работает `switch`?**  
```go
switch x {
case 1: fmt.Println("One")
default: fmt.Println("Unknown")
}
```

**16. Что такое `goroutine`?**  
Легковесный поток, управляемый рантаймом Go.

**17. Как запустить `goroutine`?**  
```go
go func() { fmt.Println("Hello") }()
```

**18. Что делает `chan`?**  
Канал для обмена данными между горутинами.

**19. Как создать канал?**  
```go
ch := make(chan int)
```

**20. Что такое `select`?**  
Ожидание операций на нескольких каналах.

### **🟡 Средний уровень (20 карточек)**  
**21. Как работает `append()`?**  
Добавляет элементы в slice, при необходимости расширяя его.

**22. Что такое `rune`?**  
Псевдоним для `int32` (хранит Unicode-символ).

**23. Как читать файл?**  
```go
data, err := os.ReadFile("file.txt")
```

**24. Что делает `iota`?**  
Автоинкремент для констант:  
```go
const (
    A = iota // 0
    B        // 1
)
```

**25. Как работает `json.Marshal()`?**  
Преобразует структуру в JSON-строку.

**26. Что такое `context`?**  
Механизм для отмены и таймаутов в горутинах.

**27. Как обработать ошибку?**  
```go
if err != nil { return err }
```

**28. Что делает `sync.WaitGroup`?**  
Ожидает завершения группы горутин.

**29. Как использовать `Mutex`?**  
```go
var mu sync.Mutex
mu.Lock()
defer mu.Unlock()
```

**30. Что такое `embed`?**  
Директива для встраивания файлов в бинарник.

**31. Как тестировать код?**  
Файлы `*_test.go` с функциями `TestXxx(t *testing.T)`.

**32. Что делает `-race` флаг?**  
Включает детектор гонок (data races).

**33. Как работает `time.Ticker`?**  
Периодически отправляет время в канал.

**34. Что такое `reflect`?**  
Пакет для работы с типами в runtime (интроспекция).

**35. Как парсить аргументы командной строки?**  
```go
import "flag"
port := flag.Int("port", 8080, "Port number")
```

**36. Что делает `strings.Builder`?**  
Эффективная конкатенация строк.

**37. Как отсортировать slice?**  
```go
sort.Slice(s, func(i, j int) bool { return s[i] < s[j] })
```

**38. Что такое `go.mod`?**  
Файл для управления зависимостями (модули).

**39. Как работает `http.HandlerFunc`?**  
Адаптер для функций-обработчиков HTTP.

**40. Что делает `recover()`?**  
Ловит `panic` (только внутри `defer`).

### **🔴 Продвинутый уровень (10 карточек)**  
**41. Как работает escape analysis?**  
Определяет, выделять ли объект в куче или стеке.

**42. Что такое `unsafe.Pointer`?**  
Обход типизации для низкоуровневых операций.

**43. Как устроен `sync.Pool`?**  
Пул объектов для уменьшения нагрузки на GC.

**44. Что делает `runtime.Gosched()`?**  
Освобождает поток для других горутин.

**45. Как работает `cgo`?**  
Мост между Go и C-кодом.

**46. Что такое `pprof`?**  
Инструмент для профилирования (CPU, память).

**47. Как реализовать graceful shutdown?**  
Через `context` + `signal.Notify`.

**48. Что делает `-gcflags=-m`?**  
Показывает решения компилятора (инлайнинг, escape).

**49. Как работает `interface` под капотом?**  
Два указателя: на тип и значение (`iface`/`eface`).

**50. Что такое `data race` и как избежать?**  
Конкуретный доступ к данным. Решения: `Mutex`, `atomic`, каналы.
