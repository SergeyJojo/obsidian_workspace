# 📚 Типы данных в PHP (полное руководство)

В PHP **все переменные хранятся как `zval`** — структура, содержащая тип, значение и счётчик ссылок. PHP — **слабо типизированный язык**, но начиная с PHP 7 появились строгие типы.

---

## 🔢 1. **Скалярные типы (Scalar Types)**

### 🟢 `int` (целое число)

- Диапазон зависит от архитектуры (обычно 32-бит / 64-бит):
    
    - `32-bit`: −2,147,483,648 to 2,147,483,647
        
    - `64-bit`: −9,223,372,036,854,775,808 to 9,223,372,036,854,775,807
        

```php
$a = 42;
$b = -7;
```

📌 В PHP нет unsigned int.

---

### 🔵 `float` (число с плавающей точкой)

- Плавает по IEEE 754 double precision.
    
- Поддерживает `INF`, `-INF`, `NAN`.
    

```php
$pi = 3.1415;
$e = 2.71e0;
```

---

### 🟣 `string` (строка)

- Строки — это **массив байтов**, нет char.
    
- Одинарные ('') и двойные ("") кавычки различаются:
    
    - **"двойные"** позволяют интерполяцию (`"$name"` → значение)
        
    - **'одинарные'** — нет интерполяции
        

```php
$name = "John";
$greeting = "Hello, $name";
```

✅ С PHP 7.0: поддержка `Unicode` через `mb_*` функции.

---

### 🟠 `bool` (логический тип)

- Принимает `true` и `false`.
    
- Конвертация:
    
    - `0`, `""`, `"0"`, `null`, `[]` → `false`
        
    - Остальное → `true`
        

```php
$is_valid = true;
```

---

## 🧩 2. **Смешанные / compound types**

### 🟡 `array` (массивы)

- В PHP массив — это **упорядоченный хеш-таблицей**: и индексные, и ассоциативные.
    
- `int` и `string` ключи — всё остальное преобразуется.
    

```php
$arr = [1, 2, 3];                  // индексный
$user = ["name" => "Alex", "age" => 25]; // ассоциативный
```

📌 В PHP нет различия между списком и словарём (dictionary) как в других языках — всё `array`.

---

### 🟢 `object` (объекты)

- Объект — экземпляр класса.
    
- Внутри — ассоциативный массив свойств и методы.
    

```php
class User {
    public $name;
    function __construct($name) {
        $this->name = $name;
    }
}

$user = new User("Anna");
```

📌 Объекты по умолчанию передаются по **ссылке**.

---

## 🌫️ 3. **Специальные типы (Special Types)**

### ⚪ `null`

- Обозначает отсутствие значения.
    
- Присваивается явно: `$var = null;`
    

```php
$name = null;
```

📌 У переменной, не получившей значение, значение по умолчанию `null`.

---

### 🔴 `resource`

- Указатель на внешний ресурс: файл, соединение, сокет, curl, БД и т.д.
    
- Создаётся встроенными функциями.
    

```php
$fp = fopen("file.txt", "r"); // resource of type stream
```

📌 Нужно **освобождать вручную**, например `fclose($fp)`.

---

## 🧬 4. **Типы с PHP 7 и выше**

### 🔹 `callable`

- Переменная, которую можно вызвать как функцию: имя функции, замыкание, массив `[obj, method]`.
    

```php
function sayHello() { echo "Hi"; }
$fn = 'sayHello';
$fn(); // вызывает функцию
```

---

### 🔸 `iterable`

- Супертайп для `array` и `Traversable`.
    
- Для `foreach`, генераторов, итераторов.
    

```php
function show(iterable $data) {
    foreach ($data as $item) echo $item;
}
```

---

## 📐 5. **Типы данных в контексте базы данных**

|SQL|PHP|
|---|---|
|INT|int|
|BIGINT|string (!) — если больше 64-бит|
|FLOAT / DOUBLE|float|
|VARCHAR, TEXT|string|
|BOOLEAN / TINYINT|bool|
|NULL|null|
|BLOB|string|

> 🔥 `BIGINT` в MySQL часто нужно **хранить как строку в PHP**, чтобы не потерять точность.

## ✅ Строгая типизация

С PHP 7+ можно включать строгую типизацию:

```php
declare(strict_types=1);

function add(int $a, int $b): int {
    return $a + $b;
}
```

В PHP богатая и динамическая система типов. Вот полная классификация типов:

## 1. Скалярные типы (Scalar Types)

### string
```php
$name = "Hello World";
$char = 'A';
```

### int
```php
$age = 25;
$negative = -10;
$hex = 0x1A; // 26 в шестнадцатеричной
```

### float (double)
```php
$price = 19.99;
$scientific = 1.2e3; // 1200
```

### bool
```php
$isActive = true;
$isCompleted = false;
```

---

## 2. Составные типы (Compound Types)

### array
```php
$fruits = ['apple', 'banana', 'orange'];
$user = ['name' => 'John', 'age' => 30];
```

### object
```php
class User {
    public string $name;
}
$user = new User();
```

### callable
```php
$callback = function($x) { return $x * 2; };
$callable = 'strlen';
```

### iterable
```php
function process(iterable $items): void {
    foreach ($items as $item) {
        // ...
    }
}
```

---

## 3. Специальные типы

### null
```php
$value = null;
```

### resource
```php
$file = fopen('test.txt', 'r'); // $file - ресурс
$db = mysqli_connect(...);      // ресурс соединения с БД
```

### mixed (псевдо-тип PHP 8.0+)
```php
function process(mixed $data): mixed {
    return $data;
}
```

### never (PHP 8.1+)
```php
function redirect(string $url): never {
    header("Location: $url");
    exit; // Функция никогда не вернет значение
}
```

---

## 4. Псевдо-типы для аннотаций

### void
```php
function logMessage(string $msg): void {
    echo $msg;
    // Не возвращает значение
}
```

### false
```php
function findUser(int $id): User|false {
    return $user ?? false;
}
```

### true
```php
function isValid(): bool {
    return true;
}
```

---

## 5. Объединенные типы (Union Types) - PHP 8.0+

```php
function handle(string|int $id): string|array {
    if (is_string($id)) {
        return "string: $id";
    }
    return ["id" => $id];
}

// С nullable типами (устаревший способ)
function oldWay(?string $name): void {} // string|null

// Новый способ
function newWay(string|null $name): void {}
```

---

## 6. Пересекающиеся типы (Intersection Types) - PHP 8.1+

```php
interface Logger {
    public function log(string $message): void;
}

interface Cacheable {
    public function cache(string $key, $value): void;
}

function processService(Logger&Cacheable $service): void {
    $service->log("Processing...");
    $service->cache('key', 'value');
}
```

## 9. Enum типы - PHP 8.1+

### Простые enum
```php
enum Status: string {
    case PENDING = 'pending';
    case ACTIVE = 'active';
    case EXPIRED = 'expired';
}

$status = Status::ACTIVE;
echo $status->value; // 'active'
```

### Типизированные enum
```php
enum Status: int {
    case PENDING = 0;
    case ACTIVE = 1;
    case EXPIRED = 2;
}
```

### Enum с методами
```php
enum Status: string {
    case PENDING = 'pending';
    case ACTIVE = 'active';
    
    public function color(): string {
        return match($this) {
            self::PENDING => 'gray',
            self::ACTIVE => 'green',
        };
    }
}
```

## 11. Примеры строгой типизации

### Включение строгого режима
```php
declare(strict_types=1);

function calculate(int $a, int $b): float {
    return $a / $b;
}

// Теперь это вызовет TypeError вместо неявного приведения
// calculate("10", "20"); // Ошибка!
```

### Типы в аргументах и возвращаемых значениях
```php
class Calculator {
    public function add(int|float $a, int|float $b): int|float {
        return $a + $b;
    }
    
    public function getUser(int $id): ?User {
        return $this->users[$id] ?? null;
    }
}
```

## 12. Проверка типов во время выполнения

```php
$value = "hello";

// Функции для проверки типов
is_string($value);    // true
is_int($value);       // false
is_array($value);     // false
is_object($value);    // false
is_callable($value);  // false
is_iterable($value);  // false
is_null($value);      // false

// Получение типа
gettype($value);      // "string"
get_debug_type($value); // "string" (более точный)

// Проверка на скалярный тип
is_scalar($value);    // true
```

## Ключевые особенности системы типов PHP:

1. **Динамическая типизация** - типы определяются во время выполнения
2. **Слабая типизация** - неявное приведение типов (можно усилить strict_types)
3. **Прогрессивная типизация** - новые версии добавляют все больше возможностей для статической типизации
4. **Union Types** - возможность указывать несколько допустимых типов
5. **Много псевдо-типов** для лучшей документации и статического анализа

Система типов PHP постоянно развивается и с каждой версией становится все более строгой и выразительной.
