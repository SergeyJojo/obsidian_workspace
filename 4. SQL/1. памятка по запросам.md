### **Основные конструкции SQL-запросов в PostgreSQL**  

#### **1. SELECT (выбор данных)**  
```sql
SELECT * FROM table_name;  
SELECT column1, column2 FROM table_name;  
SELECT DISTINCT column FROM table_name;  
SELECT COUNT(*) FROM table_name;  
```  

#### **2. WHERE (фильтрация)**  
```sql
SELECT * FROM table_name WHERE condition;  
SELECT * FROM table_name WHERE column = value;  
SELECT * FROM table_name WHERE column IN (value1, value2);  
SELECT * FROM table_name WHERE column LIKE 'pattern%';  
SELECT * FROM table_name WHERE column BETWEEN value1 AND value2;  
```  

#### **3. JOIN (соединение таблиц)**  
```sql
SELECT * FROM table1 INNER JOIN table2 ON table1.id = table2.id;  
SELECT * FROM table1 LEFT JOIN table2 ON table1.id = table2.id;  
SELECT * FROM table1 RIGHT JOIN table2 ON table1.id = table2.id;  
SELECT * FROM table1 FULL JOIN table2 ON table1.id = table2.id;  
SELECT * FROM table1 CROSS JOIN table2;  
```  

#### **4. GROUP BY и агрегатные функции**  
```sql
SELECT column, COUNT(*) FROM table_name GROUP BY column;  
SELECT column, SUM(amount) FROM table_name GROUP BY column;  
SELECT column, AVG(price) FROM table_name GROUP BY column;  
SELECT column, MAX(date) FROM table_name GROUP BY column;  
SELECT column, MIN(value) FROM table_name GROUP BY column;  
```  

#### **5. HAVING (фильтрация после GROUP BY)**  
```sql
SELECT column, COUNT(*) FROM table_name GROUP BY column HAVING COUNT(*) > 1;  
```  

#### **6. ORDER BY (сортировка)**  
```sql
SELECT * FROM table_name ORDER BY column ASC;  
SELECT * FROM table_name ORDER BY column DESC;  
SELECT * FROM table_name ORDER BY column1, column2;  
```  

#### **7. LIMIT и OFFSET (пагинация)**  
```sql
SELECT * FROM table_name LIMIT 10;  
SELECT * FROM table_name LIMIT 10 OFFSET 20;  
```  

#### **8. Подзапросы (Subqueries)**  
```sql
SELECT * FROM table1 WHERE column IN (SELECT column FROM table2);  
SELECT * FROM (SELECT * FROM table_name) AS subquery;  
```  

#### **9. WITH (CTE – Common Table Expressions)**  
```sql
WITH cte_name AS (SELECT * FROM table_name) SELECT * FROM cte_name;  
```  

#### **10. INSERT (добавление данных)**  
```sql
INSERT INTO table_name (column1, column2) VALUES (value1, value2);  
INSERT INTO table_name SELECT * FROM another_table;  
```  

#### **11. UPDATE (изменение данных)**  
```sql
UPDATE table_name SET column = value WHERE condition;  
```  

#### **12. DELETE (удаление данных)**  
```sql
DELETE FROM table_name WHERE condition;  
```  

#### **13. CREATE TABLE (создание таблицы)**  
```sql
CREATE TABLE table_name (  
    column1 datatype PRIMARY KEY,  
    column2 datatype NOT NULL,  
    column3 datatype DEFAULT value  
);  
```  

#### **14. ALTER TABLE (изменение таблицы)**  
```sql
ALTER TABLE table_name ADD COLUMN new_column datatype;  
ALTER TABLE table_name DROP COLUMN column_name;  
ALTER TABLE table_name RENAME COLUMN old_name TO new_name;  
```  

#### **15. INDEX (индексация)**  
```sql
CREATE INDEX index_name ON table_name (column);  
DROP INDEX index_name;  
```  

#### **16. TRANSACTION (транзакции)**  
```sql
BEGIN;  
-- SQL-запросы  
COMMIT;  
-- или ROLLBACK;  
```  

#### **17. VIEW (представления)**  
```sql
CREATE VIEW view_name AS SELECT * FROM table_name;  
DROP VIEW view_name;  
```  

#### **18. EXPLAIN (анализ запроса)**  
```sql
EXPLAIN SELECT * FROM table_name;  
```  

#### **19. UNION / INTERSECT / EXCEPT (объединение результатов)**  
```sql
SELECT * FROM table1 UNION SELECT * FROM table2;  
SELECT * FROM table1 INTERSECT SELECT * FROM table2;  
SELECT * FROM table1 EXCEPT SELECT * FROM table2;  
```  

#### **20. WINDOW FUNCTIONS (аналитические функции)**  
```sql
SELECT column, SUM(column) OVER (PARTITION BY group_column) FROM table_name;  
```  

---

Это основные конструкции PostgreSQL. Для более сложных запросов можно комбинировать их.
